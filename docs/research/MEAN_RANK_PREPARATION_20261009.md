# MEAN 排序解释与固定对照准备

本文件是数学和代码准备，不是新方法涨分结果。没有运行新的数据集预测、读取新query标签或调用DINO。

## 已核对的解释

令含并列值的平均秩为rho，定义

`Phi(v) = sum_{i<j}|v_i-v_j|/(2N)`，

则对称次梯度为`rho(v)-0.5`。固定参考guide g，

`L_g(v) = Phi(v) - <rho(g)-0.5, v>`。

这个损失非负；g无并列时等于`sum_{g_i<g_j}[v_i-v_j]_+/N`。因此现有MEAN unary的

`y = s + 0.25*(rho(g)-rho(s))`

是一次参考排序违约的次梯度更新。图步骤仍为原代码的`(A+16L)z=Ay`。这解释两个具体操作，不证明整个流水线是某个联合目标的全局最优解，也不保证排序损失下降或最终IoU提高。

独立小数组检查验证了平均秩（包括并列）、对称次梯度、显式反序对损失、图误差展开式。CDF秩与锁定rank实现逐位一致，准备代码的MEAN unary与原公式逐位一致，尚未检查真实完整mask身份。

一个满足s在[0,1]且同时含0/1的反例：s=[0,.5,.5001,.5002,1]，g=[0,2,1,3,4]。固定0.25更新使排序损失从约0.000020升至0.009960，故不允许声称单调下降。

## 关键混杂与四个固定unary

常数guide的秩为0.5，但它产生`y=s+.25*(.5-rho(s))`，并非无操作。总秩残差为零，也不等于二值mask面积不变。

准备入口在`scripts/mean_rank_controls.py`：

| 名称 | unary |
|---|---|
| graph_only | s |
| flat | s+.25*(.5-rho(s)) |
| ordinary | .75s+.25h |
| mean | s+.25*(rho(g)-rho(s)) |

h把排序后的原s按g的排序重新分配；g并列组统一取对应原分数的平均，避免依赖像素位置拆并列。h先按FP64取组均值、转FP32，所有unary沿用FP32计算后转FP64的CG输入精度。

后续调用者必须复用同一A/W、lambda16、原CG、插值及0.5切点；不要混入新的walk求解器误差或额外层/视野。此处只准备了unary，未接入实际缓存预测或评分。
