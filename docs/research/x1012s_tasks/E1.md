# E1：固定 K64 区域描述子的监督能力诊断

结论：已完成这项此前未测的诊断。当前13维描述子加固定线性logistic头没有提取出相对mean_c单特征的通用排序增益；保留mean_c强控制，不扩大该模型网格。该结论仅约束当前描述子、线性头与硬区域读出，不能推出冻结DINOv3或单参考问题不可行。

## 协议与输入

- 动机：A6在相同LVIS小目标上的K64区域oracle高于FoRIS，但旧70门槛跳过了监督头。本轮独立脚本不读取/修改旧门槛，不覆盖A6源码或产物。
- 只读A6已封存11477例GT-free描述子及K64区域统计；固定13维，另以mean_c单特征使用相同监督头。没有编码、重建区域或读取原图。
- 全局归并原图路径、源文件SHA、RGB别名、COCO跨数据集照片号；iSAID按原始大图归并。固定hash后只保留参考和query同侧任务：训练2908、测试2817、跨侧排除5752。双角色训练/测试照片交集为0。LODO从训练半删除留出域，评测同一测试半，全局照片隔离同时排除了跨域同源照片。
- 身份检查：训练query/reference原照片组为2038/2073，测试为1983/1974；Q训练∩Q测试、Q训练∩R测试、R训练∩Q测试、R训练∩R测试全部为0。
- 固定训练内标准化、面积加权soft BCE、L2=1e-4、LBFGS最多100次、自然读出严格sigmoid>.5。不按测试分数选模型/阈值。训练共186112个区域，测试180288个区域。
- 主指标：CLI1024，硬区域nearest读出，按实际观察到的(fold,class)池化I/U后槽等权；另保留逐例均值、尺寸档、FN/GT、FP/GT。区间为query原照片组1000次配对bootstrap。当前都是已曝光explore的训练诊断和标签隔离测试，不是新confirm或官方完整基准。
- 先封存所有训练/测试概率与自然区域预测，再读取测试区域n/tp评分。固定头的逐例严格阈值oracle按完整同分组扫描，仅用来诊断排序；每例最优阈值不参与主自然成绩。

## 机制解释与决策

1. 不采用当前13D线性头作为新任务判别构造。LODO的COCO/LVIS/SUIM/Lung/Fundus排序差区间严格为负；其余域没有稳定的额外排序优势。全描述子头对mean_c的自然少量改善不足以支撑通用判别贡献。
2. 固定.5的自然失败不能被解释为没有排序信息。Fundus自然全空，但mean_c阈值oracle29.025；这是soft覆盖预测与整区域二值决策/IoU目标之间的校准缺口。此诊断不授权重新用测试GT选阈值。
3. 固定K64硬区域在该Lung测试队列存在明确几何容量限制：逐类联合IoU oracle87.159，仍低于FoRIS88.373。它仅约束当前K64硬区域输出，不约束连续token/像素输出。其他域的oracle余量也不表示已经有可提取的合法规则。
4. 下一方法决策结合E2的信息来源干预；保留mean_c及现有完整强控制，停止把当前13维线性探针包装成独立统一方法。E1完成不等于用户目标完成。
