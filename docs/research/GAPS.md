# 研究缺口：什么证据能改变下一步

更新：2026-10-12。数字、来源SHA和完整34家族结论见[结果索引](../../evidence/research/results.json)。本文件只保留会影响论文或下一实验的判断。这些是复盘建议；当前另一会话已在推进R1/R2/R3，以PLAN链接的执行规格为准，不另开E1/E2队列。

## 1. 第一优先：区域判别能力仍未测

A6已测11,477例九种区域，但因LVIS小目标最高oracle57.558低于旧门槛70，省略监督head和留一域。按计划停止是执行事实，不是科学不可行性结论。

同一2684个LVIS小目标，FoRIS逐例IoU均值32.814、K64/K256硬区域oracle48.135/57.558，仍有15.32/24.74pp余量。这些不是域级class mIoU，也不是已实现方法收益。尚缺的问题是：合法自然描述子能否让一条固定规则提取出这部分余量。

**下一决策：** 固定K64和现有描述子，仅做一次监督能力诊断与照片隔离/LODO。成功说明描述子可提取，不等于免训练准则已存在；组内有效但留域失败则不继续包装通用规则。这是E1，详见[计划](PLAN.md)。

## 2. 并行优先：多参考收益尚未隔离来源

B1在共同K3查询中，COCO/LVIS/PASCAL/SUIM的IND0自然分数分别增加17.418/11.260/8.132/11.657pp，GT严格阈值分数也增加13.647/5.431/6.133/7.186pp。因此不能继续普遍宣称“排序已经饱和、只差阈值”。

增加参考同时改变FG/BG内容、联合中心和角色核质量。它不能单独证明缺背景，也不能证明query伪参考有效。K3与K1必须用同分母，现报告中对FoRIS的区间不是K3−K1区间。

**下一决策：** 固定K1中心与角色质量，分离FG、BG、联合来源，保留重复R1及中心单独变化控制。若必须额外真实标注参考才有效，记录为多参考敏感性，不能偷换成单参考方法。这是E2。

## 3. 不再把错误解释当新路线

|历史证据|能说明什么|不能据此做什么|
|---|---|---|
|S的上下文拒识有效，宽恢复大量补回FP|新恢复必须同时解释补真与补假|不能只因多找回真目标就推新融合|
|graph/discriminant漏掉部分S负证据|特定输入定义遗漏可反证|补BG必涨尚未证；不得推广成所有方法病因|
|层级/context/轴/几何自一致固定构造失败|已测规则未提供完整判别增益|不能把收敛、source拟合或新公式当query任务正确证据|
|A3大多数FP位于含TP的预测连通分量|删孤立分量不是主要问题的通用解法|“相连”不等于纯边界外溢，不重扫迟滞网格|
|A6有限硬区域oracle、旧面积监督诊断|约束指定表示/描述子/模型范围|不能升级为冻结DINO或单参考问题的信息论上界|
|6200完整输入闭集没有精确任务别名|该批性能缺口不能由完整输入别名解释|不能外推开放世界所有定义都可辨识|

已失败构造保留一句结论与有价值反例，完整旧代码已迁出。只有新证据改变了失败前提，才值得重新研究同方向；旧队列、旧状态和源码存在本身不是理由。

## 4. 评估边界：只修影响当前判断的部分

- **C1是有效负结果。** 七域旧图新配对；另外三域仅相对IND曝光清单留图，现在均已曝光。Fundus/Lung/道路各10个确认query，正区间是该缓存池内的条件结果。
- **指标不能混名。** x1012是CLI1024、观察到的(fold,class)槽I/U池化后槽等权；旧6200有固定官方槽与fold均值。保存I/U重聚合未改变C1五正五负方向。开发时说明口径，论文主表再按明确官方分母补覆盖。
- **原图、CLI1024、token分别报告。** 不能从不同队列或不同渲染帧挑最好值，也不能用GT oracle充当自然方法成绩。
- **旧阈值oracle可能拆开同分像素。** `lab.best_threshold_iou`的任意前缀只作宽松诊断；B1 `threshold_oracle`已按完整同分组处理。仅在决策依赖旧精确值时重算保存场，不重跑整套历史扫描。
- **强控制必须匹配。** B4有MEAN、C1没有同批MEAN；当前C1已失败，无需为了补表再计算。下一有希望候选同时比较FoRIS、MEAN及适用同预算控制。
- **0新编码不等于在线零成本。** 缓存耗时与从RGB开始的完整延迟分开；有希望候选再测完整成本，不给每个失败方法补性能报告。

## 5. 论文仍缺什么

当前可写：强基线、跨域取舍、参考信息干预、特定构造负消融。尚缺：一个合法1-shot统一规则、相对强控的独有贡献、避免明显域退化的完整输出、新的未曝光确认。

先用E1/E2决定是否存在可操作的新机制，再只推进一个完整候选。若二者都不提供可提取信号，重新评估观察与假设，不继续拼接旧c/J/阈值/图构造，也不自动把目标改成多参考论文。
