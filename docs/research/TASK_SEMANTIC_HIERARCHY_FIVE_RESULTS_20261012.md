# 五域共享语义层级1000：完整负结果与方法约束

2026-10-12，续接原聊天的已冻结构造。**四臂、五域各200、8000张完整双帧Mask全部封存、评分和独立核验；adaptive五域均低于完整FoRIS及同输入density，按原规格关闭，不扩6200、不扫树深、先验、阈值或按域选臂。五域Strong及十域目标仍未完成。**

只处理已有真实O24，不产生新特征前向，不训练主干，不把FoRIS/MEAN/N预测作为方法输入。原5例40张smoke复用，本次新增995任务、7960张Mask。合法参考Mask决定源节点概率和停止/细分混合；查询标注仅在全部预测封存后读取。

## 成本、验证与复现

MPS生产本次 336.874s，全部1000记录合计case时间 327.836s（含旧5例）；输入阶段 153.930s，算法阶段 86.730s。算法阶段含MPS几何、CPU编码混合和同步，不能称纯GPU时间。评分 235.892s，独立核验 203.048s。MPS driver返回后采样最大 1.141098GiB，不是真峰值或利用率。

完整1000成员有2000次旧R/Q payload请求、1830个唯一文件；累计container请求 32.527GB，唯一文件 29.759GB，含旧5例，不代表物理磁盘IO。本次新任务995。fields/predictions/records目录总计 73.323MB，未复制raw或写dense特征。

原公式和8个源文件hash保持不变；全部1000的角色面积、树路径、3000个独立lgamma任务场、8000个双帧插值Mask、全部16000个新旧Mask整数/IoU以及160个fold/class聚合分数已检查。独立任务场最大绝对差 1.49e-08；独立bilinear的零附近符号差异 0像素。详见验证收据的精度范围。
