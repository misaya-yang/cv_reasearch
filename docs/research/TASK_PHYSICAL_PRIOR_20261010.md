## 唯一候选：用物理配对定义任务函数先验

当前要检验的是，真实对应能否在**拟合reference mask之前**排除不可靠的任务方向。原始单位O24不修改、不写回缓存，不把未知query标签代入匹配。

设中心协方差为Cx、Cy、Cxy，两视图均值差为d。独立打乱物理配对的精确期望二阶矩

`B = Cx + Cy + d dT`，真实配对差的二阶矩`A = B − Cxy − Cyx`。

用`r=trace(B)/D`作共同数值／各向同性收缩，`W=(B+rI)^−1/2`；分解对称物理相关矩阵

`W(Cxy+Cyx)W = U diag(rho) UT`。

正相关方向相对独立配对提供一致性证据，候选变换为`T=W U diag(sqrt(max(rho,0)))`。在变换后的reference特征上，用全部4096合法coverage拟合面积平方风险，带不惩罚intercept；正则固定为source中心协方差平均特征值`trace(C_R)/D`。这是每个任务的解析拟合，DINO不更新、没有跨数据集训练或query伪标签。

四个固定臂：

1. `reference_only`：原始单位特征，相同面积回归。
2. `query_variance`：仅W；判断增益是否只来自query边际方差重标定。
3. `physical_prior`：真实物理相关先验，唯一主候选。
4. `pairing_null`：打乱物理对应得到的特征方向，**赋予与真实臂完全相同的rho谱**；B、维数、谱权重与模型容量相同，检验增益是否来自真实配对。

所有臂输出whole与native任务场，并用同一个经典两尺度平方误差读出：`z_fine=f_fine+.5*(f_whole−mean2x2(f_fine))`。这一步不是创新，也不解决共同offset。主终点使用精确一维two-means（无histogram、无固定前景比例）的高分组为目标；预先同时保留coverage>.5作为零点控制。两簇读出带有分数双群结构假设，不是已证明的后验或真实面积估计，不按域选择renderer。

实现`src/ics/methods/physical_task_prior.py`；入口`scripts/run_physical_task_prior.py`。同40、四臂、两renderer、CLI1024及original全部先封存后评分。保留同批完整FoRIS、MEAN和快区域为外部比较，不进入候选计算。只有主候选同时超过source、variance与同谱pairing-null，且改善完整终点，才支持物理对应作为新增信息。单域或单renderer事后最好不能替代这个要求。

MPS执行缓存矩阵统计与应用，CPU FP64求解协方差／特征系统；单worker避免争抢设备。数学fixture已验证谱界、四臂参考标签取补的输出对称性、exact split对共同offset不变。成本仅为六既有raw后的增量，不能冒称冷端到端速度。

## 创新审查要求

二阶矩、CCA、协方差收缩、正谱核、ridge和Otsu／two-means都是经典工具，不能靠新名称成为贡献。可研究的贡献是：单参考任务在特征空间中的歧义，是否能被**来自同一query真实物理观察、相对保边际配对空模型的函数先验**可靠约束；是否能说明何时该证据不足。若匹配实验不成立，不扩为大方法；如果成立，仍须检查最近方法、跨五域验证、完整输出优势及实际新增观察成本。

文献核对还找到了直接先例：[Kakade与Foster，Multi-View Regression via Canonical Correlation Analysis](https://deanfoster.net/research/CCA_regression.pdf)，已经用无标签配对视图学习函数范数／核，再用有标签样本做ridge。本文具体归一化与空模型控制不同，并不足以把整个候选包装成新方法。其分析依赖每个view能支持同一预测任务等条件，不能无条件套到单张source与另一张query。另有[FSSDINO的semantic selection gap](https://arxiv.org/abs/2602.07550)，已明确展示中间表示oracle与支持／无监督选择之间的缺口。本研究需提出并验证实际解决原则，诊断“存在但选不中”本身也不自动成为新贡献。

## 下一问题收敛

全图、与任务无关的视图相关性能表达哪些视觉变化稳定，却没有直接说明稳定的变化属于哪个reference任务。因此暂不继续全局CCA式先验，也不以更多权重、层或图优化代替任务证据。

仍可用的下一信息问题是**跨观察的对应身份绑定**：当前参考读出通常把同一物理区域的whole与focus证据先各自汇总，再合并分数；这允许两个观察分别匹配到不同参考区域。应先检验，要求两个观察由**同一个物理参考位置**共同解释，能否增加目标与干扰的判别，而不要求两个视图的特征或分数相同。现有R-focus、wholeQ与nativeQ缓存足够做真实配对、保每个view/role边际的打乱配对、因子化读出三种明确对照。此项尚未实施，不先称为新算法；只有新增身份信息及完整输出都成立才继续。
