# 同原600：有效S否决被三条失败路线反复推翻

对同一精确历史LVIS600，读取已封存maxrole、query graph、joint task discriminant的主完整Mask，分别与保留的S和FoRIS B逐像素对齐。只作GT后诊断，未重跑这些方法、生成新预测或追加实验臂。

S相对B删去675694真前景、2439283假前景；恢复误删真前景有机会，但不能同时恢复已有效排除的假前景。新对齐将每条路线的新增进一步区分为“恢复S已删B”和“B也没有的新区域”。

三路线共同新增136252真/262906假，其中恢复S已删B的109753真/188013假。不同模型同意恢复，不构成正确性证明；这些FP是此前已被S有效否决的明确冲突，不是新编码或样本差异。

CLI共同新增假前景1,075,988px，726,684px（67.536%）所在16×16 native cell内没有任一GT目标像素，349,304px与某目标像素同格。多数共同错误不是同格精细边界的误切；同格也不自动证明边界问题，无目标同格不证明DINO特征不可识别。只检验这三条已失败配方的同600输出，不外推五域。

本次完整ridge曾用四方一致Q前景和背景，S已排除但B/G/R0仍报前景的争议区域不作为Q背景标签；已有效S的负判断因此没有直接进入那些独立正负角色拟合约束。这是可核查的代码/约束事实，不能仅由此断言将全部S背景强制当GT或改变旧seed即可成功，旧ridge配方已关闭。新的约束应消费S正负邻域和合法R正负角色的共同关系，明确检验该关系是否使恢复真与扩假区别开。

三路线保持同S、数据/图像/Mask/crop/原完整输出，坏增量发生在新判据/融合/读出；这些对齐不分离融合和readout，不提供全模型首个不可恢复步骤。原强S、输入/权重/缓存及全部失败结果继续保留。

实际main段wall 8.426401s / CPU 8.004662s / RSS 0.621597GiB，读取600旧QGT一次、旧最终Mask；0raw特征/encoder/fit/CRF/新预测。所有三个seal的1800预测包SHA与600身份先通过再读QGT；root另12662项savedscalar闭合与既有评分增量对齐，0重复GT/Mask/raw。
