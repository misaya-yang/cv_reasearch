## 预先写定的读法

1. **性能：** 开发 S、已读 T、新照片、官方协议分开；MFU 结果不计给 SH；GT oracle 只说明在既定候选内的诊断余量。
2. **贡献：** 有匹配消融且能重复的结果记为已支持；缺少独立确认或因果识别的解释记为待验证。简单组合的有效性不自动等于新的学习/推断原理。
3. **文献：** 按冻结编码器、额外模型、训练、参考数量、完整 mask、数据与指标协议判断可比性。检索未发现不等于不存在；不将“当前最强已核实基线”扩写成无条件 SOTA。
4. **失败：** 具体构造未通过只关闭该构造。只有充分的假设与证明才能支持不可辨识等一般结论。
5. **统计：** “未检出显著下降”不等于等效或非劣；发表单值不能提供配对差区间；注意多域主张、照片复用和自适应开发历史。
6. **下一步：** 若完整确认支持 SH，优先完成公平主表和最小论文证据；若存在稳定退化，缩准主张并回到 S 研究新机制，不在已读确认集上调参。理论与新方法只写可证伪设计，不在本轮执行。
