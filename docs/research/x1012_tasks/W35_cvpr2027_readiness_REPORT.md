## 1 当前成果到底到哪一步

### 1.1 问题定义与方法身份

输入为一张参考 RGB、完整参考 mask、一张查询 RGB；使用冻结 DINOv3-L/16，输出完整查询 mask，无任务训练、不增加其他模型。1024 输入、末层 64×64 token；参考 mask 保留 token 覆盖率。

最终 SH 的实际结构是：位置去偏 → 点证据 U0 与单前景/难负背景原型证据 M′ → 同一查询图上的两次求解 → 固定等权融合 → 固定 CRF。参考几乎没有纯前景 token 时，走核迁移回退，跳过两线融合与 CRF。[方法定义](W23_simple_pipeline.md)、[实现](../../../scripts/x1012/w23_simple_pipeline.py)

必须准确表述三个区别：

- **不调用 FoRIS 完整头，不等于组件全部原创。** 难负背景选择与正交化有 FoRIS 的明确先例，位置去偏有 INSID3 先例。
- **去掉 FoRIS 的聚类先验，不等于完全无聚类。** `r5_candidate.py:201` 仍做 k-means-64，为新奇度调制的 max-J 选择服务。
- **training-free 不等于 tuning-free。** 所有域共用固定参数成立；这些参数和规则有开发 S 上的选择历史，不能声称没有开发选择。

### 2.2 真正值得写进论文的问题

W14显示：前20%的大余量例贡献约65%的切点余量；它们的面积偏差往往达到倍数级，且扩张和收缩两种需要都存在。MFU主要减少内部FP，内部FN基本未变。**方法常已找到目标核心，难的是确定哪些相邻内容仍属同一任务目标。** [W14](W14_headroom.md)

已有案例记录把这一问题表现为：整物体或病灶只保留与参考最像的核心；相邻外观相似实体被吞入；部件与整体的范围混淆。这些例子是既有可视化记录中的定性说明，不是本轮重新抽样得出的频率；论文应配合已封存样例ID、参考mask、两单线、融合和GT，展示成功与失败，并明确选例规则。[W32动机](W32_key_entity_PLAN.md)、[W34经验题面](W34_theory_PLAN.md)

“范围错”也不能被压成唯一根因：iSAID有漏实例，Fundus/Road有块内混合与细结构问题，某些自然图像有任务身份误匹配。内部/边界诊断由GT定义、依赖划分宽度，各类oracle增益也不能直接相加当可实现总增益。

W31还给出一个实用提醒：J与候选IoU的例内Spearman中位数约0.83，argmax仍比自然切点差1.68。**优化端点的能力与整体排序相关性不同。** 下一验证器必须报告实际选择收益、最优候选损失和选择面积偏向，不能只报相关系数。

### 3.3 FROST带来的一个值得检查的机制解释

在**相同特征、相同核、硬二值支持标签，且前/背景均非空**的简化下，令前/背景核和为 `F=Σ_fg K`、`B=Σ_bg K`，前/背景token数为 `N_f,N_b>0`。原始软迁移为 `c=F/(F+B)`，而等类先验的核密度对数比为：

```text
log(F/N_f) - log(B/N_b) = logit(c) + log(N_b/N_f).
```

因此，核前景份额与平衡密度比的区别首先包含支持前景占比的先验，而不只是“点对应”与“区域语义”。该恒等式是对简化读出的代数分析，不是两种完整方法等价：SH还有软coverage、联合中心化、novelty、minmax、图求解；FROST还有自身带宽、whitening与空间步骤。[FROST原文](https://arxiv.org/html/2606.31136v1)、[本地核迁移](../../../scripts/x1012/r5_candidate.py)

**对准备工作的含义：** 先在方法比较中说清核读出的先验与标度，再判断范围错误是信息缺失还是已有证据的标定问题。不能直接把这个公式包装成新方法，也不能据它重启按参考面积选尺度；后者已经失败。若要做新诊断，须保持候选、表示与预算固定，只检验明确的先验假设，另写一轮读法。

## 5 理论准备：避免重复旧结论和过度证明

### 5.1 一般不可辨识不是当前错误的现成解释

仓库已在10-12推导了相同输入下粗类/细类任务歧义的确定性与随机minimax边界，同时核验6200个原生任务：完整参考任务唯一6200/6200，查询多答案为0。旧报告明确不把开放任务歧义当作这批失败的解释。[既有可辨识性审计](../archive/IDENTIFIABILITY_AND_METHOD_CONSTRAINTS_20261012.md)

W34 T1应分清三件事：原输入未指定任务；算法压缩成标量场后损失信息；信息仍在但现有估计器没有利用。通用反例只证明第一种或一个最坏情况，不能替代后两种的实际证据。固定面积优于FoRIS也不等于排序完美，更不等于场是未知单调变换后的真实后验。

### 5.2 比“实体结构必要”更有用的是容纳误差与选择误差分解

设查询分片为 `P_j`，面积 `w_j`，目标 `Y`非空。令多数标签近似的混合误差 `δ_P=Σ_j min(|P_j∩Y|,|P_j\Y|)`；算法相对该多数选择选错的片段集合为E。由对称差与并集面积关系，有：

```text
1 - IoU(pred,Y) ≤ (δ_P + Σ_{j∈E} w_j) / |Y|.
```

这是简单的诊断界，不是待宣称的新定理：分片更细可以降低容纳误差，却增加选择自由度；oracle只检查前一部分。完美分片仍需要参考指定身份与粒度，实体划分既不是普遍必要条件，也不独立保证成功。

### 5.3 未知单调标度与IoU目标不能被跳过

仅给排名、允许任意后验标度，minimax可能退化。即使完美排序且真值是前k个点，k在1至N间完全未知，预测前m个点的最坏IoU也是 `min(1/m,m/N)`，最优m约为√N；这是缺少范围信息的保守折中，不是语义推断。

边际后验还不能唯一确定期望IoU。两个像素的边际为0.6和0.4，联合前景概率为t：预测第一个像素的期望IoU为`0.6−0.5t`，预测两个为0.5。t=0和t=0.4时最优选择不同，即使边际和排序完全相同。T2需要明示空间依赖或独立假设，不能无条件套top-k。

官方槽内池化指标 `ΣI/ΣU = Σ_e (U_e/ΣU)·IoU_e` 的权重由预测相关的并集决定；逐例IoU最佳候选策略不一定使池化指标最大。因此“逐例GT选择后再汇总”应称诊断策略，不能冒称官方mIoU严格上界。

### 5.4 固定融合的理论边界

MSE中的等权融合风险为 `(R_U+R_M+2C)/4`，其中C是误差交叉矩；降低MSE并不保证阈值后的IoU提高。例如GT=(1,0)，U=(0.6,0.49)、M=(0.39,0)，均值场MSE更低，却在0.5阈值下预测空集，而U预测正确。

实际U0做minmax，M′含秩修正，且两线置信矩阵不同；共享L只表示使用同一图，不自动意味着两解均值等于一个自然联合目标的解。[simple_head](../../../scripts/x1012/w23_simple_pipeline.py)、[mean_solve](../../../scripts/x1012/w19_simple_head.py)

对论文更有用的是阈值附近FP/FN如何被修正、共同错误有哪些、尺度交换能否被预测。不要为解释0.5权重而追造“全局最优融合”定理。

### 5.5 W32与W31的负结果需要局部解释

W32阴性最多否定“末层key/O24＋指定非负稠密余弦＋NJW＋指定K＋当前样本”的构造，不能推成编码器内部不存在实体结构。谱值接近1可能表示慢混合方向；稠密谱衰减快也可能表示强混合，均需用实际容纳/选择表现判断。W32使用W15旧场定位困难例，也不是最终SH完整确认。[W32计划](W32_key_entity_PLAN.md)

DINO跨裁剪学习目标不能推出任意masked crop的backbone CLS不变；即使完全不变，也只推出候选打分相同，不推出偏爱小核心，更不能推出−10.17。W31只证实具体渲染/编码/余弦选择失败，原因仍需区分尺度、上下文、分布偏移与评分。[DINOv3原文](https://arxiv.org/html/2508.10104v1)、[W31结果](W31_demonstration_PLAN.md)

## 6 实验与统计如何经得住审稿

1. **保留实际研究历史。** W19已读同一T子样本，W23再次确认；MFU照片成绩公布后才形成SH。照片隔离和方法冻结是有价值的事实，但“每方法只读一次”不等于整个研究从未见过该测试。没有发现query GT进入SH推理的证据，也不能据此宣称不存在任何自适应选择影响。
2. **已读确认集不用于修参数。** W30结束后如结果不理想，照报并收窄主张。新方法继续在S上研究，最终确认另行规定方法身份和未被用于选择的评估；不能通过换名字无限复用同一留出。
3. **照片bootstrap的目标要明示。** 它合理保留同一query多episode的依赖，但通常条件于既定参考分配，不包含重新抽参考的方差。新照片脚本跨域共享canonical query权重；W27/W28宏区间域内独立抽样，如果存在跨域同源照片则仍需处理该依赖。不要只因已有bootstrap就称所有不确定性已覆盖。
4. **不显著下降不是非劣效。** 区间跨0可能同时容纳实质下降和提高。若未来确要声明每域非劣，应在看对应结果前给出有用途依据的δ，以每域差值下界对−δ检验。全部域均非劣是交并主张；逐域挑显著正域是另一类多重推断问题，不能混用。
5. **发表常数不提供配对推断。** SH区间与FoRIS发表值比较，只是相对固定报告值的条件比较，不包含基线实现/抽样误差；不能写成同例配对显著优越。需要配对主张时优先找回合法旧账本并核验episode、预处理、权重、代码与指标，而非擅自启动全量FoRIS重跑。
6. **宏平均、逐域与机制结论分开。** 十域平均、排除Fundus的敏感性、Road自定义、单线消融、官方类/fold池化都单列。开发槽均值与官方fold均值不能相减。显著性星号说明是名义95%还是同时推断，不把名义计数变成“普适”。

推荐主表字段：数据域与协议；SH+/SH；FoRIS发表；已核验同例FoRIS；INSID3/RSRM/FROST/FSSDINO对应条件；训练与额外模型；输出分辨率/后处理。缺失值留空或写未完成，不用不同协议填格。机制表使用W27/W28和后续真正完成的单线确认；MFU仅作历史或强对照。

### 7.3 新机制只保留一个有条件的入口

**候选问题：在不把查询结构压成单个标量场的情况下，参考示范能否决定哪些查询片段属于同一任务范围？** 这比“重新调阈值”明确，但仍不是算法。W32提供当前最具体的新结构候选，需先看其已预定的容纳性结果。

- **容纳通过后：** 将片段混合损失与选择损失分开；提出一条无query标签的固定选择规则。与同一片段上的简单均值/多数票、已有J或适用的现行规则比较，不能靠换候选池赢。正确/错误参考控制须针对任务定义；Lung/ISIC的另一张合法参考不自动是错误参考。
- **任务粒度主张：** 若声称区分部件与整体，需要合法原生任务的参考mask切换证据；同RGB、同候选池、不同真实任务，观察范围偏好是否对应变化。仅换类别最多证明类别身份，不证明完整性。
- **容纳失败：** 关闭本次key/O24谱构造，不接着搜索大量层、头、K和亲和参数。新一轮若有理由，应先写出不同信息来源与正/负读法。
- **选择失败：** 不能把oracle当方法成绩；也不重复已失败的局部角色边核、源mask选层级、逆向预测或面积门控。[角色边失败](../archive/TASK_ROLE_EDGE600_RESULTS_20261011.md)、[层级失败](../archive/TASK_SEMANTIC_HIERARCHY_FIVE_RESULTS_20261012.md)

W34宜先交付明确假设的范围/选择论证与统计措辞，不必把六道题全部包装成定理。FROST先验关系可作为比较解释，但是否有可用增量应由独立预写诊断判断，不把它立即增加为第二条实验路线。

### 7.4 建议的论文结构和主张模板

1. **问题与现象：** 同一冻结表示下，目标识别、完整范围和细结构不是同一难点；用有代表性的证据说明具体问题。
2. **方法：** 逐一写清继承部件与新增设计，给出SH完整定义、回退与复杂度；若B线成功，再以新机制组织这一节。
3. **主结果：** 九域公开协议与Road自定义分开；相同训练/模型条件比较；成本同时给头部与整链。
4. **为什么有效、哪里失败：** 两单线、回退、CRF、范围诊断和最近邻机制比较。原始复杂失败日志放补充材料索引，正文保留能改变结论的结果。
