## 1 本轮推进的结果

本线留下两类可以并列比较的对象，不能把它们都叫“换一个实体图”。

1. **B0 参考选图：** 用参考隐藏块的 harmonic completion 风险选择分头关系，再用于查询 SH 的两条求解线。本报告补上源内选择、跨图迁移、选择目标与部署目标错位的精确分解，并给出无查询标签的保守选图变体。
2. **局部森林编辑：** 关系仅提出正负终端之间的局部闭包，直接针对漏范围和邻体误增。本报告补上源证据删块的一致性拒识，以及按“能影响多少编辑面积”计算的风险分解。它能修改两线共同错误区域；共同同意不是它的正确性证据。

此外，A1 的秩前缀闭包可以形成第三种**条件性决策接口**：保留所有仍有依据的结构解释，再只做对这些解释都改善的切点改变。它不靠把参考的 K 或树深搬到查询。若这些解释无法排除自然切点，则该接口正确地不改。

这些推进没有给出“单参考自验证已经足以选对查询关系”的结论。真正缺的仍是任务条件关系的跨图稳定性；可见的支持不足可以拒识，落在错误类别支持内的条件漂移通常无法从无标签 query 检出。

## 3 B0 的完整部署对象与双重错位

### 3.1 原 Web B0 的可计算合同

输入是同一冻结编码器产生的参考/查询 O24、末块 k_norm 后且 RoPE 前的 16 个 key head，以及合法参考覆盖率 y。额外参考图、增强编码、查询 GT 均不使用。具体边权构造沿 [Web B0 原稿](/Users/misaya.yanghejazfs.com.au/Downloads/CVPR2027_research_package_20261015/W36_NEXT_EXPERIMENTS_PLAN.md) 的定义，以下重述会影响结论的部分。

- 候选 h=0 为原 O24 图，h=1…16 为各 head 图；top-20、互邻、局部距离尺度、平均加权度归一为 1。均匀分头控制先平均 16 张邻接，再重取 top-20/互邻/归一，不能平均最终 mask 冒充同一控制。
- 参考网格固定四象限留出，隐藏一象限及一 token 保护带；隐藏标签不参与任何种子、原型、置信度或全 mask 统计。用可见 y 作 Dirichlet 边界，在隐藏区域解 L_UU f_U = −L_UA y_A。
- 没有可见锚的分量置 .5；失败的 head/折也按 .5 计分，不能挑掉困难折。只有由标签质量条件共同决定的有效折可用，各 head 共用同一折集合。无有效折选 h=0。
- 每折按原稿的平衡软 Brier 风险打分，等折平均得到 S_h；选最小 S_h，平局先 h=0 再固定 head 序。
- 对查询使用同一 h 的图，其他 SH unary、两支 confidence、λ=16、融合、阈值、fallback 和 CRF 固定。查询求解失败整例回原 SH，计入失败率及完整端点。

这是一个部署规则，尚未证明它选择了更好的任务关系。对一个 reference 产生的四个块风险，不能当四张独立照片的跨图证据。

### 3.2 新推导：B0 的三项损失差

固定一例和候选 h，定义：

- S_h：实际可见的参考隐藏块 harmonic 风险；
- T_h：在 query 上按同一隐藏块合同、使用真正 query 标签作边界的 harmonic 诊断风险；这是**只为定义缺口的不可部署量**，本轮未计算；没有有效折时统一令所有 h 的 T_h=.25，只保证差分有定义，不给它准确率含义；
- L_h：该 h 完整部署输出的损失，例如逐例 1−IoU。

对原基线 h=0，有恒等式

\[
\begin{aligned}
L_h-L_0
={}&(S_h-S_0)\\
 &+\underbrace{[(T_h-T_0)-(S_h-S_0)]}_{\text{参考到查询的关系风险漂移 }D_h}\\
 &+\underbrace{[(L_h-L_0)-(T_h-T_0)]}_{\text{harmonic 到实际读出的目标错位 }M_h}.
\end{aligned}\tag{1}
\]

这是确定性代数分解，不依赖独立像素、校准概率或域适应定理。原选择保证 S_ĥ−S_0≤0；要得到实际改善，还需要 D_ĥ+M_ĥ 小于源内优势的绝对值。**源内隐藏块预测好，只控制第一项。**

若对全部候选有 |D_h|≤d、|M_h|≤m，则相对任意固定候选 h*：

\[
L_{\hat h}-L_{h^*}\le 2(d+m).
\tag{2}
\]

证明只需写 L_h=S_h+常数+D_h+M_h，再用 S_ĥ≤S_h*。d、m 不能由一张参考图的拟合误差自动估出；没有它们时，(2) 是条件命题而非可用置信区间。

S/T 与 IoU 的量纲都可取 [0,1]，但风险函数并不相同；M_h 正是保留这种错位，而非把 Brier 下降换算成 IoU 点数。数据集槽池化的 1−ΣI/ΣU 也不是逐例 L_h 均值；式 (1) 可对明确相同的聚合重新定义，不能直接把逐例分解当宏指标归因。

### 3.3 为什么同一图在两条 SH 线上的作用仍不同

在阈值/插值前，某支的形式可写为

\[
x_h=(A+\lambda L_h)^{-1}Av,
\quad
x_h-x_0=-\lambda(A+\lambda L_h)^{-1}(L_h-L_0)x_0.
\tag{3}
\]

第二式由两次线性方程相减得到，是图替换的精确响应。A 正定且该支 unary v 固定时成立。现有实现中 U0 与 M′ 的 A、v 不同：U0 的 A 还含 log_e 项，M′ 含 score/guide 秩引导。因此即使共用 L_h，也得到两个不同的响应算子。最终 U0 还经过全图 minmax，M′ 使用自己的既定读出，再融合/阈值/CRF。minmax 的极值移动可改变远处阈值，完整输出不能化约为一次“同强度平滑”。

令 H=A^(−1/2)L_h A^(−1/2)，求解频率的收缩率是 1/(1+λη_j(H))。平均加权度归一固定的是 tr(L_h)/N，既不固定 H 的谱，也不固定特征向量、连通分量、两支 A 或任务信号在各方向的能量。即使 A=I，等 trace 的图也可有完全不同的收缩方向和零空间。

**可区分控制：** 若 B0 实际胜出后要主张“关系比普通平滑更对”，可以在机制对照中令 O24 图的 λ 分别匹配两支的无标签收缩量 ||x−v||_A；该量沿非负 λ 单调，目标超出原图可达范围时记为不可匹配，不能临时换目标。这只能匹配一个作用幅度，不能匹配所有方向；它改变 λ，仅作机制控制，不能冒充冻结 SH 主对照。先有完整净增益，再决定是否需要这一额外归因，不把它设成所有方向的先行大网格。

### 3.4 一个无需估计跨图误差界的拒识变体

保留原 B0 为独立候选，再定义 **B0-block-stable**，不要悄悄改原合同：

1. 计算每个有效参考折的差 d_v(h)=S_h,v−S_0,v。
2. 仅保留每个有效折 d_v(h)≤0、且至少一折严格小于 0 的非基线 head；没有候选则返回 h=0。
3. 在保留候选内最小化等折平均风险，平局按固定序；query 部署及回退与 B0 相同。

这是对“同一参考不同空间部位支持相反的 head”作可见拒识，没有新数值门槛。它可能减少编辑，也可能拒掉实际最好的 head；它没有给 d、m 上界，更不能把 all-fold 同意当跨图证书。其意义是形成一个能被真实 query 输出直接否定的更具体假说：**只有跨参考空间块方向一致的关系优势更有迁移价值。**

## 4 为什么同 K、同树深和源可表达不是任务粒度

“同 K”只是同一个分组数。四个 token 的参考标签为 1100，K=2 划分 {1,2}/{3,4} 完全可表达；查询的同 K 划分 {1,3}/{2,4} 对同样的标签 1100 都混合。两个抽象树可以通过叶节点置换同构，任务边界却不受这个同构保持。该反例说明条件缺失，未声称实际 benchmark 存在输入完全相同而 GT 相反的案例。

一个任务可能要求一棵树的一个节点、多个兄弟节点的并集，或若干不相邻实例。源树找到唯一节点只标识了源上的范围；转移需要的是能将该节点的**任务归属**对应到 query 的规则。面积、数值深度、谱顺序都未提供这种对应。

因此使用完整层级有两个代价：

- 如果保留所有细分直至单 token，表达能力提高，但所有排序前缀可能都重新合法，结构不再提供切点辨别力。
- 如果压成少数粗单元来获得强闭包约束，跨真边界合并的风险增加。不能用减少候选数本身当作语义证据。

### 4.1 秩闭包的可部署条件接口

按 [A1 §10](W34_A1_identifiability_REPORT.md) 固定 F 的严格排序；每个分组 C 给禁切区间 [min r(C), max r(C)−1]。扫描得到合法前缀集合 Z_θ。参考只可剔除与自身明确模型矛盾的结构假设 θ；没有独立跨图依据时不能用“参考上哪层最纯”剔除其余 query 层级。保留 Z=∪_θ Z_θ。

对有限候选 A_k 可以直接枚举

\[
G(A_k)=\min_{S\in Z}[\operatorname{IoU}(A_k,S)-\operatorname{IoU}(A_0,S)].
\tag{4}
\]

只接受严格 G>0 的最大者，平局用固定顺序；否则输出 A0。前缀互相嵌套，IoU(A_a,A_b)=min(a,b)/max(a,b)，含空集的情况按协议明定，因此 (4) 可以只用索引计算，不读 GT。如果 A0∈Z，严格改善不可能；这时不应改用 argmin 闭包缺陷来制造赢家。

保证的条件是至少一个保留结构在 query 上任务纯，且真目标是 F 前缀。近似排序/混合需要有根据的误差预算；一张参考的误差不能自动充当该预算。式 (4) 已闭合的是决策算法，没有闭合的是 Z 是否覆盖 query 真值、又能排掉错误的 A0。

## 5 局部关系森林：完整输出与可计算拒识

### 5.1 保留 A8 的关系对象，不包装成新求解器

关系向量沿 [A8 §6](W34_A8_spectrum_REPORT.md)：query/参考各自 4 邻接边，去偏 O24 对比，加逐头 key 差分除以该图该头方差后的饱和分量；不消费自然 mask 邻居角色。每头共同的平移、正交变换、非零缩放不改变该分量；图像组成改变方差仍可漂移。

参考边分 FG–FG join 与 FG–BG cut，覆盖纯度作为支持权重；距异类最近关系的距离给支持球半径。query 落在互不相交的同类球内才获得支持，否则 unknown。球不交只保证支持输出不自相矛盾；BG–BG 的 query 关系在参考 FG–FG 样本之外，不能默认已被完整建模。“query 被接受的 join 不跨真实任务边界”仍是额外条件。

join 按权重递减做 Kruskal 合并；任何合并只要会把某条 cut 两端通过**直接或间接路径**放进同树，就拒绝。不能只删 cut 本身、却留下绕行通路。保留整个森林，不选全图 K。

终端沿 [A2 §10.3](W34_A2_partition_REPORT.md)：纯参考 token y=1/0，跨图双向最近邻且正负优势严格；混合 token、平票或类缺失不锚定。双向和严格优势都是可见量，均不证明语义正确。

对 query 每点算到两类终端的最大瓶颈 κ+/κ−。仅在严格不等时给标签；没有终端或平票为 unknown。若全体输入可用，**可直接输出的森林编辑探针**为

\[
A_{\rm forest}=(A_0\cup D_+)\setminus D_-,
\quad D_+=\{i:\kappa_+(i)>\kappa_-(i)\},\quad
D_-=\{i:\kappa_-(i)>\kappa_+(i)\}.
\tag{5}
\]

式 (5) 不声称安全，优点是接受规则终于没有藏着一个尚不存在的 query 错误预算。把 token 集铺回 pixel 单元时，明确只编辑这些单元中 A0 原本需要改变的像素；其他像素保留。若仅修改一部分壳层，风险必须针对该壳层计算，不能拿完整闭包纯度代替。

若要严格 worst-case IoU 安全，仍必须将有依据的终端/边错误预算交给 C 线比较器。预算未知时使用全体合法真值，不会凭空通过编辑；不能把式 (5) 与安全版本混称为同一保证。

### 5.2 新构造：删源证据后仍一致才编辑

旧方案的支持球只做几何 OOD 拒识。这里增加一个确定、可实现、没有查询监督的证据敏感性拒识；它是新的待验证变体，不覆盖 A8 原稿。

构造五个参考证据版本：完整参考，以及四个分别删去一象限和一 token 保护带的版本。删块版本只保留两端均在可见区的参考边，锚也只能来自可见 token；参考 RGB/key 仍可完整观察。描述归一化只由无标签图像特征决定，不能因 mask 的隐藏位置改变。每个版本独立按完全相同的支持、森林、终端和瓶颈规则产生 ℓ_v(i)∈{+,−,?}。

- 任一版本没有所需两类参考边/纯正负 token，或 key/求解不可定义，整例新变体返回 A0，不能跳过这个版本再说“所有版本同意”。
- 仅当五个有效版本对 i 全部给出同一个严格标签时，i 进入 D+ 或 D−；否则保持 A0。
- 最终仍用式 (5)，默认返回原 SH；固定 fallback 例不改变。将两类终端全缺的树输出 unknown，不以最近原型强制填充。

它问的是**一个局部参考部位是否独占了这次 query 编辑的证据**。这和只把源训练边随机拆分不同，也不等价于五张独立参考。五个版本可能一起错：共同的语义混淆或所有源关系同时失配仍然保留。删源证据稳定是拒识信号，不是 correctness certificate。

这个版本会漏掉依赖单个合法参考部位的真改动；例如参考前景完全落在一个象限时，删除该象限的版本没有正锚，该例直接不改。它可能因此大部分回退，这也是要接受的负结果，不能在评分后跳过缺类版本。完整输出必须计入回退/未改的例子，不能只在被编辑像素上报高 precision。

### 5.3 为什么它确实能触及共同错误

若 U0/M′ 都漏掉同一条目标延伸，但 query 中该延伸与一个正终端间有强同侧通路、到负终端的路径必须越过更弱边，则 κ+>κ− 可把它加回，不要求两线先出现分歧。相反，邻体若有更强负终端连接，即便两线都误报也可被删。

这不是无条件承诺。完全没有终端的真目标分量不会被恢复；强跨界桥或错终端可把两线原本共同正确的区域一起破坏。只限制在线间分歧带编辑会丢掉上述能力，若使用那种限制应作为一个另外的局部控制，不是这里的主机制。

## 6 新推导：少量错边为什么仍可能造成大面积错误

边分类错误率没有描述其影响范围。先在二值任务纯节点模型下，对一个已产生严格标签的编辑点 i，固定一个达到胜出瓶颈的终端 t(i) 和森林路径 P(i)；完全相同的同类终端/路径平票按预定编号决定。令 w_i 是该点实际要改的像素质量，未编辑者 w_i=0。

定义可见的影响体积

\[
V_t=\sum_{i:t(i)=t}w_i,
\qquad
V_e=\sum_{i:e\in P(i)}w_i.
\tag{6}
\]

令 B_t 表示终端真标签错误，B_e 表示接受的 join 跨过真实任务边界。只要 t(i) 正确且路径每条边均不跨任务边界，该编辑点的标签就正确。因此逐点有

\[
\mathbf 1[\hat\ell_i\ne\ell_i]
\le \mathbf 1[B_{t(i)}]+\sum_{e\in P(i)}\mathbf 1[B_e],
\]

从而

\[
\sum_i w_i\mathbf1[\hat\ell_i\ne\ell_i]
\le \sum_t V_t\mathbf1[B_t]+\sum_e V_e\mathbf1[B_e].
\tag{7}
\]

这是一个 union bound 型确定性上界，可重复计算同一错误，因而不要求独立终端、独立边或概率模型。若真的有条件错误概率上界 π_t、ε_e，则条件期望再被 ΣV_tπ_t+ΣV_eε_e 上界；**本项目目前没有可由源内拟合直接提供的这些 query 概率界。**

**混合 patch 必须另计。** 实际 token 可含两类像素。固定一个二值 proxy t_i（例如只在封存后诊断使用 GT coverage≥.5），令 M_edit 是实际被改壳层中、像素 GT 与其 token proxy 不一致的质量。将 B_t、B_e 也相对于同一 proxy 定义，则像素误编辑质量的上界是式 (7) 右端 **再加 M_edit**。这由逐像素的三角不等式直接得到。M_edit 不是完整 patch 混合率乘任意面积；它对应真正被编辑的子集。本轮未计算这些 GT 量。路径关系和终端即使对 proxy 全正确，也不会自动解决 patch 内位置误差。

式 (7) 有三个实际后果：

1. 一条错误桥接边可以有极大的 V_e；低“错边百分比”不能为整个实体编辑背书。删块一致性若总由同一高影响桥支撑，也仍有此风险。
2. 锚数量多、token ESS 大不等于独立证据多；一个错误终端的 V_t 才直接连接到可能破坏的面积。参考重用和强相关不会被此分解忽略。
3. 该分解给出未来封存后诊断的具体对象：终端影响、边界桥影响、未覆盖三者分别报告。不能用 query GT 估出这些项后再调整拒识门槛。

V 本身不含 GT，可在部署时记录；它只能说明**风险暴露在哪里**，不能说明该边真的错。没有经过事先固定的错误预算时，本报告不增设任意 V 上限作通用过关标准。

若未来确有“最多 b 个约束错误”的外部合同，最坏影响可用最大的 b 个 V 求和控制，而非按错边均匀摊分。但 b 不是从单参考支持球的零训练冲突推出的，本轮不假定 b=0 或 1。

## 7 源支持、可观测拒识与不可检测漂移

| 条件 | 推理时可见？ | 本线动作 | 仍不能保证 |
|---|---|---|---|
| 参考缺 join/cut 支持、纯锚缺类、留出无有效折 | 是 | 返回 SH，不把缺支持解释成不存在该 query 关系 | 被拒的 query 目标可能可恢复 |
| query 关系远离全部参考支持球 | 是 | unknown，不传播 | 落在源球内的 query 关系正确 |
| 源不同象限对 head/编辑方向相反 | 是 | B0-block-stable 或森林删块一致性拒识 | 方向一致时没有共同偏差 |
| 相似关系在 R 是目标内边、Q 是目标外边 | 否，只有关系描述及无标签 Q 时通常无法检出 | 不虚构证书；作为迁移失败机制预写 | 新编码器通道一定无用、或本 benchmark 本身不可解 |
| 查询终端把外观相同的邻体错配成目标 | 否，仅双向/大间隔不能证明 | 保留终端风险项，接受完整端点检验 | 两线同意或更多近邻能自动消歧 |

这里的无保证与域适应的经典边界相容：没有约束标签条件分布，源标签和无标签目标分布不足以决定目标风险；[Ben-David 等的原论文](https://proceedings.mlr.press/v9/david10a.html)给出一般不可能性结论。它约束的是假设不足，不证明当前有完整合法参考的十域 benchmark 不可解。需要验证的具体跨图条件是：**同一关系/终端证据在所声明任务下，仍对应相同的 query 任务归属，且覆盖所需范围。**

## 8 创新性边界：哪些已经被占位

| 最近对象 | 已有机制 | 本线可能剩下的具体贡献 | 最近的否定证据 |
|---|---|---|---|
| [Gaussian fields/harmonic functions](https://pages.cs.wisc.edu/~jerryzhu/pub/zgl.pdf)，ICML 2003 | 图上 Dirichlet 标签扩展、随机游走解释及图参数选择 | 不是 harmonic solver；只能研究隐藏空间块的任务风险是否能选出可迁移的 DINO 分头关系 | 原算法本身没有保证跨图语义条件不变 |
| [TokenCut 原论文](https://openaccess.thecvf.com/content/CVPR2022/papers/Wang_Self-Supervised_Transformers_for_Unsupervised_Object_Discovery_Using_Normalized_Cut_CVPR_2022_paper.pdf)、[作者实现 ncut](https://github.com/YangtaoWANG95/TokenCut/blob/master/object_discovery.py) | 最末 key、阈值亲和、广义特征分解、均值切分和极值 seed 对应分量 | B0 的参考任务条件选关系与多实例/部件完整输出不同；森林也不依赖单个谱二分 | W32 已说明照搬 key+谱不是实体恢复，末层 key 本身不新 |
| [Power Watershed 原论文](https://perso.esiee.fr/~coupriec/power_watershed.pdf)、[作者代码入口](https://perso.esiee.fr/~coupriec/code.html) | 种子、最大生成森林、Kruskal/Prim、随机游走等有成熟统一关系 | 不是瓶颈传播或森林求解器；可能是关系证据的任务转移与有依据的局部拒识 | 仅换成森林并未解决终端/错桥语义 |
| [FSSDINO v1](https://arxiv.org/html/2602.07550v1)、[fss_oracle.py](https://github.com/hussni0997/fssdino/blob/24858986ea55e312200079937989ad32360f09b2/fss_oracle.py) | 295–326 行已含 support-self IoU 与 query-pseudo→support reverse IoU 选内部层 | B0 的 blocked hidden-mask harmonic 选图目标比普通自分割更具体，但不能称首次用参考验证内部表示 | 作者已报告这些 support-guided 选择低于强 last-layer，选择余量并非可用收益 |
| RSRM 的 SAFR（固定版本及代码见 [W36](W36_method_directions_REPORT.md)） | 支持 mask 指定 Fisher/位置信息并重加权内部层/头相关表示 | 逐头关系图的可迁移风险判据与共同错误纠正若成立，才是具体增量 | “任务条件内部选择/加权”已占位，不能只以无训练或多头为新 |
| 本项目旧角色边/语义层级 | 参考局部关系迁移、参考节点条件与跨图读出 | query 内路径、显式 unknown、影响体积与删证据稳定性使失败可定位 | 来源可靠性仍未解决，不能将新拒识步骤当成功证据 |

当前最可争取的主张应当是**一个经完整对照证实的任务关系迁移机制**，而非“首次图传播”“首次用 key 找实体”或“首次参考自验证”。是否达到投稿创新性，需要 F 线继续按最近邻比较；本线没有比较依据押定 B0 或森林。

## 9 实验读法草案：现在只写，不执行

本节不给各方向统一样本数、相关系数或逐域全正门槛；未来运行前应把样本、候选、所有输出、无效/回退和读取范围冻结为一次方案。优先用已开放 S，不借 T 或新照片补调试。

### 9.1 B0 的最小可区分比较

**主要完整输出：** 原 SH、均匀分头图、原 B0、B0-block-stable。若要判断“参考选对 head”而不只是“任一 head 更强”，还需一个在当前样本成绩之外事先固定的单 head；不得以本轮全局最优 head 当已预定控制。逐例 best-head 只作容量诊断，与实际 SH 比，不要求胜另一个更高 oracle。

**最少机制量：** 每折 S_h 差及选择稳定率；两支原始解/读出后的变化分开；λ=16 的图谱/收缩仅解释作用，不作标签正确性证据。若取得完整收益且要做归因，再用 §3.3 的幅度控制区别关系方向与一般收缩，不能看到分数后从多个控制定义中选一个。

**共同错误：** 按冻结 U0/M′ 的同意/分歧区域分层，分别给增加 TP、增加 FP、删除 TP、删除 FP。两线同意区域仍允许改。原 fallback 独立列出，不能充当图关系收益。

### 9.2 森林的最小可区分比较

**主要完整输出：** 原 SH、式 (5) 的完整证据森林编辑、五版本一致性拒识编辑。固定关系表示与 terminal 读法；无终端/unknown/拒识例按真实返回 SH 计入。

**最少机制控制：**

- 同一 forest+terminal，改为只在 U0/M′ 分歧区允许编辑：识别共同错误区域的净作用，不能只报能修改共同错误。
- 同一 forest，参考终端标签去任务化的控制只能检验任务分支是否影响输出；即使胜过它，也必须胜原 SH 才算方法收益。
- 固定同一完整输出的面积编辑预算，按原 F margin 选择加/删像素作位置控制，可判断森林是否比原排序更会选位置；不能用 oracle 预算重新定义方法。

关系边是否过真边界、终端是否错、V 加权风险、同侧可达率和候选容量只在所有输出封存后诊断。均值低错边率但影响体积高，应按 §6 读成错桥支配，不能归为阈值未调好。

### 9.3 正、负、混合结果分别改变什么

| 预定结果形态 | 支持/否定的对象 | 下一步判断 |
|---|---|---|
| B0 胜 SH/均匀图，参考优势跨块稳定，且实际获益不由单一固定 head 解释 | 支持该选择器的任务条件增量 | 保留为可部署方法候选，才考虑独立冻结确认与成本 |
| 候选 best-head 有余量，B0 不胜完整控制 | 否定这个源风险选择器，不否定候选关系的容量 | 不扫 head 温度/换源风险在同批挽救；记录错位属于迁移还是部署读出 |
| 源 harmonic 风险很优，query harmonic 诊断差 | D 项主导，参考关系不能迁移 | 源自验证不足，不能通过更精确源求解免责 |
| query harmonic 也优，实际 SH 无益或更差 | M 项主导，选择目标和部署目标不对齐 | 不能继续宣传“选到正确实体图”；另立与实际动作一致的选择目标 |
| 森林内部边准、但目标到终端不可达 | 连接覆盖不足 | 不能只报高边 precision；这套闭包无法补所需范围 |
| 边准但错终端高 V_t，或少量错桥高 V_e | 对应源语义/连接错误放大 | 否定该 terminal/关系迁移条件；不借多数同意免责 |
| 删块一致性提高编辑 precision 但完整 IoU 无益 | 拒识过强或错过重要范围，尚未形成方法提升 | 报真实回退与净端点，不在本批放松一致条件 |
| 共同错误纠正多，但 pooled IoU 不升 | 像素收支与指标/域权重不一致，或同时破坏关键 TP | 不能将错误像素数减少写成 mIoU 提升 |
| 秩闭包常包含 A0、G≤0 | 现有结构未提供足够决策信息 | 不把拒识当算法失败；也不声称有可实现收益 |

所有读法以完整、相同指标的输出比较为准。新机制若只在局部诊断漂亮、最终未优于原方法，则完整构造没有通过；不将假设的名字代替结果。

## 10 复杂度、来源和仍未闭合的合同

B0 额外成本包括 17 张参考候选图、至多 4×17 个 harmonic 求解和选中 query 图的两支求解。逐头精确近邻朴素仍有 O(16N²d_head) 的距离计算；可分块而不保留磁盘特征，不能将“同一次编码”写成免费。query-GT oracle 若输出所有候选还会额外计算，不能混进部署耗时。

森林的边数 O(N)，但支持球的 source 异类最近距离和 Q/R 全边比较朴素为 O(M_R²d_z+M_QM_Rd_z)。受 cut 约束的 Kruskal 若每次扫描所有 cut，最坏 O(M_QM_C)；瓶颈传播可用优先队列 O(M_Q log N)。路径影响体积可以在树上对各 node→winner-terminal 路径做 LCA 差分累加，不需要逐个路径逐边走。五版本重复构图仍有实际成本，未来须量出峰值内存和头部时间，不承诺它比 SH 更快。

**已闭合：** 两种主算法及一个明确拒识变体的允许输入/输出/回退；式 (1)–(3) 的选择/部署错位；式 (7) 的面积风险暴露；K/depth 不足的反例；完整正负混合读法。

**尚未闭合：** 源→query 的关系/终端语义稳定性；目标内可达覆盖；五版本稳定性是否有实际选择价值；相对于强最近邻的可实现净增量及成本。没有因这些条件难而宣布方向无效，也没有把条件写下就当条件已满足。
