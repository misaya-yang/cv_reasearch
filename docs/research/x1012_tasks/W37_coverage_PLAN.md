# W37：边界带的覆盖率——容量与可部署估计

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。

## 1 动机

- **已知余量：** 自然图像域一个 token 宽的边界带约值 +8～9（W14）；在 Fundus、Road 上，细结构是主要误差（E15）。
- **理论（[W34 Claude 稿](W34_theory_REPORT_claude.md) T7）：**
  - 若 patch 覆盖率准确，双线性插值后取 .5，对直边的误差不超过 1.4 px；
  - 因此边界带损失应主要来自覆盖率**估计**，以及比 patch 还细的结构。
  - 核迁移的 c（τ = .05）接近二值，丢掉了亚 token 信息。
- **方向：** 这条路方法内在，不提高输入分辨率，不用编码器，与 W32 关闭的“实体结构”是不同的余量。
- **本任务回答两个问题：**
  1. 边界带上，“正确的覆盖率”到底值多少（容量）？
  2. 两个无标签的覆盖率估计能收回多少？

## 2 设计

**样本：** W23 / K0 的 S 样本，1,285 例，含 195 个回退例。T 半和新照片留出都不读。

**场与自然掩码：**
- 非回退例：F 为冻结 `simple_head` 中 CRF 前的融合场，捕获方式同 K0；
- 回退例：F = minmax(up(c))；
- 自然掩码 N = F > .5，必须与 W23 SH（CRF 前）的整数 I/U 一致，≥ 1,280/1,285。

**边界带：**
- N 的 token 覆盖率 $n_i$ 由 16×16 平均池化得到，token 多数标签为 $n_i \ge .5$；
- 带 B = 3×3 邻域内同时含多数内、多数外 token 的 token，并上 $0 < n_i < 1$ 的 token；
- 带外像素一律保持 N 不变。

**带内的覆盖率来源 π：**
- **O（容量诊断）：** GT 的 16×16 平均池化。
- **C：** 核迁移 c（`c32`）。
- **U（线性解混）：** 在去偏的单位查询 token 上计算：
  - 核心 = token 平均 F ≥ .75，取 â 为核心 token 均值；
  - 背景 = token 平均 F ≤ .25，取 b̂ 为背景 token 均值；
  - $\hat\pi_i = \mathrm{clip}\big((q_i - \hat b)\cdot(\hat a - \hat b)/\|\hat a - \hat b\|^2,\ 0,\ 1\big)$；
  - 核心或背景少于 4 个 token 时，改用 C。

**带内重建（R1–R3）：**
- **R1：** 带外用 $n_i$、带内用 π，拼成 64×64 的覆盖率图，双线性上采样（与 `lab.up` 相同）后取 > .5，只取带内的块。
- **R2：** 每个带内 patch 取 round(256·π_i) 个 F 最高的像素。
- **R3：** 每个带内 patch 取 round(256·π_i) 个颜色对数几率最高的像素。
  - 颜色模型：RGB 每通道 16 级直方图，加一平滑；
  - 前景 = F > .75 的像素，背景 = F < .25 的像素；
  - 两类之一为空时，改按 F 排序。

**臂：**
- 自然；
- O1–O3、C1–C3、U1–U3；
- 主臂 U3；
- U3+：在 U3 上加与 SH 相同的 CRF，回退例不加 CRF，与 SH 保持一致。U3+ 与 W27 的 SH+ 比较。

**指标：**
- 与 W23–W27 相同：CRF 前，(fold, 类别) 槽池化后等权，十域再等权；
- 区间用 `score.paired_ci`，500 次照片 bootstrap，rng = c.SEED。

## 3 读法（运行前写定）

1. **容量：** max(O1, O2, O3) − 自然，十域均值。
   - **≥ +5：** 边界带的覆盖率值得追，进入第 2 条；
   - **< +2：** 关闭“边界带覆盖率”这条方向，读法 2 只报告；
   - **介于两者之间：** 只在细结构域（Fundus、Road）上继续，由 O3 − O1 的符号决定细结构是否需要按 patch 重建。
2. **可部署：** U3 − 自然，十域均值 ≥ +1.0，配对区间下界 > 0，且 ≥ 7/10 域 ≥ 0。
   - 满足时，进入方法验证：U3+ 对 SH+ 在 S 上，再读 T 一次，另写计划；
   - 不满足时，这两个估计器关闭。
   - C、R1、R2 臂只作诊断，**不在看过结果后替换主臂**。
3. **一并报告：**
   - 各臂逐域结果；
   - 带内像素占比；
   - 在 GT 边界 patch 上，c 与真实覆盖率 π 的标定曲线（10 档），用来检验 T7 命题 7.2 的“阶梯状”；
   - 用时。

**2026-10-15 03:50 完成。读法 1 通过（容量 +9.43），读法 2 不通过（U3 −3.05）；两个估计器关闭。**

- **运行：** 1,285 例，2 个进程 × 1 线程，约 15 分钟，中位 1.4 s/例。
- **实现检查：** nat 与 W23 SH（CRF 前）的整数 I/U 一致，1285/1285。
- **带的大小：** 带内像素占比中位数 8.3%。

**逐域：**
- O2 在九个域上为 +7～+14，Fundus 为 +4.0；
- O1 在 Fundus 上为 −11.5，双线性会抹掉细血管，与 T7 的预测一致；
- U3 在 0/10 个域 ≥ 0，配对区间全为负；只有 ISIC 的区间含 0（−0.06，[−0.67, +0.44]）。

**判定：**
- **读法 1：** max(O) − nat = +9.43 ≥ +5，边界带覆盖率值得追，进入读法 2；
- **读法 2：** U3 − nat = −3.05，十域区间 [−3.43, −2.94]，0/10 域 ≥ 0，不通过。c 与线性解混这两个覆盖率估计器关闭。

**诊断（不改变判定）：**
1. **F 的亚 token 排序是对的，缺的是量。**
   - 给定正确的逐 patch 覆盖量，按 F 在 patch 内取像素（O2）最好，比颜色（O3）高约 2 点，也比双线性（O1）高。
   - 所以边界带的问题不是“在哪”，而是“取多少”。这与全局尺度上“排序对、范围错”是同一个结构，只是换到了局部尺度。
2. **c 不是覆盖率。** 在 GT 边界 patch 上，真实覆盖率 0.9–1.0 时，c 落在最低一档的仍有 13.7%，落在最高一档的只有 29.3%；真实覆盖率 0–0.1 时，60% 在最低一档。c 偏向两端、按行分布很宽，与 T7 命题 7.2 的“近二值”一致。
3. **线性解混**比 c 略好（U1 −1.74 对 C1 −4.24），但仍明显低于 nat。去偏 O24 特征对覆盖率并不近似线性。

**结论：**
- 边界带约 9 点的余量确实存在，并且可以表达为“每个带内 token 的覆盖量”这样一个很小的未知量（约 8% 的 token）；
- 这个量从核迁移和线性解混都读不出来；
- 按 W34 的 T8，任何 F 可测的局部覆盖率估计都要先过 ρ 筛查，才值得进入正式实验。
