# W39 D：覆盖量与像素位置——精确分解和一个可计算逆问题

2026-10-15。对应 [W39 计划](W39_astra_open_questions_PLAN.md) D 线。这里只读研究文档、两份历史算法源码和原论文；**没有运行模型、模拟、数据诊断、GT 解码或新评分**。W37 数值只引自其[已发布结果节](W37_coverage_PLAN.md)；W38 先读[已写定设计](W38_band_amount_PLAN.md)，得知另一会话完成后仅补读其结果节，未修改其计划、代码或执行。下文的方法是新的可计算候选，尚无实现或性能结果。

这条线现在闭合了三件事：质量与排序误差可在像素计数上精确分开；GT 覆盖量加 F 排序不是该排序族的完整 IoU oracle；可以不输入 oracle 质量，用参考边界条件化的像素图和逐 patch 排序约束，联合反求各块取多少。未闭合的是：这种参考边界关系是否跨图成立、是否足以改变正确决策，以及这一组合是否超过现有图割和引导上采样。

## 1 W37 实际支持什么

W37 的 1,285 个 S 例中，GT patch 覆盖量加 F top-k 的 O2 相对 CRF 前自然掩码为 +9.43；双线性 O1 为 +6.91，颜色排序 O3 为 +7.43。核迁移 C 和线性解混 U 的可部署估计没有收回该容量，主臂 U3 为 −3.05。自然输出与 W23 整数 I/U 为 1,285/1,285 一致。这些均为已发布结果，未在本任务复算。

可以据此说：**在既定带内、给定真实局部数量时，当前 F 的像素排序具有可利用的容量。** 不能据此说排序已完美、全部错误都只在数量、所有 F 可测估计均不可能，或所有冻结内部通道已经用尽。C/U 关闭的是两个具体估计器，O1 在 Fundus 的失败也说明数量与位置重建必须分开。

W38 的 RGB 类间分离是在每块既定 F 排序上挑 k 的一个具体规则。它的成败不能升级成 RGB 所有边缘、纹理、参考条件关系或全局逆问题的结论。本报告不改其冻结读法。

### 1.1 收尾时新增的 W38 已发布结果

W38 另一会话发布：主臂 rgb 的 Pearson ρ=.353（CRF 的量为 .170），但完整十域 mIoU 为 −1.73、0/10 域非负；不门控诊断臂 rgb_all 的 ρ=.457，mIoU 却为 −5.37。其已定三项继续条件没有同时满足，原构造关闭。本任务未启动该实验，也未读取对应原始产物。

报告还独立给出计数 MSE 从 12,523 到 12,153，以及 E[x²]/(2E[xy])=.94；这些是另一会话报告的 sufficient statistics，未复算。它们若按所述定义计算，依据本报告式 (6) 确实说明该计数平方损失下降；**不是由 Pearson ρ=.353 自动推出**。ρ 是中心化、标准化协变，MSE 收益还含均值、实际幅度与未中心化二阶矩。

因此结果支持“该 RGB 规则与真数量改变量存在正协变，但整套动作没有改善完整输出”，而非“方向已解决”。幅度、排序、FP/FN 分布和槽权重仍可能共同作用。crfA +.13 与 SH+ +.18 的接近，只说明两个已定义输出的宏观分数接近，不单独证明 CRF 的全部像素行为或全部收益都可由数量解释。

## 2 质量与排序误差的精确分解

### 2.1 可分解的是计数，不是两项 mIoU

令一个带内 patch 有 n=256 个像素，GT 前景集合为 G、数量 s=|G|。按实际 F 降序及固定坐标并列规则得到前缀 A_F(k)，并定义

\[
t_F(k)=|A_F(k)\cap G|,\qquad
h_F(k)=\min(k,s)-t_F(k)\ge0.
\tag{1}
\]

则精确有

\[
\begin{aligned}
FN(k)&=(s-k)_++h_F(k),\\
FP(k)&=(k-s)_++h_F(k),\\
|A_F(k)\triangle G|&=|k-s|+2h_F(k).
\end{aligned}\tag{2}
\]

证明只需把 FN=s−t、FP=k−t 代入，分别讨论 k≤s 与 k≥s。第一项是这个数量下不可消除的质量错误，第二项是同数量下因位置选择增加的错误。对任意选取 k 个像素的重建都成立，不限于 F；F 只决定 t 和 h。

这比“总面积偏差”严格：不同 patch 的高估和低估可以抵消，使 Σ(k−s)=0，但 Σ|k−s| 仍很大。也不能把 patch 内前景误分类率、soft coverage MSE 和这两个像素计数当作同一指标。

**关键限制：** h_F 随 k 改变。因此将自然 k 改为真值 s，同时改变了质量项和所经过的排序位置；这是精确误差分解，不是一次 oracle 替换产生的可加因果归因。

### 2.2 接到真实 IoU 的方式

对一个完整输出或一个按官方规则池化的 (fold,class) 槽，令 S 为全部 GT 前景总数，带外固定部分为 FN₀、FP₀。定义

\[
A=\sum_i(s_i-k_i)_+,\quad
B=\sum_i(k_i-s_i)_+,\quad H=\sum_i h_{F,i}(k_i).
\]

那么

\[
IoU=\frac{S-FN_0-A-H}{S+FP_0+B+H}.
\tag{3}
\]

先在槽内求和，再求比值，最后按现有类别、fold、域的规则平均；不能先求每块或每例比值再代替开发/官方指标。式 (2) 的两项不能换成两个可加的 mIoU 收益。

在 k 固定且重建使 H 减少 d>0 时，I'=I+d、U'=U−d，因而

\[
IoU'-IoU=\frac{d(U+I)}{U(U-d)}>0.
\tag{4}
\]

但改 k 同时改 A、B、H，不能仅由覆盖量 MAE 更小推出 IoU 更高。小目标中同一像素误差还对应更大的相对损失。

**即使排序完全正确，MAE/MSE 也不足。** 一个 256 像素块中 GT 数量 s=20，F 将全部 GT 排在最前。自然 k=30：FP=10、FN=0、IoU=20/30；改为 k=11：FP=0、FN=9、IoU=11/20。数量 MAE 从 10 降到 9、MSE 从 100 降到 81，h 在两臂均为 0，IoU 却从约 .667 降到 .55。这是手工有限集合反例，未运行模拟；它说明 W38 的 L2 改善而 IoU 下降，不一定必须靠排序错误才能发生。

对完整输出，S 固定且 U=S+FP。多一个 FN 的有限损失为 1/U，多一个 FP 的有限损失为 I/[U(U+1)]=IoU/(U+1)；一阶微分才写作 (dI−IoU·dFP)/U。因此“前者恰为后者 1/IoU 倍”只是大 U 近似，且应在同一个池化槽、同一当前状态讨论。总像素错误 FP+FN 也不等于槽等权宏观 IoU；未来直接换用 MAE 或像素错误作唯一筛查，仍不足以闭合方法判断。

### 2.3 O2 仍有排序残差，也不是完整的 F-prefix IoU oracle

O2 令 k=s，式 (2) 仍剩 2h_F(s)。只有 h_F(s)=0 才在该块精确恢复。O2 高于自然，并未测出 h_F(s) 是否为零。

更强的反例：一个两像素 patch，GT 是第二个像素，F 却将第一个排在前面。k=s=1 时 IoU=0；k=2 时 IoU=1/2。因此，**正确前景个数加错误排序，甚至未必是该排序下 IoU 最好的数量。** 这不是 W37 的新数据结论，而是有限集合反例。

可以定义更合适的诊断上界。允许每 patch 独立选 F 前缀，带外固定。对一个池化槽，记带外 TP 为 I₀，S>0，构造

\[
\Phi(v)=I_0-v(S+FP_0)
 +\sum_i\max_{0\le k\le n_i}
       \{(1+v)t_i(k)-vk\}.
\tag{5}
\]

其唯一零点 v*∈[0,1] 是这个候选族的最大池化 IoU；在 v* 处逐块取式 (5) 的 argmax 即达最优。证明：对每个联合候选，I−vU 可分离为式 (5) 的求和；U≥S>0，所以 max(I−vU) 在最大比值处恰为零，并严格随 v 下降。可用二分和逐块累计 TP 求解，不需训练选择器。空 GT 必须沿用协议的空集效用，不能生搬此根方程。

这仅是未来授权评分时的 oracle 诊断，不能部署。若按例各自最大化 IoU 再池化，也不必得到槽池化 IoU 的真正最大值。O2 是其中一个合法候选；自然 N 也是，因为 F>.5 在每块是前缀。故此 oracle 至少不低于自然与 O2。

由此可分开问：

- 数量约束 s 下，F 还丢了多少位置：h_F(s)；
- F 前缀族还有多少决策容量：式 (5) 相对自然；
- 可部署估计在哪些块减少 |k−s|、又在哪些块增加 h_F(k)。

这些问题还未被 +9.43 单独回答。

**Ignore/valid 的计数边界。** 仓库的 ignore/valid 是 scoring-only 信息，主算法只看完整 RGB 画布，不能在部署读取 query truth 或据其裁剪 band、排序、图节点。若评分有无效像素，封存后的诊断须先沿固定 F 顺序过滤它们：令 V_i 为评分有效区，实际输出的有效数量为 k_i^V=|A_F(k_i^{full})∩V_i|，s_i^V=|G_i∩V_i|，t_i^V=|A_F(k_i^{full})∩G_i∩V_i|。式 (2)–(4) 均用这些 valid 计数，带外 I₀/FN₀/FP₀ 与总 S 也只在 valid 区求和，不能把完整 patch 的 k_i^{full} 当作 k_i^V。全前缀族过滤后仍是 valid 顺序的前缀族，式 (5) 的诊断 oracle 可在 k=0,…,|V_i| 上求解；valid 只供评分侧 oracle 与诊断使用，不成为任何可部署估计器的输入。无效像素全空的块对这些计数贡献为零。

## 3 信息来自哪里，不能由哪些门槛判死

### 3.1 F 之外不只绝对 RGB 颜色

允许观测包括参考 RGB 与完整 mask、查询 RGB、同一次冻结编码中可保留的中间 token/QK/V、位置与未归一化响应。最终 F 是这些观测的压缩函数。没有证明所有这些通道都可由 F 重建，就不能说“F 之外只剩 RGB”。

一个建设性信息反例：令同一次编码的两个坐标为 Z=(u,v)，现行 F=u，真实 patch 量为 s=n·v；参考可见 v 与完整 mask 的对应关系。任何只用 u 的规则都可能分不出数量，读取 v 却可以。这不证明实际 DINO 存在这种坐标；它证明由压缩输出的失败不能推出未读取通道的不可能性。已有多层读出失败同样只约束试过的表示与规则。

若第一层 patch 投影保留了未归一化的线性响应，可讨论它含有多少原始像素信息；但后续 unit/LN、attention 和 MLP 不满足一般的 foreground/background 线性混合。W37 的 O24 解混失败不能被重新命名后再当物理面积方程。实际可用的原生响应路线由 [W39 E](W39_E_native_response_REPORT.md) 独立研究；本线不声称它已能估量。

所有冻结特征最终都由 RGB 确定，“新信息”应相对于 F 这个摘要定义，不等于必须增加外部模型。

### 3.2 ρ 既非充分，也非一般必要条件

令 δ=s−k_nat，η=k_est−k_nat。对面积平方误差，精确收益为

\[
E[\delta^2-(\delta-\eta)^2]
=2E[\eta\delta]-E[\eta^2].\tag{6}
\]

即使相关为 1，η=3δ 也使该收益为负。反之，令 δ 独立取 75/125、η 独立取 90/110，各等概率，则 Pearson ρ=0，而式 (6) 为 9,900>0。可取自然量 128，所有自然/真实/估计数量均在 [0,256]，并非非法数量反例。这里是手工代数构造，没有运行模拟。

这是平方误差的例子，不能再换算成同等 mIoU；它足以否定“任何方法必须先达到统一 ρ 门槛”这个一般命题。一个有偏但方向有用的保守动作可能改善决策，一个强相关但幅度错误的动作也可能伤害输出。F 可测的 η 也可能利用 F 中尚未用到的形状或置信度结构，除非另证 E[δ|F]=0，不能一律排除。

因此 W38 的 ρ=.25 是其已写定的具体继续规则；不更改该实验，但不将此门槛继承为所有新构造的理论前置条件。新规则应直接报告完整输出和配对 I/U，并辅以式 (2)/(6) 对应的诊断。

## 4 一个新的可计算候选：参考边界电导的逐 patch 前缀逆问题

### 4.1 机制与允许输入

W38 对每块颜色分离独立选 k；本构造改问：**在保留该块 F 排序时，哪一组局部数量能让整个带内轮廓落在参考所支持的图像边界关系上，同时付出尽量小的自然场改动？**

输入仍只有现行 F、查询 RGB、参考 RGB 与完整参考 mask。无需新模型、额外编码、分辨率提高、oracle 质量或查询标签。输出为完整二值 mask，以及由该 mask 计数得到的每块 k̂_i。这里的 π̂_i=k̂_i/256 是算法给出的占用量，**不是已标定的像素后验或物理 alpha**。

带 B、带外固定 N 的约定与 W37 一致。每块的 F 排序也固定。前景的语义方向来自现行 F 与带外 N；参考边界模型只提供什么 RGB 变化应允许分断的关系证据。

### 4.2 从真实参考边界估计非负电导

将参考/查询 RGB 置于 [0,1]。对无向 4 邻接像素边 e=(p,q)，用

\[
g_e=(|R_p-R_q|,|G_p-G_q|,|B_p-B_q|)
\]

每维固定均分 4 档，得到 64 个 bin。参考 mask 将边分为 FG-FG、BG-BG、跨边界三类。每类先归一化为经验频率，再以固定 η=1/16 与均匀分布混合：

\[
p_c(b)=(1-\eta)\frac{h_c(b)}{n_c}+\frac{\eta}{64},\quad
p_{same}=\tfrac12(p_{FGFG}+p_{BGBG}),\quad p_{cross}=p_{FGBG}.
\tag{7}
\]

先归一化再混合，是为避免纯粹由三类边数量不同、加一收缩强度不同产生虚假的 likelihood ratio；它并未解决小样本不确定性。

对查询边，定义

\[
r_e=\max\!\left(0,\log\frac{p_{same}(b(g_e))}
                                      {p_{cross}(b(g_e))}\right),\quad
w_e=\frac{r_e}{1+r_e}\in[0,1).
\tag{8}
\]

含义是：参考中更像类内变化的边有较大连接代价；更像真实边界或未知的边不强迫连接。没有负电导或“喜欢切开”的负 Potts 项，保留可精确图割的条件。若某类参考边为空，整例保持自然输出；不临时引入另一个颜色模型。查询 bin 在三类参考中都未出现时三者均为 η/64，w=0。

这种校准不同于参考 FG/BG 绝对颜色直方图：它使用相邻差值与参考 mask 的边界标签，而非把某种颜色在跨图中固定认作 FG。也不同于 Otsu 的无标签类间方差最大化。但跨图光照、材质与边界类型改变时，式 (8) 仍可能迁移失败。

**可核对的对称性：** 参考 mask 取补会交换 FG-FG/BG-BG，保留 cross，因此 w 完全不变。本构造本身不能解决补集语义或同边界的任务归属；不能将“参考条件边界关系”夸大为完整 task identification。

### 4.3 联立反求各块的数量

对带内像素 p，设

\[
a_p=|2F_p-1|+2^{-20},\qquad \lambda=1/4.
\]

求二值 m 的下式最小值：

\[
\boxed{\min_m\quad
E(m)=\sum_{p\in B}a_p|m_p-N_p|
 +\lambda\!\sum_{e=(p,q):e\cap B\ne\varnothing}
               w_e|m_p-m_q|}
\tag{9}
\]

约束为：

\[
m_p=N_p\ (p\notin B),\qquad
m_{i,j+1}\le m_{i,j}\quad(j=1,\ldots,n_i-1),
\tag{10}
\]

其中 j 是 patch i 内 F 由高到低的顺序。约束 (10) 使每块恰有某个前缀被选择，k̂_i=Σ_j m_{i,j} 自动成为未知局部数量的解。**没有把 s_i 或 oracle π_i 写进能量。**

λ=1/4 使最多四条物理邻接边对一个像素的总最大代价不超过 1，与 unary 的最大尺度约为 1 对齐；这只是明确、无标签的构造尺度，不是最优参数定理。64 档、η、λ、margin 形式在将来运行前必须作为这一候选固定，不能看分数改到获利。并列采用最小 source-side 的最小割；输入 F、排序和坐标须与自然臂一致。

### 4.4 全局可计算性与默认动作

式 (9) 的 unary 与非负 Potts 项可建 s-t 图。约定 source-side 为 1，对每个排序相邻对加弧

\[
(i,j+1)\longrightarrow(i,j)
\]

其代价为 L>所有有限代价之和；例如

\[
L=1+\sum_{p\in B}a_p
       +\lambda\sum_{e:e\cap B\ne\varnothing}w_e.
\]

若低排名像素为 1 而较高排名为 0，该弧被切断，费用≥L。自然 N 是满足全部前缀约束的可行解，其能量<L，所以最小割不会违约。其余 unary、Potts、固定带外标签分别对应 terminal arc、双向邻接弧与吸收后的 unary。因此一次精确 s-t mincut 得到式 (9)–(10) 的全局最小值。**全局最优指这一个能量，不指真实 IoU。**

这一图表示与求解性质属已有图割理论；有向无限代价蕴含边也已有明确先例，不能作为本方法的创新点。原论文见 [Kolmogorov–Zabih 2004](https://www.cs.cornell.edu/~rdz/Papers/KZ-PAMI04.pdf) 与 [Veksler 2008 §3 Eq.3](https://cs.uwaterloo.ca/~oveksler/Papers/eccv2008Final.pdf)。

默认动作写清楚：参考三类边任一为空、无带、非有限输入、求解未达到事先固定的容量/约束精度时，整例输出 N 并计为该臂结果；不能丢例或临时换估计器。若所有查询 w=0，则 unary 使 N 为唯一解。λ=0 也应严格复现 N，可作为实现身份检查。普通 band 内连接分量即使没接到带外，unary 仍给出良定能量，但没有因此获得真实语义锚。

设带内有 P 个像素。参考直方图 O(HW)，patch 排序 O(P log 256)，图的节点/边数 O(P)，外加每块排序链；最大流为有限规模多项式问题，但不承诺实际近线性用时。没有 P² 全连接像素矩阵，不增加编码器调用；仍须测实际 CPU 时间和峰值内存。一个 token 宽的带约占 8.3% 画面只是 W37 的中位值，不是资源上限。

## 5 这是否真的能从 RGB 边缘得到量

### 5.1 得到的是有条件的逆问题，不是颜色分离即面积

本构造先估计 mask，质量是其像素计数；它不要求 O24 token 是两个端元的线性混合，也不把局部颜色方差最大的位置认作数量。跨 patch 的边与固定带外标签把不同块的停止位置联立；这就是它区别于独立 Otsu 的机制。

若真实带内 mask 在各块确实为 F 前缀，且参考电导能连接真实同类、避开真实边界，式 (9) 可以通过降低无根据的轮廓切割来修正数量。反之，错误带外标签可以向内传播；参考把纹理变化误学成语义边界时会停止过早；真实边界弱于物体纹理时会跨界连接。图割的短边界偏好还可能抹掉细线，不能因用 RGB 就声称解决 Fundus。

有一个明确但未验证的恢复条件。令 M 在带内为真实 mask、带外固定 N，且 M 满足 (10)。翻转任意非空可行像素集合 D⊆B，记 e_p=1[M_p≠N_p]，W_same(D)、W_diff(D) 为 D 与其补集之间、按 M 标签分别同类/异类的电导总和，则

\[
E(M\triangle D)-E(M)
=\sum_{p\in D}a_p(1-2e_p)
 +\lambda\{W_{same}(D)-W_{diff}(D)\}.
\tag{11}
\]

这是展开 unary 和被翻转边得到的恒等式。若对全部非空可行 D 右侧均正，M 就是唯一最优解；如果仅对错误自然像素的有利移动成立，才有该类局部修正的理由。式 (11) 显示最难的条件是**正确类内连接的余量能否压过错误 unary 与错误跨界连接**，而非是否存在某条清晰 RGB 边。它涉及 GT，只是分析条件，不能冒称部署可认证的安全判据。

### 5.2 不可识别和拒识范围

- 查询 RGB 恒定、可见 F 和内部摘要相同，却允许两个不同语义 mask 时，任何本构造都输出相同结果，不能两者都对。参考关系不自动消除任务本身的歧义。
- 两个颜色不同的区域也可能同属目标，或颜色相同的区域分属 FG/BG；RGB 对比不是完整标签。
- 若真实像素不是 F 前缀，约束 (10) 禁止精确恢复。O2 有收益不能移除这一障碍。
- 很细、与带外不相连、并且自然 unary 全部指向背景的结构，正 Potts 电导通常缺少使其出现的理由；这里不承诺召回共同漏检区域。
- 参考图只有一个对象，边数量很多不等于大量独立物体；式 (7) 的稳定性不是跨图置信区间。

目前只有上节的输入/数值默认动作，没有足以保证真值风险的自动拒识证书。可报告 source 边计数、query 未见 bin 比例、电导图和 edit 大小，但不能把这些无标签量命名为已经可靠的“安全门”。

## 7 最小区分控制与正负读法——只设计，不运行

### 7.1 输入、候选与比较固定

将来若进入实验，先另写运行计划，固定一份 S 清单、现行 F 的捕获、band、RGB 处理、算法参数、默认动作和并列规则。T 半、留出集和其它会话执行不用于本轮选择。

主比较应保留以下五个完整输出，不以相关筛选后只跑赢家：

| 臂 | 与主候选的差别 | 所问问题 |
|---|---|---|
| N | 现行 CRF 前自然 mask | 实际净收益；λ=0 必须复现它 |
| R | 式 (7)–(10) 原样 | 参考边界电导与逐块停止位置联立是否有效 |
| G | 保留前缀与 unary，以通用 RGB 距离电导替换式 (8) | 是否只是通用边缘平滑；通用电导用预定非零颜色差中位数作尺度，并将总电导匹配 R，披露此控制不保持每个节点度数 |
| U | 使用 R 的同一能量，但移除排序蕴含链 | F 前缀限制是否妨碍有效位置调整；较低优化能量不自动意味较高 IoU |
| K | 保留 R 的每块数量，改用 U 的标签优先、再按 F/坐标排序取这些数量 | 在完全相同数量下，U 提供的位置变化是否有用；K 的好坏与 R 直接比较，不能归因于新的量 |

U 为二值时排序键明确为 (U_p,F_p,−坐标)，不是把未知 soft posterior 隐含进去。G 的颜色尺度若无任何非零差值时须采用预定默认；R 总电导为零时 G 也置零。电导总量匹配控制幅度的一部分，不保持 cut capacity、局部连通性或 degree；不得把它写成所有数值量完全匹配。

具体固定 G 为：对式 (9) 的同一物理邻接边集 E_B，d_e=||I_p−I_q||₂；若存在 d_e>0，取 σ_Q 为这些正值的中位数，并令 v_e=exp(−d_e²/(2σ_Q²))；若没有正值，则固定 v_e=1。令 w_e^G=v_e·(Σ_{E_B}w_e^R)/(Σ_{E_B}v_e)。E_B 为空或 R 总电导为零时全部置零。最小割的硬容量按 G 的实际有限代价重新计算，不能沿用可能较小的 R 硬容量。这个控制没有查询 GT，也没有颜色尺度备选集。

如果只允许更小的初轮，N/R/G/U 已能区分数量联合优化与通用平滑，K 可作为同轮的预定诊断输出；不能看 U 成绩好后才补 K。无需为所有路线设相同样本量或同一个 ρ 硬门槛。

### 7.2 记录什么才回答问题

完整输出按现行槽池化 I/U 和域口径报告；CRF 前与后分开，若另测 R+CRF，须与同合同 SH+ 比较并保持回退规则。数量/排序分解在同一评分阶段使用 GT，**不参与推理、调参或挑选臂**：

1. Σ|k−s|、Σ2h_F(k) 或各臂实际排序对应的残差，及 FP/FN；保存正负变化，不能只统计被修好的像素。
2. 相对 N 的新增 TP、删去 TP、新增 FP、删去 FP；数量更准但净指标下降时保留反证。
3. 真数量下的 h_F(s)，以及式 (5) 的槽池化前缀 oracle；它们用于判断排序/决策瓶颈，不能作为部署结果。
4. edit 比例、每块实际 k、自然不动病例、回退/失败病例、source 三类边数、query 未见 bin 比例、用时与峰值内存。

统计目标与重复照片依赖沿用 [W34 A5](W34_A5_bootstrap_REPORT.md) 的界限，不能把像素边、patch 或重复 reference 当独立样本。数量/排序计数是机制诊断，不替换官方/开发 IoU。

### 7.3 正、负、混合结果改变什么判断

| 固定结果 | 支持的判断 | 下一步及不允许的升级 |
|---|---|---|
| R 相对 N/G 均有净收益，数量误差下降，排序残差没有抵消收益 | 参考条件边界关系支持了局部停止位置，而非只通用 RGB 平滑 | 才值得独立确认/成本评估；仍未证明所有域泛化或新颖性 |
| R≈G，二者均好 | 主要是既有图像引导平滑/局部化收益 | 可保留工程结果，但不能用 reference 关系作新贡献 |
| U 明显好于 R，K 在相同 k_R 下也更好 | F 位置排序仍有可动作错误，前缀限制过强 | 不能继续宣称缺的只有量；后续位置路线需新计划，不在本轮换主臂 |
| R 数量更准但 IoU 不升，或 K 的排序收益反向抵消 | 小目标权重、排序残差与 FP/FN 代价不能由 MAE 概括 | 依据式 (3) 解释，不用 ρ 或覆盖率 MAE 给负结果改判 |
| R 只产生普遍收缩，通用 G 相同，细线被删 | 短边界偏好与自然 unary 的作用更像原因 | 关闭这个能量/电导构造；不改 λ、门控或目标后宣称同轮通过 |
| R/G/U 都差，而前缀 oracle 与 O2 仍高 | 该关系迁移/能量/默认动作没有把容量兑现 | 关闭这一具体候选，不能关闭 coverage 或全部 RGB 信息 |
| source 关系稳定而 query 失败，或 unseen bin 多 | 单图边界关系迁移假说不足 | 记录外观/语义迁移限制；不从更多 query GT 回填电导 |

## 8 真正还未闭合的条件

**算法定义已经闭合：** 输入、参考边电导、有限参数、二值能量、排序链、全局求解、默认动作与复杂度均已给出，不以 oracle 质量代替估计器。

**条件命题已经闭合：** 式 (2) 的质量/排序计数分解、式 (3) 的 IoU 关系、式 (5) 的真实前缀容量、式 (11) 的能量恢复条件均可直接核对；它们没有证明 DINO 或 RGB 满足语义假设。

**最难的经验条件仍未闭合：** 一张参考的 RGB 邻接关系是否能跨图区分目标边界与物体内部纹理；F 带外标签是否足够可信；F 前缀族是否限制真实位置；保守 unary 与短边界偏好是否会系统漏细结构；组合收益能否超出通用图割/引导上采样及已有先行工作。没有理由在这些问题解决前押定这一线，也没有理由因 C/U 或 W38 单一颜色规则失败而预先关闭它。
