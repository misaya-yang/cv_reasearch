# W23：FoRIS-free 头 SH 的独立实现、准确率与直接计时

2026-10-14。

- 代码：`scripts/x1012/w23_simple_pipeline.py`（`simple_head()` 一个函数完成全部推理）
- 证据：`evidence/research/w23_simple_pipeline_S.jsonl.gz`、`w23_simple_pipeline_T.jsonl.gz`、`w23_timing.json`

## 方法 SH

**输入：** 冻结的 DINOv3 O24 特征（参考和查询各一份）、参考 mask，以及用于 CRF 的查询 RGB。

1. 计算去偏后的单位特征 r 和 q，以及参考在 64² 网格上的覆盖率 y。rho 定义为前景质量中不落在纯前景 token 上的比例。
2. 核迁移 c（点证据）：以 exp(sim/.05) 为权重，计算参考 token 中前景所占的软份额。若 rho > .9，直接返回 minmax(up(c)) > .5。
3. U0 = minmax(up(solve(c_mod)))。其中 c_mod = c × novelty^s，s 由 max-J 规则选择；solve 是在查询 kNN 图 L 上、λ=16 的求解。
4. M′ = 对 p 做排序引导的 λ=16 求解，使用**同一张图 L**（W22 中的 Ash）。p = q·μ_fg − .55·q·μ_bg⊥（原型证据）。
5. 最终掩码：官方 CRF([.5 M′ + .5 U0 > .5])。

完全不调用 FoRIS 的聚类、投票、先验和语义修正。保留了两个通用部件：位置去偏投影和 dense CRF。

## 直接计时

协议：
- 单进程，CPU 2 线程；
- O24 特征在内存中提供；
- 计时包含参考 mask 和 RGB 的读取，以及 CRF；
- 27 个非回退例，丢弃 2 个预热例。

FoRIS 和 MFU 用 `w19_time.py` 在同一时段新跑一次。SH+ 是端到端实测，不是分段相减。

| 方法 | 平均（秒） | 中位（秒） | 相对 FoRIS |
|---|---:|---:|---:|
| 完整 FoRIS | 1.555 | 1.502 | 1.00× |
| MFU | 2.163 | 2.101 | 1.39× |
| **SH+** | **1.282** | 1.237 | **0.82×** |
| SH（不做 CRF） | 0.294 | 0.293 | 0.19× |

- CRF 约 0.96 s，是 SH+ 的主要耗时。C640 可以在不损失准确率的情况下把它减到约 0.46 倍（W21）。
- 整链还要加上编码时间，R+Q 双编码约 3 s。

## W24：继承常数的敏感度（S 半，1,285 例，CRF 前）

- 代码：`scripts/x1012/w24_sensitivity.py`
- 证据：`evidence/research/w24_sensitivity_S.jsonl.gz`

做法：每次只改变一个因素，其余固定在 SH 的取值（w=.5，λ=16，w_bg=.55）。读法在运行前写定：这是敏感度表，不是搜索；只有某个替代值使均值提升 ≥ +0.5、且无一域显著更低时，才考虑更换。

| 变化 | 十域均值（相对 SH） | 显著正／负 |
|---|---:|---:|
| 融合权重 w = .3 / .4 / .6 / .7 | −0.46 / −0.14 / −0.10 / −0.31 | 1/2、2/1、0/2、0/3 |
| λ = 4 / 64 | −0.37 / −0.17 | 2/5、0/3 |
| w_bg = 0 / 1 | −1.20（Lung −4.92）/ −0.10 | 0/4、1/2 |

**结论：** 三个继承值都处在局部最优，SH 不改。

所有替代值都沿同一个轴做交换：

| 变化方向 | 受益的域 | 受损的域 |
|---|---|---|
| 更强的区域整合（λ 更大，或 M′ 权重更高） | COCO、ISIC、SUIM（大目标） | LVIS、PACO、iSAID、Lung、Road（小目标、细结构） |
| 更弱的区域整合 | 小目标、细结构域 | 大目标域 |

这与 W20 中粗粒度先验的结果、C4（按大小选尺度不可行）一致。全局常数只能在这条轴上取折中。

## W25：用 max-J 逐例选择整合尺度 λ——关闭

- 代码：`scripts/x1012/w25_j_scale.py`
- 证据：`evidence/research/w25_j_scale_S.jsonl.gz`

**动机：** W24 显示所有继承常数都沿“区域整合尺度”这一轴做交换。W09 中逐例最优 λ 值 +4.4（oracle），按面积选择 λ 已失败。另一方面，SH 的调制强度本来就由无标签的质量 J 逐例选择，去掉它会损失 1.31。J 还没有用来选 λ。

**做法：** 对每例计算 λ ∈ {4, 16, 64} 下的 SH 掩码（CRF 前），取 J 最大者。

| 臂（相对 SH） | 十域均值 | 显著正／负 |
|---|---:|---:|
| λ=4 | −0.37 | 2/5 |
| λ=64 | −0.17 | 1/3 |
| **按 J 选** | **−0.38** | 2/4 |
| 三选一 GT oracle（诊断） | +1.57（10/10 ≥0） | 9/0 |

J 选择 λ=4 的比例为 79%（863/1,090），而 oracle 的分布为 4 : 64 : 16 = 470 : 458 : 162。J 选中 oracle 的比例为 44.6%。

**结论：** J 在不同尺度之间不可比，偏向小 λ。它能选调制强度，但不能迁移到尺度选择，这条路线关闭。逐例尺度余量（三选一 +1.57）仍然存在，但到目前为止没有可用的无标签信号。
