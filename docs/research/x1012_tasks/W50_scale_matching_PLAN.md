# W50：迁移失败是不是因为参考与查询的目标大小不同

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。

## 1 动机

- **[W48](W48_reference_specificity_PLAN.md)：** 迁移是 SH 最大的损失。十域 mIoU 自参考 75.7，真参考 53.6，差 22 点。
- **[W46](W46_transfer_PLAN.md)：** 迁移偏差不是协方差偏移，也不主要是参考特有的伪相关。
- **运行前的描述性分析**（W48 逐例数据，未预注册，只用来提出问题）：
  - 迁移损失（自参考 − 真参考的逐例 IoU）随参考与查询目标的面积比 |log₂(q/r)| 对称增大：
    - |log₂| < 1：+.134（649 例）；
    - 1–2：+.19–.21；
    - 2–4：+.27；
    - > 4：+.38–.47；
  - Spearman ρ = .31；排序质量（最佳阈值 IoU）也随之下降；
  - 面积相近的例子仍贡献约 35% 的总损失。
- **假设（尺度）：** DINOv3 的 patch 特征对物体尺度不是不变的。同一类物体，占 2 个 token 时 token 编码的是“整个小物体加周围环境”；占几百个 token 时编码的是“物体内部的局部纹理或部件”。参考与查询尺度差得多时，参考前景 token 与查询目标 token 不在同一个特征区域，核迁移与原型都找错。
- **可检验的预测：** 把参考图缩放到使参考目标的面积占比等于查询目标的占比，再编码、再跑同一个 SH，尺度不匹配例子的迁移损失应明显收回。若收不回，尺度只是相关量，不是机制。

## 2 设计

**样本：** W37–W49 同一批 1,285 个 S 例。T 半和新照片留出都不读。

**编码：** 冻结 DINOv3-L/16（timm `vit_large_patch16_dinov3`，同一权重），MPS 单进程。输入经官方 `build_transform(1024)`（拉伸到 1024×1024、ImageNet 归一化）；O24 取 `forward_features` 去掉前缀 token 后的 4096 × 1024，与缓存的定义（model.norm 输出）相同。

**臂（SH 本身一律不改，只替换参考图像、mask 与特征）：**
- **id：** 原参考图重新编码，不缩放。用作比较基线，同时检查编码是否复现缓存特征；
- **match（oracle，诊断）：**
  - s = sqrt(q / r)，截断到 [1/8, 8]。q 为查询 GT 在 1024 帧中的面积占比（只用这一个标量），r 为参考 mask 的占比；
  - **s ≥ 1（放大）：** 在原分辨率的参考图（含官方 crop）上，以参考 mask 的质心为中心取边长为原图 1/s 的窗口（两轴分别按比例，越界则平移到图内），裁剪图像与 mask，再走同样的变换；
  - **s < 1（缩小）：** 把 1024 帧的参考图与 mask 缩小到 1024·s，居中贴到 1024 画布上。画布颜色取 ImageNet 均值（124, 116, 104），mask 为背景。
- **SH：** 与 W48 相同，调用 `w42.capture`（CRF 前），只替换参考的特征与 mask（在内存里替换 `rc.raw` 与 `lab.mask1024` 的返回值）。自参考取 W48 的 self0。

**指标：** 逐例 IoU（`c.iu`）、最佳阈值 IoU；class mIoU 十域，区间用 `w37._boot`。

## 3 读法（运行前写定）

1. **实现检查：** id 与缓存特征逐 token 余弦的中位数 > .999，且 id 与 W48 真参考的逐例 SH IoU 相差 < .01 的例子 ≥ 95%。不满足就停，不解读后面的量。
2. **尺度收回率（主读法）：**
   - 取 |log₂(q/r)| ≥ 2（面积差 ≥ 4 倍）的例子，R = mean(match − id) / mean(self0 − id)，用逐例 IoU；
   - 放大（q > r）与缩小（q < r）两侧分开报告。
   - **R ≥ 50%：** 尺度不匹配是这些例子迁移失败的主要机制。下一步研究不看查询 GT 的尺度选择，例如参考的多尺度编码加一致性准则；
   - **R < 20%：** 尺度只是相关量。面积差大的例子通常同时有别的差异（实例外观、上下文、部件与整体），下一步按 W48 的错配对照找别的因素；
   - **两者之间：** 按数值记为“部分”。
   - 若只有一侧 ≥ 50%，分别下结论（缩小一侧有画布伪影的可能，见第 4 条）。
3. **整体：** 十域 mIoU 的 match − id 及区间；|log₂| < 1 的例子上 match − id（这里 s ≈ 1，应接近 0，作为对照）。
4. **缩小一侧的画布：** 画布 token 是人为的背景。若缩小一侧的 match 在 |log₂| < 1 的对照上也明显偏离 id（|Δ| > .02），说明画布本身有影响，缩小一侧的结论只作参考。
5. 用了查询 GT 的面积，只作诊断，不是方法；不读 T。
