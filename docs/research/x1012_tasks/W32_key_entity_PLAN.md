# W32：冻结编码器的注意力 key 是否携带实体结构

2026-10-15 凌晨写定，W30 运行期间以最低优先级执行。第 1–3 节在运行前固定，执行中不改。

## 1 动机（来自哪些已有结果）

**范围误差的形态（本日新看，K0 的 S 样本，1,090 个非回退例）：**
- 九级候选里，自然切点在 47% 的例子中已是最优；其余例子两侧都有，总体无偏：

  | 域 | 过分割 | 欠分割 |
  |---|---:|---:|
  | 部件域（PASCAL-Part、PACO） | 22–29% | 35–38% |
  | LVIS、iSAID、COCO | 30–48% | 13–21% |

- 16 个最差例的可视化显示，两类错误都是实体级的：
  - 过分割：溢出到相邻的另一个实体，例如风筝 → 旁边穿彩衣的人，飞机 → 登机桥，病灶 → 周围色素皮肤；
  - 欠分割：只取了与参考最像的核心，漏掉同一实体的其余部分，例如火车后段、整片珊瑚、病灶的浅色部分；
  - 切线穿过了查询图的实体边界。

**已知 O24 输出特征不按实体分组（W15）：**
- 查询 kNN 图几乎全连通，前 10 个特征值都 > .995；
- K ≤ 16 的谱分组即使由 GT 选片段，也低于切点 oracle。

**试点（6 例，CPU，不计结果）：**
- 遮掉核心后，同一实体 token 的特征变化只在 1 个 ISIC 例中明显大于非实体；
- 火车、珊瑚两例无差异。输出特征的上下文依赖通道信号弱。

**未覆盖的通道：** 文献中的无监督物体发现（LOST、TokenCut、Deep Spectral Methods）用自监督 ViT 末层注意力的 **key** 和**稠密非负亲和**来分组物体，而不是输出 token 和 kNN 图。W15 两者都没试。

## 2 设计

**样本：** 与 W15 完全相同，416 例。
- 样本由 `w15_query_extent.sample()` 给出：S 半，rho ≤ .9，每域 ≤ 50 例；
- 范围场仍用 W15 的 G = .5·mean + .5·minmax(VP_UN)，以便和 W15 的数字逐项可比；
- T 半和新照片留出都不读。

**编码：**
- CPU、FP32，与 O24 同一份 timm DINOv3 ViT-L/16 权重，输入为同一 1024² 变换；
- 一次前向同时取：
  - 末块注意力的 key：k_norm 之后、RoPE 之前，去掉 5 个前缀 token，16 个头拼接成 4096×1024；
  - O24 输出：经 `lab.debias`。
- 不写特征文件，只保存分组标签与指标。

**分组（无参考、无 GT）：**
- `kspK`：key L2 归一化后，稠密亲和 W = max(0, cos)，对角置 0。对 D^-½ W D^-½ 取前 32 个特征向量，行归一化后做 k-means（NJW，种子与 W15 相同），K ∈ {4, 8, 16, 32}；
- `ospK`（对照）：同样的稠密构造，改用去偏 O24 输出。用来区分收益来自 key 还是来自稠密亲和。

**度量：** 与 W15 相同。
- `SO_g`：由 GT 选片段的最优并集；
- `rule_g`：片段内 ≥ 50% 有效像素在自然掩码内则保留，与 token 量化的自然掩码 natQ 比较；
- 两组各报前 10 个特征值。

## 3 读法（运行前写定）

切点 oracle（orc）、前 20% 余量例的划分，均与 W15 相同。

- **R1 容纳性（前 20% 余量例）：**
  - SO_ksp8 或 SO_ksp16 ≥ orc + 5：key 空间装得下正确范围，值得设计选择规则（下一步写 W33，在 S 上验证）；
  - K ≤ 16 的 SO_ksp 全部低于 orc：冻结编码器内部（输出与 key）都没有可用的实体结构，关闭这条通道；
  - 介于两者之间：只报告，不据此继续，除非 R2 通过。
- **R2 可部署规则：** rule_kspK − natQ（class mIoU）在 ≥ 7/9 域 ≥ 0，且均值 > +1，就在此基础上构建。
- **对照：** 若 osp 与 ksp 相差不到 2 点，收益归因于稠密亲和的构造而不是 key，写进结论。
