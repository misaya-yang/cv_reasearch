# W27：最终 SH 的严格单线消融

2026-10-14，按用户要求执行。以下定义、样本与读法在新增预测和结果分析之前写定。

## 1 动机与决策用途

W19 显示用原型分数替代 FoRIS 后仍能保持融合准确率；W23 又统一了两条线使用的去偏特征与查询图，得到最终 SH。现有 MFU/W19 单线结果不能直接替代最终 SH 的匹配控制。本次只检验最终 SH 的点证据与原型证据是否互补，不改变方法，不继续 W26 的尺度选择路线。

正结果支持“最终 SH 的固定融合在本机 S 半总体优于两条单线”；负结果或域间取舍则收窄该主张。不由此选择新权重、阈值、CRF 配置或下一变体。

## 2 固定样本与六个臂

- 样本为 `w23_simple_pipeline.rows_for('S')`，即 W23 同一批 1,285 例；有序索引与 `w23_simple_pipeline_S` 核对后冻结。
- 各域例数：COCO/LVIS/PASCAL/PACO/SUIM/ISIC 各150，iSAID110，Lung105，Fundus108，Road62。非回退共1,090例。
- 只读这些 S 任务的缓存 O24、合法参考 mask、查询 RGB；预测封存后才读这些 S 任务的查询 GT。T 半及新照片留出的 manifest、输入、预测和评分记录均不读取。
- 所有字段直接来自冻结的 `w23_simple_pipeline.simple_head` 同一次调用：只对它调用的两个求解函数作返回值捕获，不改变其返回值、特征、图、计算顺序或参数。

| 臂 | CRF 前定义 | CRF 后定义 |
|---|---|---|
| U0 | `minmax(up(solve(c_mod, log_e, L, 16))) > .5` | 同一个官方 CRF |
| M′ | `up(mean_solve(p, guide, L)) > .5`，不额外 minmax | 同一个官方 CRF |
| SH | `[.5*M′_field + .5*U0_field > .5]` | 冻结 `simple_head` 原样返回的 SH+ |

所有臂保留 rho>.9 的原回退：六个掩码均等于该回退掩码，不运行 CRF。Fundus 全部回退，因此该域只能报告相等，不能作为融合互补的证据。阈值、权重、λ、原型背景权重及 CRF 均不调整。

## 3 实现与检查

- 新代码 `scripts/x1012/w27_sh_single_line.py`，命令 `produce` / `check` / `report`。
- 输出 `../cv_data/a/x1013_W27/`，每例一个外置压缩掩码文件和一条 JSONL 完成记录，支持断点续跑。全部预测齐全并封存后才评分。
- 最多4个worker，每个torch 2线程；开跑前检查top，目标保留约30% CPU，内存紧张时减少worker。
- 不调用编码器，不改冻结源码、不覆盖旧产物、不删除文件、不做Git提交。
- 检查后才解释结果：
  1. 每个非回退例恰好捕获一次 U0 求解、一次 M′ 求解，且二者使用同一个 L；每例只请求两份缓存 O24，编码器调用为0。
  2. 捕获字段重组成的融合掩码与当前冻结 `simple_head` 的 CRF 前输出逐像素一致，所有回退例六臂一致。
  3. 1,285例的融合 SH/SH+ 整数 I/U 均须与 W23 保存记录一致；若不一致先排查实现，不据此调整方法或进入结果解释。

## 4 指标、报告与事先读法

- 主指标：每域 `(fold,class)` 内池化 I/U 后槽等权，再十域等权；不把逐例 IoU 均值当作该指标。
- 主比较：`SH+−U0+`、`SH+−M′+`。同时完整报告 CRF 前 `SH−U0`、`SH−M′`。
- 逐域报告六臂绝对 mIoU、上述四项差值、三条线各自的 CRF 后减 CRF 前、照片成组95%配对bootstrap区间。
- 逐域区间复用 `score.paired_ci`（500次，rng=`c.SEED`）。十域均值区间采用域内按查询照片成组重采样、域间等权的500次分层bootstrap（独立rng=`c.SEED+1`），每次保留出现的槽口径；三条线和CRF前后使用同一组重采样权重。
- 另报告非回退子集（1,090例、9个有样本的域）相同主比较，避免把共同回退收益归给融合。Fundus无非回退例，不伪造该域的条件分数。
- FoRIS只取同例的既有 S 半 `x1013_E1_iu`，作为上下文参照，不新增基线运行。

读法：
1. 若两个 CRF 后主比较的十域平均增益95%区间下界均>0，可写“在本机S半匹配消融中，固定融合总体优于两条单线”。逐域是否同样成立另按逐域结果说明，不把总体改写成逐域全优。
2. 若只胜一条，或任一主比较区间含0/为负，不能写“稳定优于任一单线”；如实写出优势、区间和域间取舍。
3. CRF前后两套结果说明互补是否在精修前已存在，以及CRF是否改变结论；共同回退不作为互补证据。
4. 本次全为开发 S 数据，不新增独立确认。SH 的新照片、官方主表和 GPU 端到端速度主张仍需服务器实验；本次不启动它们。
