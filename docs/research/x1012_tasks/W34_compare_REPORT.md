# W34 对比：Claude 推导 × Astra 九路报告

2026-10-15 凌晨。

**对比的材料：**
- Claude：[W34_theory_REPORT_claude.md](W34_theory_REPORT_claude.md)；
- Astra：[A1](W34_A1_identifiability_REPORT.md)、[A2](W34_A2_partition_REPORT.md)、[A3](W34_A3_bayes_iou_REPORT.md)、[A4](W34_A4_minimax_REPORT.md)、[A5](W34_A5_bootstrap_REPORT.md)、[A6](W34_A6_noninferiority_REPORT.md)、[A7](W34_A7_fusion_REPORT.md)、[A8](W34_A8_spectrum_REPORT.md)、[A9](W34_A9_cls_REPORT.md)。

两边独立完成：Astra 不接触数据；Claude 用 S 半的现有证据核对了能核对的推论。本文新增的三项数据核对都只用 S 半证据或清单结构，不读 T 半、新照片留出的 GT，也不读 W30 的未封存输出。

## 1 总评

- **两边独立得到的核心结论一致：**
  - 只用场决定不了范围；
  - 需要场以外的结构，例如实体划分，加上参考指定选哪些格；
  - 汇总比值的阈值规则、嵌套族的几何中点极小极大、十域非劣效用交并检验、固定 ½ 融合的条件极小极大，两边都推出来了，而且形式相同。
- **Astra 更严谨的地方：** 量词、模型层次、反例都更完整，并纠正了 Claude 的三处过强说法（第 4 节）。
- **Claude 独有的贡献：** 数据裁决。
  - 两条线夹住真值（83% / 83%）；
  - T8 锚定定理及其 ρ 筛查；
  - W32 的实测阴性；
  - 以下两项是本次新核：Astra A4 的几何中点规则在用场给出上下界时**不通过筛查**；Astra A5 的簇依赖风险在官方协议上**确实存在且很大**。
- **共同的瓶颈：** Astra 的全部建设性方案（A1 §10、A2 §10、A3 §8、A4 §12、A7 §9、A8 §6）都依赖一个“场以外的结构来源”：
  - 纯的实体划分；
  - 跨图可交换的片段分数；
  - 或可迁移的边关系。

  今天的 W32 排除了其中最直接的一类（key 或输出的全局谱分组）。下一步的核心问题就是：**找到一个能通过 T8 筛查的结构来源。**

## 3 本次新增的数据裁决

### 3.1 用场给出上下界时，Astra A4 的几何中点规则不通过 T8 筛查

**规则：**
- U0 和 M′ 的面积作为 [l, u]；
- 取 F 的 top-k，k = √(|U0|·|M′|)。

这是 A4 的极小极大规则，加上 Claude 的“两线夹住真值”。

**在 1,090 个非回退 S 例上：**

| 量 | 值 |
|---|---|
| corr(η, δ) | +0.096 |
| E[η²] / 2E[ηδ] | 0.153 / 0.049，不满足改进条件 |
| 均方误差 | 自然 0.713 → 几何中点 0.817 |
| 逐例平均 IoU（取最近一级） | 自然 61.60 → 59.19，oracle 69.58 |
| 两线真正夹住真值的 392 例中的相关 | .074 |

**解读：**
- A4 的定理没有错，但它的前提“真值在 [l, u] 内”不能由场来保证：同号的占 64%；
- 在场可测的前提下，它再次落入 T8；
- 结论：**极小极大规则的上下界，必须来自场以外的结构。**

## 4 采纳的修正（Claude 稿中相应表述降级）

1. **T1：** “范围一般不可辨识”改为“在场压缩层，存在场相同而 GT 差 k 倍的双世界”。不由 E4 推出“冻结表示没有范围信息”（A1）。
2. **T4：** “多裁剪迫使 CLS 不变”改为“在‘语义核心 + 异质外围’的条件模型下，比较分数偏向小核心”（A9）。
3. **T6：** “谱间隙 = 语义类型簇”降为猜想；公共正分量同样能造成快速衰减（A8）。
4. **T5：** δ = 1.0 只能作为“E2 开封前写定的分析选择”，不能称预注册，并要附 δ 敏感性（A6）。
5. **T3：** “统一目标”的说法收回。SH 不是单一图目标的解；只能说每条线各自是一个二次能量的解（A7）。

## 5 汇合后的判断与下一步（都需要先写读法并经用户同意）

**判断：**
- 新的范围信息必须来自场以外，并且必须先通过 T8 的 ρ 筛查（约 150 例，只需九级梯度）；
- Astra 的构造（闭包求交、证书式修正、conformal 编辑）提供了**拿到结构之后**如何安全使用的接口，并且都保留自然 SH 作为回退。这比以往“选一个切点”的做法更稳；
- 缺的仍然是结构来源。

**候选结构来源（按“新信息 × 成本”排序）：**

1. **A8 §6 的参考监督边关系迁移。**
   - 做法：在 4 邻边上比较 key 各头的**内部对比关系**（对每张图做仿射不变的归一化），由参考掩码把边标为“同前景内部”或“前景边界”，迁移到查询；不确定时弃权，只生成局部候选。
   - 它不是 F 可测的，T8 不能先验排除。
   - 成本：需要编码，CPU 约 40 s/例；或者 W30 之外的 MPS 空档。
   - 先做的诊断：加权错误连接率、同侧可达率，再过 ρ 筛查。
   - 负面先验：旧的角色边构造（O24 绝对外观）失败了，W32 的 key 全局分组也失败了。
2. **T7 覆盖率诊断（Claude）。**
   - 不需要编码器，只用缓存字段、GT 和 RGB；针对边界带约 8～9 点的余量；方法内在，不提高分辨率。
   - 先用真实 π 测三种读出的容量，再测 c 和解混得到的 π̂。
3. **A3 §8 的 conformal 片段编辑。** 需要纯划分，还要参考与查询可交换，目前两者都没有。等第 1 项有结果再说。

**W30 相关（E2 开封前）：**
- 追加双向乘积权重 bootstrap 作为敏感性分析（第 3.2 节）；
- δ 的处理按第 4 节第 4 条。
