# W34 理论题：Claude 的推导与数据核对

2026-10-15 凌晨。题面见 [W34_theory_PLAN.md](W34_theory_PLAN.md)，记号和 E1–E16 都沿用题面。

本文件和 Astra 的回答相互独立，回来后逐题对比。凡是能用现有证据检验的推论，都已在 S 半的开发数据上算过，标为 **【已核】**。没有读取 T 半或新照片留出。

## 总结（先看这里）

1. **范围误差是“实体归属”问题，而且只集中在一条带上。**
   - **数据：** U0 和 M′ 正好夹住真值（【已核】，T3）。
     - 融合场偏大的 311 例中，U0 更好的占 83%；
     - 融合场偏小的 263 例中，M′ 更好的占 83%；
     - U0 面积的中位数偏小（log₂ −0.80），M′ 偏大（+1.55）。
   - **含义：** 两条线之间的分歧带就是不确定区。要回答的问题只有一个：这条带属于核心所在的实体，还是另一个实体。
2. **只用场本身做选择，在理论上就不可能胜过自然切点（T8）。**
   - 只要选择量只依赖场 F，它引起的偏移就与真实范围误差条件无关；它只增加方差，不带方向信息。
   - 判据：E[η²] < 2E[ηδ] 才可能改进。【已核】J 和 CLS 都远不满足：
     - J：相关 +0.084，方差 .257 对“两倍协方差” .070，均方误差 .713 → .890；
     - CLS：相关 +0.073，方差 1.35，均方误差 → 1.89。
   - 二十多个读出 / 选择实验失败，是同一个原因。
   - 以后任何新信号都先过 **ρ 筛查**：约 150 例、只需候选梯度，ρ 的下界 > 0 才进入正式实验。
3. **可辨识的充分结构是查询的实体划分（T1）。**
   - 任何划分都满足 IoU ≥ 1 − η − ε。η 是划分不纯度，ε 是片段身份判错的质量，而 ε 正是我们强项（排序）的问题。
   - 关键是要在粗尺度（片段少）上同时做到 η 小，这样片段级判断才能聚合足够的证据。
   - W15 证明 O24 输出 + kNN 图做不到。
   - **W32 已测，同样做不到：** 末层 key、O24 输出、稠密亲和，前 20% 余量例上 K ≤ 16 的 oracle 为 43.7–55.9，切点 oracle 为 71.4。
   - 这一阴性只关闭这些构造。
4. **边界带是另一个独立的、方法内在的方向（T7）。**
   - 对直边，覆盖率若准确，双线性插值后取 .5 的误差 ≤ 1.4 px；
   - 所以边界带约 8～9 点的损失主要来自覆盖率**估计**，而不是重建。
   - 核迁移的 τ = .05 很尖，c 接近二值，丢掉了亚 token 信息。
   - 可以检验的新构造：在查询自适应的前景 / 背景均值之间做线性解混，得到 π̂；遇到细结构时，按 RGB 在每个 patch 内取 top-k 像素。
5. **统计（T5）：**
   - 要主张“十个都不低于”，用交并检验即可，不需要多重校正；
   - 非劣效边界 δ 必须在看 E2 结果前写定。建议 δ = 1.0：复现值与发表值的最大差为 0.57（Fundus）；
   - 已修正 W30 E2 的 bootstrap：w12 会把缺席的类记为 0。E2 还没评分。
6. **真正的 0→1 候选：“身份 × 实体”分解。**
   - 参考只决定是哪个概念；范围由同一个冻结编码器给出的查询实体结构决定；
   - 理论上，T1 给出充分性，T8 给出“只用场”的不可能性，T4 说明为什么整体比较看不到完整性；
   - W32 已排除末层 key 和输出的谱分组，实体信号需要换来源；
   - 在找到能通过 T8 ρ 筛查的来源之前，最具体、可以马上做的方法方向是 T7（边界带与覆盖率）。

## T1 范围的可辨识性：需要什么额外结构

### 设定

- **记号：**
  - 查询像素（或 token）集合为 Ω，GT 为 $S \subset \Omega$；
  - 场规则：决策 $D = \Phi(F, A)$，其中 F 是由 token 相似度得到的分数场，A 是任意查询特征亲和结构（例如 kNN 图）。
- **两个假设：**
  - **语义特征假设：** 冻结特征主要编码“是什么类型的外观”，较少编码“属于哪个实体”。W15 的 kNN 谱不按物体分组，可以作为佐证。
  - **实体级 GT：** GT 是若干实体（或部件）的并集。

### 命题 1.1：只用场时，范围不可辨识；歧义的代价

存在两个输入，它们的 (F, A) 相同，但 GT 不同：
- $S_1 = C$；
- $S_2 = C \cup B$，其中 $|B| = (k-1)|C|$。

两个输入的构造：
- 世界 1：B 是相邻的另一个实体，外观与参考部分相似；
- 世界 2：B 是同一实体中与参考外观不同的部分。

只要 B 的 token 在两个世界里得分和亲和相同，(F, A) 就无法区分它们。E6 的风筝和人、珊瑚，E15 中“干扰物峰值中位数为真实峰值的 .62、漏实例处于背景水平”，都给出了实例。

**任何规则的代价：**
- 取 $D = C \cup B'$，$|B'| = x|C|$。则 $\mathrm{IoU}_1 = 1/(1+x)$，$\mathrm{IoU}_2 = (1+x)/k$；
- **极小极大值**为 $1/\sqrt{k}$，在 $x = \sqrt k - 1$ 处取得（对冲）；
- **先验为 π 时的贝叶斯期望**为 $\pi/(1+x) + (1-\pi)(1+x)/k$。它对 x 是凸的，所以最优解在端点，即全押一边；最坏情况是 $1/k$。

**与数据对照：**
- 自然切点等于“全押”：押对时 IoU 高，押错时约为 $1/k$ 乘以实体内的质量；
- 前 20% 余量例：自然 39.3，oracle 68.7，比值 .57，相当于平均 k ≈ 1.8–2，并有部分押对；
- 这与 W14“面积错 2–5 倍”一致。

### 命题 1.2：实体划分的充分性

**定义：**
- 划分 $P = \{P_k\}$；
- 不纯度 $\eta(P) = \sum_k \min(|P_k \cap S|,\ |P_k \setminus S|) / |S|$。

**结论：**
1. 按多数取片段：FN + FP = η|S|，所以 $\mathrm{IoU} = (|S| - FN)/(|S| + FP) \ge 1 - \eta$。
   - 证明：$(a-x)/(a+y) \ge (a-x-y)/a$ 等价于 $0 \ge -xy - y^2$。
2. 若可部署的片段分类器还额外判错了 ε|S| 的质量，则 $\mathrm{IoU} \ge 1 - \eta - \varepsilon$。

**含义：**
- 范围问题被拆成两部分：划分质量 η，以及片段级的身份判断 ε；
- 身份判断在片段级可以聚合很多像素的证据，这正是我们排序强的地方（E1）。

**尺度的取舍：**
- 细划分（km64）的 η 小，但每个片段只有一两个 token，ε 退化为逐 token 判断。W15 中多数规则相对 natQ 为 −1.30；
- 粗划分若不按实体，η 很大。W15 的 K16 只有 60.5；
- 只有“粗且纯”的划分（实体级）同时让 η 和 ε 都小。

### 命题 1.3：粒度如何进入

- 给 R 一个层级 $H_R$。取 $\ell^*(M_R)$ 为使 $M_R$ 的不纯度 ≤ ε₀ 的**最粗**层：
  - 若 $M_R$ 是“狗头”，最粗的一致层是部件层；
  - 若 $M_R$ 是“狗”，则是物体层。
- 把 $\ell^*$ 迁移到 Q 需要两个条件：
  - (i) 两图的层级在语义上对齐；
  - (ii) 层级与实体一致。
- **历史实验：** 由参考选择凝聚粒度得 42.5，oracle τ 也只有 48.4（E13）。即使给 oracle 层也低，说明失败的是 (ii)，层级本身不按实体。
- **预测：** 换成与实体一致的层级（若 W32 的 key 是）后，同样的规则会有效。

### E5 在这个模型下的解释

- 部件域以欠分割为主：部件小、内部外观变化大（同一部件中只有与参考相似的子区域得分高），所以实体内的得分方差大。
- 物体域以过分割为主：杂乱场景中相邻的相关实体得到中间分，所以实体间的得分重叠大。

### 可检验的推论

1. 对任何划分族，用 GT 分别测 η 和 ε，看是哪一项主导部署误差。只需缓存的场和 GT，便宜。
2. **分歧带上的实体判定：**
   - 只在 U0 与 M′ 的分歧带内，评估“与核心同片段就并入，否则排除”的规则；
   - 对比自然切点在带内的准确率；
   - 这把问题隔离到真正不确定的区域，比全图 SO 更敏感。
3. 若某个划分族在带内的不纯度明显低于 kNN 谱分组，它就是值得做方法的实体信号源。

**证伪：** 若 key / 稠密亲和的粗划分在带内的不纯度不低于 kNN 谱分组，就说明“编码器内部有实体结构”这一前提不成立。

## T2 划分给定时，片段级决策的最优规则

### 命题 2.1：汇总比值目标的最优解是按纯度取阈值

**设定：**
- 片段 k 的期望 GT 质量为 $\mu_k$，大小为 $n_k$，全图期望 GT 为 G；
- 目标：最大化 $R(D) = \sum_{k \in D} \mu_k \,/\, \big(G + \sum_{k \in D}(n_k - \mu_k)\big)$。

**Dinkelbach 推导：**
- $R^*$ 是最优值，当且仅当 $\max_D \sum_{k \in D}[\mu_k - R^*(n_k - \mu_k)] - R^* G = 0$；
- 内层对片段可分，所以纳入片段 k 当且仅当纯度 $\pi_k = \mu_k / n_k > R^* / (1 + R^*)$；
- 做法：按 $\pi_k$ 排序，取最优前缀。这正是 W15 `seg_oracle` 的结构，只是把 GT 换成期望。

**阈值数值：**

| $R^*$ | .4 | .5 | .6 | .9 |
|---|---:|---:|---:|---:|
| 纳入阈值 | .286 | .333 | .375 | .474 |

**两个指标：**
- 官方指标对同一类的多个例子汇总 ΣI/ΣU，决策仍按例子可分，阈值由类级的 $R^*$ 决定，各例共用；
- 大目标的例子只是权重更大，不改变阈值；
- 逐例 IoU 的期望在像素多时近似为 E[I]/E[U]，结论相同。

### 命题 2.2：标定未知时，纯片段让决策对标定不敏感

- 设 $\pi_k = h(\text{统计量})$，h 单调但未知。排序没问题，未知的是切在哪一个前缀上，也就是片段级的范围标量。
- 若片段近似纯（$\pi_k \in \{0, 1\}$），纯度呈双峰，切点落在两峰之间的大空档里，结果对 h 不敏感；
- 不纯时，切点位置重新依赖标定。

这从另一个角度说明，**纯度比规则更重要**。

### 命题 2.3：片段统计量的选择

| 场景 | 最优统计量 |
|---|---|
| **纯片段**，片段内是“典型核心（高分）+ 非典型部分（中分）”的混合，干扰物片段为单峰中分 | 区分两类片段的是“有没有高分子区”，似然比近似单调于**上分位数**，例如 75% 分位 > t |
| **不纯片段**（核心与相邻干扰物同一片段） | 上分位数会把干扰物带进来；**中位数（多数）**在最坏情况下最稳 |

**预测：**
- 若有粗而纯的划分：上分位数规则在欠分割例上收益大，中位数规则在过分割例上收益大；
- W15 的 km64 片段太细，两者都约等于 natQ，与已测的 −1.30 一致。

**建议：** 下一步若做片段级规则，事先只登记“中位数”“75% 分位”两个候选，不扫描分位数。

## T3 两条线融合的理论

### 【已核】数据事实（1,090 个非回退 S 例，W27 单线 × K0 方向）

| 组 | 例数 | M′−U0 的 IoU 均值 | M′ 更好的比例 | U0 面积 log₂ 中位 | M′ 面积 log₂ 中位 | SH 面积 log₂ 中位 |
|---|---:|---:|---:|---:|---:|---:|
| 融合偏大（oracle s < 0） | 311 | −14.9 | 17% | +0.54 | +1.55 | +0.85 |
| 自然最优 | 516 | −6.2 | 34% | −0.05 | +0.23 | +0.03 |
| 融合偏小（oracle s > 0） | 263 | +14.8 | 83% | −0.80 | −0.04 | −0.48 |

- Spearman(M′−U0, oracle s) = .50；
- 两线面积误差同号的占 64%，36% 的例子两线夹住真值；
- 各域 M′−U0 的均值：COCO −2.8，LVIS −8.3，PASCAL −0.8，PACO −5.2，SUIM +0.4，iSAID −5.9，ISIC −1.3，Lung −8.3，Road −1.6。

### 模型

- **U0 是 Nadaraya–Watson 回归**（核宽 τ = .05，很尖）：
  - 典型外观上偏差小；
  - 遇到参考中没有的外观时外推失败，只取与参考相似的核心 → **偏小线**；
  - 解释度权重和图求解只能局部传播。
- **M′ 是线性判别**（方向 $\mu_{fg} - .55\,\mu_{bg\perp}$）：
  - 参数化，能平滑外推到语义相近的外观，所以能覆盖非典型部分；
  - 同时也会推广到语义相关的干扰物 → **偏大线**。
- **逐域预测：**
  - 类别多、相关类别相邻的物体域（COCO、LVIS），M′ 的过度推广代价大；
  - 外观变化大的 stuff 或病灶（SUIM、ISIC），M′ 的推广收益大；
  - 这与 E11 的逐域取舍以及上表各域均值一致。

### 命题 3.1：融合是在两条有相反面积偏差的估计之间对冲

- **两条线的面积误差：** 在 log 面积上记 $e_U \approx -b + \epsilon_U$，$e_M \approx +b' + \epsilon_M$；
- **对冲为何有利：** 场平均后，切点大致落在两者之间。对嵌套集合，IoU ≈ $2^{-|e|}$。在两线异号（夹住真值）的那 36% 中，中间位置的 |e| 小于两端；同号时，中间位置的误差也介于两者之间；
- **与命题 1.1 的关系：** 命题 1.1 说“全押优于对冲”，前提是真值恰好在两个候选之一上。这里真值是连续分布的，单线各自还有噪声，对冲因而是有利的。

### 命题 3.2：为什么逐例权重做不到更好

- 逐例最优权重 $w^*_e$ 取决于这一例是“偏大型”还是“偏小型”；上表说明它与 oracle 方向几乎一一对应；
- 由 T8，这个方向不能由场决定；
- 所以任何由场决定的逐例权重，都只给固定权重增加方差；
- 在方向无信息、两线偏差对称时，固定 ½ 是极小极大的选择。

这解释了逐例选尺度、选 λ、选线一再失败（W16、W25、W26）。

### 统一目标（可写进论文方法节）

- **单线：** 两条线分别是 $\min_f \sum_i a_i (f_i - s_i)^2 + \lambda f^\top L f$ 的解，unary 分别为核迁移和原型对比，权重 a 来自各自的置信度。
- **两种统一形式：**
  - **联合求解（专家乘积）：** $f = (A + A' + 2\lambda L)^{-1}(A s + A' z)$。用局部置信度加权两条线，但历史上的“单一求解”是域间交换（OVERVIEW 第 8 节）；
  - **现行的场平均（专家混合）：** 在“方向未知”下更稳。理由是联合求解按置信度加权，而偏大线在错误方向上往往也很自信。
- **论文措辞：** 方法可以写成“两种归纳偏置（局部非参数、全局参数）的估计在方向未知下的极小极大组合”。常数 τ、.55、λ 来自开发阶段的固定选择，理论只预测它们在一定范围内不敏感，不给出最优值。

### 可检验的推论

1. **分歧带的定位：** 带内像素的 GT 比例应接近 50%，并且随例子的方向两极分化。可以用缓存场核对。
2. **COCO 的差距：** 过分割例中，溢出区域的 M′ 分应高于 U0 分。

**证伪：** 若分歧带内 GT 比例与方向无关，“夹住真值”的解释就不成立。

## T5 “十个基准不低于 FoRIS”的检验与措辞

### 1 bootstrap 对比值型指标是否有效

- **成立条件：** 指标是 slot 内 ΣI/ΣU，再对 slot 平均，是均值的平滑函数。只要 (i) 簇（照片）独立，(ii) 簇数多，(iii) 分母远离 0，照片簇 bootstrap 就是相合的（delta 方法）。
- **会出偏差的地方：** 例子很少的 slot。
  - 比值估计有 O(1/n) 偏差；
  - 更要紧的是：**某次重抽样中整类缺席时，w12 的实现把该类记为 IoU 0**，于是 bootstrap 的水平分布系统性偏低。和发表值比时，“显著更低”会变得反保守，“显著更高”会变得过保守。
- **已修正：** `w30_confirm.py` 的 E2 抽样只对出现的类取平均，点估计不变，在任何 E2 评分之前完成。E1 用的辅助函数本来就是这样做的。
- **区间方法：** 照片簇少于约 100 时（新照片留出中 Fundus 只有 16 例），改报 BCa；其余用百分位即可。

### 2 和误差未知的发表单值比较

- **区分两种推断目标：**
  - 若发表值来自同一组官方例子（固定协议），那么在“这个基准上谁更高”这个问题上，两个数字之差没有抽样误差，只有实现误差；
  - 照片 bootstrap 给出的是推广到新例子时的不确定度。
- **实现误差的量级：**
  - 复现减发表：ISIC −0.17，Lung +0.11，Fundus −0.57；
  - Road 不可比。
- **推荐：**
  - **主表：** 报点差（我们 − 发表），并附我们的非配对区间作为保守参照；
  - **四个有复现的域：** 报配对区间；
  - **其余六域的近似配对区间：** 用新照片留出上同域的配对 / 非配对方差比 ρ_d 做近似，即 $\hat\Delta \pm 1.96\sqrt{\rho_d}\,\mathrm{SE}_{ours}$。必须标明是近似。

### 3 十个域同时下结论

- **“十个都不低于”（非劣效）：**
  - H0：存在某个域 $\Delta_d \le -\delta$；
  - **交并检验**：每个域单侧 5% 的检验都拒绝，即双侧 90% 区间的下界 > −δ。整体水平就是 5%，不需要多重校正（Berger 1982）。
- **“k 个域显著更高”（优效）：** 对这个家族用 Holm 或 max-T 同时区间。
- **“无一域显著更低”：** 只是没能拒绝，不能写成“不低于”。

### 4 边界 δ（必须在看 E2 之前定）

- **建议 δ = 1.0 mIoU。** 理由：大于复现与发表的最大实现差 0.57，并且小于各域之间方法差异的常见量级。
- 这一条应在 W30 恢复、E2 评分之前追加到 W30 报告，作为补充读法。**需要用户确认。**

### 5 功效

- **新照片留出：** 每域 16–500 例，Fundus 无法单独做到非劣效；
- **主张结构建议：**
  - 留出集上，十域均值的配对优效作为主证据；
  - 逐域只在样本足够的域报非劣效；
  - 官方集上，主表加上述近似。

### 措辞模板

| 结果模式 | 写法 |
|---|---|
| 十域下界都 > −δ，且 k 域优效 | “在全部十个基准上非劣于 FoRIS（δ = 1.0，交并检验），其中 k 个显著更高（Holm）” |
| 有域区间跨 −δ | “在 9 个基准上非劣；X 上差 Δ，区间 [a, b]，未能确立非劣”。并给出开发集上的诊断原因 |
| 有域上界 < 0 | 如实写“在 X 上显著低于 FoRIS”，放进局限 |

## T6 kNN 图与稠密亲和的谱差异

### 命题 6.1

- **kNN 图（互近邻、自调带宽、按度归一化）：** 近似的是特征流形上的局部几何。图像上特征缓慢变化，所以图像网格状 / 流形状，低频模态的特征值都接近 1。这是流形 Laplacian 的连续谱 $\lambda_k \sim (k/N)^{2/d}$，没有谱间隙，所以 W15 观察到“前 10 个都 > .995”。
- **稠密 $\max(0, \cos)$：** 近似 Gram 矩阵 $XX^\top$ 的截断。它的谱反映特征协方差的主成分：少数语义方向占主导，所以衰减很快。
- **两者看到的东西不同：** kNN 图看到“外观连续性”；稠密图看到“全局语义类型”。两者都不直接等于“实体”。
- **对 W32 的预测：**
  - `osp` 的片段是语义类型簇：能分开不同 stuff 类型（SUIM、iSAID），但会把同类的不同实例合在一起；
  - `ksp` 是否更接近实体，取决于 key 中是否保留了实例 / 路由信息。DINO 系列的物体发现方法（LOST、TokenCut）用的是 key，这是正面先验。

### 【已核】W32 结果（416 例，前 20% 余量例）

| 分组 | K = 8 | K = 16 | K = 32 |
|---|---:|---:|---:|
| kNN 图 + O24 输出（W15） | 48.4 | 60.5 | 69.7 |
| 稠密亲和 + 末层 key（ksp） | 43.7 | 55.9 | 67.0 |
| 稠密亲和 + O24 输出（osp） | 51.4 | 62.1 | 68.8 |

切点 oracle 为 71.4。

- **谱：** 稠密亲和前 10 个特征值的中位数，key 为 1, .20, .15, .11, …，输出为 1, .26, .13, .08, …，都有明显间隙。kNN 图则是 > .995 的连续谱。
- **与命题 6.1 的预测一致：**
  - 谱间隙对应语义类型，而不是实体，所以 K 小时片段不纯；
  - key 并不比输出更接近实体；
  - LVIS 最差，因为目标小、类别细。
- **修正：** 我原先说“LOST、TokenCut 用 key 是正面先验”。这条对 DINOv3 末层不成立。那些方法做的是显著物体发现（一图一个主物体），并且常常靠种子 token 和颜色项，而不是纯特征的谱分组。

### 命题 6.2：对 λL 求解的含义

- kNN 图沿外观连续体扩散：病灶渐变到皮肤，标签会跟着渗；同实体内外观突变处，扩散又会停下；
- 所以图求解并不尊重实体边界，只尊重外观连续性；
- 理论上更合适的是“空间邻接 × 特征 / 颜色对比”的边感知图，这正是像素级 CRF 在做的事；
- 它是否值得在 token 级重做，取决于 W32 和 T7 的诊断。

## T4 DINO 的 CLS 对裁剪不变：整体比较为什么偏向小核心

### 命题 4.1：多裁剪目标让 CLS 只测纯度、不测完整度

- **DINO 的训练目标：** 局部裁剪（覆盖原图约 5–40%）的学生 CLS 分布要匹配全局视图的教师分布。所以对同一物体，$E(\text{局部}) \approx E(\text{整体})$。
- **视图模型：** $E(v) \approx \mathrm{unit}(\alpha\, o + \beta(v)\, s)$。其中 o 是物体分量，s 是场景 / 背景分量，β 随视图中非物体内容的比例上升。
- **对掩码裁剪的后果：**
  - 由裁剪不变，只要视图是物体的一部分，α 项就近似不变。所以“包含了物体的多少”不进入 E，**完整度不可见**；
  - 背景比例一增加，β 就增大，与参考（以物体为中心的遮罩裁剪，$\approx o_R$）的余弦单调下降。所以 E 只测**纯度**；
  - 结论：相似度对 s ≤ 0（核心到完整物体）几乎平坦，对 s > 0（带入背景）下降。最大点因此偏向纯度最高、也就是最小的候选。
- **与 E10 对照：**
  - Dsel 有 410 例选了 s ≤ −1；
  - 例内 Spearman 为 .48，只有在“偏大一侧”的下降上才有信息；
  - 换成别类参考后，余下的只有“以物体为中心”这一项，于是更偏向最小候选（266 例选 −2），结果也更差。
- **方法含义：**
  - 任何范围验证器都必须测**完整度**，而完整度关乎候选**之外**还剩下什么；
  - 遮罩裁剪的整体表示天生看不到这一点；
  - 若测补集里的残余证据，用的又是同一个场，就会落入 T8 的自指问题。所以需要独立的实体信号（回到 T1）。

## T7 边界带：与覆盖率一致的亚 token 重建

### 命题 7.1：覆盖率准确时，双线性插值 + .5 对直边几乎精确

**一维推导：**
- patch 中心间距 16，直边位于中心 0 的 patch 内的 e ∈ [−8, 8]，前景在左；
- 覆盖率为 $\pi_{-1} = 1$，$\pi_0 = (e+8)/16$，$\pi_1 = 0$；
- 在 [−16, 0] 上做线性插值，值为 .5 的位置是 $x = -16 + 128/(8 - e)$；
- 误差 $x - e$ 在 e = 0 和 e = ±8 处为 0，最大约 1.37 px（e ≈ −3.3）。

**推论：** 边界带约 8～9 点的损失（E15）主要来自覆盖率**估计**误差，以及曲边 / 角点、比 patch 还细的结构，而不是双线性重建本身。

### 命题 7.2：核迁移的 c 不是覆盖率估计

- **c 的性质：** $c_i$ 是参考覆盖率 $y_j$ 对特征的 Nadaraya–Watson 回归。
- **相合的条件：**
  - (i) 特征对覆盖率近似线性混合：$x(\pi) \approx \pi a + (1-\pi) b$；
  - (ii) 参考中边界 patch 的混合方向 $(a_R, b_R)$ 与查询的 $(a_Q, b_Q)$ 一致；
  - (iii) 核宽足以在边界 patch 之间插值。
- **实际情况：**
  - τ = .05 很尖，c 退化为最近邻标签，接近二值，亚 token 信息丢失；
  - 跨实例时 $a_Q \ne a_R$，前景外观不同的边界 patch 被系统性低估。
- **预测：** 在 GT 边界 patch 上，c 与真实覆盖率 π 的标定曲线呈阶梯状，而不是对角线。可以用缓存场和 GT 直接验证。

### 新构造（方法内在，不提高输入分辨率）

1. **查询自适应的线性解混。**
   - 由查询的高置信核心和背景估计 $\hat a, \hat b$（去偏特征空间）；
   - $\hat\pi_i = \mathrm{clip}\big((x_i - \hat b)\cdot(\hat a - \hat b) / \|\hat a - \hat b\|^2,\ 0,\ 1\big)$，只用于边界带内的 token；
   - DINO 特征对混合并非线性，这是近似，需要先做诊断。
2. **覆盖率约束的像素重建。**
   - 在每个 patch 内取 $\mathrm{round}(256\hat\pi_i)$ 个像素，按 RGB 前景似然排序；颜色模型取自查询核心或参考前景；
   - 加上平滑项后，就是带线性约束的图割，可以用拉格朗日乘子逐 patch 求解；
   - 对比 patch 还细的结构（血管、道路），面积约束能保留“多少”，RGB 决定“在哪”。
   - 失效条件：RGB 在 patch 内不可分，例如 ISIC 的低对比边界；或者 $\hat\pi$ 有偏。

### 便宜的诊断（建议作为新编号的任务，不需要编码器）

在 S 样本上，先用**真实覆盖率** π（由 GT 平均池化得到）测三种读出的容量：
1. 双线性插值后取 .5；
2. 每个 patch 内按 RGB 取 top-k；
3. 每个 patch 内按 F 取 top-k。

**读法：** 若 (1) 已接近 GT，边界带的问题就在覆盖率估计，下一步去做解混。然后再分别换成 c 和解混得到的 $\hat\pi$。

## T8 自指选择器为什么被锚定在自然切点

### 设定

- **记号：**
  - 候选是 F 的水平集；
  - δ 是逐例的 oracle 偏移，以自然切点为 0，单位为 log₂ 面积；
  - η 是选择器的偏移，$\eta = g(F)$。
- **两个误差量：**
  - 自然切点的误差为 $E[\delta^2]$；
  - 选择器的误差为 $E[(\eta - \delta)^2] = E[\eta^2] - 2E[\eta\delta] + E[\delta^2]$。

### 命题 8.1：改进的必要条件

1. **能改进的条件：** 选择器胜过自然切点当且仅当 $E[\eta^2] < 2E[\eta\delta]$。
2. **最佳收缩：** 先收缩为 $\beta\eta$，最优 $\beta^* = E[\eta\delta]/E[\eta^2]$。此时误差为 $E[\delta^2](1 - \tilde\rho^2)$，$\tilde\rho$ 是未中心化的相关。所以收益比例就是 $\tilde\rho^2$：要收回一半余量，大约需要 ρ ≈ .7。
3. **只依赖场时：** 若 $\delta \perp F$（命题 1.1 的不可辨识），对任何 $\eta = g(F)$ 都有 $E[\eta\delta] = E[g(F)]\,E[\delta] \approx 0$，因为自然切点总体无偏（E5）。这类选择器只能变差，最好也只是不动（β = 0）。
4. **δ 与 F 不独立时：** 收益上界是 $\mathrm{Corr}(E[\delta \mid F],\ \delta)^2$。E4 的监督融合约等于 FoRIS，可以作为这个量 ≈ 0 的估计。

### 【已核】K0 的 1,090 例（δ 取九级梯度 oracle 的 s）

| 选择器 | corr(η, δ) | E[η²] | 2E[ηδ] | 均方误差：自然 → 选择 | β* |
|---|---:|---:|---:|---:|---:|
| J | +0.084 | 0.257 | 0.070 | 0.713 → 0.890 | 0.14 |
| CLS 示范（Dsel） | +0.073 | 1.353 | 0.135 | 0.713 → 1.894 | 0.06 |

- 两者都远不满足改进条件，结论与 −1.68、−10.17 一致；
- 即使对 J 做最佳收缩，理论收益也只有 $\rho^2 \approx 0.7\%$ 的余量。

### 为什么“例内 Spearman”会误导

- IoU(t) 与 Ψ(t) 只要都是单峰、峰都落在同一宽区间，例内秩相关就会很高（J 为 .83）；
- 但它衡量的是曲线形状的相似，不是峰位是否随例子一起移动；
- **应当用的诊断量：**
  - 跨例的 corr(η, δ)；
  - 改进条件 $E[\eta^2] < 2E[\eta\delta]$；
  - 或相对自然切点的 regret。

### 筛查协议（以后每个新信号先过这一关）

1. 在开发 S 上取约 150 个非回退例。用现有字段就能生成九级梯度和 oracle δ，不需要编码器。
2. 计算信号偏好的偏移 η，以及 Fisher-z 下 ρ 的 95% 下界。
3. **样本量**（单侧 α = .05，功效 .8）：ρ = .2 需要约 158 例，.3 约 72 例，.4 约 42 例。
4. **进入正式实验的门槛：** ρ 的下界 > 0，且预测收益 $\rho^2 \times$ 余量 ≥ 0.5 点，相当于要求 ρ ≳ .25。
5. 还要看方向的二分版本：在 η ≠ 0、δ ≠ 0 的例子上，做符号一致率的二项检验。

## T9 指标感知决策与转导标定

1. **后验已标定时：** 由命题 2.1，汇总 ΣI/ΣU 的逐像素最优阈值是 $J^*/(1+J^*)$，由类级的 $J^*$ 决定，同类各例共用。
   - 典型 $J^*$ 在 .4–.9 时，阈值为 .29–.47，低于 .5，难类更应当偏向纳入；
   - 但 F 没有标定，F 的 .5 不等于后验 .5；
   - 开发数据上最佳常数接近自然切点（TOKEN_READOUT 的固定水平扫描），说明 F 的自然切点已大致落在汇总最优的常数附近。
2. **转导标定（参考当标定集）。**
   - 做法：在参考内部留出空间邻域做交叉拟合，得到带标签的分数，拟合单调的 $h_R$，再迁移到查询；
   - 偏差方向：参考对参考的相似度高于参考对查询，所以 $h_R$ 会高估查询分数对应的后验，导致切点偏高、偏向欠分割；
   - **更根本的原因**：δ 是 (R, Q) 这一对、特别是 Q 的实体结构决定的。只由 R（或全局）得到的标定，都是 (F, R) 可测的，由 T8 只能贡献全局平移。这解释了 E16：LVIS +.44 像是全局平移，其余域 ±.1。
3. **归类：** 指标感知阈值对任何打分器（包括 FoRIS）同样适用，按 OVERVIEW 第 9 节属于通用设置，不算方法贡献；可以作为协议说明，但不进入方法主张。
