# W42：参考边电导与 F 前缀链最小割（W39 D §4 的一轮运行）

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。方法、常数和对照都取自 [W39 D](W39_D_coverage_REPORT.md) §4、§7，本计划只把它冻结成一轮运行，不改 W39 的文件。

## 1 动机

- **W37–W40：** 带内正确覆盖量的容量为 +9.43，但逐块独立估计的四种量（c、解混、颜色切点、参考带字典）都不如 N。
- **W39 D §4 的新机制：** 不再逐块独立估量，而是在保留 F 块内排序的前提下，用一次全局最小割联立求各块的停止位置。参考图告诉我们“哪种 RGB 相邻变化更像类内、哪种更像边界”。
- **W41：** 55.3% 的像素错误在两线共同区，凸融合与 CRF 都动不到。本构造在带内可以推翻两线共识，所以同时回答：带内的共同错误占多少，这个能量能否修到它们。

## 2 设计

**样本：** 同 W37–W41 的 1,285 个 S 例，含回退例。T 半和新照片留出都不读。

**场与带：** F、N 与 W37 相同（回退例 F = minmax(up(c32))）；带 B 为 W37 的 token 带，展开到像素。带外固定为 N。

**参考边电导（W39 D 式 (7)–(8)）：**
- 参考 RGB 与查询 RGB 都双线性缩放到 1024 后取 [0, 1]；参考 mask 用 `mask1024`；
- 4 邻接边的 |ΔR|、|ΔG|、|ΔB| 各均分 4 档，共 64 个 bin；
- 按参考 mask 分 FG-FG、BG-BG、跨边界三类直方图，先各自归一化，再与均匀分布按 η = 1/16 混合；
- p_same = (p_FF + p_BB)/2，p_cross = p_FB；
- r = max(0, log(p_same / p_cross))，w = r/(1 + r)。

**能量（W39 D 式 (9)–(10)）：**
- 带内像素 p 的 unary：a_p·|m_p − N_p|，a_p = |2F_p − 1| + 2⁻²⁰；
- 对至少一端在带内的 4 邻接边，Potts 项为 λ·w_e·|m_p − m_q|，λ = 1/4；
- 前缀链：每个带内块按 F 降序（与 W38 的 `place` 同一稳定顺序）要求 m_{j+1} ≤ m_j；
- 用 s-t 最小割精确求解，取最小 source 侧。
- **数值：** scipy 的 `maximum_flow` 只接受整数容量，所以容量乘以 scale 后取整。scale = min(4096, 2³⁰ / 有限容量总和)；若 scale < 256，该臂输出 N。前缀链用大于全部有限容量之和的整数。

**五臂（W39 D §7.1）：**
- N：自然；
- R：上面的原样构造；
- G：保留前缀与 unary，电导改为通用 RGB 核 exp(−d²/2σ²)，σ 为带边上正颜色距离的中位数，总电导与 R 匹配；
- Uc：R 的能量去掉前缀链（W39 D 中的 U 臂，改名以免与 U 线混淆）；
- K：保留 R 的每块数量，块内按 (Uc 标签, F, −坐标) 降序取这些数量；
- 另报 R+ = CRF(R)，与 W27 的 SH+ 同合同比较（回退例不加 CRF）。

**默认动作：**
- 参考三类边任一为空，或没有带：整例各臂输出 N；
- 整数精度不足：该臂输出 N。
- 这些例都计入结果，不丢例。

**记录：**
- 各臂 I/U；带内计数误差 Σ|k − s|；
- 相对 N 的四种编辑，按 W41 的区域 C0/C1/D/回退分；
- N 的错误按区域 ×（带内、带外）分；
- 参考三类边数、查询未见 bin 比例、求解用时与 scale。

## 3 读法（运行前写定）

1. **实现检查：**
   - N 与 W23 SH 一致 ≥ 1,280/1,285；
   - R 在每个带内块都是 F 前缀（违反数为 0）；
   - λ = 0 时各臂严格复现 N（冒烟测试 5 例已核：COCO、LVIS、ISIC、Fundus、Road 全部一致）。
2. **机制**（十域 mIoU，CRF 前，区间用 `w37._boot`）：
   - **a：** R − N 与 R − G 都 > 0，且区间下界 > 0：参考边界关系对局部停止位置有用，超出通用平滑；
   - **b：** R − N、G − N 区间都 > 0，但 R − G 区间含 0：只是通用的图像引导平滑，参考关系不构成贡献；
   - **d：** R、G、Uc 相对 N 的十域均值都 ≤ 0：关闭这个能量与电导构造；
   - **其他：** 记为混合，如实描述；
   - **另判前缀是否过严：** Uc − R 与 K − R 区间都 > 0。
3. **方法验收**（与科学判别分开）：R+ − SH+ ≥ +1.0，区间下界 > 0，且 ≥ 7/10 域 ≥ 0，才写方法验证计划（S 上已比，再读 T 一次）；否则不读 T。
4. **共同错误在不在带内**（与 R 的成败无关，决定下一步的方法族）：
   - N 的共同错误（C0 中的 FN 加 C1 中的 FP）有 ≥ 50% 在带内：共同错误主要在边界局部，带内方法对口；
   - < 50%：共同错误主要在实体层面（整块多取或漏取），下一步应转向能整块增删的动作（W39 B 线一类）。
5. **运行前已知的一点（不改读法）：** 冒烟测试中，λ = 1/4 下 R 与 N 的差 ≤ 0.03 点。a_p = |2F − 1| 在带内多数像素远大于单条边的 λ·w ≤ 1/4，能量只在 F ≈ .5 的细条上可能改动。这是 W39 D 事先固定的常数，**不在看过结果后调 λ**；若全量仍近恒等，按读法 2 的 d 或混合如实记录，并注明原因是 unary 的尺度。

## 结果

**2026-10-15 07:05 完成。按 W39 D 的固定常数，这个能量在实际数据上近乎恒等：R 平均每例只改 37 个像素，五臂与 N 的十域差都 < 0.01 点。按规则判为“混合”（均值为 +0.00x，不满足 d 的 ≤ 0），实质是没有动作，不能回答“参考边界关系是否有用”。读法 4 是本轮最重要的结果：SH 的共同错误只有 21.0% 在边界带内，79% 在带外，属于实体层面。**

- **运行：** 1,285 例全部正常求解，没有默认回退；整数 scale 中位 4096，没有精度不足的例。最小割中位 0.07 s/例，最长 1.4 s；全程中位 1.9 s/例。
- **实现检查：**
  - N 与 W23 SH 一致 1285/1285；
  - R 的前缀违反 0；
  - λ = 0 时 5/5 冒烟例严格复现 N。
- **查询未见 bin：** 中位 0，参考的三类边统计都够用。
- **数据：** 完整报告在 `../cv_data/a/x1013_W42/report.txt`，证据在 `evidence/research/w42_ordered_cut_S.jsonl.gz`。

**五臂：**
- 十域 mIoU 相对 N，R、G、Uc、K 都是 +0.00；R+ − SH+ 为 −0.00；
- 改动像素占带内像素的比例：R、Uc、K 都是 0.038%，G 为 0.060%；
- 带内计数误差与 N 相同（比值 1.000）。

**判定：**
- **读法 2：** 规则给出“混合”。没有可读的效应：R − N、R − G、G − N 的区间都在 ±0.005 以内；前缀过严的判据不成立。
- **读法 3：** R+ − SH+ 不满足，不读 T。
- **原因（运行前第 5 条已预见）：** unary 的尺度 a_p = |2F − 1| 在带内大多数像素上远大于 λ·w ≤ 1/4，能量只在 F ≈ .5 的一两像素细条上起作用。这只关闭“W39 D 这组常数下的这个能量”。参考边界关系本身是否有信息，本轮没有测到，因为能量没有给它动作空间。**不在看过结果后调 λ。**

**读法 4：共同错误在哪里**（N 的像素错误，M = 10⁶ 像素）：

| 区域 | 带内 FN | 带内 FP | 带外 FN | 带外 FP |
|---|---:|---:|---:|---:|
| C0（两线都判背景） | 4.19 | 0 | **20.93** | 0 |
| C1（两线都判前景） | 0 | 8.85 | 0 | **28.00** |
| D（两线分歧） | 8.02 | 9.51 | 14.12 | 7.51 |
| 回退例 | 1.94 | 3.83 | 4.96 | 0.22 |

- 共同错误中只有 21.0% 在带内，79% 在带外（距 N 的边界超过约一个 token）。**按读法 4，共同错误主要是实体层面：两条线一起多取了整块区域，或一起漏了整块区域。**
- 所有区域合计，SH 的像素错误有 67.6% 在带外。W37 的带内容量 +9.43 是真实的，但只对应约三分之一的错误。
- **逐域，带外共同错误占该域全部错误的比例：**
  - COCO 43.7%（其中共同 FP 32.4%）；
  - ISIC 54.1%（FN 24.4%、FP 29.7%）；
  - PASCAL-Part 45.5%（以共同 FN 为主，29.9%）；
  - PACO-Part 50.8%、SUIM 49.3%、iSAID 49.5%；
  - Lung 只有 18.6%，错误主要在分歧区的带内（43.1%）；
  - Fundus、Road 的错误主要在回退例。
- SH+ 落后 FoRIS 的两个域（COCO、ISIC），恰恰是带外共同错误最重的域之一。

**结论：** 下一个方法要在**实体层面推翻两线共识**：整块删掉两线都判前景的区域，或整块补上两线都漏掉的区域。边界带内的“量”是次要余量。已关闭的实体层面构造（W15/W16 查询自身分组、W31 示范匹配、W32 key 分组）说明这一层很难，但它是错误的主体所在。
