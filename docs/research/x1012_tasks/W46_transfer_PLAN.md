# W46：参考定义的方向为什么到查询上会偏

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。

## 1 动机与理论假设

**已知（[W45](W45_solvability_PLAN.md)）：**
- 在 SH 使用的去偏 O24 token 上，用查询自己的 GT 交叉拟合线性探针，上限是 71.6 mIoU；SH 是 53.6。
- 在参考 token 上拟合同样的探针，直接用到查询上，只有 38.3。
- 只看排序（最佳阈值 IoU，逐例平均）：

  | | 参考探针 P_R | 查询探针 P_Q |
  |---|---:|---:|
  | 非灾难例 | .684 | .811 |
  | 灾难例 | .300 | .606 |

- 冻结特征里有能分开目标的方向；参考定义的方向到了查询上会偏。这是“迁移”这一层的核心。

**一个简单模型。** 设 token 特征 x = s(t) + g_I + n。其中 s(t) 是与目标标签 t 有关的概念信号，g_I 是整张图共有的偏移，n 是 token 级扰动，其协方差 Σ_I 随图而变。参考上的岭回归方向

w_R = (X_Rᵀ X_R + λI)⁻¹ X_Rᵀ y

会吸收参考图上任何与 y 相关的方向。三种原因都会让它在查询上失效，而且对应的补救不同：

| 假设 | 机制 | 可检验的预测 |
|---|---|---|
| H1 协方差偏移 | Σ_R ≠ Σ_Q，同一个方向在两张图上的尺度和相关结构不同 | 逐图标准化或 CORAL 对齐后，P_R 的排序明显变好 |
| H2 参考特有的伪相关 | 参考图上，背景内容、位置、光照恰好与前景相关；岭回归在 1024 维、4096 个高度相关的 token 上会拟合这些方向，而它们在查询上与目标无关 | 加强正则（方向趋向前景、背景均值差，即原型）后，P_R 明显变好；对齐没用 |
| H3 概念不确定 | 参考 mask 本身不能唯一确定概念（部件还是整体、stuff 的边界）；任何只看参考的方向都可能指向另一个概念 | 正则与对齐都救不回；只有利用查询自身的信息（转导）才可能缩小差距 |

这三种假设不互斥。实验要测的是各自能收回多少差距。

**转导一臂。** 查询自己的特征里有分开目标的方向（P_Q），那么用 SH 的场 F 当作带噪标签，在查询 token 上做空间交叉拟合，能否把方向拉向 P_Q？这测试的是“查询自身几何 + 参考给出的粗定位”能不能纠正方向偏差。H3 下，这是唯一可能有效的途径。

## 2 设计

**样本：** W37–W45 同一批 1,285 个 S 例。T 半和新照片留出都不读。

**特征、标签、读出：** 与 W45 相同。
- 特征：单位化的去偏 O24 token；
- 标签：16×16 平均池化的覆盖率；
- 场经 `lab.up` 上采样后，计算最佳阈值 IoU（120 个分位点）与自然阈值（.5）IoU。

**臂（除 P_Q 外都不读查询 GT）：**
- **R1：** 参考岭回归，λ = 1（即 W45 的 P_R）；
- **R2：** 同上，λ = 100；
- **R3：** 原型方向，即参考前景、背景 token 均值之差（λ → ∞ 的极限方向），偏置取两类均值投影的中点；
- **A1：** 两张图各自逐维标准化（减本图均值、除本图标准差）后，再做 R1；
- **A2：** CORAL 对齐。参考特征用参考协方差白化，再用查询协方差着色，然后做 R1。协方差向“平均方差 × 单位阵”收缩 10%（特征是单位向量，每维方差约 1/1024，直接向单位阵收缩会压倒原协方差）；
- **T1（转导）：**
  - 目标为 SH 场 F 的 token 均值；
  - 在查询 token 上做岭回归，λ = 1，按 W45 的 8×8 块棋盘 2 折交叉拟合，每个 token 的预测都来自没见过它的模型；
- **P_Q（上限）：** 用查询 GT，同 W45；
- **F（参照）：** SH 的场。

**诊断：** R1、R3、T1 的方向与 P_Q 方向（在全部查询 token 上用 GT 拟合，λ = 1）的余弦。

**汇总：** 逐例平均的最佳阈值 IoU，灾难例与非灾难例分开；class mIoU（自然阈值，十域）；十域区间用 `w37._boot`。

## 3 读法（运行前写定）

1. **实现检查：** SH 与 W23 一致 ≥ 1,280/1,285；R1 与 W45 的 P_R 最佳阈值 IoU 一致（逐例差 < 1e-6）。
2. **差距收回率**：(臂 − R1)/(P_Q − R1)，用全部例子的最佳阈值 IoU 均值计算，灾难例与非灾难例分开报告。
   - **H2 为主：** R2 或 R3 的收回率 ≥ 50%，且 A1、A2 都 < 20%；
   - **H1 为主：** A1 或 A2 的收回率 ≥ 50%，且 R2、R3 都 < 20%；
   - **H3 为主：** R2、R3、A1、A2 的收回率都 < 20%；
   - **其他：** 按数值如实描述，不归类。
3. **转导：** T1 − F 的最佳阈值 IoU 均值，以及 class mIoU（自然阈值）的十域差与区间。
   - T1 的 mIoU 比 F 高 ≥ +1.0、区间下界 > 0，且 ≥ 7/10 域 ≥ 0：转导纠偏有效，另写方法验证计划（固定 λ 与划分，在 S 上与 SH+ 比，再读 T 一次）；
   - 否则记录收回率，不读 T。
4. 所有臂都是诊断或候选，不在看过结果后改 λ、收缩比例或划分。

**2026-10-15 10:30 完成。** 运行 1,285 例，中位 1.7 s/例。实现检查：SH 与 W23 一致 1285/1285；R1 与 W45 的 P_R 逐例完全一致。完整报告在 `../cv_data/a/x1013_W46/report.txt`，证据在 `evidence/research/w46_transfer_S.jsonl.gz`。

| | R1 | R2 强正则 | R3 原型 | A1 逐图标准化 | A2 CORAL | T1 转导 | P_Q 上限 | F（SH） |
|---|---:|---:|---:|---:|---:|---:|---:|---:|

**与查询 GT 方向的余弦：**
- 灾难例：R1 .145、R3 .158、T1 .241；
- 非灾难例：R1 .304、R3 .294、T1 .563。

**自然阈值的 class mIoU（十域）：** SH 53.63、R1 38.31、R2 22.80、R3 43.48、A1 31.10、A2 31.80、T1 51.79、P_Q 71.57。

**判定：**
- **读法 2：**
  - 灾难例上，四种补救的收回率都 < 20%，按规则归为 H3（概念不定）。严格说，这只证明了加强正则、分布对齐、转导重拟合三种补救都救不回来。“参考没有确定概念”是剩下的解释之一，本实验没有直接证实；W47 直接检验它。
  - 非灾难例上，R2 收回 22%、T1 收回 35%，没有一类达到 50%，记为“其他”。
- **读法 3：** T1 − SH 为 −1.84 [−2.18, −1.54]，3/10 域 ≥ 0，不通过。T1 的排序（.729）也略低于 F 本身（.736）：把 SH 的场投影回特征的线性空间，没有带来新信息。

**结论：**
1. **H1（协方差偏移）被否定。** 两种对齐都让排序变差，逐图标准化尤其严重：两张图各自的特征分布本身就携带了区分信息，对齐反而把它抹掉了。
2. **参考特有的伪相关（H2）只占小部分。** 加强正则在非灾难例上收回约五分之一，在灾难例上几乎没有作用。
3. **灾难例上的方向偏差，靠参考本身和查询的无标签几何都收不回。** 参考方向与查询真实方向的余弦只有 .145。
4. **Fundus 是例外。** 查询探针 P_Q 比 SH 低 21 点。token 级线性读出装不下细血管，SH 的回退分支（核迁移加双线性）反而更好，与 W45 的“表示不足”一致。
