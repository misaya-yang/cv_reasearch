# W61：消除参考面积响应，没有消除参考依赖的错误

2026-10-16。按 [计划](W61_reference_stability_PLAN.md)，十域各 40 个原 S 查询，固定查询和类别，每例独立使用三个合法同类参考。共 1,200 次 one-shot 配置、两种头、CRF 前后全部封存后评分。原参考 SH/SH+ 整数 I/U/预测面积 400/400 复现 W23。没有三参考融合，没有修改或重跑 W57。

## 1 显式通道被改变，但准确率下降

按计划将每查询三参考 I/U 纳入同一开发槽，FixedPrior π=.088 相对原 SH：

| 指标 | CRF 前 | CRF 后 |
|---|---:|---:|
| 十域 mIoU 差，pp [95% 查询照片区间] | **−1.125** [−1.902,−.366] | **−1.069** [−1.867,−.324] |
| 原 SH 的查询内参考面积斜率 | .295 [.216,.371] | **.294 [.208,.374]** |
| FixedPrior 的同一斜率 | .011 [−.057,.075] | **.005 [−.071,.075]** |
| 原 SH 的平均 log₂ 预测面积标准差 | .473 | .493 |
| FixedPrior 的同一标准差 | .421 | .442 |

斜率对每查询中心化的 log₂ 参考面积与 log₂ 预测面积回归，固定查询本身；参考内容仍随参考一起改变。500 次分域查询照片 bootstrap。固定先验是每个参考内的配对干预，确实强烈改变这一面积通道，却不是本批完整错误的有效修复。不能将剩余标准差除以原标准差解释为某种因果份额。

三个参考序号分别算槽 mIoU 后再平均，是另一种权重。其 CRF 后差为 **−1.019 pp**，方向一致，但不与上面先合并 I/U 的 −1.069 混名。各序号原 SH+ 为 55.070/54.534/55.708，FixedPrior 为 54.638/53.349/54.269。

## 2 固定查询仍对参考内容敏感

| 三参考描述（逐查询平均） | SH+ | FixedPrior+ |
|---|---:|---:|
| 平均 IoU | .5554 | .5432 |
| 观察到的最差 IoU | .4433 | .4388 |
| 观察到的最好 IoU | .6515 | .6325 |
| 原参考 SH+ <.3 的 89 例中，被另外参考输出救到 ≥.5 | **22/89** | 21/89 |

这里的最好、最差和救回只描述预定的三个参考；不能部署 GT 挑参考，不能称 3-shot 增益，也不是任意参考的总体最坏保证。原 SH 的平均最好−最差约 .208，说明在相同查询和任务下，合法参考内容足以显著改变预测正确性；不能把这整个差距归于参考面积。

## 3 域别结果与结论边界

CRF 后 FixedPrior−SH，单位 pp：COCO +1.88、LVIS −4.14、PASCAL-Part −4.17、PACO-Part −2.60、SUIM −5.46、iSAID +2.20、ISIC +1.32、Lung +.43、Fundus +1.09、Road −1.25。LVIS/PASCAL/PACO/SUIM 的区间负，Fundus 正，其余含零。本批的域别变化不用于门控或选择新 π。

可以确定：显式参考质量先验是输出面积的实际计算通道；把它替换成这一固定先验能大幅降低面积响应，但损害总体正确性。因而“发现该通道”与“找到了主根因及修复”之间仍有缺口。

仍不能确定：去掉参考先验后的剩余误差分别有多少来自外观覆盖、负证据、目标语义或读出。完整参考变化同时改变这些信息；下一项 [W63](W63_task_switch_PLAN.md) 固定 R/Q RGB，只切换合法完整 mask，检查任务响应是否朝正确方向。
