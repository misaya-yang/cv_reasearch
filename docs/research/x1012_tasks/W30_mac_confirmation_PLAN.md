## 6 评分与读法（运行前写定）

### E1 新照片留出（只评分一次）

- **统计：** 与 [PHOTO_HOLDOUT_RESULT](../x1012s_tasks/PHOTO_HOLDOUT_RESULT.md) 相同：每域 (fold, class) 槽池化后等权，十域再等权；2,000 次按 canonical 查询照片的配对 bootstrap，seed 2026101303。
- **主比较：** 冻结方法 − FoRIS。FoRIS 用该留出上已封存的逐例预测（MFU 那次运行中的 FoRIS 臂），同例配对，不重跑。
- **读法：**
  - 所有域点估计 ≥ 0，且十域均值下界 > 0 → 可写“十域都不低于 FoRIS”；
  - 有域为负但区间含 0 → 写“无一域显著低于 FoRIS，k 域显著更高”；
  - 有域区间上界 < 0 → 十域主张不成立，如实报告该域。
- **次要：** 冻结方法 − MFU（同为本机运行，同例配对，可以检验）。

### E2 官方协议

- **指标：** `scripts/x1012/w12_official.py::score`。每个 fold 内类 IoU = ΣI/max(ΣU, 1)，对期望类别平均，再对 fold 平均；CLI-1024 画面。区间用 1,000 次照片 bootstrap，seed 2026101303。
- **与 FoRIS 发表值比较**（COCO 60.9、LVIS 42.8、PASCAL 55.8、PACO 42.3、SUIM 59.1、iSAID 53.6、ISIC 62.9、Lung 87.6、Fundus 19.7）：
  - 区间下界 > 发表值 → 显著更高；
  - 点估计 ≥ 发表值 → 不低于；
  - 区间上界 < 发表值 → 显著更低，作为局限写出，原因只在开发数据上诊断。
- **配对比较：** ISIC、Lung、Fundus、Road 另做冻结方法 − FoRIS 重现的同例配对，FoRIS 取 `../cv_data/a/x1013_official` 已封存的逐例记录。Road 只和重现值 27.26 比，发表值 13.3 不可比。
- **数据曝光：** COCO 官方 4,000 例在 10-05～10-11 被 FoRIS 增强链当作开发数据用过。官方成绩是基准数字，但不是未曝光的留出；干净的证据是 E1。
