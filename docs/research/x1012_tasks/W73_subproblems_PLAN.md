# W73 子问题拆分：一个数据集、一个方法地推进

2026-10-16。用户提出：目标太大、太散，应结合已有记录定义子问题，一个数据集一个数据集、一个方法一个方法地研究。

## 1 为什么这样做

- **过去的修正多是跨域交换。** 同一个改动在一些域涨、在另一些域跌；按十域均值判断，最后什么都没留下。例子有 W20/W21 聚类先验、W24 常数、W59、W60、W62。
- **唯一的大胜正是只解决了一个子问题。** Fundus +15 来自细结构：它走单独的回退路径，由可观测的 rho > .9 触发。
- **最终方法仍是一套，不按数据集调参。** 但可以包含由可观测量触发的子机制，像 rho 回退那样。

## 3 子问题与顺序

**P1 ISIC：单个病灶的范围读出。**
- 我们输给 FoRIS（−0.90）和 MFU（官方 −1.77，显著）。
- 但 SH 的场本身不差：逐例最佳阈值 82.3，FoRIS 的场是 78.7。
- 20 个灾难例里，14 个在现有场上有好切点。
- 问题集中在读出。

**P2 COCO：整物体的响应。**
- 与 FoRIS 持平，比 MFU 低 1.16（区间含 0）。
- 23 个灾难例里，18 个属于“场不够、但探针可达”：这是场的质量问题，不是切点问题。
- MFU 比 SH 好，说明在 COCO 上，FoRIS 线提供了 M′ 没有的整物体证据。

**P3 iSAID：多个小实例。**
- 输 FoRIS 0.53。
- 旧开发协议上，INSID3 为 54.77，高于 FoRIS 的 50.43（R6）。

**P4 部件（PASCAL-Part、PACO-Part）：区分目标部件和同一物体上的其他部件。**
- 这是我们的强项。
- 剩下的灾难例多是探针可达的（PACO 24/31）。
- 查询内部的成组与归属方向相反（W66）。

**其余：**
- **P5 LVIS：** 小而罕见的类别，60 个灾难例里 28 个未解决。
- **P6 细结构：** Fundus 的机制由 W71 在周末拆解；Road 未解决。
- **P7 SUIM：** 先处理标签解码问题。
- **Lung：** 已接近上限，不做。

**顺序：P1 → P2 → P3 → P4。**
- 前三个是我们输的域，也正是 FoRIS 线（A）强于 M′（A′）的地方；解决它们，就是走向 A′+B > A+B 的路。
- P1 最干净：单一类别、单个目标，问题只在读出。
- 一个子问题有了结论（解决了，或说清为什么解决不了），再进入下一个。

## 4 每个子问题的做法

1. **只用该数据集的 S 半，先用已有缓存：** SH 两线与融合场、FoRIS 场、MFU 场、W58 的精确阈值账本。
2. **一个方法一个方法地看：**
   - 顺序：SH 的 U0、M′、融合、CRF → FoRIS 及其各组件 → MFU → INSID3、FROST、RSRM、FSSDINO；
   - 逐例记录谁赢、赢在哪类错误上，用四项编辑账本。
3. **回答两个问题：** 在这个数据集上，起作用的是什么信息？是在哪一步丢掉的？
4. **把答案写成一个带可观测触发条件的机制，然后：**
   - 在全部 S 域上检查它不伤别的域；
   - 在 T 半确认一次。

**P1 的第一组问题（只读已有缓存）：**
- **读出错误的方向：** ISIC 上 SH 是欠分割还是过分割？与面积比、病灶大小有什么关系？
- **FoRIS 做对了什么：** 它的场更差（逐例最佳 78.7 对 82.3），完整输出却更好（S 半 63.65 对 62.88）。它的读出（聚类先验、投票、后处理）在 ISIC 上做对了什么？
- **理论：** 单个团块的场，经 minmax 后取 .5，误差从哪里来？
  - 可能一：背景里的高分离群点抬高了最大值；
  - 可能二：病灶内部响应不均。
  - 两者能直接在场上区分。
