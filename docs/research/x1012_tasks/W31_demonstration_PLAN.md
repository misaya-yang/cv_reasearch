# W31：用示范匹配决定范围

2026-10-14 写定，K0 当晚执行。本文件第 1–4 节在任何新编码和任何结果之前固定，执行中不改。

## 1 问题与命题

**证据链：**
- **排序不差。** 同一面积下，我们的场在十个域上都不低于 FoRIS，其中九个域区间为正（W04）。
- **差在范围。** 逐例按 GT 选切点可多约 10 个点（W14）。这部分集中在 20% 的例子上，面积错 2–5 倍。
- **范围从分数场读不出来。** 面积估计量、直方图、查询自身分组、λ、线间选择、监督融合都已试过（TOKEN_READOUT_CEILING、W15、W16、W26）。
- **原因：** FoRIS 和我们都用“查询 token 与参考的相似度”决定范围（W14 §3）。
- **已有的正信号：**
  - 唯一胜过拟合常数的无参数范围规则，是“候选范围与参考 mask 的双向一致性 J”（r ≈ .65–.70，+2.2）。不过它是通过 token 迁移来比较的；
  - 候选族里已经包含完整目标，失败在选择（历史第 7 条，oracle 80.95）。

**命题：** 参考 mask 示范了“分割多大”。让冻结的编码器整体地看一个假设的范围，并与示范比较，就能得到分数场里没有的范围信息。

**K0 只回答这一个前提：** 在同一组候选上，整体比较是否比现有的 J 携带更多范围信息，而且这些信息确实来自示范本身。

## 2 K0 设计

**样本：** W23 的 S 样本，1,285 例，`w23_simple_pipeline.rows_for('S')`。
- 回退例（rho > .9，共 195 例）所有臂都等于 SH，不参与选择；
- T 半和新照片留出都不读。

**候选（无标签）：**
- 由冻结的 `simple_head` 得到 CRF 前的融合场 F = .5·M′ + .5·U0（1024²），捕获方式与 W27 相同。
- 自然掩码 m₀ = F > .5，即 SH，面积为 a₀。
- 9 个候选：s ∈ {−2, −1.5, −1, −.5, 0, .5, 1, 1.5, 2}。
  - s = 0 就是 m₀；
  - 其余取 F 最大的 k = round(max(a₀, 256) · 2^s) 个像素，k 限制在 [64, .95·1024²]。

**渲染（对候选和参考做同一件事，无标签）：**
1. 图像用 FoRIS 宿主的 `_transform` 得到 CLI-1024 画面的归一化张量；
2. 掩码外的像素置 0，即归一化后的均值色，编码器的“空输入”；
3. 取掩码外接框的中心，裁出边长为 max(32, ⌈1.1·max(h, w)⌉) 的正方形，超出图像的部分填 0；
4. 双线性（antialias）缩放到 448²。

参考用 `lab.mask1024` 读出的参考 mask。

**编码：** 冻结的 DINOv3 ViT-L/16，与 O24 同一份 timm 权重，FP32，MPS。取最终 norm 之后的 CLS token（索引 0）。

**选择规则（都无标签，同一组候选；平局时取 |s| 较小的）：**

| 臂 | 规则 |
|---|---|
| natural | s = 0，即 SH |
| Dsel（主） | argmax cos(CLS(候选), CLS(本例参考)) |
| Psel（安慰剂） | argmax cos(CLS(候选), CLS(换来的参考))。换来的参考：同域、按 index 排序后本例之后第一个类别不同的非回退例（循环）。只在多类别域计算：COCO、LVIS、PASCAL-Part、PACO-Part、SUIM、iSAID |
| Jsel | argmax J，即 `rc.quality(m, c, back_f)`，与 SH 内部所用的 J 相同 |
| D2sel（次要，只报告） | 同 Dsel，但改用渲染掩码内 patch token 的均值 |
| orc（诊断） | GT 最优候选 |

**封存：** 全部选择写入 `selections.json` 并记录 SHA 之后，才读取 GT。

**判定：**
- P1：Dsel − natural = −10.17（要求 ≥ +1.0），不通过；
- P2：Dsel − Jsel = −8.49（要求 ≥ +0.5），不通过；
- P3：六个多类别域上 Psel − natural = −20.79，并不比 Dsel 的一半（−7.06）好，不通过。

**诊断（不改变判定）：**
- **整体比较偏向小范围。** Dsel 选 s ≤ −1 的有 410 例，Psel（换成别类参考）选 s = −2 的有 266 例。外接框裁剪加缩放之后，小核心区域的特写与任何以物体为中心的参考裁剪都更像，这一偏好压过了范围是否正确。
- **例内排序信号：**
  - CLS 相似度与候选 IoU 的例内 Spearman 中位数为 +0.48，J 为 +0.83；
  - 但按 J 取最大值仍比自然切点低 1.68。J 在自然切点附近的排序是对的，取最大值的位置却有偏差。
- **自然切点本身：** 在 47% 的例子里（516/1090）就是 9 级候选中 GT 最优的一级。
- **候选组 oracle：** 十域 +7.56。前 20% 余量例的 IoU 为 natural 39.3、oracle 68.7，Dsel 39.7、Jsel 41.1。

**结论：** 用“掩码裁剪后的全局 token”去和示范整体比较，不携带可用的范围信息，而且有系统性的尺度偏差。按计划关闭，不改渲染或规则重试。W30 按 SH+ 开跑。
