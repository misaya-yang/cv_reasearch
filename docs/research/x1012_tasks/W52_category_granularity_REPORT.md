# W52 理论：参考指定的类别与粒度，怎样在跨图证据和查询结构中被保留

2026-10-15 写。本文是理论分析和可检验的预测，**没有新实验**。数字都引自已完成的任务，并注明出处。各命题的地位分三种：
- **结构性：** 由方法的形式直接推出；
- **有支持：** 已有数据与之一致，但没有专门检验；
- **待检验：** 只是假设。

## 1 参考指定了什么

一张参考图 I_r 和它的 mask M_r，指定的是一个目标概念。它有两个成分：

- **类别 A：** 目标“是什么东西”，即特征空间里的一块外观区域。它由 mask 内部的内容决定。
- **粒度 ℓ：** 目标“到哪里为止”。它是部件还是整体，一个实例还是全部同类，物体还是一片区域。
  - 粒度**不是内容的属性，而是 mask 与参考图自身结构之间的关系**：mask 在哪里切断了本来连在一起的东西。
  - 例如，参考 mask 只盖住车轮，而车身就在旁边、特征相近。粒度信息就在“车身被排除了”这件事上。

**形式化：**
- **层级：** 对一张图 I，设 H(I) 是由其 token 特征相似度得到的层级分割（嵌套划分，按合并距离 d 索引）；
- **参考的粒度：** M_r 的粒度可以表示为一个层级 d_r，使 M_r 在 H(I_r) 的 d_r 层近似是若干分块的并，而在更粗的层上有分块跨过 mask 边界；
- **切断邻居 N_r：** 在 d_r 之上的下一次合并中，与 M_r 合并的那块区域，也就是被排除的、最相似的相邻部分。

**单张参考对两种成分的约束不对称：**
- **类别：** mask 内部的所有 token 都是正例，信息量大；
- **粒度：** 只靠 mask 边界附近的少量关系表达，而且只有当 N_r 出现在参考图里时才存在。

## 2 两条通道

参考的信息进入查询，只有两条通道：
- **跨图证据：** 查询 token 与参考 token 的相似度，即逐点的证据场；
- **查询结构：** 查询自身的相似度图、分组、CRF，它们决定证据如何扩散、在哪里停。

## 3 命题

### 命题 1（结构性）：逐点证据加上与参考无关的结构算子，只能通过外观传递粒度

**设定：** 方法的形式为 T̂ = Θ(S_q(e_q))，其中：
- e_q(i) = g(φ_q(i); φ_r, y) 对查询 token 是逐点的：特征相同的两个 token 得到相同的证据；
- S_q 只依赖查询，例如查询 kNN 图上 λ 固定的求解、CRF；
- Θ 是全局阈值。

**结论：** 目标范围由 S_q 在给定 e_q 下决定。粒度 ℓ 能影响输出的唯一途径，是改变 e_q 的空间分布。

**推论：** 如果目标部件 P 与同一物体的其余部分 O 在特征上相近，e_q 就分不开它们（DINOv3 末层特征带上下文，部件 token 常带有整体的语义）。证据会沿查询结构扩散，输出停在 S_q 自身的自然层级，而不是参考指定的层级。

**SH 正是这种形式：**
- 核迁移 c、原型 p 和 guide 都是逐点的；
- 新颖度强度 s 只是一个按 max-J 选的标量；
- 查询图 L、λ = 16、min-max、.5 阈值和 CRF 都与参考无关。

**与已有结果的对照（有支持）：**
- “所有变体落在同一条整合尺度轴上”，大目标与部件、小目标之间存在粒度交换（W20、W24、W26）。命题 1 的解释是：粒度由与参考无关的整合尺度决定，改常数只能整体前后移动；
- 按参考面积、预测面积、数据集、max-J 选尺度全部失败（W09、W10、W25、W26）。面积是标量，而粒度是 mask 与结构的关系，标量带不过去；
- 灾难例以误检为主，占 54%；W45 中 66% 的灾难例面积偏大（W51）。这与“证据扩散到比参考更粗的层级”一致，但没有专门检验。

### 命题 2（结构性 + 有支持）：负样本只对参考里出现过的干扰物有效

**结构：**
- B_i（像参考背景的程度）高，当且仅当查询 token 像某个参考背景 token；
- 因此 F − B 只能压住在参考背景里出现过类似物的干扰；
- 对参考里没有的干扰，B 什么也不说，判定退化为只看 F，再加上方法的默认行为（SH 中，min-max 之后相对最强的部分成为前景）。

**这也是粒度的第二条通道：**
- 部件级目标的切断邻居 N_r（其他部件、物体其余部分）通常就在参考背景里；
- 查询中与 N_r 相似的 token B 高，从而被压住。
- 所以粒度能否传递，取决于 N_r 是否出现在参考里，并且以背景 token 的身份被利用。

**已有数据（W51 证据，真参考，纯 token 上 AUC 的中位数）：**

| 域 | A_F（像参考前景） | A_B（不像参考背景） | A_D − A_F |
|---|---:|---:|---:|
| Lung（同类场景） | .993 | **.958** | +.006 |
| PASCAL-Part（部件） | .950 | **.618** | **+.026** |
| PACO-Part（部件） | .956 | **.510** | **+.014** |
| SUIM | .986 | .496 | +.006 |
| ISIC | .995 | .356 | .000 |
| COCO | .994 | .229 | .000 |
| iSAID | .985 | .188 | +.007 |
| LVIS | .999 | .136 | −.001 |
| Road | .996 | .122 | +.003 |

- **场景相同（Lung）时，负样本强有力；** 部件数据集里，负样本有中等作用，并且让 F − B 的排序优于 F 单独。这与“兄弟部件在参考背景里”一致。
- **物体数据集里 A_B 远低于 .5：** 查询目标反而比查询背景更像参考背景。有两种解释，**尚未区分（待检验）：**
  1. **场景不同：** 参考背景里没有查询背景的类似物，查询背景的 B 很低；
  2. **边界环的机械效应：** 覆盖率介于 0 与 .5 之间的边界 token 外观是前景，却以 1 − y 的权重计入 B，于是目标的 B 被抬高。
- 两种解释的含义不同：第 1 种是任务本身的限制，第 2 种是证据定义的缺陷。

### 命题 3（结构性）：粒度可以从单张参考识别的必要条件

粒度 ℓ 可识别，至少需要：
1. **参考里看得到切断邻居 N_r。** 如果参考只露出部件，没有物体的其余部分，“部件还是整体”无法区分。这是单参考任务本身的歧义。
2. **M_r 在参考自身的特征层级里可表示。** 即 mask 边界是特征上的结构边界。否则粒度是一种标注约定，特征看不见。
3. **查询目标在查询层级里可表示，且层级可比：** 两张图的合并距离能对应起来。
4. **token 分辨率够用**（W49）。

**含义：** 这四条都不成立时，失败不是方法的问题，而是这类信息不在输入或特征里。其中条件 1、2、4 只用参考或 GT 形状就能检查，不依赖任何方法。

**与已有结果的对照：**
- W44 关系森林在 token 级迁移“前景内部 / 边界”关系，冒烟时查询边从未获得边界支持：参考的边界边几乎都落在混合 token 上（条件 4 加条件 2 的边界版本）；
- W32 用末层 key 和 O24 的谱分组（K ≤ 16）表示 GT，oracle 只有 43.7–55.9，低于阈值切分的 71.4。
- 这两条提示条件 2、3 可能经常不成立，但它们只检验了固定的 K 和边级关系，不是完整层级，**不能据此下结论**。

### 命题 4（有支持）：在参考没有提供信息的区域，类别判定需要绝对标准

- 查询里两边都不像的区域，参考既没有说是，也没有说不是；
- SH 的比较在这里由噪声决定，min-max 再把相对最强的部分推过 .5；
- 要让类别在这些区域得到保留，判定必须基于 F 的绝对水平，并且用参考自身来校准，例如参考内部“前景对前景”的相似度分布（排除相邻块以防泄漏），而不是 F − B 或 min-max 之后的相对值。
- W51 中，灾难例的“两边都不像”占 19.9%，COCO、ISIC 上居首（45.2%、47.1%）。

## 4 对问题的回答（当前理解）

- **类别**主要走跨图证据的正样本通道，总体上保留得不错。换成错配类别的参考，十域掉 34.5 点（W48）。它在三种情况下丢失：
  1. token 装不下目标（W49）；
  2. 查询里有参考没见过的干扰，判定落到默认行为（命题 2、4）；
  3. 正样本的相似度本身就区分不开（W51 的竞争者，8.9%）。
- **粒度**不是内容，是关系。在 SH 这类“逐点证据 + 与参考无关的结构算子”中：
  - 它只能借外观差异传递（命题 1），或在参考背景里有切断邻居时借负样本传递（命题 2）；
  - 其余情况下，输出粒度由查询自身的结构和固定常数决定。
  - 这解释了为什么 SH 在“大而清楚的物体”上好（目标粒度恰好等于查询结构的自然粒度），在部件、stuff 和小目标上发生粒度交换。
- **要同时保留两者，参考必须参数化结构算子本身。** 也就是说，参考不只提供逐点证据，还要决定查询里在哪一层停、在哪些边上切断。可能的形式：
  - 在查询层级中选与参考同等合并距离的层；
  - 由参考选用其层级最能表示 mask 的特征层；
  - 在 token 以下分辨率迁移边界关系（W44 在 token 级失败）。
  - 这是方法的设计空间，不是结论。前提是命题 3 的条件 2、3 经常成立，而这一点还没测。

## 5 可检验的预测（实验计划另写，W30 结束、机器空闲后再跑）

以下都只用 CPU。层级的构造事先固定：O24 去偏单位 token、4 邻接 token 图、余弦距离、平均连接凝聚聚类。

| 编号 | 检验什么 | 怎么测 | 我的预测（运行前） | 预测不成立意味着 |
|---|---|---|---|---|
| G1 | 条件 2、3：粒度在特征里看得见吗 | 参考 mask 与查询 GT 被层级分块并表示的最好 IoU（R_r*、R_q*），与 W49 的 C64 对比 | 物体域（COCO、ISIC、Lung）R_q*/C64 ≥ .85；部件域（PASCAL-Part、PACO）与 SUIM 明显更低 | 若部件域也高：粒度看得见，失败在传递；若物体域也低：末层特征的层级与标注不对齐，需换层或换结构 |
| G2 | 层级能否跨图对应 | 参考的 d_r 与 GT 的最佳层 d_q 在域内的相关 | 域内 Spearman ρ > .3 | 若接近 0：合并距离不可跨图比较，“迁移层级”这条路不成立 |
| G3 | 命题 1：SH 的粒度由谁决定 | SH 输出在查询层级中的最佳层 d_SH，与 d_r 的相关，以及与只看查询的量（种子所在最大连贯块的大小）的相关 | 与 d_r 的相关弱（\|ρ\| < .2），与查询量的相关明显更强 | 若与 d_r 强相关：SH 已能传递粒度，命题 1 的推论与实际不符 |
| G4 | 命题 2 的两种解释 | 计算 B 时去掉边界环（0 < y < .5）的 token，看物体域的 A_B | A_B 上升但仍 < .5：两种效应都有 | 升到 > .5：主要是边界环效应，是证据定义的缺陷，可修 |
| G5 | 条件 1：切断邻居是否可见 | 参考 mask 外一圈 token 与 mask 内的相似度（相对全图背景），把参考分成“切断连贯结构”与“沿自然边界”两类，域内比较 SH 面积偏大率 | “切断”类的面积偏大率更高 | 若无差异：粒度丢失与切断邻居无关，命题 1、2 的解释需要修改 |

- **G1 是关键。** 它决定“参考参数化结构算子”这个方向值不值得做。如果粒度本身在特征层级里看不见，就要先研究表示（换层、更细分辨率），而不是设计结构算子。
- **数据规则：** 只用 S 半，事先写定，跑一轮，看到结果不调参。

## 6 与“修补 SH”的界线

本文用 SH 作具体例子，因为它的形式正好落在命题 1 的范围里。但命题 1–4 是关于一类方法（逐点证据 + 与参考无关的结构）和单参考任务本身的。G1、G2、G5 完全不依赖 SH；G3、G4 用 SH 或它的证据作为被检验的对象，而不是要改进的对象。
