# W59：SH 与 FoRIS 的差别在分数场的哪里——排序还是切点

2026-10-15 深夜写定，用户要求先看计划。第 1–3 节在运行前固定，执行中不改。

## 1 动机

- **已有现象（新照片留出 3,211 例，已评分数据的事后描述）：** 去掉 Fundus，SH+ − FoRIS 逐例均值 +1.5、中位数 +0.6。按 GT 占比分档：

  | GT 占比 | < 1% | 1–5% | 5–20% | 20–50% | > 50% |
  |---|---:|---:|---:|---:|---:|
  | SH+ − FoRIS | +5.8 | +2.7 | +1.1 | +0.2 | −1.1 |

  领先约八成来自 GT < 5% 的三成例子。SH+ − MFU 在同一条轴上交换。
- **原解释不成立：** 我原以为是“FoRIS 整块判断、我们软概率加插值”。读 FoRIS 代码后，`_binarize_response` 同样是对 64×64 连续分数做 min-max、双线性上采样、.5 阈值，与我们的出掩码方式相同（W58 也指出）。所以差别只能在 64×64 分数场本身，或在之后的 CRF。
- **以前的相关结果：** x1013 E2（T 半）中，UFraw 与 FoRIS 去 CRF 在等面积下的排序差，大多数域只有 +0.2 至 +0.7，Lung +1.4，Fundus +14.7。那次按域报告，没有按目标大小分，也不是 SH。
- **本次要回答：** 在每个大小档里，SH 与 FoRIS 的差距有多少来自“像素排序更好”（同样多的像素，谁选得更准），多少来自“切点位置不同”（选多少像素）。这决定下一步该研究排序还是范围。

## 2 设计

**样本：** W23 S 半 1,285 例（与 W55–W57 相同）。T 半与新照片留出不读。主分析去掉 Fundus（全部走回退），Fundus 单列。

**三个像素场（1024×1024，都在 CRF 之前，> .5 即为各自的自然掩码）：**
- **P_F（FoRIS）：** 缓存的 FoRIS 最终 64×64 分数 → 双线性上采样 → min-max。与 x1013 记录里的 `foris_noCRF` 同一定义。
- **P_SH（SH）：** 按冻结 `simple_head` 的同一计算取出融合场 .5·M′ + .5·U0；回退例为 min-max(up(c32))。
- **次要：** SH 的两条单线 U0、M′ 各自的场，用来看小目标优势由哪条线带来。

**排序/切点分解（GT 只用于计分和分档）：** 对每例，A_X 为方法 X 自然掩码的面积（valid 内）。“X 的排序取 k 个像素”指 P_X 在 valid 内最高的 k 个像素（同值按像素序号）。

- IoU(X, k)：X 的排序取 k 个像素的 IoU。自然成绩 = IoU(X, A_X)。
- 总差 = IoU(SH, A_SH) − IoU(F, A_F)，精确分成两项（两种顺序取平均）：
  - **排序效应** = ½ [ IoU(SH, A_F) − IoU(F, A_F) ] + ½ [ IoU(SH, A_SH) − IoU(F, A_SH) ]
  - **切点效应** = ½ [ IoU(SH, A_SH) − IoU(SH, A_F) ] + ½ [ IoU(F, A_SH) − IoU(F, A_F) ]
- 这里不用 GT 面积或最佳阈值，交换的是两个方法各自实际选的面积。

**报告：**
- 按 GT 占比五档 × 逐域：自然 IoU（F、SH）、总差、排序效应、切点效应（逐例均值，按查询照片 bootstrap 500 次）。
- 每档 log₂(A_F/GT)、log₂(A_SH/GT) 的中位数，看各自切点偏大还是偏小。
- U0、M′ 对 F 做同样的分解（次要）。
- CRF 的作用：每档 SH+ − SH、FoRIS − FoRIS 去 CRF（已有记录，不重算），看 CRF 是否参与造成大小规律。
- 自然 class mIoU 也报告，供与 W23 对照。

**看图：** 每档按种子 2026101505 随机取 3 例（去掉 Fundus，共 15 例），另取 Fundus 3 例。每例一行：查询图叠 GT 轮廓｜P_F 热图叠其掩码轮廓｜P_SH 热图叠其掩码轮廓。记录两张场在形状上的差别（峰窄还是平铺、背景是否有平台、目标内部是否均匀）。看图只用于理解，不改读法。

## 3 预测与读法（运行前写定）

**实现检查：**
- P_SH > .5 与 W23 SH 的 I/U 逐例一致 1,285/1,285；
- P_F > .5 与 x1013 E1 的 `foris_noCRF` 一致 ≥ 1,280/1,285；
- 每例排序效应 + 切点效应 = 总差，误差 < 1e-9。

不满足则先修实现，不看结果。

**我的预测：**
- **P1 小目标（GT < 5%，不含 Fundus）：** 总差 > 0，且切点效应占总差的 60% 以上；FoRIS 的切点更偏大，log₂(A_F/GT) 中位数比 SH 大至少 0.5。
- **P2 大目标（> 50%）：** 总差 < 0，主要来自切点效应；SH 的面积比 FoRIS 小。
- **P3 中间（5–50%）：** 总差、排序效应、切点效应都在 ±1.5 以内。
- **P4 Fundus：** 排序效应大于切点效应。
- **P5：** U0 的大小规律与 SH 相同；M′ 更接近 FoRIS。

**读法：**
1. **切点效应在两端占主导，中间排序差很小：**
   - SH 与 FoRIS 排像素的能力在 Fundus 以外差不多；SH 在小目标上的领先和大目标上的落后，是同一个面积偏向的两端（归一化场在哪里过 .5）。
   - 那么，SH 在 Fundus 以外的领先主要是随大小变化的面积偏向，不是识别得更好。调面积偏向给不出普遍领先：按大小或代理选尺度已多次失败（W09、W25、W26）。
   - 要普遍领先，必须在 5–50% 档有更好的排序。下一步改看这一档里两者排序都差的例子，不再看面积。
2. **小目标上排序效应占主导：** 点证据在小目标上确实排得更准，是真优势。接着要问 FoRIS 的哪一步把小目标抹平。这需要拆 FoRIS 的内部步骤，另写计划，先确认能否从缓存特征重跑 FoRIS 各步。
3. **大目标上排序效应为负（FoRIS 排得更好）：** 这是第一处具体的“FoRIS 有、我们没有”。下一步定位 FoRIS 的哪一步带来它，同样另写计划。
4. **CRF 的作用在两端明显不对称：** 大小规律有一部分来自后处理，如实记录，不归给分数场。
5. **都不明显，或各域方向相反：** 这个分解解释不了大小规律。先看图，不提新方法。
6. 只跑一轮，看结果后不改分档、不换分解方式。这是诊断，结果不直接产生方法；若之后据此提出方法，按规则在 T 半与新数据上各检验一次。

**适用范围：** S 半、SH 与 FoRIS 两种方法、CRF 前；FoRIS 只有最终分数，本次不拆它的内部步骤。
