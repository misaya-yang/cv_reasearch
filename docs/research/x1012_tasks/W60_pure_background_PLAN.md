# W60：参考混合 token 是否污染负证据——保持参考先验的配对干预

## 1 动机

W51 的物体域中 −B 的 AUC 低于 .5；W52 给出两个未区分的解释：查询背景缺乏参考支持，或混合 token 的前景外观以 1−y 权重进入负样本。W58 说明这种描述本身不是因果证明。这里固定图像/特征/核/先验，只改变负核均值中的混合 token，检验后一条通道。

## 2 固定干预

原 W23 S 半 1,285 例，同一次 `independent` 的 r/q/y、中心化、核 K、图、原型线和所有常数保持。

- A0：原 c=df/(df+db)，df=K y，db=K(1−y)。
- PureBG：负样本只保留 **y=0** 的参考 token，`db_new=(K 1[y=0]) * sum(1−y)/count(y=0)`；df 不变。

该缩放保留原负质量 N_B，因此显式 `log(N_F/N_B)` 项不变；检验的是负核类内分布，不能将效果归于去先验。若参考没有纯背景 token，则原样回退并计数，不人为造背景。c32 以及 ind0/indn 同步更新，其余字段和分支不变；回退分支也消费这一新 c。没有改 reference mask 或重新编码。

两臂均输出完整 CRF 前/后 mask；全量封存后评分。原图纯前/背景 token（GT 覆盖率≥.9、≤.1）仅用于事后 AUC，不进入方法。输出保存所需标量 F/B/c 场及 mask，均在数据目录，不建立新 DINO 特征缓存。

## 3 预测与读法（运行前固定）

- 若混合 token 是负证据反向的重要来源，PureBG 应提高 −B 的目标/背景 AUC，尤其参考混合负质量较多的例子；不预设它一定提高最终 IoU。
- AUC 改善且完整输出改善，支持这一具体负字典修正；AUC 改善但完整输出无收益，说明局部诊断尚未兑换成读出收益；AUC 不改善则不支持混合背景解释，不能据此排除全部背景迁移问题。
- 完整终点：与 W59 相同十域开发 mIoU、配对照片区间、四类像素编辑、W58 诊断组和逐域结果。单独记录纯背景缺失、混合负质量、c 原式复现误差；不删不利例子。
- 不修改纯背景定义、不加新阈值或按域门控，只执行这一轮。是否进入后续确认由完整净结果及机制条件共同决定，另写计划，不用 T/留出做选择。
