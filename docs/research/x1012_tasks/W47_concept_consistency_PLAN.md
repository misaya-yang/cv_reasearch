# W47：参考与查询的 mask 在特征里是不是同一个概念

> **W58 更正（2026-10-15）：** 本页为已中止探针的历史记录；共同线性拟合成功不证明单参考可识别，失败也不证明特征无信息。其最佳阈值工具沿用旧 W45 近似；不得把历史 oracle 与 W58 精确计分混用。见 [W58](W58_theory_archive_REPORT.md)。

## 1 动机与理论

**已知：**
- **[W45](W45_solvability_PLAN.md)：** 灾难例中，62.5% 在查询自己的特征里线性可分，但参考定义的方向找不到目标。
- **[W46](W46_transfer_PLAN.md)：** 加强正则、分布对齐、转导重拟合都收不回这个偏差。灾难例上，参考方向与查询真实方向的余弦只有 .145。

**还没回答的问题：** 这些例子是“原则上可解、只是选不出方向”，还是“根本不可解”？

**线性读出下的判据：**
- 设 W_R 为能分开参考 mask 的方向集合，W_Q 为能分开查询 GT 的方向集合；
- 任何只看参考的线性规则，输出都落在 W_R 里；
- **若 W_R ∩ W_Q 为空：** 不存在同时分开两张图的方向，参考 mask 与查询 GT 在这层特征里不是同一个概念。无论用什么规则从这张参考取方向，都会失败。这才是有证据的难例（限于本表示的线性读出）。
- **若 W_R ∩ W_Q 非空：** 概念在两张图之间是一致的，失败来自归纳偏置，即从 W_R 里选错了方向。原则上可解，需要的是更好的选择原则。

**可计算的检验：** 用两张图的标签联合拟合一个方向（交叉拟合），看它在两张图上是否都还分得开。
- 如果联合方向在查询上明显不如只用查询拟合的方向，说明参考的约束与查询的概念冲突，交集近乎为空；
- 如果联合方向在两张图上都接近各自单独拟合的水平，交集非空。

## 2 设计

**样本：** 同 W37–W46 的 1,285 个 S 例。T 半和新照片留出都不读（本实验读查询 GT，只作诊断）。

**特征与标签：** 与 W45 相同。单位化去偏 O24 token；标签为 16×16 平均池化的覆盖率；岭回归 λ = 1；W45 的 8×8 块棋盘 2 折。

**探针（每个都按棋盘 2 折交叉拟合，被评估的 token 都没参与训练）：**
- **P_Q：** 只用查询（同 W45）；
- **P_RR：** 只用参考，评估在参考上（参考自身可分性）；
- **P_J：** 联合。每一折用参考与查询同一棋盘半区的 token 一起训练（两张图各 2,048 个，权重相等），分别预测两张图的另一半区。得到 P_J(Q)（查询上）和 P_J(R)（参考上）；
- **P_QR：** 在全部查询 token 上用 GT 拟合，用到参考上（反向迁移）。

**指标：** 最佳阈值 IoU，参考上对参考 mask、查询上对查询 GT，都在 1024 像素上计算。

**一致性代价：**
- c_Q = P_Q − P_J(Q)：为兼顾参考，查询损失多少；
- c_R = P_RR − P_J(R)：为兼顾查询，参考损失多少。

## 3 读法（运行前写定）

1. **实现检查：** P_Q 与 W45 的 cut_PQ 逐例一致（差 < 1e-6）。
2. **对 W45 中“迁移失败”的灾难例逐例归类**（按顺序取第一个满足的类）：
   - **概念冲突（有证据的难例）：** P_J(Q) < .5，或 P_J(R) < .5，而对应的单图探针 ≥ .5。没有一个方向能同时分开两张图。
   - **概念一致、选择失败（原则上可解）：** P_J(Q) ≥ .5 且 P_J(R) ≥ .5。存在共同方向，只是参考单独选不出来。
   - **其他：** 单图探针本身 < .5 等情形。
3. **同样报告全部灾难例与非灾难例的分类与平均一致性代价，作为对照。**
4. **含义：**
   - **概念冲突占多数：** 这些失败在本表示的线性读出下不可解。进一步的研究要换信息来源（层、注意力、像素），或承认单张参考的任务歧义；
   - **一致占多数：** 问题是“从一张参考在 W_R 中选方向”的归纳偏置。下一步研究什么原则能选中交集，例如查询的聚类结构、跨图稳定的特征子空间。
5. 诊断用了查询 GT，任何量都不作为方法的一部分。

## 3b 运行前追加（2 例冒烟之后、正式运行之前）

冒烟的 COCO 例中，联合方向在两张图上几乎都没有损失（P_J(Q) .637 对 P_Q .638），但查询方向用到参考上只有 .196。这暴露了一个混淆：1024 维线性模型容量很大，两张不同场景的图占据不同子空间，联合拟合可能同时拟合两种不相干的标注。这样，“一致”就不能证明概念相同。因此追加：

- **错配参考对照：**
  - 每个例子配一张同域、不同类别的参考：按例子编号排序，取后面第一个类别不同的例子，循环；
  - 用它的参考图和 mask，与本例查询做同样的联合拟合，得到 P_J'(Q)、P_J'(R')。
- **低维版本（k = 32）：** 两张图 token 合并后中心化，取前 32 个主成分，投影后重做全部探针。真参考与错配参考各自在自己的合并集合上做 PCA。
- **区分力条件：**
  - 在某个容量（1024 维或 32 维）下，只有当“概念一致”的比例在真参考下比错配参考高至少 20 个百分点（全部例子），该容量下的归类才有效；
  - 两个容量都不满足时，结论为“本检验区分不了概念一致与容量吸收”，不做难例判定。
- 第 3 节的归类规则不变，按满足区分力条件的容量报告；两个都满足时报告两者。

## 结果

**2026-10-15 10:55：冒烟测试显示本检验没有区分力，未运行全量，无判定。**
- COCO 例：真参考联合拟合 P_J(Q) .637（P_Q .638）；换成不同类别的错配参考，P_J'(Q) 仍是 .634，参考一侧 .945 对 .944。降到 32 维后，错配参考仍为 .581 对 .607。
- ISIC 例中，真参考与错配参考都“一致”。
- 结论：两张不同场景的图在特征空间里各占一块，线性联合拟合能同时拟合两种不相干的标注。“存在共同分离方向”在这里几乎总是成立，不能证明两张图是同一个概念，也不能用来判定难例。
