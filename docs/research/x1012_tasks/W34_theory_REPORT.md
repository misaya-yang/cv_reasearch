## 2 先校正经验前提和量词

### 2.1 “排序相对较好”不是“真值为完美前缀”

固定面积时优于某个基线，不能推出场与真实后验只差一个未知单调函数，更不能推出每例 GT 都是该场的 top-k。W34 题面的旧场经验也不能自动转成最终 SH 的同样性质。W14 的约 10 点余量、W31 最终 SH 的九候选 +7.56、不同场的排序诊断应保留各自方法、样本和指标归属。特别是 W31 的 +7.56 是全部1,285例、十域宏平均；不能把它挂在1,090个非回退例的九域口径上，后者涉及候选的例数不等于前者的汇总分母。来源：[A1 §1、§9 P1](W34_A1_identifiability_REPORT.md)、[A3 §1–§2](W34_A3_bayes_iou_REPORT.md)、[W31结果表](W31_demonstration_PLAN.md)、[W35 §1.4](W35_cvpr2027_readiness_REPORT.md)。

### 2.2 可辨识性反例否定的是统一保证

设可观测统计为 O、目标为 S。对一个明确模型类，存在处处正确的确定规则，当且仅当

\[
O(w_1)=O(w_2)\ \Longrightarrow\ S(w_1)=S(w_2).
\]

A1 构造了观测相同、目标分别为 A 与 A∪B、面积至少相差两倍的合法世界；两个真值都可以是相同排序的前缀。这说明缺少附加结构时没有该模型类上的统一恢复保证。**它不证明真实基准满足这种观测冲突，也不证明整个 DINO 表示或 RGB 输入缺信息。** 若一个固定合法读出在独立任务中恢复了范围，有限失败记录不能排除它。来源：[A1 §2–§6、§12](W34_A1_identifiability_REPORT.md)。

因此本汇总不采纳 Claude 原报告中“只用场本身做选择，在理论上就不可能胜过自然切点”的无条件说法。只有另加例如平方损失下范围误差的条件均值为零等具体假设，才能推出相应规则无收益；“很多选择器失败”不是这些假设或互信息为零的证明。来源：[A1 §1、§11–§12](W34_A1_identifiability_REPORT.md)；T8 的完整修正见[补充报告](W34_selection_coverage_REPORT.md)。

### 2.3 划分容纳与任务选择各自需要证据

令 S* 是划分 P 的格并集中对 GT 的最佳对称差近似，记 δ=|S*△S|、e=|Â△S*|。非空 GT 下有诊断界

\[
1-\operatorname{IoU}(\widehat S,S)
\le \frac{\delta+e}{|S|}.
\]

纯划分只能消除表达误差 δ，不能自动消除选择错误 e。两个片段在所有可用参考关系上不可区分时，即使二者都纯，参考仍不能决定选哪一个。进一步细分不降低可表示的最优 IoU；实际下降必须由锚缺失、选择噪声或其他限制解释，不能称“过分割天然有害”。来源：[A2 §3–§5](W34_A2_partition_REPORT.md)。

## 3 片段决策：概率尺度和目标函数不能省略

精确逐例 Bayes 目标是 E[I/U|X]。它需要片段标签的联合分布；仅给边际概率通常不足。即使标签独立且片段纯，不等面积时按概率扫 top-k 也未必最优：A3 的三片段反例中，面积为 (10,1,10)、概率为 (1,.47,.48)，唯一最优选择为 {0,1}，跳过了概率更高的大片段 2。来源：[A3 §3–§4](W34_A3_bayes_iou_REPORT.md)。

必须区分

\[
\mathbb E[I/U],\qquad \mathbb E[I]/\mathbb E[U],
\qquad \sum_s\alpha_s\,\frac{\sum_e I_{es}}{\sum_e U_{es}}.
\]

已标定后验下的阈值 J*/(1+J*) 对应单个总体比值目标；不能直接冠于有限例精确期望 IoU，或多个槽等权且共享同一受限规则的官方总分。F 的 minmax 不提供后验标定，片段均值也不与任意单调变换交换。来源：[A3 §5–§6](W34_A3_bayes_iou_REPORT.md)、[A4 §2、§10](W34_A4_minimax_REPORT.md)。

未知单调校准的 minimax 问题还必须固定：GT 是否非空、空集得分、联合依赖、片段面积、允许动作和是否随机化。不同模型会产生零保证、1/K 或嵌套候选的几何中点等不同答案；不能从其中选一个公式移植到实际 SH。对称九候选没有增加范围信息，minimax 返回自然面积也不构成方法提升。来源：[A4 §2–§8、§13](W34_A4_minimax_REPORT.md)。

## 4 融合与图谱：保留精确结论，撤回跨层推断

### 4.1 MSE 互补不证明 IoU 提升

对共同连续目标，记两线风险 R_U、R_M，交叉误差矩 C，则等权融合风险为

\[
R_F=(R_U+R_M+2C)/4.
\]

同时优于两线的条件是 C<min{(3R_U−R_M)/2,(3R_M−R_U)/2}。C 包含偏差乘积，不能以去均值相关性替代；固定 ½ 是 minimax 还需要明确的交换对称风险集合。当前 SH 是否满足这些条件，未由理论报告测量。来源：[A7 §4、§8](W34_A7_fusion_REPORT.md)。

反例：Y=(1,1,1,0)，U=(1,.51,0,0)，M=(1,0,.51,0)。在 >.5 读出下，两单线 IoU 均为 2/3，均值场 IoU 只有 1/3；均值场的 MSE 却更低。**当前融合的可信依据是 W27/W28 的直接分割结果，不是 MSE 恒等式。** 来源：[A7 §5 反例2](W34_A7_fusion_REPORT.md)。

两线分别是二次能量的解，但实际置信矩阵不同，M′ 含秩引导，U0 末端含 minmax，后面还有阈值和 CRF。因此不能把现行 SH 等价称为“同一图能量中先平均两个 unary 再求解”。τ=.05、.55、λ=16 仍是冻结经验设置，不能倒推其理论最优性。来源：[A7 §6–§7](W34_A7_fusion_REPORT.md)。

### 4.2 谱值不认证实体

十个纯实体各自形成互不连接的块时，归一化亲和的前十个特征值全是 1，但划分可以完全纯。反过来，稠密正相似度中的公共分量可以压低非平凡特征值，谱衰减快也不保证实体结构好。高维、hubness、稀疏或稠密均不能单独替代目标容纳证据。来源：[A8 §2 命题1–2、§3](W34_A8_spectrum_REPORT.md)。

对实际异质置信矩阵 A，平滑频率由 H_A=A^(-1/2)LA^(-1/2) 决定，滤波因子为 1/(1+λη)。它同时压低图高频噪声与真实结构。是否损害目标要看目标对该图的能量、输入误差与后续读出；不能仅凭前几个谱值宣称“kNN 系统抹平实体”。来源：[A8 §2 命题3–4、§4](W34_A8_spectrum_REPORT.md)。

### 4.3 CLS 的小核心偏好是条件机制

跨视图蒸馏约束投影头输出，不自动使原始 CLS 对范围严格不变；投影头可以忽略包含范围信息的坐标。即使范围完全不变，也只产生平局，不自动偏好更小候选。A9 的小核心模型另需“加入真实异质外围使语义方向占比下降”等条件。W31 的负结果关闭该裁剪/渲染/分数构造，不能概括为任何冻结全局表示都看不到完整性。来源：[A9 §2–§4](W34_A9_cls_REPORT.md)。

## 5 两条构造不能合并背书：正式取舍

### 5.1 A1：纯实体闭包与 F 排序相交

对每格 P_j，记录 F 全序中的最小/最大秩 l_j、u_j。合法切点满足

\[
\mathcal K(P,F)=\{k:\ \forall j,\ k<l_j\ \text{或}\ k\ge u_j\},
\qquad \mathcal Z=\{\operatorname{top}_k(F):k\in\mathcal K\}.
\]

GT 是 F 前缀且 P 对任务纯时，GT∈Z；这一条件比“相对基线排序较好”强。它与失败多数票的区别，是排除割裂整个单位的切点，而不是在自然切点上逐格投票；不需要迁移参考局部边角色。空/全图解释只有在真实协议或独立证据允许时才能排除。来源：[A1 §10.1–§10.5](W34_A1_identifiability_REPORT.md)。

比较候选与自然掩码 A0 的稳健差值

\[
\Delta_{\min}(A)=\inf_{S\in\mathcal Z}
\{\operatorname{IoU}(A,S)-\operatorname{IoU}(A_0,S)\}.
\]

真值在 Z 且该值严格正，才有模型内的改善保证；若 A0∈Z，任何不同 A 在 S=A0 的解释下都不能严格胜出。排序/纯度近似时需要有根据的误差预算，参考源内误差不能冒充查询预算。**当前这只是决策接口，缺的仍是能保留正确范围并排除错误自然点的新结构。** 来源：[A1 §10.6](W34_A1_identifiability_REPORT.md)、[A4 §12.1–§12.2、§12.5](W34_A4_minimax_REPORT.md)。

### 5.2 W32 未达到原定继续门槛，不等于所有新读出均无收益

W32 的 416 例全部完成，nat/natQ 与 W15 为 416/416 一致。最大余量 78 例的自然/切点 oracle 为 35.7/71.4；key 稠密分组 K=8/16/32 为 43.7/55.9/67.0，O24 稠密分组为 51.4/62.1/68.8。R1 未达到预定条件，R2 多数保留规则所有 K、所有域均负；key K16/K32 的报告均值变化为 −10.95/−5.62。此处是原报告的逐例均值口径，不与开发类/fold 池化 mIoU 相减。来源：[W32「结果」](W32_key_entity_PLAN.md)。

按原计划，该轮构造停止；不能因此自动接上新选择器并声称原读法通过。但原定“超过切点 oracle”是继续投入的门槛，不是优于实际自然输出的必要条件：同一困难子集里，key K16 的55.9低于切点71.4，却高于自然35.7。这个事实不能证明可部署选择器已有收益，也不能证明所有使用该划分的新规则都无收益。新规则应分别说明任务纯度、实际可选性及相对部署基线的净收益；不借旧负结果替代这些问题的回答。W32 文本中把“实体划分”简称充分结构时，还须补上参考语义选择条件。来源：[A1 §10.3、§12](W34_A1_identifiability_REPORT.md)、[A2 §3、§7](W34_A2_partition_REPORT.md)、[W32「结论」](W32_key_entity_PLAN.md)。

### 5.3 A2/A8：关系森林与终端闭包仍继承迁移假设

A8 使用 O24 邻边差和逐头 pre-RoPE key 差构造关系描述；参考 FG–FG / FG–BG 边给出 join/cut 支持球，再生成带 cut 约束的查询森林。A2 用纯参考正负 token 的双向唯一最近邻作候选终端，按最大瓶颈连接提出局部补入/删除。它不同于旧 O24 两端乘积核和 query 伪角色，也没有重写整张 SH 排序。来源：[A8 §6.2–§6.4](W34_A8_spectrum_REPORT.md)、[A2 §10.2–§10.4](W34_A2_partition_REPORT.md)。

但支持球不相交只证明算法不会同时给同一关系两种支持；它不证明 query 关系落入的球具有正确语义。BNN 与正负相似度间隔也只产生候选锚，不能证明跨图标签正确。两条保证都额外要求同真实类别的跨图覆盖、片段纯度和足够内部连通性；这正是旧角色边支持失配反例触及的缺口。来源：[A8 §6.3 命题5及其限制](W34_A8_spectrum_REPORT.md)、[A2 §10.3、§10.5](W34_A2_partition_REPORT.md)、[A7 §9.1、§9.4](W34_A7_fusion_REPORT.md)。

**裁决：A1 是不迁移局部角色的条件读出；A2/A8 是尚未证实跨图迁移的结构生成假说。二者不互相证明前提，本轮不把森林直接推进成实验。** A1 缺新的结构证据；A2/A8 的保守接受器若没有可信误差范围只能保留 SH，回退本身没有增益。若将来提出新信号，必须同时说明它怎样避免旧角色支持失配、怎样覆盖现有错误；不能把“未测过”作为立实验的充分理由。来源：[A1 §10.1、§10.6](W34_A1_identifiability_REPORT.md)、[A2 §10.5–§10.6](W34_A2_partition_REPORT.md)、[A4 §12.6](W34_A4_minimax_REPORT.md)、[A7 §9.5、§10 P4](W34_A7_fusion_REPORT.md)。

| 无一域显著更低即十域不劣 | 未检出下降、δ 内非劣和严格优势不同；正 δ 的 NI 甚至可以与小幅显著下降同时成立 | [A6 §2–§4](W34_A6_noninferiority_REPORT.md) |

全域 NI 的整体原假设为“至少一个域 Δ_d≤−δ_d”；只有各域有效单侧下界全部大于 −δ_d 才通过 IUT。这个合取主张无需对组成检验做 Bonferroni；选择性公布逐域赢家/输家，则另需控制相应比较族。没有实质正 δ 时，保留严格目标或报告最差域下界和清楚标注的敏感性，不能为了通过而放大 δ。来源：[A6 §3–§4、§6](W34_A6_noninferiority_REPORT.md)。

固定官方清单完整评分的数值差与新照片总体推断不同。六域发表数字可作核实协议后的数值对照，不能提供未经假设的方法总体配对置信推断；Road custom200 与发表 13.3 不可比。W30 仍按已冻结读法处理，本报告不修改指标、阈值、bootstrap 方法或暂停状态。来源：[A5 §1、§8–§9](W34_A5_bootstrap_REPORT.md)、[A6 §1、§5、§7–§8](W34_A6_noninferiority_REPORT.md)。

### 9.1 Astra提出的是多种不同决策规格

| 分支 | 真正交付的机制 | 仍需回答的问题 |
|---|---|---|
| A1/A2：可辨识性与划分 | 区分完整输入歧义、表示压缩、读出未找到；对称差精确分解为划分混合量α与面积加权错选量β | 当前主要残差属于哪一层？纯度、语义选择与标注协议分别提供了什么信息？不能用一个双世界反例包办解释 |
| A1/A4：排序与闭包相交 | 用片段完整秩跨度排除非法前缀；对基线求最坏IoU差，必要时clamp | 真值是否接近前缀/格并集？结构能否保留真值并排除错误自然点？clamp与最大化最坏差不总是同一规则，不能混称唯一解 |
| A2/A8：关系森林与瓶颈闭包 | join/cut/unknown支持、禁止间接跨cut的森林、正负终端的最大瓶颈传播 | 支持球是否跨图保真？终端是否正确？unknown和无锚分量有多少？低误连接若来自零覆盖，没有方法价值 |
| A3：可信联合后验下的配对决策 | 对相同后验状态比较候选与基线的IoU差，用有界数值误差决定编辑/保留 | 从何得到可信联合后验？增加后验抽样数只减少数值误差，不减少模型失配；不能用minmax(F)或J替代后验 |
| A3：类条件conformal编辑 | anchor与calibration分开；预测标签集合为单标签时整片补/删，模糊时保留 | 参考与查询片段的完整生成流程是否可交换？有效校准项是否足够？这是覆盖保证，不是后验概率 |
| A4：未知校准的稳健决策 | 明确真值歧义集、utility/regret、确定/随机策略以及相对基线的严格改进条件 | 歧义集与误差预算从何而来？若基线仍是合法真值，严格证书不能成立；保守回退不创造增益 |
| A7：有界坏见证认证 | 用错误见证总质量界构造可行标签集合，不要求见证独立；只修正认证片段 | 坏见证界必须有独立结构依据；复制相关token不能增加证据票数却保持同一错误预算。它与A3的交换性概率保证不同 |

conformal分支存在可在运行前检查的分辨率条件：若单标签显著性阈值为α/K_max，类y最小p值为1/(n_y+1)，要有排除该标签的可能，必须满足n_y+1≥K_max/α。例如α=.05、K_max=16时需要至少319个该类校准项；这只是算术例子，不是当前数据的计数。把单个实体切成许多token不能自动建立所需的跨图可交换性。[A3 §8](W34_A3_bayes_iou_REPORT.md)

增删也不能共用一个多数票解释。新增区域前景率至少1/2可给出一个不依赖基线IoU的充分条件；删除区域要满足前景率≤J/(1+J)，没有J的有效下界时，近似纯背景也未必给出普遍安全删除。完整片段高纯不等于其尚未预测的小壳层高纯。[A7 §9.3](W34_A7_fusion_REPORT.md)

### 9.3 整体科学问题尚未解决

1. **互补的来源尚未识别。** W27/W28证明具体输出的功能互补；还没有证明是“核/原型天然相反偏差”。P3和阈值交叉的四种编辑用于区分解释。
2. **共同范围错误尚未解决。** 只处理两线分歧带，动作上不能纠正两线共同FN/FP；A7的结构认证与Web B0因此要求证据能够反对两线共识。旧W16的98%不能冒称最终SH的同一测量，像素错误比例也不是mIoU收益比例。
3. **任务指定的成员/粒度尚未获得可靠转移机制。** 对应A1/A2的任务假设、A3的交换性、A8/B0的关系迁移和P4/P5；这些条件不能互相替代。
4. **边界质量与亚token位置须分别解决。** T7的覆盖率估计、RGB重建与W37的具体九臂是另一条可检验问题，不能用“都是范围”将它并入实体闭包或声称已由QK→V覆盖。
5. **最终证据与推断仍有缺口。** P0–P2、Road协议、六域缺失配对基线和随机参考/查询的依赖仍需各自完成。独立query/reference乘积权重并不自动涵盖跨角色同图的dyadic依赖。[A5 §4.3](W34_A5_bootstrap_REPORT.md)

因此QK→V只是已展开定义的候选测量，不是Astra全部研究的归宿，也没有比较证据支持“唯一最值得推进”。下一步应根据每条线真正缺失的可计算输入、可检验条件和已有实现状态推进；不以补齐文档代替这些科学问题的闭合。
