# W61：固定查询、替换合法同类参考——范围稳定性与准确率

## 1 动机

W56 的参考面积回归没有固定查询，W57 去显式先验降低面积系数却使总体 IoU 下降。本轮不调 π0，也不重复 W57 全池比较。利用原 S 缓存，固定查询与真实任务，改变完整合法参考；同时在每个参考内配对原 SH 与已固定 π0=.088 的点先验替换。目标是区分“对参考扰动更稳定”与“预测更正确”，不将不同参考内容的全部作用归因于面积。

## 2 样本（只按元数据选择）

原 W23 S 半为查询候选；额外参考只来自同一 S 目录的合法 episode，要求同 dataset、fold、global_class_id。参考图不得是该查询图；三个参考的 RGB/完整 mask/crop 身份不同。原参考作为 R0；另外两个按固定种子 2026101606 从去重候选中不放回选取。

按域用同一随机数序列选 **40 个不同查询照片**，共 400 查询，每查询独立运行 3 个 one-shot。40/域用于两小时剩余缓存预算内的配对诊断，不声称精确功效保证。缺候选与去重排除在 manifest 中记录，不按表现补样；不读任何 query GT 选成员。预测不是三参考融合，不进入 one-shot 官方成绩表。

## 3 固定臂

每个参考两条完整路径，均有 CRF 前后输出：

- SH：冻结原方法。
- FixedPrior：仅 c32 及 ind0/indn 替换为 W57 已固定 π0=.088；其余字段、原型、图、ρ 和 CRF 不变。使用自己的新封装，不修改或执行 W57 脚本。

保持每次参考内同一核/特征/中心化。完整参考替换会同时改变外观、背景、ρ 等；该干预不是参考面积的纯因果实验。保留所有参考及全部输出后再评分。

## 4 预测与读法（运行前固定）

- 预期固定先验降低同一查询内预测面积随参考面积的变化；是否增加准确率保持开放，不能用稳定性作为替代终点。
- 报告每查询三个参考的平均 IoU、观察到的最差/最好 IoU、log 预测面积标准差，以及原参考灾难例被另外参考自然输出达到 .5 的次数。最好/最差是三个预定参考的描述，不是可部署参考选择或总体最坏保证。
- 用查询固定效应计算参考面积—预测面积斜率，比较两臂；在同一个参考内的方法差才是显式先验通道的配对干预，不把参考间外观变化抹掉。
- 主准确率按每查询三参考 I/U 纳入固定开发槽后计算；另报逐查询均值，照片配对 bootstrap。不能把1200次参考配置当1200张独立查询。
- 固定先验若降低波动但损害平均/最差准确率，拒绝“更稳定即更正确”；若替换完整参考能明显改变正确性，支持现有系统对参考内容敏感，但不证明任意更多参考或该参考选择可部署。
- 本轮不根据结果挑新参考、不调先验、不做门控。T/留出不读，不新增编码。
