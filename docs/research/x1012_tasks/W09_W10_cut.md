# W09／W10：落后域为什么落后；整合尺度旋钮；排序与范围的拼接

2026-10-13。只读 x1013 T0 字段包、FoRIS 缓存分数与掩码，无新增编码。全部在选择半 S（6,752 例，其中 ρ≤.9 的 6,186 例参与重解）；报告半 T 未读。配对均已曝光，属开发测量。class mIoU 为 (fold, class) 池化后槽等权；`*` 为按 query 照片成组的 bootstrap 95% 区间不含 0。

**结论。**
1. 落后的不是某几个数据集，而是大目标。除 PASCAL-Part 外，候选在每个域占图 >25% 的目标上都输给 FoRIS；这一档占各域真值像素的 37–78%，池化指标由它主导。一个域的正负只是“小目标赢多少”减“大目标输多少”。
2. 大目标上输的全部是切点，不是排序。按真实面积取 top-k，候选场在每个面积档都高于 FoRIS 分数（25–50% 档 73.3 对 71.3，>50% 档 83.5 对 81.9）。
3. 解图常数 λ 是一个真实的旋钮，最优值随目标变大而变大；但它只移动切点。按数据集调 λ 平均只多 0.7，COCO 仍低于 FoRIS；用第一遍预测面积自动选几乎无效；逐例最优（诊断）多 4.4。
4. 排序用候选、范围取 FoRIS（同面积、双方都不做 CRF）：十域全部为正，七域显著。这是排序优势在最终指标上的直接度量。
5. 与带 CRF 的完整 FoRIS 相比，上述拼接在 COCO、LVIS、SUIM 上仍低 0.2–0.3，幅度与 FoRIS 的 CRF 收益相当。候选一侧尚未加 CRF。

这两个拼接都消费 FoRIS 的输出（一次完整 FoRIS 加一次我们的读出，共用同一次编码），是组合，不是独立方法。

## 4 COCO 与 SUIM 为什么余量最薄

同一批 W10 记录，ρ≤.9、S 半。“同面积”指候选场按不做 CRF 的 FoRIS 掩码面积取 top-k，与该 FoRIS 掩码逐例比较。
