# 授权执行：DeepGlobe100与PACO100联合读出

本chat用户在方案之后明确要求“那你做啊？”。本轮执行固定原DeepGlobe100，以及原PACO600清单中每折按原顺序前25例。共200，不按分数或缓存命中挑样，不增加模型编码。只在`codex_m4`增加独立实验入口，保留另一聊天正在修改的原参照实现与文档。

实际候选为当前修订的R1-G：whole reference、whole query及四个真实query象限的原O24；沿用原全角色LSE和16候选b0；reference角色合法像素支持、去掉已知resize形变的坐标、逆向相对几何、采样推导的跨度边；4+4同步概率阻尼BP，中间一次固定真实edge-belief的合法位置/K更新。原b0、lambda1和T1保留。R2的role-logit压缩不启用，故强prior纠错上界仍存在；先验证几何本身是否有净收益。

核心两臂为同观察的`role.unary`和`role.joint`。各自连续128前景场直接双线性读到原图和1024后严格>0.5，没有FoRIS anchor、局部FoRIS、CRF或新编码。完整FoRIS、快九窗、whole竞争及Deep原慢版直接读封存预测；PACO MEAN直接复用同批，Deep缺少的MEAN从实际whole raw做一次原CPU前端和锁定MEAN读出。首个PACO输入的MEAN重放与保存mask核对；Deep前端score与原保存score逐位核对。这些是对照成本，单列。

200个输出全部封存后才开启query GT。Deep主口径为道路总I/总U；PACO主口径为本100已观察类别的class pooledI/U、等权fold平均，同时附303槽位的缺类记0版本。两帧、配对区间和补真/补假/删真/删假均保留；不与原600绝对分数直接相减。全部仍为已曝光开发结果。

执行前完成14项合成检查：塌缩不随scale变便宜、合法fine/coarse别名、非凸角色支持投影与幂等、跨度/图着色、对称歧义、固定信念MM不增、多实例加背景桥、最终位置合法与有限。其结果只证明功能与实现，不证明涨分。整个实现与依赖、原清单、来源路径/SHA和配方在实验目录冻结；恢复只读已有完整预测收据，不能混入新源码。

产物：`cv_data/a/joint_role_pilot200_20261010/`。入口：`scripts/joint_role_pilot.py`。使用3个CPU worker，每个2线程，分别记录raw读取、候选准备、几何、baseline、输出和墙钟。缓存计时不能当六个真实输入的完整冷推理速度。没有新参数网格、其他数据集或官方全量任务。
