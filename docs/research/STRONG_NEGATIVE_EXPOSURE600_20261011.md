# 原强S负证据在后续判据输入中的暴露：同600已完成

本项核对失败链路，**没有生成新配方、预测或训练**。只读取已封存S/B/G/R0 Mask，重建原query角色，并与旧query graph及task discriminant全部600生产收据的FG/BG seed SHA逐例相同，1200项hash核验通过。600 query GT仅用于封存后诊断。

两个旧判据的像素角色定义：FG=`S&B&G&R0`，BG=`~S&~B&~G&~R0`。因此，S0/B1处无FG或BG标签；S1/B0同样无标签。当B/G/R0本身不一致时，无论S是哪一类，该像素的两个角色标签都为零。**这里丢掉的是判据训练/种子输入中的S任务标签；S原Mask在宿主/读出中仍保留，不能说整个模型完全忘记Mask。**

原图S正确删除B假前景2439283像素、误删675694真像素，都被这个BG像素角色定义排除。以下进一步检查实际CLI1024原生格子和128 BG sampler；两种frame数值不混用。

|---|---:|---:|
| 总数 | 2520940 | 9305101 |

**99.7032%的正确S删B假前景所在格子未被128 BG样本选中。** 不能把像素未入监督直接说成其特征绝对未进入模型：表中27618 FP通过同格其它BG像素仍有间接负暴露。图法使用全部area种子，不能把128 sampler漏选归到图法；其中6819854 FP所在格子确实零BG种子质量，另2485247 FP格子有其它BG质量。128 sampler是双角色判别器实际输入规则。

在这些正确否决中，5135545 CLI FP处的弱B/G/R0标签混合，4169556处三弱控制均为FG。前一组的角色投影对S位完全无响应；后一组在S正确判BG时两个角色都变为未知。S还新增700020真/2266334假CLI前景，均因B0不进入FG种子。**这不是S全部更可靠的证明**，表中的2520940误删真目标正说明把S负区全作为硬负类会伤害目标。

当前可定位：强S作出的任务判断在“要求所有弱控制同意的query角色构造”阶段被过滤；实际BG sampler进一步缩减了可用负暴露。然后后续字段在未见这些负例的争议域允许修改S，给纯RFG近邻、几何或低fit风险留下重复错误迁移的入口。后一句是待因果验证的解释，**本次没有修正角色并重新运行，不能声称已证明它造成全部失败或修正后会涨分**。

结论限两个已核输入定义与同原600。不是跨数据集统一理论、全模型不可恢复证明，也不是同query换reference Mask的新干预。角色边方法有完整S邻域输入，注册方法使用S正锚及RBG，两者不能直接套用本项seed SHA结论。后续研究保留这个范围，不以另造一条seed/ridge变体替代任务身份问题。
