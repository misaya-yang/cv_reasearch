# 冻结 DINOv3 单参考分割：token 级读出的信息上界（2026-10-12）

**结论先行。** 本轮没有得到在十个基准上全面超过 FoRIS 的方法。得到的是一组可复现的界：

1. **排序已饱和。** 任何单视角 O24 读出（中心化原型、前向标签迁移、placebo-z、双向注意力、最优传输、FoRIS 自己的分数）在 GT 最优水平下的 mIoU 都落在同一平台（五域均值 62–66）。
2. **差距全部在范围，而范围等价于每个 episode 的一个标量。** 用真实目标面积做 top-k，FoRIS 分数可达 63.0，而它的自然阈值只有 52.8（完整输出 53.7）。面积必须准到约 ±25%：0.7× 得 50.8，1.4× 得 56.6，2× 得 45.1。
3. **这个标量从现有字段不可得。** 十余种与排序水平无关的面积估计量，对数误差都不小于 FoRIS 的隐式估计（中位 |log2| 0.46）；用 query GT 监督拟合的线性／提升树融合（外观、FoRIS 分数、对应场几何、episode 统计）在留出 episode 上最高 54.3，等于 FoRIS 的 54.4。**FoRIS 大致位于固定常数 token 级读出的信息上界（分辨力约 ±1 分）。**

   **更正（同日）：** 这个界比较的是无 CRF 的融合输出与带 CRF 的 FoRIS，分辨不了 1 分以内的差别。仓库已有的加法臂（MEAN、三方投票、supported_mean）在 6,200 例上确实高于 FoRIS 0.3–1.2 分，但它们都以 FoRIS 的输出为输入。独立方法的现状与后续计划见 `INDEPENDENT_BASE_PLAN_20261012.md`。
4. 简单读出只在部分域取胜：部件（PASCAL-Part、PACO）和细结构／肺（Fundus、DeepGlobe、Lung）；在 COCO、LVIS、SUIM、ISIC 上输。

以下数字均为已暴露过的 dev episode、CLI-1024 帧、按类汇总 mIoU；除标注外不加 CRF。监督界使用 query GT 仅作诊断，不是可部署方法。

## 3 面积估计量与监督信息界

**面积估计量**（`d25_area_estimators.py`，半 B，中位 |log2 误差|）：FoRIS 隐式 0.46（COCO 0.31、LVIS 0.91、PASCAL 0.42、PACO 0.65、SUIM 0.26）；|f>0.5| 0.59；Σf 0.67–0.69；反向质量困惑度 0.72–1.04；逆 Simpson 0.78–1.59；参考面积 1.13；全部估计量的监督对数线性组合 0.52。用它们做 top-k 均低于 FoRIS（最好 46.7，监督组合 49.4，对 54.4）。

**监督融合界**（`d23`／`d26`／`d27`，半 A 拟合、半 B 评测；FoRIS 完整 = 54.4）：

## 5 仍然成立的正信号

- 用参考均值或联合均值中心化对排序是必需的。
- 含背景竞争的读出（全参考 token 的前向迁移、placebo-z）在部件上排序优于 FoRIS（GT 水平 PASCAL 68 对 65，PACO 61–62 对 60）。
- 软覆盖率迁移 + 双线性渲染在细结构上显著优于 FoRIS（Fundus 34.2 对 19.1），因为 64 网格硬 token 的上限只有 24.0。
- 双向注意力替代量 J(S)=ac/(a+c−ac) 与真实 IoU 跨水平相关 r≈0.65–0.70，是唯一无参数且胜过拟合常数的范围规则（+2.2），但仍低于 FoRIS。
