# 单参考、零新编码：可靠度与块内几何实验

用户授权：深入分析、设计并完成实验，保持单参考、不新增编码。当前分支codex_m4。每次推理只消费一张参考的已有O24、参考完整Mask、一张查询的已有O24及必要RGB；不新增视角编码，不读取查询GT，不使用FoRIS输出作为方法输入，不按域选方法。原计划及C1产物保持冻结。

目标仍是统一方法在十域达到或超过完整FoRIS，并比较已有MEAN强控。不能用多参考、GT最优阈值、局部案例或跨域均值代替这个目标。

## 1 证据与新假设

- B1的K-shot结果显示，参考覆盖会同时影响排序与范围；这不等于允许增加参考。当前可利用的补充信息是同一查询中的结构与已有像素信息。
- e06/e07把低解释度乘到前景分数上，会把陌生真目标也压低。d07则强制给整个查询二分伪标签并移除参考约束，已经失败。
- A7图法仍将极端但错误的迁移分数视为强锚点。新的可检验差异是：参考解释度控制锚定强度，未知区域由相邻可靠证据决定，不被直接定义为背景。
- A6只检验过最近邻硬区域并集；它不限制连续像素输出。已有全图像素分类器、先插值特征再读出也试过；新几何实验仅学习参考混合块内的相对位置，严格保留语义基线的每块面积。

图谐波/查询传播本身是已有方法，不宣称原创。参考：[Zhu等，ICML 2003](https://mlg.eng.cam.ac.uk/pub/pdf/ZhuGhaLaf03a.pdf)、[LaplacianShot](https://proceedings.mlr.press/v119/ziko20a.html)。[SSP](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136790689.pdf)利用查询高置信区域缓解参考覆盖不足，但本轮不把未经验证的查询预测当作新GT。

## 2 R1：陌生作为未知，还是作为背景

使用原B4固定1360例十域开发队列，继承P0字段与单参考身份。两组输入分别为原c和已冻结的max-J调制c+V+P；后一组沿用ρ>.9直接T的固定细结构规则。两组各比较同样四个臂，禁止扫描λ/温度/阈值。

令s=minmax(输入场)，a0=.1+|2s−1|，e=sigmoid(logE−median(logE))。沿用A7互惠20NN边权、平均度归一及λ=16，求解(diag(a)+16L)f=a·y。

|臂|目标y|锚定a|解释|
|---|---|---|---|
|G0|s|a0/mean(a0)|原图基线|
|BG|s·e|a0/mean(a0)|陌生作为背景，位置对应对照|
|UN|s|a0·e/mean(a0·e)|陌生降低锚定，主假设|
|PERM|s|a0·permute(e)/mean(a0·permute(e))|同分布错位置对照|

置换由episode身份SHA固定。输出统一64 token连续场、双线性1024、minmax、严格>.5。参考固定标签的joint RQ谐波能量等价于E加权的c锚定，因此不另造大图重复测试；本式对E作稳健压缩。

全部1360例自然输出先封存后评分。报告完整自然指标和GT逐例最优严格阈值诊断，另报告UN对G0/BG/PERM的配对照片bootstrap。最优阈值只用于分辨排序与校准，不参与选择最终阈值。检查低e错误在原20NN图中是否能接触到正确方向的高e邻居，及部件边界的跨标签连边；这仅为评分诊断。

只有UN胜过对应G0及PERM，才认为可靠度的空间位置有用。若不成立，不扩大λ网格，不把joint RQ重命名为下一候选。

## 3 R2：保留语义范围，只修正块内位置

固定旧VP_thin09作独立语义基线。它不读取FoRIS输出，最大借用V/P两步。每个16×16块保留基线前景像素数k，混合块才允许重排。

参考图中，用合法Mask的混合块形成块内FG/BG像素描述子差；拟合小型pairwise logistic，仅参考监督，无跨任务训练。描述子采用已有RGB/局部对比/梯度/纹理12D实现。空间留出用于选择残差强度，包含零修正。最终Query只在每块内对语义场加参考残差排序，取严格相同的k个像素。

固定实现：每个参考混合块取8对FG/BG位置；差分按训练RMS标准化，12个斜率、无截距、L2=.01。训练/选择为64像素棋盘空间划分、8像素间隔，沿用已有描述子协议。语义场和像素残差都在各16块内标准化；强度仅在参考留出上从{0,.25,1}选择，按真实块内面积下的TP最大、同分优先较小强度。另报固定强度1的因果对照。置换只打乱参考块内训练标签，保持其面积，选择仍用合法真实参考留出。

必要对照：原语义排序同k（必须逐位复原基线）；真实描述子；块常数描述子（不能改块内排序）；参考块内置换标签（无真实边界对应）。不使用原FoRIS答案保护或补丁。报告完整IoU、四种像素编辑及每块面积恒等性；面积误差不变不能冒称校准改善。若本实验无有效增益，保留负结果，不拓展低层颜色网格。

上述面积恒等针对完整1024输出。iSAID评分排除ignore像素，跨ignore位置的重排可能改变有效面积；推理不读取ignore标签，报告单独保留该差异。

R2的作用范围是块内位置，不能修复整块漏检或错误身份。若R1有有效语义候选，才把已固定的R2组件作用到该候选，不重新选择强度。

## 4 选择与验证

开发选择沿用最差域差值优先、再十域等权平均、再较少组件，固定一个方法。与完整FoRIS、MEAN、旧VP_thin09同任务比较。每域指标：按(fold,global_class)池化I/U的mIoU、逐例均值、三档面积、FN/GT、FP/GT、面积误差、照片配对95%区间。

若没有候选使十域均≥FoRIS−0.5pp，报告距离目标的域及错误，不称通用成功。若达到开发门槛，在冻结后用缓存观测生成最多50个/域的未使用有向新配对，排除P0 explore/confirm、原任务和K-shot已用配对；只重放缓存FoRIS，不新增编码。旧C1不再次作为盲测。新配对仍来自旧照片，验证只支持缓存照片内的新配对泛化，不声称全新照片或论文完整基准。
