# 研究导读：我们在研究什么，为什么走到这里

> **2026-10-14：** 当前方法、证据、已关闭路线和下一步，统一见 [OVERVIEW.md](../OVERVIEW.md)。本文件保留术语与研究演化；与总览冲突时以总览为准。

这份文件面向拿到分支、没有这几天聊天记录的人。先读本页，再根据问题进入完整研究记录。成功与失败的价值取决于它们支持了什么、排除了什么，不能只按分数或文件日期判断。

## 1. 问题和目标

输入是一张参考图R、它的完整二值目标Mask M_R，以及一张query图Q；冻结DINOv3，预测Q中对应任务的完整Mask。完整Mask同时提供正负监督，单参考不等于一个点或只有正样本。query GT只用于评测或明确标记的oracle诊断，不进入自然预测。

目标是同一规则跨域获得完整输出优势，超过完整FoRIS与必要强控制，而非只改一个token指标或在某个域调阈值。当前独立方法不直接消费FoRIS最终答案；旧依赖FoRIS的增强结果仍是有效强控。允许比较中的额外计算，但须说明实际编码、观察和后处理成本。

十域为COCO、LVIS、PASCAL-Part、PACO-Part、SUIM、iSAID、ISIC、Lung、Fundus、DeepGlobe road。它们覆盖整物体、部件、场景区域、遥感、病灶、器官和细结构；道路队列为本地协议，缓存子集不等于每个官方完整测试集。[协议说明](autonomous_20261010/protocol_inventory.md)中的任务定义有用，旧资产数量/进度是日期快照。

## 2. 论文里的几个名字到底是什么

|名字|具体含义|容易误解的地方|
|---|---|---|
|O24|冻结DINOv3末层输出；当前常用1024输入、64×64 token，每token 1024维|不是原图像素分割，也不是已经过RCG的分数场|
|去位置|投影掉已有位置子空间，再归一化特征|投影资产是方法输入的一部分；不能混同原始O24|
|coverage|每个16×16块里合法参考Mask前景的比例，保留软质量|不同于FoRIS实际bilinear/回退后的hard参考角色|
|FoRIS / B|完整参考方法：包含其前景/背景处理、投票、先验、聚类及既定完整后处理|只取前两步或裸场不能冒充完整基线|
|RCG / MEAN / G|从FoRIS连续场出发，以参考guide做rank修正，再作query互惠近邻图求解；MEAN的guide是纯FG均值|是依赖FoRIS的增强，不是独立基座；两者guide及系数都不同|
|fine16 / fine64|用四个真实shifted query编码进行细读出；后缀是粗图λ|不是16/64分辨率，也不是免费插值|
|固定残差|把fine(RCG)−上采样RCG加到上采样MEAN|不同于直接fine(MEAN)；不能把FoRIS至最终总增益全归残差|
|R0|6200旧账本的有界ridge全图anchor|仍有FoRIS宿主依赖，且不等于后来final-CRF版本|
|C / N / K|C是B/G/R0多数；N在指定争议新增域补像素；K同域同新增数量、按MEAN margin选择|N胜B不等于新参考排序有贡献；需看N−K|
|S|LVIS600真实局部窗口输出，经query-context区域拒识和覆盖strict多数形成的强结果|有真实观察预算，不能叫单whole同成本控制|
|c / T|已有特征下的参考软Mask核加权迁移场；T直接从c读出|是独立参考证据；不能把GT最优阈值当自然T|
|IND0 / INDN|IND0对c做K64区域均值；INDN另用新颖度调制|新颖度抑制误报也可能抹掉陌生真目标|
|max-J / VP_thin09|标签无关J选择调制；VP借用投票/先验，固定ρ>.9时退回T|是完整固定候选，有依赖、系数和失败边界，不是已成功基座|

构造原文：[RCG/MEAN/fine/残差](parallel_signal_20261010/03_graph_readout/REPORT.md)、[B/G/R0/C/N/K与具体反例](FIVE_DATASET_CASE_MECHANISMS_20261011.md)、[S阶段](STRONG_STAGE600_RESULTS_20261011.md)、[IND计划](INDEPENDENT_BASE_PLAN_20261012.md)、[C1冻结](../x1012_tasks/C1-freeze.md)。同名臂跨批次不一定同处理链，引用时保留队列和frame。

## 3. 几天研究的主链，而不是启动日志

|阶段|当时的问题|真正留下的证据|因此下一步为何改变|
|---|---|---|---|

## 4. 哪些失败值得保留，究竟否定了什么

- **理论反例与界：** [可辨识性](IDENTIFIABILITY_AND_METHOD_CONSTRAINTS_20261012.md)定义任务族和条件风险；6200闭集检验限制其应用范围。它没有证明当前单参考基准不可解。
- **表达与选择的区别：** [source-span](TASK_TRANSFER_SOURCE_SPAN_20261010.md)、[任务迁移核心](TASK_TRANSFER_CORE_20261010.md)说明同样解释参考的规则仍可在query不同；oracle方向不是合法方法。
- **完整计算图的边界：** [有效读出](FIVE_DATASET_EFFECTIVE_READOUT_20261011.md)追踪Mask旁路、soft/hard压缩和gate；某一通道消失不能推出完整模型信息不可逆丢失。
- **恢复的代价：** [否决反转](STRONG_VETO_REVERSAL600_RESULTS_20261011.md)、[负证据暴露](STRONG_NEGATIVE_EXPOSURE600_20261011.md)保留错误FP与正确TP同时被恢复的事实；补BG必涨并未得到证明。
- **内部特征与非线性：** [任务核](TASK_TANGENT_KERNEL_20261010.md)、[context兼容性](TASK_CONTEXT_COMPATIBILITY120_20261012.md)、[共享层级](TASK_SEMANTIC_HIERARCHY_FIVE_RESULTS_20261012.md)应保留固定构造、强控和失败原因；不是对全部核、非线性或层级的否定。
- **像素信息与新观察：** [物理像素证据](autonomous_20261010/physical_pixel_evidence.md)、[真实focus](autonomous_20261010/REFERENCE_FOCUS200_RESULTS.md)保留局部正信号、匹配插值控制及域间失败。它们直接解释当前R2为何只改块内位置，不重复整个像素分类器。

[便携机制报告](../../../evidence/research/mechanism_reports.json)和[方法规格](../../../evidence/research/method_specs.json)携带关键原数值及公式配置；所有保留正文/代码的理由在[保留清单](../../../evidence/research/retained_work.json)。

## 6. 家里拿到分支后如何开始

1. 本页建立术语和主链；[STATUS](../STATUS.md)说明目标及状态边界。
2. [RESULTS](RESULTS.md)选要用的正/负证据，必要时查完整研究记录；[GAPS](GAPS.md)说明尚欠的证据。
3. [PLAN](PLAN.md)指向当前R1/R2/R3；其结束后的结论以任务报告为准，不把本次复盘建议当并行新队列。
4. 运行 `python -B scripts/read_research_results.py`，无需外部资产即可复算C1/B1表。
5. 按[跨机器接续](CONTINUING_ELSEWHERE.md)准备实验所需数据集、模型、缓存与环境，补齐缺少的资产，适配路径并验证目标实验入口。重要文档和代码随Git，大文件单独传输，同属接续实验的准备内容。

分支提供研究背景、代码和小型证据；回家继续实验的交付还包括数据、模型和运行环境。仅复算已有结果表不代表目标机器已能运行实验，具体准备状态见接续说明。
