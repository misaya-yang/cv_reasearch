**基线定义（所有任务共用）。**
- 特征：`r, q = lab.debias(lab.feats(b, role))`；`mu = 0.5*(r.mean(0)+q.mean(0))`；`sim = unit(q-mu) @ unit(r-mu).T`。
- `y = coverage64(参考掩码)`；`k = exp(sim/0.05)`；`D_F = k@y`，`D_B = k@(1-y)`，`E = D_F+D_B`，`c = D_F/E`。
- 区域：`lab.kmeans(unit(q), 64, iters=6)`，取区域均值。
- **IND-0** = 区域均值的 `c`，双线性上采样到 1024，min-max，`>0.5`。
- **IND-N** = 区域均值的 `c × minmax(sim.max(1))`，同样读出。
- **T**（细结构用）= 不做区域平均的 `c`，同样读出。
- 参考实现：`scripts/x1012/e06_open_set.py`、`e04_dump_arms.py`。

**统一报告格式。** 每个结果表必须含：逐域按类汇总 mIoU 与逐例均值；按查询目标面积分三档（<2%、2–20%、>20%）的逐例均值；汇总的漏检率 FN/GT 与误报率 FP/GT；面积对数误差中位数 `|log2(预测面积/真实面积)|`；例数；相对 FoRIS 的差值及按查询照片配对 bootstrap 的 95% 区间。iSAID 用 `lab.ignore1024`。

### 第 1 波：拆对手、拆自己（互不依赖，可并行）

**A1 FoRIS 逐阶段阶梯 × 目标大小 × 错误类型**（CPU，约 4 小时）
- 问题：F3 只有 LVIS 的总分。FoRIS 压掉中小目标误报的是哪一步？
- 做法：沿用 `lvis_atomic_study.py` 的只读钩子，在 COCO 200、PASCAL 300、PACO 300、SUIM 300、ISIC 300、iSAID 60 上重放，保存七个阶段前缀的场。每个前缀按原读出（min-max、双线性、0.5）出掩码，按统一格式报告。
- 产出：每域一张"阶段 × {mIoU、三档大小、FN/GT、FP/GT、面积误差}"表。
- 判据：找出让 COCO 中等目标与 ISIC／SUIM 小目标的 FP/GT 下降最多的一到两步，它们就是"可借用步骤"的候选，交给 B4。若下降均匀分散在各步，说明没有可单独借用的步骤，B4 降级。

**A2 交换实验：优势在证据还是在决策**（CPU，约 3 小时）
- 问题：FoRIS 强在分数（前景/背景项）还是强在后面的决策整形（投票、先验、惩罚、簇）？
- 做法：两个方向各做一次。
  1. 把 FoRIS 前两步的分数换成 IND 的 `log D_F − log D_B`（或 `c`），后续阶段原样运行。
  2. 把 FoRIS 前两步后的分数（`s2`）送进 IND-0 的读出（区域均值、min-max、0.5）。
- 判据：若（1）≈ FoRIS（±0.5），则证据侧已等价，之后只研究决策；若（2）≈ FoRIS，则决策侧已等价，之后只研究证据。两者都不成立说明是耦合的，记录差值。

**A3 误报解剖**（CPU，约 3 小时）
- 问题：F5 的误报是什么？
- 做法：对 IND-0 在 COCO、LVIS、SUIM、ISIC 上的误报像素，按连通分量归类并统计面积份额：
  1. 与真目标相连（边界外溢）还是分离（独立干扰物）。
  2. COCO：落在哪些已标注类别上（用 `demo4_cache/data/COCO2014/annotations` 的语义图），还是未标注背景。
  3. 该分量内 `c` 的最大值与目标内最大值之比；`E` 的分位数。
  4. 分量面积相对目标面积。
- 判据：分离型占多数 → A5 优先；外溢型占多数 → A6（区域质量）与 A7（CRF）优先；集中在少数语义相近类别 → 属于语义混淆，记录为当前特征下不可解的部分并估算其上限。

**A4 两个独立变体的逐例上界与预测量**（CPU，约 2 小时）
- 问题：IND-0 与 IND-N 各赢一半域。若每例能选对，够不够？能否仅凭参考图选？
- 做法：
  1. 逐例取两者中 IoU 较高者（用 GT，仅作上界），报告十域分数与对 FoRIS 的差。
  2. 计算不读查询 GT 的候选预测量：参考图内前景/背景可分性（去掉 3×3 邻域后的留出 AUROC）、参考背景中与前景相似的质量份额、ρ、参考前景面积、查询中 `E` 低于中位的份额、两个掩码的面积比、双向一致性替代量 J（见 `d19_bidir_extent.py`）。
  3. 报告每个预测量对"IND-N 是否更好"的 AUROC（按 |ΔIoU| 加权），以及用它选择后的十域分数。
- 判据：上界若在 COCO／SUIM／ISIC 上仍低于 FoRIS 2 分以上，则"在这两个变体间切换"这条路关闭。上界够而所有预测量 AUROC <0.65，则关闭"仅凭参考统计切换"。有预测量 >0.75 则进入连续调制（`c × 新颖度^s`）。

**A5 迟滞与连通分量验证**（CPU，约 3 小时）
- 问题：用"高阈值定种子、低阈值连通生长"替代单一阈值，能否去掉分离型误报而不丢大目标？这类空间连通规则此前从未测过。
- 做法：在 IND-0 的 1024 场上（min-max 后）：
  1. 迟滞：种子 `>h`，生长到 `>l` 的连通区域。扫 `h∈{0.6,0.7,0.8,0.9}`、`l∈{0.3,0.4,0.5}`。
  2. 分量验证：对 `>0.5` 的每个连通分量，保留"含有互为最近邻的 token"或"分量内最大值 ≥ 全局最大值的 γ 倍"的分量，γ∈{0.7,0.8,0.9}。
  3. 上界：用 GT 选择保留哪些分量。
- 判据：先看上界。上界相对 IND-0 在 COCO 提升不足 3 分 → 误报不是分量级问题，关闭。上界够 → 找一组在十域上都不降的固定 (h,l) 或 γ；多实例域（COCO、LVIS、iSAID）要单独报告漏检率是否上升。

**A6 区域上界与区域级监督界**（CPU，约 4 小时）
- 问题：把决策单元从 token 换成区域，信息上界会不会明显高于 token 级的 52.4？区域本身的质量是否是瓶颈？
- 做法：
  1. 区域上界：每个区域按 GT 多数标注后的 mIoU。区域取法：k-means K∈{16,32,64,128,256}；凝聚聚类（FoRIS 的 τ=0.6 及 0.5、0.7）；加空间邻接约束的聚类。
  2. 区域级监督界：每个区域的描述子（`c` 的均值与最大值、`E`、区域大小、互近邻数、与参考前景/背景区域的区域对区域核相似度、相邻区域的 `c`）。在 explore 的一半上拟合逻辑回归，另一半评测，另做留一域。
- 判据：区域上界若在 LVIS 小目标上 <70，区域质量是瓶颈，优先改聚类。区域级监督界若 ≥ FoRIS+2（留一域也成立），"区域分类"成为主线并交给 B4；若仍约 52–54，与 token 级结论一致，关闭。

**A7 可借用的通用步骤**（CPU，约 3 小时）
- 问题：CRF 与查询图平滑不属于 FoRIS 独有，借来能补多少？
- 做法：
  1. 对 IND-0、IND-N、T 的场套用仓库的 CRF（`src/ics/m4_crf.py`，与 FoRIS 相同参数）。
  2. 把 MEAN 的图求解（`mean_control.py` 中的互惠 20 近邻图、λ=16）作用在 IND 的 `c` 场上，替代区域平均；去掉其中依赖 FoRIS 分数的秩修正项。
- 判据：报告十域增量。CRF 增量若 ≥ +1 则计入独立基座的固定后处理。图平滑若不优于区域平均则关闭。

**A8 逐类解剖：SUIM、ISIC、COCO 中等目标**（CPU，约 2 小时）
- 问题：F8 里 SUIM 独差 6.5 分，是哪些类、哪种错误？
- 做法：SUIM 逐类、ISIC 按病灶面积十分位、COCO 逐类，对比 FoRIS 与 IND-0 的 IoU、FN/GT、FP/GT；每域挑差距最大的 12 例出对比图（参考、查询、GT、两种预测、`c` 场）。

### 第 2 波：依赖第 1 波的结果

**B1 缓存内 K-shot 诊断**（CPU，约 3 小时，依赖 P0-1）
- 问题：缺的是"参考没覆盖到的类内变化"，还是"校准"？
- 做法：用 P0-1 的 K-shot 清单，把 K 张参考的 token 合并后跑 IND-0 与 IND-N。报告 K=1,2,3,5 时的 GT 最优阈值分数、自然阈值分数、面积误差、FP/GT。
- 判据：若 K 增大主要降低 FP/GT 与面积误差，而 GT 最优阈值分数变化小，说明缺的是背景与类内变化的覆盖，下一步研究"伪参考"（从查询自身取高置信背景）。若两者同涨，说明排序也受限，结论回到 F1 之外，需重审。

**B2 缓存窗口上的独立读出**（CPU，约 4 小时）
- 问题：LVIS 小目标（<2%）IND-0 为 28.4，FoRIS 31.0；缓存里已有 LVIS 固定窗口 5,400 个、PACO 九窗 5,233 个、DeepGlobe 组件 1,100 个，放大观测对独立读出有没有用？

**B3 细结构门控的敏感度与确认**（CPU，约 2 小时）
- 做法：ρ 阈值扫 0.5–0.9；在 LVIS 的 ρ>0.5 子集上比较 T、IND-0、FoRIS（当前为 33.1／33.3／33.0，几乎相同）；在 P0-1 的 Fundus／DeepGlobe 新配对上复核 F7。

**B4 最小借用集**（CPU，约 4 小时，依赖 A1、A2、A6）

- 判据：存在组合在十域上相对 FoRIS 均 ≥ −0.5，即得到"独立基座"，冻结后进入 C1。不存在则报告最接近的组合及其差距所在的域和目标档。
