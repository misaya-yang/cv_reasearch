# A4_modulation 实验报告

A4 J差值的报告半weighted AUROC>.75后，按计划进入逐例连续调制检验。
s固定0..1九点只是标签无关目标J的数值搜索，未用GT选s/阈值/域；并列选更小s。c/novelty/region均复用原缓存。
J_endpoint用J直接在原两端点选择；J_continuous可选择中间强度。无FoRIS输出进入推断。
首轮仍是已曝光原开发1360，不是confirm；无新增encoder、view、训练。

主指标沿用计划lab.Meter：每个(fold,global_class)池化I/U，再对观察槽等权平均；CLI1024。不同于先平均fold的指标。
GT/预测忽略iSAID ignore像素。FN/GT、FP/GT用像素总量之比；面积误差为空预测时为∞。95%区间按query照片配对bootstrap，seed20261012，1000次，每次重新聚合。全部为开发/诊断结果，未评分confirm。
