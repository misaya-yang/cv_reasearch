## 1 设定与记号（与代码一致）

### 1.1 特征

- 输入缩放到 1024²，得到 $N = 64 \times 64 = 4096$ 个 patch token，取第 24 层（最终 norm 后）的输出，维度 $D = 1024$。
- **去位置偏置：** $x \leftarrow \mathrm{unit}(\hat x - B B^\top \hat x)$，其中 $\hat x = \mathrm{unit}(x)$，$B \in \mathbb{R}^{1024 \times 500}$ 是由黑图估计的位置子空间。
- 查询 token 记 $q_i$，参考 token 记 $r_j$。
- **参考覆盖率：** $y_j \in [0, 1]$，即 patch $j$ 的 16×16 像素中落在 $M_R$ 内的比例。

### 1.2 核迁移线 U0

**相似度与核：**
- $\mu = \tfrac12(\bar r + \bar q)$；$s_{ij} = \cos(q_i - \mu,\ r_j - \mu)$；$m = \max_{ij} s_{ij}$；
- $K_{ij} = \exp((s_{ij} - m)/\tau)$，$\tau = 0.05$。

**由核导出的量：**
- 前景比例：$c_i = \sum_j K_{ij} y_j / \sum_j K_{ij}$；
- 对数解释度：$e_i = \log \sum_j K_{ij} + m/\tau$；
- 反向捕获：$b_i = \sum_j \mathrm{softmax}_i(s_{ij}/\tau)\, y_j / \sum_j y_j$。softmax 对查询下标 $i$ 归一化。

**一致性 J：**
- 对 token 集合 $A$：$a = \mathrm{mean}_{i \in A}\, c_i$，$\beta = \sum_{i \in A} b_i$；
- $J(A) = a\beta / (a + \beta - a\beta)$。

**新颖度调制：**
- 新颖度 $n = \mathrm{minmax}(\max_j s_{ij})$；
- 对 $t \in \{0, \tfrac18, \dots, 1\}$ 取 $c^{(t)} = c \odot n^t$；
- 在查询的 k-means-64 区域上取区域平均后读出掩码，选使 J 最大的 $t^*$，令 $c_{mod} = c^{(t^*)}$。

**查询图：**
- 在去偏 $q$ 上取余弦互为 20 近邻的点对；
- 权重 $w_{ik} = \sqrt{\exp(-d_{ik}/\sigma_i)\exp(-d_{ki}/\sigma_k)}$，其中 $d = 1 - \cos$，$\sigma_i$ 为第 20 近邻的距离；
- 按平均度归一化后，$L = D - W$。

**U0 的求解：**
- $s = \mathrm{minmax}(c_{mod})$；
- 置信权重 $a_i = (0.1 + |2s_i - 1|)\cdot \sigma(e_i - \mathrm{median}\, e)$，并归一化到均值 1；
- $u = (\mathrm{diag}(a) + \lambda L)^{-1} \mathrm{diag}(a)\, s$，$\lambda = 16$；
- 最后双线性上采样到 1024² 并做 minmax。

### 1.3 原型线 M′

**原型：**
- 前景原型：$\mu_{fg} = \mathrm{unit}(\mathrm{mean}\{\hat r_j : y_j \ge .5\})$；
- 困难负例：背景 token 中与 $\mu_{fg}$ 最相似的 20%，取其均值；
- 背景原型 $\mu_{bg}$：困难负例均值对 $\mu_{fg}$ 正交化后再单位化。

**打分与引导：**
- 打分：$p_i = \hat q_i \cdot \mu_{fg} - 0.55\, \hat q_i \cdot \mu_{bg}$；
- 引导：$g_i = \hat q_i \cdot \mathrm{unit}(\mathrm{mean}\{\hat r_j : y_j \ge .9\})$。

**秩引导求解：**
- $s = \mathrm{minmax}(p)$；$z = s + 0.25(\mathrm{rank}(g) - \mathrm{rank}(s))$，其中 rank 为归一化秩，取值在 (0, 1)；
- $a_i = 0.1 + |2s_i - 1|$，并归一化；
- $m' = (\mathrm{diag}(a) + 16L)^{-1}\mathrm{diag}(a)\, z$，再双线性上采样。

### 1.4 融合与读出

- **融合场：** $F = \tfrac12\, m' + \tfrac12\, \mathrm{minmax}(u)$，两者都在 1024² 上；
- **自然掩码：** $\{F > .5\}$，之后接一个固定的稠密 CRF。这就是当前方法 SH+。
- **回退：** 当 $\rho = 1 - \sum_j y_j \mathbb{1}[y_j \ge .9] / \sum_j y_j > .9$ 时（参考掩码几乎全由部分覆盖的 patch 组成，即细结构），改用 $\mathrm{minmax}(\mathrm{up}(c)) > .5$。
- **候选梯度：** $a_0 = |F > .5|$；对 $s \in \{-2, -1.5, \dots, 2\}$，取 $F$ 最大的 $k_s = \mathrm{round}(\max(a_0, 256)\cdot 2^s)$ 个像素。

### 1.5 指标与区间

**逐例量：** 每例在有效区域内给出交集 $I_e$ 与并集 $U_e$（像素数）。

**开发指标：**
- 每个域内，按 (fold, 类别) 槽汇总：$\mathrm{IoU}_{slot} = \sum I_e / \sum U_e$；
- 对出现的槽取等权平均，再对十个域取等权平均。

**官方指标：**
- 每个 fold 内，对该 fold 应有的类别计算 $\sum I / \max(\sum U, 1)$；
- 先对类别取平均，再对 fold 取平均。

**区间：**
- 以“规范化的查询照片”为簇做多项式重抽样，同一照片在所有域、所有臂上用同一权重；
- 重新汇总比值，配对作差，取 95% 百分位区间。

## 4 交付格式

每题按以下结构写：
1. **形式化设定：** 写明全部假设；
2. **主要结论：** 写成定理或命题，附完整证明。需要反例时给出构造；
3. **可检验的预测：** 写明在我们的数据上计算哪些量（只用第 1 节定义的量，或新的冻结编码器量），以及正、负结果分别如何判读；
4. **对方法设计的含义：** 下一步该构造什么，哪些方向可以不做；
5. **证伪条件：** 什么样的经验结果会推翻你的结论。

**篇幅：** 只回答分派给你的题，写透。

**其他要求：**
- 不确定的地方明确标为猜想，不要把启发式写成定理；
- 引用文献时给出处，不要编造。
