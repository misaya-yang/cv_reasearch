# W40：从参考图的边界带迁移覆盖量

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。

## 1 动机

- **W37：** 带内每个 token 的正确覆盖量值 +9.43（O2）。用核迁移 c 当覆盖量（C2）是 −2.12，c 在边界 patch 上近二值。
- **W38：** 图像颜色有方向信息（ρ .353），但切点的量过冲，mIoU −1.73。F 排序正确时，IoU 对应逐块计数的绝对误差。
- **c 为什么近二值，一个可检验的解释：条件总体不匹配。**
  - [T7 补充](W34_selection_coverage_REPORT.md) §1 指出，c 估计的是参考上的条件均值 m_R(x) = E_R[Y | X = x]，平均范围是参考的**全部** token；
  - 而被估的查询 token 已知落在边界带内。参考的纯前景、纯背景 token 远多于边界 token，并且一个混合 token 的最近邻往往是某一侧的纯 token，所以 c 被拉向 0 或 1；
  - 正确的条件应是两边同一事件：E_R[Y | X = x, token 在边界带]。参考 mask 已知，参考的边界带可以精确算出。
- **本任务回答：** 把核迁移的字典限制在参考的边界带（两边用同一带定义），覆盖量能否超过 F 自身的量（nat）；限制总体这一项改动，能收回 c 的多少损失。

这条路只用参考 mask 和已有特征，不加模型，不提高分辨率，也不调温度。

## 2 设计

**样本、场、自然掩码、查询带：** 与 W37、W38 完全相同，同 1,285 个 S 例，含回退例。调用 `w37_coverage` 的 `capture`、`pool16`、`band`。

**参考带 B_R：** 对参考覆盖率 y（`independent` 返回的 64×64 软覆盖率）调用同一个 `band`。

**覆盖量来源（只在查询带内使用）：**
- **C：** 核迁移 c32，字典为参考全部 token（即 W37 的 C）。
- **Bd（主）：** 与 c32 相同的去偏、中心化与温度（τ = .05），字典只取 B_R 内的 token：
  $\hat\pi_i = \sum_{j\in B_R} w_{ij}\,y_j / \sum_{j\in B_R} w_{ij}$，$w_{ij} = \exp((s_{ij} - \max_{j\in B_R} s_{ij})/.05)$。
  B_R 少于 4 个 token 时改用 C。
- **true（容量）：** GT 在块内的像素数，即 W37 的 O2。

**重建：** W37 的 R2。带内每块取 round(256·π̂) 个 F 最高的像素，带外保持 N。各臂记为 nat、C2、Bd2、true。

**指标：**
1. class mIoU 相对 nat，CRF 前，口径同 W37；区间用 `score.paired_ci`，十域区间用 `w37._boot`。
2. **逐块绝对计数误差比：** $L_1 = \sum|k_{est}-k_{true}| / \sum|k_{nat}-k_{true}|$，在全部带内 token 上池化；区间按例为簇 bootstrap 500 次。
   另报池化的 I、U 与像素错误 U − I。
3. 局部 ρ（与 W38 相同），只作记录。

## 3 读法（运行前写定）

- **通过：** Bd2 − nat ≥ +1.0（十域均值），十域配对区间下界 > 0，且 ≥ 7/10 域 ≥ 0。
  通过后写方法验证计划：Bd2 加 CRF，对 SH+ 在 S 上比较，再读 T 一次。
- **不通过时，用 Bd2 − C2 区分两种原因：**
  - **Bd2 − C2 ≥ +1.0：** 总体不匹配确实是 c 失败的原因之一，但参考迁移来的量仍不如 F 自身的量。关闭“用核迁移从参考带取覆盖量”。
  - **Bd2 − C2 < +1.0：** 限制总体收不回 c 的损失，c 的失败主要来自跨图差异（m_R ≠ m_Q），不是总体不匹配。同样关闭这条构造，并在 OVERVIEW 第 8 节写明原因。
- 不在看过结果后改温度、带宽或字典范围。
- **运行前的一处修改（3 例冒烟测试之后、正式运行之前）：** 原稿第二种原因还要求 L1(Bd) < L1(C)。冒烟测试的一个 COCO 例中，C 的计数误差和带内像素错误都低于 nat，IoU 却从 47.1 降到 40.1；再查 W37、W38 已有结果，C2、U2、rgb 的池化像素错误都高于 nat。计数误差不是 IoU 的可靠代理，所以把它从判据中去掉，只作报告。通过条件不变。

**逐域：** Bd2 − C2 只在 PACO-Part（+0.23）、ISIC（+0.32）为正；ISIC 是唯一区间含 0 的域（−0.18，[−0.77, +0.39]）。

**判定：**
- Bd2 − nat = −2.91 < +1.0，十域区间 [−3.23, −2.73]，0/10 域 ≥ 0，不通过；
- Bd2 − C2 = −0.79 < +1.0：按读法，限制总体收不回 c 的损失，c 失败的主因不是条件总体不匹配。
- **范围说明：** 读法写的是“主要来自跨图差异（m_R ≠ m_Q）”。严格说，本实验只排除了总体不匹配；剩下的解释是跨图差异，或特征本身不能确定覆盖率（[T7 补充](W34_selection_coverage_REPORT.md) §1 第 2、3 点），本实验不区分这两者。

**诊断（不改变判定）：**
1. **限制字典让量向中间收**：Bd2 的 U 增加 6.1M、I 只少 0.7M，多出的主要是假阳性，错误分布在本应为空的带内 token 上。
2. **ρ 不是好的筛查：** C、Bd 的局部 ρ（.48、.53）都高于 W38 的颜色（.35），mIoU 却更差；C 的计数 L1 与 nat 持平（1.008），像素错误仍更多。
3. **nat 的量很强：** 到目前为止，c、线性解混、颜色切点、参考带字典四种量都低于 F 自身的阈值量。要收回 +9.43 的容量，带内量需要接近逐块精确；ρ 约 .5 量级的信息远远不够。
