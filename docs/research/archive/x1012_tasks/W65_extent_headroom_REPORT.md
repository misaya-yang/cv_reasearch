# W65 报告：单个“每例切点”规则拿不回范围余量

2026-10-16。按 [计划](W65_extent_headroom_PLAN.md) 由两个子代理并行完成，我核对了预注册时间、哈希、关键数字和代码中有无 GT 泄漏，并看了图板。

- **样本：** S 半 W14 样本中 1,970 个 G 场例子（rho ≤ .9，不含 Fundus）。
- **场：** MFU 的 CRF 前融合场 G。
- **口径：** 逐例 IoU 均值。
- **未读数据：** T 半与新照片留出。
- **资源：** 每个代理 1 进程 × 2 线程、nice 19，不用 MPS。

## 0 结论

**没有量过预注册门槛**（大余量例方向 AUC ≥ .70，且多数域同号）。两个分支各自独立给出同一个结构，它解释了以前十几种切点线索为什么全部失败：

1. **80% 的例子不该动，20% 的例子要大幅移动。** 所需修正的中位，前者 0.19 倍频，后者 1.44 倍频。
2. **IoU 对面积很陡。** 面积偏 ×/÷1.41 就损失 12–15 分；2 分近优区间中位只有约 .27 倍频宽。
3. **不看 GT 的信号只能弱地分开这两件事：**
   - “该不该动”：最好的 AUC 为 .745，是场在 .5 附近的坡度；
   - “往哪动”：最好的 AUC 为 .65–.70，是参考前景的反向注意力一族。
   - 两个都不完美的决定串起来，在不该动的 80% 上亏掉的分，大于在 20% 上赚到的分。
4. **即使某一半已知，收益也很少：**
   - 即使用 GT 完美判断“哪些例子该动”，最好的旧线索也只收回约 1.1 分（总余量 12.0）；
   - 即使方向完美、量取 GT，方向信号也只比随机方向多约 1 分。

**含义：** 继续寻找“每例一个全局水平或面积”的规则，已没有依据，这条路线在此场上关闭。这不等于输入里没有信息，而是这类标量决策的形式不对。

  - 大余量组最佳 IoU < 50 的只有 16%；

**图板上的观察（只用于理解，GT 用于分组）：**
- **欠覆盖：**
  - G 在目标上分级：最像参考的子部分高，例如罐顶、物体正面、脸、病灶核心；连着一大片 .15–.45 的中等区，例如侧面、头发、船舱、桌布、病灶外围。
  - 参考常只展示目标的一个子集或另一视角，例如戴帽的头、夜里只见船体、俯视的罐顶。
- **过覆盖：** 高峰外连着一层 .5–.8 的台阶，例如托台、杯沿、窗框、掌托、皮肤晕；或者另有峰较低的独立块，例如贴纸、墨迹、其他容器。
- **两类有同一种形状：** ISIC 的“核心 + 晕”、PACO 的细沿参考，两类里都出现。区别不在场的形状，而在相连的那一片算不算目标。
- **方向主要跟真实目标大小走：** 在 V 半，GT 大小本身对方向的 AUC 为 .92。
- **13–19% 的大余量例子，最佳切点本身也只是拼凑：** 包括找错物体、场极性反转、场没有定位、部件分不开。
- **SUIM 疑似标签解码丢失：** 6153、4536、4648、5510；另外 6133 的 RI/SR 边界存疑。

## 3 读法

- 计划第 3 节的四条读法，都没有覆盖“有 .60–.70 的弱信号、但无一过门槛”这种结果：
  - 读法 1 不成立；
  - 读法 2、3 不适用：没有线索属于 (c)；(b) 标签大多来自自然面积；
  - 读法 4 要求全部 < .60，也不满足。
- 我不在事后补门槛，只记录以下事实：
  - 输入里存在弱方向信号，主要来自参考前景反向注意力（J / back_out）；
  - 但“每例一个标量切点”这种决策形式，被 80/20 的需求结构和陡峭的 IoU 曲线限制住。两个分支给出的上界都只有约 1 分。
- **由此看到的下一个问题（只是重述问题，不是方法）：** 不再问“整幅场切在哪个水平”，而是问：与已覆盖核心相连的那一片中等区域，是否属于同一个目标。这是空间上局部的范围归属判断。图板显示，欠覆盖与过覆盖的差别正在这里。W43 记录过“带外共同 FN 91% 连在已检出物体上”，与此一致。
- 立项前必须先回答一个问题：这种局部判断需要的信息，参考里有没有？在欠覆盖例中，相连区域常常不在参考 mask 展示的部分里。

**适用范围：** S 半、MFU 的 CRF 前场、非回退例、逐例 IoU。都是相关，不是因果。结论不外推到 FoRIS 场、带 CRF 的掩码或 T 半。
