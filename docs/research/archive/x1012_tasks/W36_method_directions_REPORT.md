## 2 三篇到底改变了什么

### 2.1 RSRM：表示重组、查询回馈、三粒度竞争

论文的 SAFR 用参考 mask 的类间/类内 Fisher 比与位置敏感通道方差，筛选并加权原生 attention 子层输出；ASE 用较可靠的查询正负区回馈参考；HPM 对全局、区域、逐点三种原型分别匹配再融合。它已经覆盖“单骨干、无梯度更新、局部/全局互补”的大部分概念空间。[论文§3](https://arxiv.org/html/2606.24297v1)

固定源码还明确了三个不能靠模块名字省略的细节：[rsrm.py](https://github.com/Sparkling-Water/RSRM/blob/4173c9fd38b4156b9d9200dd6ef941d88eca91bd/model/rsrm.py)。

- SAFR 实际还除以各层输出的整体标准差；不是仅把论文 Eq.4 的原始层输出相加。
- ASE 的二类 cosine logits 乘 10。代码的稳健阈值取“参考 IoU 不低于峰值 0.75 倍”的阈值均值；论文 Eq.5 写的是阈值大于 `0.75*t*` 的集合。二者不是同一规则，复现应标采用哪个版本。
- HPM 的 FG 原型数为 `1/9/全部`，BG 为 `1/18/全部`；每族先取最大匹配，再以查询分离度形成 softmax 权重。此处的“regional”是参考特征聚类中心，不是已经确认的查询实体。

**对本地失败的含义（本报告的推论）：** 多粒度保留了参考外观的不同压缩程度，却没有显式要求相邻区域属于同一个实例或同一个任务范围。最大匹配可能接纳一个偶然相似的背景模式；ASE 的查询伪区如果错，会把错误写回参考。它是必须正面比较的完整基线，不能从其成功摘要推出它能修复本地共同范围错误，也不宜重启一套不同权重的 HPM 当原创。

### 2.2 FROST：全锚点密度比，不是点/原型故事的另一名字

FROST 在去位置、类内 shrinkage whitening 后，对 FG/BG 全锚点分别估计核密度，采用对数比；支持集 LOO 选择带宽，再传播、门控和上采样。其零阈值对应等类先验下的逐点分类，不能升级为任意 query 分布、空间传播之后或 IoU 指标下的最优性。[论文§3](https://arxiv.org/html/2606.31136v1)

在**相同特征、相同核、硬支持标签、正负均非空**时，设核和为 `F,B`，类数量为 `Nf,Nb`，则

```text
c = F/(F+B)
log(F/Nf) - log(B/Nb) = logit(c) + log(Nb/Nf).
```

这是简单读出之间的恒等式，不是 SH 与 FROST 完整等价。它说明先验和标度本身就能改变范围，不能把所有差异归因于“点证据 vs 语义证据”。这也不是新方法：W35 已记录该关系。[本地核迁移](../../../../scripts/x1012/r5_candidate.py)、[W35§3.3](../../x1012_tasks/W35_cvpr2027_readiness_REPORT.md)

固定代码与论文存在应记录的差别：[model.py](https://github.com/jhpark-ai/FROST/blob/b9ece69d7495a698c298e7cc3d16efacd4497a43/frost/model.py)、[density.py](https://github.com/jhpark-ai/FROST/blob/b9ece69d7495a698c298e7cc3d16efacd4497a43/frost/density.py)。

- LOO 代码最大化 FG 均值减 BG 均值，是类平衡形式；论文 Eq.4 按全部锚点数量平均。
- 传播代码用 raw-normalized query 特征、欧氏距离窗口，并额外乘 score-difference kernel；论文 Eq.5 用 whitened token 与无穷范数窗口。不能只实现 Eq.5 就称作者完整代码。
- 代码所谓 backward 是每个 query 的 top-3 参考标签投票，并非论文文字描述的完整互为近邻检查。前向为空还会改用 0.9 分位。
- 注释称 noise-image 的位置基，实际用归一化黑图。whitening 后为 KDE 再做 L2 normalize，传播采用另一条 raw-normalized 特征路径。

**对本地失败的含义（推论）：** 这是核读出与标定最强的直接邻近控制，可能解释 SH 部分收益，值得公平比较；但多模态密度仍要求参考覆盖 query 的目标外观。参考中缺失的非典型身体、部件或实例，不会因为带宽选择自动获得成员身份。给 SH 加类平衡常数或 LOO 核宽只能算校准路线，不能据此承诺 0→1。

### 2.3 FSSDINO：二阶外观能量，尚不是跨 patch 归属

其读出为每类多原型匹配，加上参考通道 Gram 的 query 能量；逐点竞争形成最终 mask。layer oracle 与 Fisher、自分割、逆分割等可部署选择器间的差距，是其核心诊断。[论文§III、VI](https://arxiv.org/html/2602.07550v1)

按固定实现，参考单位特征为 `x_j`，`G=N^-1 Σ x_j x_j^T`，Gram 场是

```text
g(q_i) = q_i^T G q_i = (1/N) Σ_j (q_i^T x_j)^2.
```

该展开是代数说明，不是新定理：Gram 保留参考外观二阶矩，但对参考 patch 的排列不变；每个 query 点独立求能量，没有 `q_i` 与另一个 query 点“应共同属于该任务”的变量。实现先将各原型/Gram 场插值，再以 `max × mean` 聚合竞争；不能把它描述成明确的空间实体建模。[module.py:67–230](https://github.com/hussni0997/fssdino/blob/24858986ea55e312200079937989ad32360f09b2/fssdino/module.py#L67)

**对本地失败的含义（推论）：** “oracle 有余量但当前选择器失败”已经有明确先例；本项目的范围候选差距与它的层差距对象不同，但不能泛称首次发现选择差距。二阶统计可补外观模式，却不能由“Gram”一词推出实体归属；直接给 SH 添加 Gram 能量没有新的机制依据。

### 2.4 PAHNet 补上了另一项直接排重

Web 包指出的 [PAHNet，ICCV2025](https://arxiv.org/html/2507.19140v1)确已把 prototype–affinity 的保守/激进互补作为中心，使用预训练 prototype predictor 引导训练式 affinity learner。它不是本项目同条件控制，但“首次发现两路互补并融合”不能成立。其偏差方向与本地具体 U0/M′ 不同，恰说明偏差不是分支名称自带的定律；需要受控区分表示、标度与读出。

## 5 候选探针：候选边界与原生混合依赖

### 5.1 问题与可用输入

假说不是“真正物体内部 attention 一定大”，而是：**参考完整 mask 所规定的任务，在冻结模型最后块中留下的混合响应结构，能否为 query 候选的完整性提供原标量场以外的可用判别？**

仍只输入 `(R,M_R,Q)`，同一冻结 DINOv3；额外保留两图最后块的真实输入 X、原生 Q/K/V、RoPE、attention 输出投影、LayerScale、MLP 和最终 LayerNorm。没有新模型、查询标签或外部实体分割器。相对只保存 O24，这增加了内部测量与重放成本；原始 RGB 的信息并没有凭空增加。

最后块原生 attention 为 `A_h=softmax(Q_h K_h^T/sqrt(d))`，包含真实 RoPE、prefix 与所有归一化。记输出为

```text
t_i = X_i + gamma1 * W_O concat_h(sum_j A_h[i,j] V_h[j])
z_i = final_norm(t_i + gamma2 * MLP(norm2(t_i))).
```

实际代码里的 bias、head norm 和缩放必须逐项保留，上式仅展示依赖关系。key cosine Gram 没有显式保留 Q、V、输出投影及残差；标量 F 更没有保留这些混合路径。在一般算子层面，相同 key Gram 不能恢复上述响应。**这不是已构造两个真实图像有相同 O24 的证明，也不证明 O24 所有维度信息不足；更不意味着新增测量可被正确选择。**

### 5.2 唯一主干预：跨角色质量送回 self

参考 mask 与每个 query 候选都在相同 CLI-1024 坐标，以 16×16 面积下采样得到 `a_i∈[0,1]`。两侧使用同一定义，禁止参考 soft、查询 hard。

只对 patch–patch 的 `i!=j` 定义

```text
chi_ij(a) = a_i(1-a_j) + (1-a_i)a_j
A^a_h[i,j] = A_h[i,j] * (1-chi_ij(a))
r_hi(a) = sum_{j patch,j!=i} A_h[i,j] * chi_ij(a)
A^a_h[i,i] = A_h[i,i] + r_hi(a).
```

prefix 相关行列维持原值；self 不先切再补；每个 head、每行总质量严格不变。hard mask 时它隔离跨边界 patch 混合；soft 时它只是一个确定 gate，不是已经证明的子 patch 物理解混。`a=.5` 会对许多边共同衰减，必须如实承认混合 token 的影响。

Q/K/V 固定，只把 A 替换为 `A^a`，运行原投影、残差、MLP、final norm。attention 子层的变化可直接写成

```text
Delta t_i(a) = gamma1 * W_O concat_h(
    sum_{j patch,j!=i} A_h[i,j]*chi_ij(a)*(V_h[i]-V_h[j]) ).
```

这显示为何不能仅凭 cut-mass `r_hi` 判断：相同质量在 value 相近时可几乎抵消，在 value 不同且投影敏感时可很大。全块非线性又会改变响应。该恒等式是所定义干预的代数结果，不是新的 attention 理论。

必须另存 zero-cut 和重新归一化 cut 的响应作诊断，不能把三种干预混用：zero-cut 改变行质量；renormalize 放大剩余边；主干预把质量送 self。若只有 zero-cut 区分候选，优先解释为幅度/分布效应，不称实体依赖。

**测量边界：** 只干预最后块，只能观察最后块的局部读取作用。早层已经混入的跨区域信息、经 prefix 传递的结构都仍在；这里不能证明整编码器的因果实体结构。

### 5.3 一个确定的实际选择器草案

为避免先改变候选池解释收益，首轮诊断固定复用 W31 修正版的九级无 GT 候选定义，主 F、自然 mask 与两单线完全不改：

```text
A0 = |F > .5|; s in {-2,-1.5,-1,-.5,0,.5,1,1.5,2}
s=0: 原自然mask；其余 k_s=clip(floor(A0*2^s+.5),0,1024^2)
candidate_s = F的top-k_s，平局按坐标；去重。
```

空自然 mask 原样保留；相同候选 coverage 造成相同响应时，不伪造分辨能力。195个细结构回退任务若进入完整分母，各臂保持原输出，单列有效测量与回退，不能把回退写成新机制收益。此处用 SH 只作为**固定的候选载体和强控制**，不是把选图、参数或新分支并入 SH，亦不改 W30。

令 `u_i=unit(z_i)`，`u_i^a=unit(z_i^a)`，每个位置的向量响应为 `b_i(a)=u_i^a-u_i`，不取 CLS、不裁 RGB、不重新缩放图像。参考用完整合法 mask 的响应。分别以 `a_i` 和 `1-a_i` 归一化加权，形成 FG/BG 两个响应向量经验分布。参考任一角色无正质量，或自然候选本身无法定义双角色分布时，整例保留自然 mask；仅某个其他候选角色质量为零时，该候选不可选并记录原因，不因此删除其他合法候选。全例无可计算候选时保留自然 mask。

一个无带宽选择器为两个角色的**能量距离**之和：

```text
E(P,Q)=2 E||p-q|| - E||p-p'|| - E||q-q'||
score(a) = -.5*E(P_R,FG,P_Q(a),FG) -.5*E(P_R,BG,P_Q(a),BG)
selected = argmax score；平局依次优先s=0、最小|s|、较小s。
```

所有期望都按上述归一化权重取有限和，可分块精确计算，不把大量相邻 token 假称独立校准样本。能量距离是既有统计量；本草案只把它当固定的、可被否定的读出。主输出是所选完整 1024 mask；CRF 前为主端点，若报告 CRF 后则全部臂统一使用同一 CRF。

此规则比较**响应结构是否相容**，没有假定“变化越小越正确”。但它仍有强假设：目标与背景在跨图间有可迁移的响应分布。原型、KDE、旧 context 的失败已经提醒该假设可能不成立。这个选择器尚未工程实现，也未通过任何查询验证。

### 5.4 与旧 context 的实质差异与仍然共享的风险

旧 context 把跨图参考 FG/BG 的 V-context 各与 query native context 混合 1/2，再以表示较少变化判相容；新算子**不跨图注入 value**，不新造 QK，对每个候选只改变 query 自身的跨边界混合，并保留行质量及 prefix。推断对象从“此点接受哪类参考上下文”改为“此完整候选切断哪些原生依赖”。

这个差异足以提出不同的可证伪问题，却不足以证明更好：若新读出仍只追逐响应幅度、或跨图分布不稳，它就是旧相容性问题的另一个失败构造。必须同时赢自然强控制、同池 J 与注意力质量控制，才有继续研究的理由；不能只展示 mask 响应或内部差异。

### 5.5 原创性排重与反例

内部 patch 干预不是新概念：[Patch Interactions，2022](https://arxiv.org/abs/2203.05922)研究 patch 影响与响应范围；[Value Zeroing，EACL2023](https://aclanthology.org/2023.eacl-main.245/)通过改变 value 并观察完整块输出量化混合；[CAAP v2](https://arxiv.org/abs/2603.13652v2)使用内部 activation patching 做视觉归因。不能把重放最后块、value 影响或“因果”作为首次贡献。

[SCLIP](https://arxiv.org/abs/2312.01597)已有冻结最后层 attention 改造；[FSA，ICCV2025](https://arxiv.org/html/2508.20265v1)已有输出预测回馈、attention isolation 与训练自由分割。拟争取的区别只能是：**由完整单参考任务定义的混合响应，实际提供范围选择增量，并经相同外观证据的结构破坏及合法 task-switch 支持。** 本轮检索不是穷尽优先权审计。

至少有以下确定的失效可能：

1. 全部相关 value 相同，或投影抵消它们：`Delta t=0`，候选响应不能区分真实范围；候选 oracle 再大也无帮助。
2. 目标依赖背景作识别上下文，或相邻同类物体相互关注：真正 mask 未必有低隔离代价；低代价甚至可能偏向最小核心。
3. 参考是正面、query 是侧面，或医学边界由标注惯例定义：合法同类任务的响应分布也可不同；source fit 无法保证迁移。
4. 早层已完成混合、最后层主要读取 prefix：主干预看不到需要的实体结构。阴性只关闭最后块这个测量。
5. 不同候选产生相同 soft coverage、或响应分布相同但空间排列不同：本读出不可区分，不宣称恢复亚 patch 拓扑或左右身份。

[DINO zero-ablation 替换控制研究](https://arxiv.org/abs/2604.14433)在 register 消融上显示，置零和其他替换可导致不同的任务退化；据此推论，本方案也应区分质量、幅度与替换效应。保持行质量并不保证激活幅度相同，这些控制仍不能消除全部内部干预的分布偏移。

### 6.1 样本、封存与主比较

未来若执行，先冻结 manifest、代码、模型/特征身份、候选和全部选择，再读 S query GT；不因余量大小选例，不事后挑自然差例。特征缺失先在评分前按完整清单披露，不能看结果换例。只用一个 MPS 进程，不能自行恢复 W30 或抢其运行资源。

主要实际比较预定为主选择器分别相对自然、同池 J、cut-mass 控制；同时列全块响应与 attention 子层线性响应。不能先筛相关性再只给通过的完整结果。按现有 `(fold,class)` 槽池化、域等权报告；小样本区间只作开发不确定性，不冒称独立确认或十域非劣效。

### 6.2 必须分开的四项判断

| 问题 | 预定观察 | 正结果意味着什么；负结果后做什么 |
|---|---|---|
| 固定候选容量 | 自然与同池逐例 IoU 最佳诊断策略；另报该策略的槽指标 | 只有容量，不是部署分数；容量很小则这批候选无法回答该问题，不继续改 selector |
| 新测量是否可用 | 实际选中 mask 的净差、选择 regret、选中 s、增真/增假/删真/删假、自然已正确例毁伤 | 相对所有完整强控制均有正净收益才支持继续；只胜弱控制、只相关或只保守回退均不通过 |
| 增量来自结构还是幅度 | 外观场与候选固定，比较下节破坏控制；zero/renorm/self 三种反应分开 | 只有 zero-cut 有效或 raw cut mass 足以解释，则不支持 value/残差结构解释 |
| 是否由任务定义 | S 中已有合法同 RGB A/B 任务，共同候选并集，完整 2×2 正确/交叉参考评价 | 两真实任务均朝正确方向切换才支持任务条件；仅换类有效不能宣称完整/部件粒度 |

本轮不替这个探针编造 +1pp 或相关系数下界门槛。统计门槛、最小值得继续的效应和成本上限必须在正式执行计划中有用途依据地写定；在此之前它不是可执行冻结协议。不能看完结果再决定“足够大”。

### 6.3 外观保持与结构破坏：明确每种控制实际保持什么

- **场保持：** 所有机制臂复用同一原始 F、U0/M′、候选、RGB、token 坐标。反事实只生成候选的内部响应，不重算一个更差的 unary 充当对照。
- **attention 质量控制：** 对每个候选记录 `r_hi` 的 FG/BG 加权分布，以与主选择器相同的能量距离匹配参考。这保持候选与行切走质量，丢掉 value 对齐、投影和非线性效应。若它已经解释收益，不能把收益归给完整块结构。
- **质量送往何处：** self 为主；zero 和 renorm 为固定诊断。三者不同时保持输出幅度，不能只看最有效的一种事后改主臂。
- **同边际配对破坏：** 可在单 head 的 patch attention 子矩阵作非负 2×2 circulation：`(+epsilon,-epsilon;-epsilon,+epsilon)`。它严格保持行/列和，外部 F 不变；在 hard 同源角色、同目的角色组内操作，还能保持每行跨角色质量。但 soft gate 的逐行 `sum A*chi` 通常不由普通 circulation 保持，不能声称已同时保持。正式实现必须选择明确约束构造，记录实际破坏量；若约束使所有改动近零，该阴性对照无信息。
- **mask 几何安慰剂：** 固定循环平移/反射可保持面积，环面 perimeter 也可保持；普通画面边界长度及 attention cut mass 未必相同。只能按无 GT 的面积、边界和 cut-mass 描述子预先匹配，并披露匹配误差；匹配失败保留为失败，不能换到有利安慰剂。

不存在本报告已经构造并验证的“同时精确保留面积、普通边界、每行切走质量和所有注意力边际”的万能 shuffle。上述控制分别回答不同替代解释，不能把愿望写成保证。

### 6.4 成立条件、代价与停止

相对现有报告，新测量有意义需要三件事同时成立：固定候选覆盖正确范围；原生混合响应对这些范围有区分；参考响应相容性把这种区分转成正确实际选择。任一环失败都关闭对应构造，不能继续扫层、head、距离、候选或渲染寻找正数。

若只获得容量/响应差异而无实际选择收益，结论是“此读出没有兑现新增测量”，不是新方法；若所有主比较不正，停止该选择器；若只相对打乱有差异，不能进入新确认。即使六域筛查正，也只进入一次另行冻结的完整 S 方法验证，不读取 T/照片或改 W30。

代价须分开报告：完整 encoder 次数、复用/新增内部特征、每候选最后块重放、全量响应距离、CRF、峰值内存。每 head 的 4096² attention 在 FP32 约 64 MiB，16 个 head 同时保留约 1 GiB（不含中间量）；应按 head/候选分块，不能把“无需完整重编码”写成免费。响应距离是额外计算，实际耗时未知。

## 7 完成了什么，仍缺什么

本轮完成了三篇固定论文/代码比较、代码与论文差异标注、Web B0 与本地旧路线排重，以及一个独立于 SH 图替换的候选混合测量定义。该方案只是**结构增量探针**，没有运行结果、已证明的原创性或跨图风险保证，也没有科学依据在其他研究问题完成前把它定为唯一主线。
