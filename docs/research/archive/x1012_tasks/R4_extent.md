# R4_extent 实验报告

已完成全部1360例。固定阈值UN_fixed仍是四臂中最接近十域目标的臂；十域等权class mIoU分别为UN_fixed 54.726、UN_JF 53.724、UN_JFB 54.026、置换对照48.314。没有一个臂达到十域均不降或旧−0.5pp门槛。

JFB对UN_fixed：COCO −3.203pp（95%CI [−6.609,−0.922]），ISIC −0.179pp（[−2.405,+2.372]）；本实验没有补齐这两个关键域。Lung +0.359pp（[+0.075,+0.635]），道路 +2.078pp（[−0.003,+4.998]），Fundus因既定回退完全相同。COCO的FP/GT由.282升至.393。JFB在七个可变域显著优于空间置换，说明对应场有可用空间信息，但这个J目标仍不能稳定选择正确范围。

本轮已穷举当前连续场所有可实现的完整同分组严格水平集，因此失败不能归因于阈值网格过粗；这不构成所有单参考范围校准方法无效的证据。全部结果是已暴露开发队列的机制实验，不作为新确认结论。

固定R1的1360例单参考开发任务；只读R1 VP_UN连续场和P0合法字段，新增编码0、无域分支、推理不消费FoRIS输出。
四臂全部自然预测封存后才评分；UN_fixed逐位复用R1 VP_UN，评分整数与R1完全相同。
沿bilinear1024 VP_UN排序，在所有可实现严格水平集上最大化J：同分组不拆分，包含空/全图，目标同分取最小前景；没有阈值网格。
JF使用bilinear1024(c32)的前景纯度与归一化back_f捕获率；JFB对前景JF和补集背景JB等权平均，JB使用1-c和back_b。
置换臂用SHA256固定种子共同置换back_f/back_b的64网格空间位置，再插值；其他规则相同。rho>.9时全部臂逐位复用R1冻结的原T回退。
R1的CPU原T重放与P0的MPS原T在Fundus两例各有1像素差异；R4全部保留R1冻结输出。初始P0逐位相等断言已在评分前修正为记录差异，未改变推理结果或参数，原config/源码与修复回执保留。
CPU最多2 worker，每worker2线程；独立runtime复用R1封存共享模块原字节，实际来源/路径/SHA及ROOT覆盖均记录在config.json。

主指标沿用计划lab.Meter：每个(fold,global_class)池化I/U，再对观察槽等权平均；CLI1024。不同于先平均fold的指标。
GT/预测忽略iSAID ignore像素。FN/GT、FP/GT用像素总量之比；面积误差为空预测时为∞。95%区间按query照片配对bootstrap，seed20261012，1000次，每次重新聚合。全部为开发/诊断结果，未评分confirm。
