# W19：用更简单、更快的头替换 FoRIS（同一冻结 DINOv3 特征与输入）

2026-10-14。

- 代码：`scripts/x1012/w19_simple_head.py`（准确率：`check` / `produce` / `report` / `confirm_t`），`scripts/x1012/w19_time.py`（计时）
- 证据：`evidence/research/w19_simple_head_S.jsonl.gz`、`w19_simple_head_T.jsonl.gz`、`w19_timing.json`

## 动机

W13 表明，MFU 对 FoRIS 内部的依赖只剩 M 中的 FoRIS 分数：

- M = `mean_control(q, r, cov, score)`，即排序引导加 λ=16 查询图求解；
- 去掉 U 里的 FoRIS 投票和先验（M0U+），只比 MFU 低 0.21。

FoRIS 分数的计算包含：
- 四次凝聚聚类，其中两次覆盖全部 4096 个查询 token；
- 一次 4096² 的最近邻投票；
- 一次语义修正。

本实验只把这个分数换成廉价分数，其余部分不变：M 的求解器逐位复现缓存的 M（`check`：最大差 0.0）。

## 设计（运行前写定，不调参）

三个廉价分数：
- **g**：与参考纯前景 token 均值的相似度（mean_control 内本已计算）。
- **p**：FoRIS 第二阶段对比的单原型版本，不做聚类。μ_bg 取与 μ_fg 最相似的 20% 参考背景 token 的均值，并对 μ_fg 正交化：

  q·μ_fg − 0.55·q·μ_bg⊥
- **pr**：p 加上它在已有 k-means-64 查询区域上的均值，作为种子聚类先验的廉价替代。

组合方式：`X_k = rho>.9 ? T : [.5·M_k + .5·U0 > .5]`，后缀 `+` 表示再经官方 CRF。U0 是不依赖 FoRIS 的 U。

## 1 准确率（S 半，W13 同一固定种子样本，每域 ≤ 150 例，共 1,285 例）

| 臂 | − 完整 FoRIS | ≥0 域 | 显著正／负 | − MFU |
|---|---:|---:|---:|---:|
| MFU | +2.82 | 9 | 5／0 | — |
| M0U+ | +2.62 | 7 | 5／0 | −0.21 |
| **Xp+** | **+2.76** | 7 | 6／0 | **−0.07**（无一域显著） |
| Xpr+ | +2.78 | 8 | 6／0 | −0.04（无一域显著） |
| Xg+ | +2.04 | 6 | 3／1（Lung −1.97*） | −0.78（Lung −4.20*） |
| Xp（不做 CRF） | +2.57 | 7 | 6／0 | |
| U0+ | +0.85 | 4 | 3／2 | |

- 区域均值（pr）相对 p 没有稳定收益，因此按简单优先，选定 **Xp+**。
- 相对 MFU，Xp+ 在 COCO（−1.66）和 SUIM（−1.80）点估计较低，但不显著。FoRIS 的聚类先验在这两个域上仍有作用。
- Xp+ 相对 FoRIS 的点估计：COCO −0.59、SUIM −1.48，都不显著。

## 2 运行时间（同一 harness、同一进程、同一输入）

- 协议：冻结的 x1012s2 runtime，CPU 2 线程，O24 特征直接在内存中提供，RGB 与参考 mask 在每次调用内读取和预处理，含官方 CRF。
- 样本：27 个非回退例，每域 3 例。丢弃 2 个预热例，FoRIS 与 MFU 的运行顺序逐例交替。
- 新头的时间计算方式：在同一次 MFU 调用的分段计时中，扣除两个依赖 FoRIS 的分段（FoRIS 语义核 0.53 s、U 中的 FoRIS 投票和先验 0.26 s），再加上廉价分数的实测时间（0.002 s）。它的其余分段与 MFU 调用中实际运行的分段相同。

| 方法 | 平均（秒） | 中位（秒） | 相对 FoRIS |
|---|---:|---:|---:|
| 完整 FoRIS | 1.591 | 1.531 | 1.00× |
| MFU | 2.199 | 2.129 | 1.38× |
| **Xp+（FoRIS-free）** | **1.406** | 1.368 | **0.88×**（27/27 例更快） |
| Xp（不做 CRF） | 0.416 | 0.397 | 0.26× |

FoRIS 内部各阶段的平均时间（秒）：

| 阶段 | 时间 |
|---|---:|
| 位置去偏 | 0.020 |
| 背景抑制（两次参考前景聚类） | 0.057 |
| 投票 | 0.066 |
| 种子聚类先验 | 0.188 |
| 语义修正 | 0.180 |
| CRF | 0.995 |

两个结论：
- 所有方法的头部时间都以 CRF 为主，约 1 秒。
- CRF 在 S 半值 +0.19（Xp+ 对 Xp）。如果按时间权衡，不做 CRF 的 Xp 可以用 0.26× 的 FoRIS 头部时间，换来 +2.57 的准确率。

注意：
- 以上只是编码之后的头部时间。整链还要加上编码时间（R+Q 双编码时 FoRIS 整链约 4.6 s）。
- Xp+ 的时间由同一调用的分段相减得到。正式报告前，需要用独立实现跑一遍端到端计时。

## 3 T 半一次性确认（预先固定 Xp+）

读法：Xp+ − MFU 在 ±0.3 以内，且无一域显著低于 FoRIS。

样本：T 半固定种子子样本，每域 ≤ 150 例，共 1,255 例。FoRIS 和 MFU 取自 W11 的 T 半记录，只新计算 Xp 和 Xp+。

| 比较 | 均值 | ≥0 域 | 显著正／负 |
|---|---:|---:|---:|
| Xp+ − 完整 FoRIS | **+3.21** | 7 | 6／0 |
| Xp − 完整 FoRIS | +2.95 | 8 | 6／0 |
| MFU − 完整 FoRIS（同一子样本） | +3.17 | | |
| **Xp+ − MFU** | **+0.04** | 6 | 1／1 |

逐域：
- Xp+ − FoRIS：
  - LVIS +4.42*、PASCAL +3.01*、PACO +3.63*、SUIM +2.14、Lung +2.06*、Fundus +15.01*、Road +3.57*；
  - COCO −0.28、iSAID −0.21、ISIC −1.23，三者都不显著。
- Xp+ − MFU：
  - COCO −2.12、ISIC −1.95*、iSAID −1.62；
  - PASCAL +1.62、SUIM +1.15、Road +2.60、Lung +0.32*。

**结论（按预定读法）：** 成立。不依赖 FoRIS 的头 Xp+ 与 MFU 均值相同（S −0.07，T +0.04），无一域显著低于 FoRIS，头部时间为 FoRIS 的 0.88×、MFU 的 0.64×。

**代价：** 域分布有变化。FoRIS 的聚类先验在 COCO、ISIC、iSAID 上仍有作用，这三个域的点估计低于 FoRIS（不显著）。MFU 在 T 半全量上是 10/10 域 ≥0。
