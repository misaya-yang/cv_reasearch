## 2 固定清单与输入

只用现有 S 目录的缓存和原生合法任务，不读取 T 或新照片留出，不编码。元数据盘点发现具有共同 R/Q 图、同域同 fold 两个合法类别的查询照片：SUIM 84、PASCAL-Part 27、PACO-Part 6（具体路径/crop 验证后可能减少）。

按种子 2026101608，每域至多 30 个不同查询 RGB/crop；每张查询只取一个预定类别对，再随机取一个同时有这两个类别完整 mask 的参考 RGB/crop。R 与 Q 必须为不同照片；参考/查询两个任务的 path、crop、RGB hash 各自一致，类别对应和原 ignore 规则保留。只据元数据和缓存可用性选择，模型分数与查询 GT 不参与选样。不同类别恰好有相同 mask 不事先删除，评分时单列。

## 3 输出及评分

每对只运行两次冻结 SH，分别输入参考 mask A/B，保存原精度的 CRF 前连续场，以及 SH/SH+。同一 R/Q 的实际特征逐元素相同；字段阈值 >.5 必须逐像素复现 SH。冒烟额外对照独立 simple_head 的输出。全清单预测封存后再打开两份 query GT。

对每个输出分别按 G_A/G_B 的原 valid 评分，得到完整 2×2。报告：

- 两个 matched IoU、均值及较小值；同时达到 .5 的 pair 数。
- D_match = (J_AA+J_BB−J_AB−J_BA)/2；若两行预测相同，该数必须为 0。
- 共同 valid 的差异像素上，T_dir = mean[(G_B−G_A)(P_B−P_A)]；没有差异则 NA。共同前景/背景的修复与破坏分列，不能只看差异区。
- 各行场对两份 GT 的并列组精确最佳阈值 IoU。自然失败而 oracle 高，只说明这个场存在更好切点；oracle 低也不是特征无解。
- 标签关系（disjoint/nested/overlap/equal）、域别及查询级配对 bootstrap 描述；主端点 pair 等权，不冒称十域官方 mIoU。

## 4 运行前读法

D 或输出变化本身不够：matched 质量、方向和共同区域保留需一起看。若两个任务都能靠自然输出做好，说明本批中 mask 语义能够迁移；若方向正确但质量差，区分该场切点可救与该场阈值族仍不足。若一边始终失败或共同区遭破坏，保留失败，不把平均正 D 写成正确粒度恢复。

相同 R/Q RGB 使参考 mask 成为这两次推理唯一变化的视觉输入；这是任务响应的受控测试，但样本限于具有两类共同出现的三个域，且原生标注合法性由现有协议绑定保证，不推广为任意语义任务。嵌套任务可用同一排序不同切点解决，正方向不证明新排序。只跑这一固定轮，不看结果后换 pair、阈值或算法。
