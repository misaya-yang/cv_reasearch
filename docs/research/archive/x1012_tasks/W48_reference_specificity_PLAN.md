# W48：SH 的输出有多少真正来自参考的概念

> **W58 更正（2026-10-15）：** 自然 self0/true/mis 成绩保留；历史最佳阈值 .358/.248 等继承 120 分位点近似，不再称精确上限或直接比较根因份额。旧 W45 分类子组由 [W58 重分组](../../x1012_tasks/W58_score_repair_REPORT.md#5-依赖-w45-的旧分析如何处理)替代。自参考同时改变多个因素并使用查询答案，不能单独把损失归因于迁移或排除读出问题。

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。

## 1 动机

- **[W45](W45_solvability_PLAN.md)、[W46](W46_transfer_PLAN.md)：** 灾难例中有一大块是“迁移失败”：查询特征能分开目标，参考定义的方向找不到它；正则、对齐、转导都救不回。
- **[W47](W47_concept_consistency_PLAN.md)：** 线性联合拟合的检验没有区分力。
- **更直接的问题：** 同一个 SH，换不同的参考，输出变多少。
  1. **自参考（oracle）：** 查询自己当参考，mask 用查询 GT。迁移零难度时，SH 的机制本身能做到多好，剩下的是读出和表示的损失；
  2. **真参考：** 实际表现；
  3. **错配参考：** 同域、不同类别的参考图与 mask。参考的概念不对时 SH 还剩多少，即与类别无关的“显著性”部分。
- **两段差：**
  - 自参考 − 真参考 = **迁移损失**：同一套机制，因参考与查询是两张不同的图而损失多少；
  - 真参考 − 错配参考 = **概念贡献**：参考的概念让输出好了多少。
- **对灾难例：**
  - 若真参考与错配参考差不多，参考的概念在这些例子里没有起作用，失败是显著性指错了对象；
  - 若自参考也失败，问题在读出或表示，不在迁移。

## 2 设计

**样本：** W37–W47 同一批 1,285 个 S 例。新照片留出和 T 半都不读。

**参考替换：** 在 binding 中替换参考图像、mask、裁剪与参考特征（`fit.reference_raw`），其余不变，调用冻结的 `simple_head(b, crf=False)`。
- **自参考：** 参考 = 查询图像与查询特征，mask = 查询 GT（`query_mask_path`）。只作诊断。
- **错配参考：** 同域，按例子编号排序后取后面第一个类别不同的例子（循环），用它的参考。与 W47 的配对相同。
- **单类别域（Lung、Fundus、Road）** 没有不同类别可配，不做错配参考。概念贡献只在其余 7 个域上计算，迁移损失仍按十域计算。（这一条在冒烟测试遇到空配对后、正式运行前补入。）

**输出：** 三种参考下 SH 的 CRF 前 mask 的 I/U，以及各自场 F 的最佳阈值 IoU（只看排序）。

**口径：** class mIoU（十域等权）；灾难例（W27 SH+ IoU < .3）与非灾难例分开的逐例平均；十域区间用 `w37._boot`。

## 3 读法（运行前写定）

1. **实现检查：** 真参考与 W23 SH 一致 ≥ 1,280/1,285。
2. **整体分解**（class mIoU）：
   - 迁移损失 = 自参考 − 真参考；概念贡献 = 真参考 − 错配参考；
   - 报告二者在十域上的大小与区间。
3. **灾难例：**
   - **错配参考的逐例 IoU ≥ 真参考的比例 ≥ 40%：** 这些例子里参考的概念基本没有起作用，SH 在做与类别无关的显著性分割，失败是显著性指错了对象。下一步研究怎样让输出真正由参考的概念决定；
   - **自参考的逐例平均 IoU < .5：** 即使迁移零难度，SH 的机制也失败，问题在读出或表示（与 W45 的分类对照）；
   - 两条可以同时成立，分别报告。
4. 只作诊断，不产生方法，不读 T。

## 3c 执行后发现的实现问题与更正（看过第一次结果后写，规则由推导决定，不由结果决定）

- **问题：** 自参考时，参考 token 就是查询 token，每个查询 token 的最大相似度 sim_max 恒为 1。SH 的“新颖度”= minmax(sim_max) 因此恒为 0；调制强度 s > 0 时 c_mod = c × 0^s = 0，U0 = 0，输出为空。是否选 s > 0 取决于两个几乎相等的 J 值的平局（如 .914 对 .913）。第一次运行中自参考有 22.3% 的例子输出为空，真参考与错配参考没有一例。
- **更正（取极限）：** 新颖度为常数 k > 0 时，c × k^s 在 solve 内部的 minmax 之后与 c 相同，与 s 无关；所以 sim_max 为常数时，正确的连续延拓是 c_mod = c。新增命令 `self0` 只在 sim_max 完全为常数时这样处理，其余照旧；真参考与错配参考永远不会触发。
- **读法不变：** 读法 2 的迁移损失与读法 3 的“自参考 < .5”改用 self0；原 self 臂的数字一并记录，标为无效。读法 1 与读法 3 的错配参考一条不受影响。

## 结果

**2026-10-15 完成。** 1,285 例，中位 1.8 s/例。实现检查：真参考与 W23 SH 一致 1285/1285。完整报告在 `../cv_data/a/x1013_W48/report.txt`，证据在 `evidence/research/w48_reference_specificity_S.jsonl.gz`（含原 self 臂，标为 self_raw）。

**第一次运行的自参考臂无效（见 §3c）：** 22.3% 的例子输出为空，十域 57.23 不可用。下面的自参考都是更正后的 self0（0 例为空；85.5% 的例子触发了新颖度退化）。

**class mIoU（CRF 前；自参考与真参考为十域，错配参考为 7 个多类别域）：**

| | 自参考 | 真参考 | 错配参考 |
|---|---:|---:|---:|
| 十域均值 | 75.65 | 53.63 | — |
| 7 域均值 | — | 54.60 | 20.14 |

- **迁移损失**（自参考 − 真参考，十域）：+22.03 [+19.88, +22.76]。每个域都 > 0，Fundus（−0.04）除外；
- **概念贡献**（真参考 − 错配参考，7 域）：+34.46 [+32.59, +36.83]。ISIC 是唯一例外（−2.85），同域的其他类别同样是病灶，参考只传达了“病灶”。

**逐例平均 IoU：**

| | 自参考 | 真参考 | 错配参考 | 错配 ≥ 真 |
|---|---:|---:|---:|---:|
| 灾难例，多类别域（211） | .686 | .126 | .107 | 35.5% |
| 其中 W45 表示不足（53） | .386 | .109 | .014 | 17% |
| 其中 W45 读出失败（58） | .886 | .165 | .220 | 48% |
| 其中 W45 迁移失败（71） | .730 | .105 | .080 | 38% |
| 非灾难例，多类别域（799） | .838 | .692 | .240 | 10.8% |
| 灾难例，单类别域（50） | .382 | .194 | — | — |

**判定：**
- **读法 3a：** 错配 ≥ 真的比例为 35.5%，低于 40%，按规则不判为“参考概念没起作用”。但灾难例上真参考与错配参考的平均 IoU 只差 .02（.126 对 .107），概念在这些例子里起的作用很弱。
- **读法 3b：** 全部灾难例的自参考平均 IoU 为 .627，≥ .5，按规则不判为“没有迁移也失败”。例外是 W45 表示不足一类（.386）和单类别域（.382，Fundus、Road），与 W45、W49 一致。

**结论：**
1. **在 SH 上，迁移是最大的损失，约 22 点。** 参考换成查询本身后，十域从 53.6 升到 75.7。
2. **W45 的“读出失败”一类在好证据下面积是对的。** 这一类在真参考下平均 .165，自参考下 .886。但自参考泄漏了答案，这只说明 SH 的读出在证据近乎完美时不出错，不能证明证据不完美时读出不是问题。（更正：初稿写作“实际由迁移造成，SH 的面积选择本身没坏”，过强。）
3. **参考的类别总体上决定输出**（概念贡献 +34.5），SH 不是与类别无关的显著性分割。只有在灾难例上，真参考与错配参考的结果接近。
4. **自参考不是不泄漏的上限。** 每个查询 token 都与自己精确匹配，它代表“迁移零难度、证据近乎完美”时 SH 机制的水平，不是一个方法。
