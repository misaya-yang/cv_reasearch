## 1 核心判断与路线

**核心判断：**
- **难点是“到哪里为止”，不是“是什么”。**
  - 类别总体能传过去：错配类别参考使十域掉 34.5 点（W48）；查询 GT 上一个线性探针 71.6，SH 为 53.6（W45；10-15 更正：71.6 不是特征的上限）。
  - 错误主要在范围：
    - 只换阈值，灾难例从 .14 升到 .34（W45）；
    - 灾难例误检占 54%，三分之二面积偏大（W45、W51）；
    - 所有 SH 变体在部件与整体之间此消彼长（W20、W24、W26）；
    - 按面积选尺度全部失败。
  - 范围是 mask 与图像自身结构的关系（W52），现有方法几乎不从参考迁移它。
- **问题的形式：区域类比。** 参考说“在这张图里选这一块”，答案是查询图里“对应的那一块”。

**任何方法都隐含三样东西：**

| 要素 | 含义 |
|---|---|
| 候选空间 | 查询里可能的答案区域，覆盖不同粒度 |
| 一致性 | 候选与参考有多像：内容像不像，与周围的关系像不像参考 mask 与它周围的关系 |
| 无法确定的处理 | 参考没说清时用什么先验；什么时候承认分不清 |

**于是每个失败都可以问三步：**
1. 答案在不在候选里？不在，是**表示**问题；
2. 在的话，参考能否把它排第一？不能，是**可识别性**问题；
3. 能的话，方法找到了吗？没有，是**方法**问题。

**路线（各阶段到时另写计划，事先写预测）：**

| 阶段 | 问题 | 结果如何改变下一步 |
|---|---|---|
| 0 看例子 | 失败长什么样 | 定下量化定义要对得上的直观类型 |
| 1 表示（G1） | 答案能否被候选空间表示 | 能：走区域类比；不能：先换表示（层、分辨率、低层边界） |
| 2 可识别性（W52 G2–G5、类别的前几名准确率） | 只看参考，答案是否被确定 | 得到每个基准“被确定 / 需先验 / 表示不了”的比例 |
| 3 理论 | 一致性须满足的性质 | 几条可证伪的设计原则，各对应 1、2 的一个发现 |
| 4 最小方法 | 按原则搭最简单的方法 | 每个部件说明解决哪一层，事先预测在哪些域提多少 |
| 5 检验 | 是否真解决了那一层 | S 开发、T 一次、新照片留出、官方协议；提升须出现在预言的地方 |
| 6 边界 | 什么确实做不出来 | 写成局限，以及需要的信息来源 |

**规矩：**
- 先写预测，以及预测落空的含义；
- 逐例平均，单独报告灾难例；
- 定义不看 GT，GT 只用来检验；
- 每条结论写明适用范围（样本、方法、是观察还是已证原因）；
- 先看图再量化。
- SH 只作对照，不再修补。

## 2 阶段 0：看例子（失败类型表）

**目的：** 今天的定量分析缺少对实际图像的系统观察。先建一份带图的类型表，后续的定义都要对得上它。

**样本（固定种子 2026101501，只取 S 半的 1,285 例）：**
- 每个域随机取 10 个灾难例（SH+ IoU < .3）和 10 个非灾难例，共约 200 例；
- 灾难例不足 10 个的域全取。

**每例一张图板：**
1. 参考图叠 mask；
2. 查询图叠 GT；
3. 查询图叠 SH+ 输出。

另附 SH+ IoU、GT 面积占比、参考 mask 面积占比。图板写到 `../cv_data/a/x1013_W53_cases/`。

**标注（由 Claude 看图标注，是模型判断，不是人工金标准；类型事先固定，可多选，另记一句备注）：**

- **A 参考：**
  - A1 mask 几乎铺满全图（没有背景对照）；
  - A2 参考目标极小或模糊；
  - A3 只露出部件，看不到所属整体（切断邻居不可见）；
  - A4 无上述问题。
- **B 目标性质：**
  - B1 完整物体；
  - B2 部件；
  - B3 stuff / 区域；
  - B4 多个实例；
  - B5 细或小（token 以下）。
- **C 输出的错误（相对 GT）：**
  - C1 找错了东西（类别错）；
  - C2 对的东西，范围过大（溢到所属整体或相邻区域）；
  - C3 对的东西，范围过小（只取了一部分）；
  - C4 漏了实例；
  - C5 只差在边界；
  - C6 近乎空；
  - C7 无明显错误。
- **D 只看参考，人能否确定答案：**
  - D1 能，清楚；
  - D2 有歧义（有不止一种合理答案）；
  - D3 不能（参考没给出足够信息，或 GT 遵循看不出的标注约定）。

**汇总：** 按域、按灾难与否统计各类型的比例。D2 + D3 的比例是“单参考任务歧义”的一个粗估，只作参考，不作结论。

**运行前的预期：**
- 灾难例中，C2（范围过大）最常见；
- 部件域（PASCAL-Part、PACO）里，C2 多表现为溢到所属整体；
- D2 + D3 在灾难例中占三分之一左右。

**落空的含义：**
- 若 C1（类别错）最常见：核心判断“难点是范围”需要修改，路线的阶段 2 改以类别为主；
- 若 D2 + D3 超过一半：很多灾难例是任务歧义，方法提升的空间比想象的小，论文应把“识别歧义”作为一部分。

## 3 阶段 1 的第一项：G1 候选空间能否表示答案

**问题：** 在冻结特征的层级结构里，查询 GT 和参考 mask 是不是“由少数几块连贯区域组成”？如果是，范围在特征里看得见，区域类比可行；如果要拼很多碎块才接近，范围不是特征里的自然结构。

**层级（事先固定）：**
- **特征：** SH 使用的去偏单位 O24 token（64×64）；
- **构造：** 4 邻接连通约束下的平均连接凝聚聚类，距离为 1 − 余弦，使用 sklearn `AgglomerativeClustering`（`connectivity` 为 4 邻接网格，`linkage='average'`，`metric='cosine'`，`compute_full_tree=True`）；
- 得到从 4,096 块到 1 块的全部层级。

**度量（对查询 GT，与参考 mask 分别计算）：**
- **每一层 k（k 块）的最好表示：** 按块纯度（块内 GT 像素占比）从高到低，取最佳前缀的块并集，计算 IoU，记为 R_k。块按 16×16 像素展开。对“若干不相交单元取并集”求 IoU 最大值，最优集合必为纯度阈值集合，所以取最佳前缀就是该层的最优。
- **R_max：** 全部单 token 层的值，即块状几何上限，与 W49 的 C64 同类，但不做双线性。
- **紧凑度 m\*：** 在所有层中，达到 R_k ≥ .9·R_max 时所用块数的最小值。
- **cc：** GT 在 token 网格上（覆盖率 ≥ .5）的 4 连通分量数。
- **自然区域：** m\* ≤ cc + 2，即每个连通部分只需一两块就能拼出。
- **另报：** R_k 在 k ∈ {8, 16, 32, 64, 128, 256} 上的曲线（除以 R_max）。

**汇总：**
- 按域、按灾难与否、按 W45 四类报告“自然区域”的比例和 m\* 的中位数；
- 参考与查询都自然的例子的比例；
- 与 W32（谱分组 K ≤ 16）的结果对照。

**读法（运行前写定）：**
1. **实现检查：** 每个例子 R_4096 等于 token 块状上限（逐 token 纯度阈值）；层级共 4,095 次合并。
2. **主读法：** 全部例子中，查询 GT 为自然区域的比例。
   - **≥ 60%，且部件域（PASCAL-Part、PACO 合并）≥ 40%：** 范围在 O24 层级里大体看得见，区域类比可行。下一步做 W52 的 G2（参考层级与查询层级能否对应）与 G3；
   - **< 40%：** O24 的相似度层级不表达标注的范围。下一步先在同一度量上比较其他表示（较浅的层、更高输入分辨率、由 RGB 得到的低层层级），再谈方法；
   - **两者之间：** 按域分开处理。哪些域可行、哪些不可行，分别进入上面两条。
3. **参考一侧：** 参考 mask 为自然区域的比例。若明显低于查询一侧，说明参考的粒度本身常常不是特征里的结构（W52 命题 3 的条件 2），粒度迁移会先卡在参考上。
4. **我的预测：**
   - 物体域（COCO、ISIC、Lung）查询 GT 自然比例 ≥ 60%；
   - 部件域与 SUIM ≤ 40%；
   - 灾难例低于非灾难例；
   - 全部例子在 40%–60% 之间，即主读法的“两者之间”。
5. 只用 GT 做诊断，不产生方法，不读 T。
