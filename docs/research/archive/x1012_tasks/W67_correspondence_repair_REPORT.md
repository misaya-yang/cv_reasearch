# W67：如何继续解决——在标签汇总之前修正跨图对应

2026-10-16。接[W64复盘](../../x1012_tasks/W64_reference_head_graph_REPORT.md)，按[本轮计划](W67_correspondence_repair_PLAN.md)完成机制推导、历史排重和无图像代数验证。**本报告给出一个具体候选，不是已经取得增益的新方法。** 全程免训练；本轮无真实图推断、无新编码、无查询GT读取。W57及另一会话的W65/W66均未操作。

## 1 我的选择与理由

**优先验证的候选，是保住现有有效证据，在参考标签被汇总成一个前景分数之前，修正跨图对应。** 它针对的是错误匹配导致的场质量问题，不打算用一条规则解决所有剩余误差。

目前的点证据大致是：每个查询位置分别匹配参考 → 把这些参考位置的前景标签求和 → 之后在查询图上平滑。参考里“这些匹配位置是否彼此相容”的信息，在求和后没有被完整保留。W64改的是最后的查询图，前面的对应和两支原始证据不变。

候选的想法是：若一个查询位置像参考中的两个部位，先看它附近位置的匹配是否也支持其中一个部位，再决定从参考哪里取标签。这样，一个较弱的单点匹配可能被邻域支持，另一个局部很像、周围却对不上的匹配可能被压下。**真正的假说是邻域对应有跨图区分力，不是“平滑总会更好”。**

例如车门只响应金属下段时，需要查明玻璃上段是否有被错误匹配压住的车门对应，并能得到相邻对应的支持。如果参考根本没有可用的玻璃部分表示，或上下两图布局差别过大，本候选不能凭几何凭空恢复它。对“另一实例也有同样完整布局”的情况，它也不自动解决实例身份。

为什么现在仍值得把这个具体候选写出来：

- 它能改变进入SH之前的排序，覆盖W58中不能只靠切点解决的那部分问题。
- 它不依赖在参考图上挑选一个风险最小的head，而是直接检验实际R/Q之间的对应。
- 它有精确的原点：修正强度为0时完整输入核不变，后续SH必须复现；不能像旧R1-G那样从已经远弱于强基线的直接读出开始讨论结构收益。
- 它能保留原核每个查询位置的总匹配质量，使“修改相对对应”和“重新定义绝对可靠度”先分开。

这几项让实验更有解释力，但还不意味着方向正确或方法原创。真正的跨图有效性仍要用完整输出证明。

## 2 先排除三种容易被误当成新解法的构造

### 2.1 标签外积不能自己产生新的任务关系

令T为逐查询行归一化的对应矩阵，参考软标签为y，现有前景份额为c=Ty。若把参考“同为前景”的关系写成yyᵀ，再转到查询：

`T yyᵀ Tᵀ = (Ty)(Ty)ᵀ = ccᵀ`。

加入背景同角色项，也只是`ccᵀ+(1−c)(1−c)ᵀ`。这没有保留超出c的参考位置关系。不是所有参考关系都如此；只有这类可分解标签关系如此。

### 2.2 可分离双侧平滑不自动构成联合推理

`(A_Q T B_R)y = A_Q[T(B_R y)]`。

它可以解释为先滤波参考标签，再传递、再滤波查询。它不一定等于`A_Q(Ty)`，但不能仅凭写成4D矩阵就称得到了新的匹配推理。候选必须实际依赖完整对应及其位置绑定，而不只是重新组织矩阵乘法。

### 2.3 优化了几何，不等于它有能力改掉原判决

旧[联合BP](../../../../src/ics/methods/joint_reference_bp.py)与[R1-G](../../../../src/ics/methods/joint_role_pilot_geometry.py)使用有界边势：log势范围不超过`λw_ik`，`w_ik=1/max(deg_i,deg_k)`，λ=1、温度1。

对一个邻居的正消息，其不同候选状态间的log比值范围不超过该边势范围。全部邻居相乘后，单节点角色前景/背景的log-odds改变量满足

`|Δ logit(p_F)| ≤ λ Σ_k w_ik ≤ 1`。

所以原前景份额高于 **0.7311** 时，无论这个有界几何项如何偏向背景，都不能把它翻成背景；低于 **0.2689** 时也不能翻成前景。这个性质解释了它的一项动作限制；**没有计算实际错误有多少落在这些区间，不能据此宣布找到了R1-G全部失败原因。**

反过来，取消这种限制只会让编辑更强，不会自动更正确。因此本轮既验证更强编辑可实现，也保留它破坏正确结果的反例。

## 3 一个可实现的最小候选

### 3.1 保留现有核，而不是另起一个弱读出

沿用冻结SH的去位置、联合中心化、温度.05，得到非负核K：

`E_i=Σ_j K_ij`，`T⁰_ij=K_ij/E_i`，`c⁰=T⁰y`。

E是原方法的总匹配质量；T⁰是相对对应份额。二者都不是已经校准的正确概率。保留所有参考token和软coverage，不先压成一个原型，也不截成固定数量的硬FG/BG原子。

### 3.2 只增加一个参考位置关系

查询侧A_Q采用规范64×64网格的四邻接、逐行平均，不用预测mask决定邻接。参考侧W_R为方形邻域内的0/1近邻关系，包含自身。设m为参考token数：

`H_R = I − 11ᵀ/m`，`B_R = H_R W_R H_R`。

双中心化使`B_R 1=0`。它去掉了“参考中心位置拥有更多邻居，所以无信息时也被偏爱”的常量效应；不是对跨图语义正确性的校准。

计算一次邻域支持：

`M = A_Q T⁰ B_R`。

M_ij表示查询i的邻居，对参考j附近的对应支持相对独立位置基准有多强。它不使用查询标签，也不直接给“前景”奖励。参考mask此时尚未汇总；同一R/Q RGB下换合法mask，匹配修正可相同，最终标签传递随y改变。

### 3.3 固定一次指数重加权，再把标签传过去

`T¹_ij = T⁰_ij exp(β M_ij) / Σ_l T⁰_il exp(β M_il)`，`K¹_ij=E_i T¹_ij`。

`c¹=T¹y`。

这是对完整对应矩阵的一次非线性修正。没有学模型参数，没有参考风险选头，没有源内拟合分类器，也没有反复迭代到某种自洽状态。**不声称这一步求得全局最优或保证某个非凸能量下降。**

首个真实图候选的建议固定设置是β=4、参考邻域半径4个token、一次更新。它们是可否定的工程选择，来自局部布局允许一定尺度变化、编辑需有足够作用幅度的设计考虑；不是理论推出的最优参数。不得看过真实结果再扫描这些数值。

没有参考列边际约束，因此没有强制每个参考位置消耗相同查询面积；也没有一一匹配，可以让多个查询实例使用同一个参考部位。但原核本来的参考占比效应仍可能存在，**本候选没有宣称解决W57/W61的先验问题**。

### 3.4 接入SH时哪些量必须保持一致

- c及由它得到的区域字段重新计算；原查询分组和kNN图不换。
- `log_e`继续来自原E；原`sim_max`仍表示原始外观匹配质量，不把几何消息冒充更强的外观证据。
- 反向参考捕获量从K¹重新做列归一化，`back_f`及max-J所用的派生量同步更新；不能只换c却继续使用旧反向量。
- 原型线、融合、阈值、CRF和ρ>.9的共同回退保留。新的c会按原规则重新产生点线的数据权重，这是固定SH算子的一部分。
- β=0须核验完整SH/SH+复现。原点未复现时不解释任何方法差异。

这种接法先问“修正对应是否提供净增益”。即使成功，也仍要比较独立读出与完整方法，不能把保留SH大部分处理隐藏在方法叙事里。

## 6 最可能失败的地方，以及如何避免又把负结果解释过头

1. **正确对应不满足局部布局假设。** 参考与查询尺度、视角或遮挡差别大时，真对应未必落在规定参考邻域。这是算子的适用假设，不是特征无信息。
2. **错误对应本身很一致。** 另一扇窗、另一只动物、相似纹理背景都可能形成自洽布局。正面合成例不足以排除它；本轮反例已经明确呈现这种风险。
3. **参考没有覆盖需要恢复的外观。** 指数修正不能创造原核完全为零的对应；对于本来就缺支持的部分，邻域关系可能仍无帮助。
4. **同一部位不等于同一任务范围。** 更平滑或更准确的语义对应不一定知道标注要车门还是整车、全部实例还是特定实例。必须同时看合法mask切换的正确输出，不能只评价对应是否顺滑。
5. **原有正确预测被扩散伤害。** β=4允许翻转强判断，也放宽了误编辑空间；要同时计新增TP/FP与删除TP/FP。回退保护或提高稳定性本身不是性能贡献。
6. **新场变好，原读出却没兑现。** 若精确阈值诊断改善而自然输出下降，只能说当前接法没有可部署收益。不能拿oracle替代主结果，也不在同一轮改阈值救回。

## 8 计算与当前状态

N=M=4096时，一个FP32对应矩阵约64MiB。使用查询四邻接聚合、参考方窗前缀和，可以以O(NM)量级完成本轮消息；无需O(NM²)的稠密关系矩阵乘法。原型目前用FP64方便检查，真实实现的精度和峰值开销尚未测量，不能提前报告速度。

完成的工作：具体公式、原SH接入约束、与已测方法和公开近邻的比较、无图像实现、正反见证、等价快速算子验证。**没有完成的工作是实际分割验证与贡献证明。** 不将它包装成“问题已解决”；它的价值在于让下一次运行有一个清楚、可否定且能保留已有有效结果的理由。
