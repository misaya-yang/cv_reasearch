# W34 A2：实体划分、范围恢复与层级消歧

2026-10-15。对应 W34 的 T1.3–T1.5；兼顾 T1 的可辨识性条件。本文只使用题面和当前 OVERVIEW 的文字，不读取数据、预测或查询 GT，不运行数学或实验代码。

## 1. 核心结论与适用边界

**正确的划分提供“哪些像素可以一起选”，参考信息还必须提供“哪些格属于这次任务”。** 两件事缺一不可。纯划分可以把范围恢复化为片段选择，但纯度本身不是语义可辨识性的充分条件。

本文给出三个可直接使用的结论：

1. 任意片段选择的像素对称差可精确分成“划分混合误差”与“选择误差”；两项必须按面积计权，不能用选错片段的比例替代。
2. 单纯把纯片段进一步切碎，不会减少可表示的掩码集合，也不会降低该集合中最好的 IoU。实际性能下降只能来自参考锚丢失、选择噪声、约束或计算方式等附加机制。
3. 参考完整 mask 能消除层级歧义，需要参考上的不同任务假设具有可区分的可见支持，而且语义层级能跨图对应。完整 mask 不自动提供这两个条件。

下文定理是明确假设下的自包含推导，不把冻结 DINOv3 已经满足这些假设当成事实，也不宣称相应数学恒等式具有文献优先性。文献用于定位“先分组、再决策”和层级表示，不引入训练、外部模型或通用多视图设置。

## 2. 形式化设定

### 2.1 像素、划分与目标

令查询的有效像素域为有限集合 \(\Omega\)，面积测度为 \(\mu\)，总面积为 \(M=\mu(\Omega)\)。真实目标 \(S\subseteq\Omega\) 满足 \(s=\mu(S)>0\)。

给定不相交且覆盖 \(\Omega\) 的划分

\[
P=\{P_1,\ldots,P_K\},\qquad w_k=\mu(P_k)>0.
\]

令

\[
a_k=\mu(P_k\cap S),\quad b_k=w_k-a_k,
\quad v_k=a_k/w_k.
\]

其中 \(v_k\) 是片段的真实前景覆盖率，只用于理论或未来已预先声明的诊断，不是推理可用输入。片段选择 \(z_k\in\{0,1\}\) 输出

\[
\widehat S(z)=\bigcup_{k:z_k=1}P_k.
\]

片段可以是 token 格的像素展开，也可以来自冻结特征的区域划分。所有面积与最终 IoU 必须在同一个有效像素域计算；token 等权面积与最终像素面积不能混用。

### 2.2 概念与参考的作用

一个局部生成模型是：先抽取语义概念、部件—整体树及实例，再抽取姿态、遮挡、纹理等外观变量，由渲染过程生成 \(R,Q\)；参考任务假设 \(h\) 决定完整可见参考 mask \(M_R\)，同一假设决定查询目标 \(S_Q(h)\)。冻结编码器是图像到 token 的确定性映射，\(q,r,y\) 均按 W34 定义。

任务假设 \(h\) 不只包含对象类别，还可能包含部件类型、取所有实例还是特定实例，以及可见范围的标注规则。只有在基准协议已经固定这些规则时，才可以把它们从未知量中删去。

可以从允许的冻结量计算：

- 参考锚 \(A=A(r,y)\)；
- 片段描述 \(d_k=d(q|_{P_k})\)；
- 参考条件化决策 \(z_k=\phi(A,d_k,P,Q)\)。

“引入划分”不意味着新增外部信息源。如果 \(P\) 由完整冻结 token 计算，它可能保留标量场 \(F,c,p\) 压缩掉的关系；如果 \(P\) 只是那些相同标量场的确定性函数，则两个在这些场上不可区分的世界，经过 \(P\) 后仍不可区分。这是确定性函数不能区分相同输入的直接结果。

## 3. 纯划分何时能够恢复范围

### 命题 1：纯度和语义锚定是不同条件

假定 \(S\) 是 \(P\) 中若干格的并集，即每个 \(v_k\in\{0,1\}\)。这保证存在正确的片段选择，但不保证从 \((R,M_R,Q,P)\) 能识别它。

**证明与反例。** 取两个查询格 \(P_1,P_2\)，令它们在可用描述及所有参考关系上完全相同。世界一的目标为 \(P_1\)，世界二为 \(P_2\)，其余观察相同。两种目标均是纯格并集，但同一观察只能产生同一确定性输出，因而不能同时恢复两者。即使允许随机化，也不能保证两世界都精确恢复。若不希望引入实例身份，可把两个世界解释成参考样例未能区分的两个语义概念；结论相同。证毕。

该反例说明需要一个**可观测的任务锚**：参考前景及背景、实体的完整描述、或能够转移的语义关系，至少有一种必须区分目标格与非目标格。仅把语义纯度设为 100% 并不能替代它。

### 命题 2：具有语义间隔的片段描述足以恢复

作如下充分条件假设：

1. \(P\) 对当前目标纯，每个片段有概念标签 \(c_k\)，目标是 \(c_k=c\) 的全部格；
2. 在同一描述空间中，每个概念有中心 \(\theta_j\)，满足
   \(\|\theta_j-\theta_c\|\ge\Delta\) 对所有非目标 \(j\) 成立；
3. 参考锚满足 \(\|A-\theta_c\|\le r_R\)，片段描述满足
   \(\|d_k-\theta_{c_k}\|\le r_Q\)；
4. \(\Delta>2(r_R+r_Q)\)，且读出阈值 \(t\) 位于
   \((r_R+r_Q,\Delta-r_R-r_Q)\)。

则规则

\[
z_k=\mathbf 1\{\|d_k-A\|<t\}
\]

精确恢复 \(S\)。

**证明。** 对目标片段，三角不等式给出
\(\|d_k-A\|\le r_Q+r_R<t\)。对非目标片段，反向三角不等式给出
\(\|d_k-A\|\ge\Delta-r_Q-r_R>t\)。因此每格均被正确选择；由目标纯度可得输出等于 \(S\)。证毕。

**此命题的实质限制：**

- 完整实体内的 token 可以异质，但用于决策的实体描述必须具有跨图稳定性；“片段均值一定稳定”并非已证事实。
- 参考没有出现的查询干扰概念也必须满足分离条件。参考背景没有覆盖的负概念不能被悄悄视为已知负样本。
- 命题证明一个有效阈值区间存在；它不证明单参考能够估计这个区间，更没有推出 SH 的 0.5 或其他现行常数。若阈值不可观测，还需要独立的校准结构。
- 多模态目标未必具有单中心。可把中心改为概念支持集，但仍需目标支持覆盖和与非目标支持的间隔；写成集合距离不会消除这些假设。

### 命题 3：一个可靠种子可以恢复其所属实体，但不能自动覆盖其他碎片

假定存在由冻结量得到的图 \(G_P\)，其节点为片段，并满足：

1. 每个连通分量 \(C\) 的片段并集要么完全属于 \(S\)，要么完全不属于 \(S\)；
2. 参考条件化种子集 \(T\) 不落在任何非目标分量中；
3. 每个目标分量至少包含一个种子。

选择所有与种子同连通分量的片段，则精确恢复 \(S\)。

**证明。** 条件 2 和条件 1 排除所有假阳性分量；条件 3 和条件 1 保留所有目标分量。分量覆盖全部片段，故没有遗漏或增加的像素。证毕。

这个构造解释实体关系可能增加什么：允许参考最像的核心为同一实体的非核心部分提供标签，而不要求每个非核心 token 单独与参考高相似。它同时揭示风险：一条错误跨实体边足以让闭包泄漏；一个完全没有锚的目标分量会被漏掉。若只给 \(P\) 而不给正确连通关系，不能默认碎片自动归属于同一实体。

这些命题与早期“超像素作为原子，再做区域决策”的分解有关；Ren–Malik 将过分割作为预处理，同时单独处理分组判别。该文包含监督学习，不作为本项目的可执行方案。原文：[Learning a Classification Model for Segmentation](https://www2.eecs.berkeley.edu/Research/Projects/CS/vision/grouping/papers/ren_malik_iccv03.pdf)。

## 4. 纯度、选择错误与 IoU 的精确联系

### 定义：目标相关的混合误差

令

\[
z_k^*=\mathbf 1\{a_k\ge b_k\},\qquad
e_k=\min(a_k,b_k),\qquad
\alpha(P,S)=\sum_k e_k.
\]

平票时固定任一选择即可。\(z^*\) 是最小化**像素对称差**的 GT 多数标记，不是推理规则，也不一定是最大化 IoU 的标记。

令选择代价

\[
\beta(z;P,S)=\sum_k |a_k-b_k|\,
\mathbf 1\{z_k\ne z_k^*\}.
\]

这里 \(\alpha\) 是当前二元任务的划分混合误差。它并不要求不同的前景实体互相分开：把两个都属于目标的实体放在同一格，仍可能有 \(\alpha=0\)。

### 定理 4：对称差的精确分解

对任意 \(z\)，

\[
\boxed{D(z):=\mu(\widehat S(z)\triangle S)
=\alpha(P,S)+\beta(z;P,S).}
\tag{1}
\]

**证明。** 对格 \(P_k\)，若不选，像素错误为 \(a_k\)；若选，错误为 \(b_k\)。取较小者的代价为 \(e_k\)，选另一侧额外付出 \(|a_k-b_k|\)。格互不重叠，因此逐格相加即得式 (1)。证毕。

令面积加权的错选量为

\[
E_{\rm sel}=\sum_k w_k\mathbf 1\{z_k\ne z_k^*\}.
\]

则

\[
D\le\alpha+E_{\rm sel}.
\tag{2}
\]

若每格少数类比例 \(e_k/w_k\le\varepsilon<1/2\)，还有

\[
\alpha+(1-2\varepsilon)E_{\rm sel}
\le D\le\alpha+E_{\rm sel}.
\tag{3}
\]

证明只需使用 \(|a_k-b_k|=w_k-2e_k\)。这表明片段越纯，选错该片段越接近付出其全部面积；纯度提升不能弥补毫无语义辨识能力的选择器。

**不能用片段错误率替代面积错误率。** 例如 100 个纯格中，一个格面积为 9,901，另 99 格各为 1；若唯一的目标是大格而它被漏选，片段错误率只有 1%，IoU 却为 0。只有另加 \(w_{\max}\le C M/K\) 之类的面积均衡条件，才有 \(E_{\rm sel}\le CM\times\) 片段错误率。实际片段大小不均时，不能省去这个条件。

### 推论 4.1：实体纯度给出任务纯度的一个界

令 \(\{E_j\}\) 是互不重叠的真实实体划分，且 \(S\) 是其若干格的并集。定义实体混合量

\[
\eta(P)=\sum_k\left(w_k-\max_j\mu(P_k\cap E_j)\right).
\]

则 \(\alpha(P,S)\le\eta(P)\)。

**证明。** 将每格标为其面积最多的实体所属的前/背景标签。该格的二元像素错误至多是“不属于该最大实体”的面积。\(z_k^*\) 又最小化二元错误，所以 \(e_k\) 不大于这项面积；求和得证。

反向一般不成立：一个片段混入多个前景实体时，\(\eta>0\) 但 \(\alpha\) 仍可为零。对于部件任务，必须把实体单位改成能表示该部件的语义原子；“整物体纯”不保证“部件目标纯”。

在二元 GT 下，\(1-\alpha/M\) 对应面积加权的 achievable segmentation accuracy。Stutz 等的原文式 (7) 以每个超像素的最大 GT 重叠定义该量，并区分多种 undersegmentation error；这些名称不能不加定义地互换。原文：[Superpixels: An Evaluation of the State-of-the-Art](https://arxiv.org/pdf/1612.01601)。

### 定理 5：确定性与期望 IoU 损失界

令 \(\mathrm{FP}=\mu(\widehat S\setminus S)\)，\(\mathrm{FN}=\mu(S\setminus\widehat S)\)。则

\[
1-\operatorname{IoU}(\widehat S,S)
=\frac{\mathrm{FP}+\mathrm{FN}}{s+\mathrm{FP}}
=\frac{\alpha+\beta}{s+\mathrm{FP}}
\le\min\left\{1,\frac{\alpha+\beta}{s}\right\}.
\tag{4}
\]

因此，只要 \(\alpha\le\varepsilon_Ps\)、\(\beta\le\varepsilon_Zs\)，就有

\[
\operatorname{IoU}(\widehat S,S)
\ge\max\{0,1-\varepsilon_P-\varepsilon_Z\}.
\tag{5}
\]

**证明。** 交集为 \(s-\mathrm{FN}\)，并集为 \(s+\mathrm{FP}\)。由式 (1) 和 \(D=\mathrm{FP}+\mathrm{FN}\) 得等式；并集至少为 \(s\)，且损失不超过 1，得到其余各式。证毕。

现在在给定 \((P,S)\) 下，对参考抽样、外观或随机选择的剩余不确定性取期望，令

\[
p_k=\Pr(z_k\ne z_k^*\mid P,S).
\]

不要求各格错误相互独立，就有

\[
\mathbb E[D\mid P,S]
=\alpha+\sum_k|a_k-b_k|p_k,
\tag{6}
\]

以及

\[
\boxed{\mathbb E[1-\operatorname{IoU}\mid P,S]
\le\min\left\{1,
\frac{\alpha+\sum_k|a_k-b_k|p_k}{s}\right\}.}
\tag{7}
\]

**证明。** 式 (6) 使用式 (1) 的线性期望；式 (7) 使用式 (4)，以及 \(x\mapsto\min(1,x)\) 的凹性。证毕。

若 \(P,S\) 也随机，外层再取期望即可；不能把 \(\mathbb E[\alpha/s]\) 换成 \(\mathbb E[\alpha]/\mathbb E[s]\)。

**为何必须按目标面积归一化。** 若只知道全图混合比例 \(\alpha/M\le\varepsilon\)，式 (7) 的混合项仅被 \(\varepsilon/(s/M)\) 控制。小目标可以在全图纯度极高时仍遭受很大损失。例如总面积 10,000、目标面积 10，目标全部落在一个含 10 前景和 10 背景的片段，其余格为纯背景。此时全图纯度为 99.9%，但片段并集的最好 IoU 仅为 0.5。

### 推论 5.1：划分可表示的最好 IoU 与 \(\alpha\)

令 \(J_P^*=\max_z\operatorname{IoU}(\widehat S(z),S)\)。则

\[
\boxed{1-\frac{\alpha}{s}\le J_P^*
\le\frac{s}{s+\alpha}.}
\tag{8}
\]

这里 \(0\le\alpha\le s\)。

**证明。** 全不选的对称差为 \(s\)，故其最小值 \(\alpha\le s\)。多数标记得到 \(D=\alpha\)，式 (4) 给出左界。任一预测的 \(D\ge\alpha\)，且 \(\mathrm{FP}\le D\)，所以

\[
1-\operatorname{IoU}
=D/(s+\mathrm{FP})\ge D/(s+D)\ge\alpha/(s+\alpha),
\]

得到右界。证毕。

式 (8) 是有方向的约束，不把多数标记的 IoU 冒充严格 IoU oracle。多数标记最小化对称差；IoU 的分母也随假阳性变化，最优选择可以不同。

### 推论 5.1a：确定 GT 下的严格片段 IoU oracle

在仅用于诊断的已知 \(a_k,b_k\) 情况下，定义

\[
\Phi(t)=-ts+\sum_k\max(0,a_k-tb_k),\qquad 0\le t\le1.
\]

\(\Phi\) 有唯一零点 \(t_*=J_P^*\)。一个严格最优选择是

\[
z_k=\mathbf 1\{a_k>t_*b_k\},
\tag{8a}
\]

等号片段任选，不改变最优比值。等价地，对 \(v_k=a_k/(a_k+b_k)\) 的阈值为 \(t_*/(1+t_*)\)，一般小于或等于 \(1/2\)。

**证明。** 由于 \(s>0\)，\(\Phi\) 连续且严格递减；\(\Phi(0)=s>0\)，\(\Phi(1)\le0\)，故有唯一零点。固定 \(t\)，片段独立地最大化

\[
\sum_kz_ka_k-t\left(s+\sum_kz_kb_k\right)
\]

时取 \(a_k-tb_k>0\) 的格，最大值恰为 \(\Phi(t)\)。在零点处，任意选择的分子减 \(t_*\) 倍分母不超过零，式 (8a) 达到零，所以所有比值不超过 \(t_*\)，且它可达到。证毕。

**多数票的具体反例。** 两格分别含 \((a_1,b_1)=(6,0)\)、\((a_2,b_2)=(4,5)\)，则 \(s=10\)。多数票只选第一格，IoU 为 \(6/10=0.6\)；选两格则为 \(10/15=2/3\)。这是确定 GT 的 oracle 计算，不等于把随机片段后验代入后就能精确最大化期望 IoU；后一问题由 T2 处理。

### 推论 5.2：官方池化比值的对应形式

对固定一个 (fold, class) 槽，令例下标为 \(e\)，且 \(\sum_es_e>0\)。则

\[
1-\frac{\sum_e I_e}{\sum_e U_e}
=\frac{\sum_e(\alpha_e+\beta_e)}
{\sum_es_e+\sum_e\mathrm{FP}_e}
\le\min\left\{1,
\frac{\sum_e(\alpha_e+\beta_e)}{\sum_es_e}\right\}.
\tag{9}
\]

条件期望界同样以 \(\sum_{e,k}|a_{ek}-b_{ek}|p_{ek}\) 替换 \(\sum_e\beta_e\)，不需不同照片或例独立。对槽、fold 和域再按协议取平均即可。式 (9) 不等于逐例 IoU 界的等权平均；也不提供置信区间有效性的结论，统计推断属于 T5。

## 5. 过分割程度如何进入，而不是被强行罚一次

### 命题 6：细分不会损坏表示能力

若 \(P'\) 是 \(P\) 的细分，每个旧格均是新格的并集，则

\[
\alpha(P',S)\le\alpha(P,S),\qquad J_{P'}^*\ge J_P^*.
\tag{10}
\]

**证明。** 对任一旧格分成的子格，\(\sum_j\min(a_j,b_j)\le\min(\sum_ja_j,\sum_jb_j)\)，相加得第一式。任何旧划分并集都可由新划分表示，新可行集合包含旧集合，得第二式。证毕。

所以不存在仅由“碎片数 \(K\) 增大”推出的必然 IoU 损失项。任何声称 \(K\) 本身必然伤害恢复的界，都隐含了额外的选择模型或资源限制。

### 两个选择模型说明真正的代价

**模型 A：每格错选率固定。** 在纯划分上，若每格边际错选概率均为 \(p\)，则 \(\mathbb E D=p\sum_kw_k=pM\)，与 \(K\) 无关。若额外假定独立，全部格同时正确的概率为 \((1-p)^K\)，随 \(K\) 降低。不能把“精确恢复概率降低”混同为“期望像素错误必然增加”。

**模型 B：只凭局部种子选片段。** 假定目标实体由 \(n\) 个等面积原子构成，每个原子独立以概率 \(\pi\in(0,1)\) 被参考识别为可靠种子。每格只要有一个种子便保留。若该实体分成 \(m\) 个等大的纯格，且 \(n/m\) 为整数，则每格漏选概率为 \((1-\pi)^{n/m}\)，目标漏失的期望面积为

\[
s(1-\pi)^{n/m}.
\tag{11}
\]

它随 \(m\) 增加而增大。若能按命题 3 把同实体的碎片正确连起来，漏失概率变为 \((1-\pi)^n\)。证明分别是“每格无种子”和“整个实体无种子”的概率。DINO token 不满足已知的独立性；这里是展示作用机制的假设模型，不是数据拟合或已证经验规律。

同一个“至少一个种子”规则遇到背景伪种子时，大片段也可能扩大一次伪种子的误报范围。因此碎片化既可能削弱目标覆盖，也可能限制背景污染；没有脱离选择器的单向结论。

设计上应关注式 (7) 中的**目标归一化混合量与面积加权选择量之和**。只追求更少格、更高全图纯度，或更高的所有格同时正确概率，都不直接等价于所需的 IoU 改善。

## 6. 部件—整体层级与单参考消歧

### 6.1 用语义树而非统一的数值深度

令图像的区域树 \(\mathcal H\) 的每个节点是一块区域，父节点是子节点区域的并集。任务可以选一个节点，也可以选多个不重叠节点的并集。类别在不同实例上的部件层数、可见性和对象大小可以不同，因此“取第 \(\ell\) 层”不必在两张图中具有同一语义。

更合适的任务变量是“哪一种语义节点或关系”：例如整只鸟、鸟头、所有轮子。它可以在不同分支对应不同深度。区域树提供候选和包含关系，参考负责选择语义解释，并把它转移到查询。

Arbeláez 等的层级分割把区域组织成嵌套集合，并明确保留后续阶段依据额外知识选择层级的空间。该结构支持上述区分，但其具体边界检测与训练流程不是本项目方案。原文：[Contour Detection and Hierarchical Image Segmentation](https://vision.ics.uci.edu/papers/ArbelaezMFM_PAMI_2011/ArbelaezMFM_PAMI_2011.pdf)。

### 定理 7：参考版本空间给出精确的消歧条件

在一个预先定义的任务假设族 \(\mathcal T\) 内，令 \(S_R(h)\) 与 \(S_Q(h)\) 为假设 \(h\) 在两图的可见目标。定义

\[
\mathcal V(R,M_R)=\{h\in\mathcal T:S_R(h)=M_R\}.
\]

假定 \(\mathcal T\) 包含真实任务，而且其各个假设对全部允许观察都相容。那么查询目标可辨识，当且仅当

\[
\{S_Q(h):h\in\mathcal V(R,M_R)\}
\]

只包含一个不同的 mask。

**证明。** 若集合只有一个元素，所有与观察相容的任务均给出同一答案，目标作为观察的函数定义良好。若包含两个不同 mask，对应两个观察完全相同的相容世界；任何确定性输出在两世界相同，不能同时等于不同真值。证毕。

这一定理的版本空间只是在模型中描述“所有仍然可能的任务”，不是建议枚举无限的自然语言概念。它把缺失条件写清楚：参考需要排除的，是会在查询上给出不同范围的任务歧义。

### 推论 7.1：有间隔的参考支持与跨图对应可以充分消歧

考虑一个有限候选族，真任务为 \(h_*\)，参考 mask 的误差不超过 \(\delta\)：

\[
\mu(M_R\triangle S_R(h_*))\le\delta.
\]

若对每个会导致不同查询答案的假设 \(h\)，

\[
\mu(S_R(h)\triangle S_R(h_*))>2\delta,
\tag{12}
\]

则以参考 mask 对称差最小的假设不会选中这些错误答案。

**证明。** 对称差满足三角不等式，故错误假设到 \(M_R\) 的距离严格大于 \(2\delta-\delta=\delta\)，而真任务距离不超过 \(\delta\)。证毕。

这一结果仍要求 \(h\mapsto S_Q(h)\) 的跨图语义对应正确。在参考树中找到了唯一匹配 mask 的节点，只解决参考侧定位；不能由此推出查询上相同数字深度、相近面积或相近 CLS 的节点就是正确目标。

### 完整参考 mask 仍可能无法消歧的构造

参考图只看见一只鸟的头部，身体被遮挡或位于画外；完整可见“鸟”的 mask 与完整“鸟头” mask 相同。查询图出现完整的鸟，令头部为 \(A\)、其余身体为 \(B\)，且 \(\mu(B)\ge\mu(A)\)。两种任务在参考上完全相同，在查询上分别要求 \(A\) 与 \(A\cup B\)，面积至少相差两倍。完美区域树仍不能补出未被参考揭示的任务意图。

即使参考对象完整可见，“汽车”与“车辆”也可以在一张只有汽车的参考上产生相同 mask，在含汽车和巴士的查询上产生不同答案。若基准协议已经固定类别层级，则这类歧义由协议解决；不能同时把协议当作不存在，又假定参考自动解决它。

### 6.2 E5 的方向性不是层级模型的自动推论

对任何选择器，

\[
\mu(\widehat S)-s=\mathrm{FP}-\mathrm{FN}
=\sum_k b_kz_k-\sum_k a_k(1-z_k).
\tag{13}
\]

因此条件期望欠分割需要

\[
\sum_k a_k\Pr(z_k=0)>
\sum_k b_k\Pr(z_k=1),
\tag{14}
\]

过分割需要相反不等式。层级中选择真节点的严格后代只产生漏失；选择其严格祖先只产生增加；选择错误兄弟则可能同时产生两者。

**但“任务是部件”并不推出选择后代，“任务是物体”也不推出选择祖先或邻体。** 一个固定偏好整物体的规则反而会对部件过分割；一个固定偏好局部核心的规则反而会对整物体欠分割。二者都是同一层级模型允许的反例。

E5 与本框架相容，需要加上可检验的误差机制：部件任务中，弱参考覆盖或部件内部外观异质使式 (14) 的漏失面积占优；物体任务中，邻体或上下文被混入/误选使误报面积占优。当前题面支持把它们列为解释候选，不足以从部件/物体名称直接证明其成立。题面中的面积比中位数与过/欠比例，也不能单独推出严格的 \(\mathbb E[\mathrm{FP}-\mathrm{FN}]=0\)。

## 7. E7 应当怎样读

**高谱值本身不能证明实体不纯。** 构造一个恰好按真实实体分块、块间无边、每块内部连通的亲和图。其归一化亲和矩阵每个块都有特征值 1；十个实体就可以有前十个特征值均为 1，同时划分完全纯。故“前十个 > .995”与语义混合之间没有逻辑蕴含。

高谱值说明存在许多接近不变的图方向；这些方向可以对应实体，也可以对应纹理碎片、稀疏性造成的弱连接或其他结构。需要目标相关的重叠诊断才能区分。

E7 中真正与式 (1)–(10) 相连的是片段重构结果，读法必须分情况：

- 若报告的“GT 选片段”严格最大化了所有片段并集的 IoU，较低的结果说明这些具体划分不能表示足够好的目标范围。它不说明所有来自冻结特征的划分都不可行。
- 若它只是按每格 GT 多数票选择，报告的是对称差最优重构，不一定是 IoU 最优重构。此时不能把该值直接当成 \(J_P^*\)。
- K=16、K=32、k-means-64 若由不同算法分别产生，彼此未必是细分关系，不能套用命题 6 推出随 K 的单调性。
- 无论严格 oracle 是否好，实际选择器仍需较小的 \(\beta\)。E7 中自然 mask 多数规则更差，已经与“良好分组自动解决选择”不相容，却不足以区分是 \(\alpha\) 大还是 \(\beta\) 大。

E8 的稠密谱衰减同样不能单独证明实体结构更好。它改变了图结构；是否有用，仍由目标可表示性与参考锚选择性共同判断。本文不读取或推测正在运行的 W32 结果。

## 8. 三组未来可检验量与正负读法

以下只是后续检验的预定义量，不构成本次运行授权。若未来执行，应在读取查询 GT 前冻结划分、选择器、候选族、容差和读法；遵循 S/T 与照片留出规则，不因诊断结果临时改门槛。所有查询 GT 只参与明确标记的诊断。

### Q1：表示误差 \(\rho_P=\alpha(P,S)/s\)

由未来固定划分 \(P\) 与查询 GT 计算 \(a_k,b_k\)，报告每例 \(\rho_P\)，并同时报告严格 \(J_P^*\) 以对齐 IoU 目标。对官方槽还报告式 (9) 的池化对应量。

- **正结果：** 相对现有划分，\(\rho_P\) 下降、\(J_P^*\) 提升，说明新的冻结特征结构更能表示目标范围，值得进入片段选择研究；这本身不是方法提升。
- **负结果：** \(\rho_P\) 仍大或 \(J_P^*\) 无改善，说明这个具体划分没有提供所需表示条件，不能靠换片段选择规则消除全部混合误差。
- **严格预测：** 若是真正的细分，必须满足式 (10)；若式 (8) 不满足，应检查像素域、忽略区域、重叠片段或 oracle 定义。数学恒等式不靠统计显著性判定。

### Q2：选择误差 \(\rho_Z=\beta(z;P,S)/s\)

对一个事先冻结、只用 \(q,r,y\) 或新冻结编码器量的参考条件化规则，计算面积加权 \(\rho_Z\)。可同时记录其片段参考匹配间隔、种子是否覆盖每个候选实体，以及被漏片段的面积；不得只给片段错误率。

- **正结果：** 低 \(\rho_P\) 的例子上 \(\rho_Z\) 也低，支持“结构可表示 + 参考可锚定”同时成立。不同外观子部件在同一实体闭包中被一致恢复，才支持命题 3 所述机制。
- **负结果：** \(\rho_P\) 低但 \(\rho_Z\) 高，将瓶颈定位为任务选择、语义间隔或锚覆盖；继续提高无条件分组纯度不能被当作已解决选择问题。
- **过分割读法：** 细分后若 \(\rho_P\) 下降而 \(\rho_Z\) 上升，只能说当前选择器受损；检查上升是否集中在无参考锚的片段。不能写成“过分割天然有害”。

### Q3：参考相容任务的查询歧义 \(\Gamma\)

给未来事先固定的层级候选及跨图对应假设族 \(\mathcal T_0\)，以固定容差 \(\delta\) 定义

\[
\mathcal V_\delta=\{h\in\mathcal T_0:
\mu(S_R(h)\triangle M_R)\le\delta\}.
\]

若非空，计算

\[
\Gamma=\max_{h,h'\in\mathcal V_\delta}
\frac{\mu(S_Q(h)\triangle S_Q(h'))}
{\mu(S_Q(h)\cup S_Q(h'))},
\tag{15}
\]

分母为零的双方空集对记为 0。此量只需参考 mask、冻结特征生成的候选及其跨图对应；查询 GT 不参与构造。若版本空间为空，单独记“候选不覆盖参考”，不能将其记为零歧义。

- **正结果：** 在候选族覆盖正确任务的前提下，\(\Gamma\) 接近零且正确范围被保留，支持参考对该候选族足以消歧。
- **负结果：** 多个参考相容候选在查询上给出明显不同范围，表示当前信息及候选模型仍有歧义，需要新的冻结结构关系；凭面积或深度任选一个不具有理论保证。
- **适用性限制：** \(\Gamma=0\) 也可能来自候选族过窄或跨图对应一致地出错。必须另做预声明的 GT 覆盖诊断；不能把算法内部的一致当作真实语义可辨识性。

对 E5 的后续解释可在 Q2/Q3 的已固定结果上报告式 (13) 的符号，并标注漏选是否位于真节点的后代、误选是否来自祖先或邻体。只有这些面积方向与对应错误一致时，才能支持上述部件/物体机制；不预设每域都必须满足。

## 9. 方法设计含义与证伪条件

最小的有意义构造是：从同一冻结编码器保留标量场遗漏的候选实体关系，再用参考锚选择或完成这些实体；评价时分开记录 \(\alpha\) 与 \(\beta\)。这给“实体结构”一个具体职责，而不是把新的聚类名称当成机制。

不值得仅凭本理论继续做的事情包括：把任意谱聚类直接称作实体划分、只靠 \(K\) 或全图纯度挑分组、把同一场的函数重新包装成额外信息、在没有语义间隔的情况下假定均值/最大值/多数票可以统一完成参考转移。它们可以是候选实现，但必须补齐所缺条件。

**数学命题的证伪与模型适用性的证伪要分开。**

- 式 (1)、(4)、(8)、(9) 和细分性质在定义满足时是恒等式或必然不等式。出现违反首先意味着证明、实现、面积口径或划分条件有误，不是“自然图像不服从理论”。
- 若纯度高而选择仍差，命题 1 已允许；这会否定“纯度足够”的经验主张，而不否定本文。
- 若宣称满足命题 2 的间隔界，却仍选错，至少一个间隔、噪声界、阈值或目标并集假设不成立。只观察均值分离不足以证实逐片段的统一界。
- 若实体闭包引入大量邻体或漏掉无锚实例，说明命题 3 的边纯度或种子覆盖条件不成立；不能再据该命题宣称必然补全范围。
- 若参考树中支持唯一，但跨图转移仍出现稳定的部件/整体混淆，说明参考侧唯一性没有带来所需语义对应，应拒绝“同深度即同概念”的具体模型。
- 若 E5 的错误方向与参考覆盖、后代漏选、邻体误选均无关联，应放弃这里列出的方向性机制，保留它只是与 E5 相容而未获验证的解释。

## 10. 一条可执行的条件性方案：锚定实体闭包，只改有结构支持的范围

本节响应“深入解决、提出具体方案”的要求。它给出一个可实现的单线接口，尚未获得新经验支持；本次仍不运行。目标是利用实体结构纠正 E6 的核心截断与邻体溢出，同时保留 E1 已有排序，不再把整张场替换成来源不足的节点概率。

### 10.1 已知负结果如何约束方案

为避免重做，补读了两份历史文字报告；没有读取其链接的数据、代码或产物。

- [任务角色边 600 例报告](../TASK_ROLE_EDGE600_RESULTS_20261011.md) 已测试 O24 的源/查询 8 邻域两端核绑定与查询邻 mask 角色，完整臂 46.21 低于强 S 52.01，新增假前景远多于新增真前景。它还给出了“参考 FG→FG 角色支持为零、同类查询却非零”的真实尺度/网格反例。因此本方案不重新生成源局部角色概率场，不以源角色支持或源内重建证明查询上的边界关系。
- [共享语义层级五域报告](../TASK_SEMANTIC_HIERARCHY_FIVE_RESULTS_20261012.md) 中，任务已在闭集唯一，但参考 mask 驱动的节点概率、停止/细分仍全面失败，而且排序明显受损。因此本方案不以源富集度选择一个树深，不将原 \(F\) 压缩成节点概率场，不以“层级任务唯一”替代查询转移正确。
- E7 已否定特定 kNN 谱分组及自然 mask 多数保留规则；E13 的参考选择单个凝聚粒度也失败。本方案使用完整层级中的局部闭包候选，不选择一个全图统一 \(K\) 或凝聚阈值。
- E10 的裁剪 CLS 比较偏向小核心。本方案不重编码候选、不用 CLS 给完整范围排名。
- U0 与 M′ 同时高分只可定义现有方法的内部支持，不能作为独立正确证据。二者共享错误时，交集仍然会错；不得把“双线同意”升级为语义硬标签。

### 10.2 固定输入与输出接口

输入为 \((q,r,y,F,A_0)\)，其中 \(A_0\) 是原 SH 的完整冻结输出；另外需要一个**只从查询冻结表示构造的层级** \(H_Q\)。输出分两层：

1. 一个小型结构候选族 \(\mathcal A\)，必含 \(A_0\)；每个新增候选只新增或删除一个锚定闭包，或合并这些互不冲突的编辑；
2. 每个编辑对应的锚、闭包、正负冲突、边界间隔和明确的条件假设，供 T2 的保守比较器判断。若无法建立涵盖真值的范围约束，不把内部结构分数当成 IoU。

**H_Q 采用 A8 的关系森林作为唯一待验证构造。** A8 从同一冻结 DINO 的 O24 和每头预 RoPE key 构造查询 4 邻边的关系描述，再与参考内边/跨界边的关系支持比较，输出 \(s_J(e),s_C(e)\) 与 unknown。这里接收这一接口，不把源关系支持球的不相交当作跨图语义正确证书。具体组装为：

1. 将 \(s_J(e)>0\) 的 query 边按 \(s_J\) 降序排序，完全平票按 row-major 的端点编号排序；
2. 按 Kruskal 方式合并两棵树，但若合并会让任一 \(s_C>0\) 边的两个端点处于同一棵树，则拒绝该合并；
3. 接受的边使用 \(W_e=s_J(e)\)；cut 与 unknown 均不作为传播边。保存所有接受合并形成的完整森林层级，不挑全局 K 或深度。

cut 禁止生成跨越该边的同一候选细胞，不禁止两个分开的细胞都被选为前景；后者对于同类多实例和部件集合是必要区别。参考 join/cut 任一支持集为空、所有关系分离半径退化或 key 不可用时，森林不扩张，原 \(A_0\) 保留。

此方案不需等待 W32 才能定义或实现：边表示、排序、合并和读出接口均已写定，key 是同一次冻结编码器的内部量。W32 的特定谱分组结果只能作为已有条件证据，不能代替该森林的 Q1 检验。现有 O24 稠密亲和最多是数学对照，不并列设为一个可在看到结果后择优的执行臂。完整 key 关系的空间/尺度不变性并不推出任务关系的跨图不变性；旧角色边反例仍然是必须面对的风险。

### 10.3 参考完整 mask 产生候选终端，而不是自封正确标签

使用精确纯参考集合

\[
R_+=\{j:y_j=1\},\qquad R_-=\{j:y_j=0\}.
\]

令 \(j(i)=\arg\max_js_{ij}\)、\(i(j)=\arg\max_is_{ij}\)。只保留双向最近邻对 \(j=j(i),i=i(j)\)，并要求最近参考的正负类有严格优势：正候选需

\[
\max_{j\in R_+}s_{ij}>\max_{j\in R_-}s_{ij},
\]

负候选取反向不等式；最近邻为混合参考 token、平票或任一参考集合为空时不建立该终端。所有平票用固定规则识别为“不锚定”，不从 tie 中人为生成语义证据。由此得到 \(T_+,T_-\)。

选择 \(y=1/0\) 是为了不把参考 mask 已知的混合污染藏进“纯终端”假设；若未来改成现行的 \(y\ge.9\) 等容差，必须把混合量显式放入不确定集合。对于没有纯前景 token 的细结构，保留现行 SH 回退。

双向性与正负间隔使终端定义可复现，也减少任意单向对应；**它们不保证查询标签正确**。参考只包含一张图，外观近似的干扰物仍可能赢得双向匹配。理论安全性必须条件化于终端正确，不能通过参考自匹配、双线同意或终端自己的相似度再次证明该条件。

### 10.4 局部层级读出：双终端瓶颈连接

在上述查询森林中，对每个点 \(i\) 定义其到两类终端的最强瓶颈连接：

\[
\kappa_+(i)=\max_{t\in T_+}\ \max_{\pi:i\leadsto t}\ \min_{e\in\pi}W_e,
\qquad
\kappa_-(i)=\max_{t\in T_-}\ \max_{\pi:i\leadsto t}\ \min_{e\in\pi}W_e.
\tag{16}
\]

自身终端的空路径连接记为 1，无路径记为 0。因为输入已是森林，每对节点的可达路径唯一，可直接在树上计算。cut 约束可能拒绝原图边，因此这些值仅针对接受后的森林，不宣称等于未加约束原图的最强瓶颈值。

当 \(\kappa_+>\kappa_-\) 时得到正结构候选，反向时得到负结构候选，平票或无可用终端时保持未定。将同符号的树连通块视为闭包 \(C\)。不以 \(F\) 的均值、多数票或预测面积决定闭包符号。

为保留现有排序与拒识，闭包首先只生成候选编辑：

\[
\mathcal A=\{A_0\}
\cup\{A_0\cup C:C\text{ 为正闭包}\}
\cup\{A_0\setminus C:C\text{ 为负闭包}\},
\tag{17}
\]

并可加入全部互不冲突的候选编辑合成的一张 mask。禁止将未定片段强行分到最近原型，也不更新查询原型。这样把“结构提出范围”与“最终接受编辑”分开，避免旧层级方法在整张图上破坏 E1 的排序。

式 (16) 是一个具体局部层级规则，没有待选择的全局树深或 K。它在候选之间转移的是查询内部的连通关系，参考只提供终端类别；没有把参考局部角色频率假定为查询角色频率。它仍可能因查询图桥接或终端错标失败，不能因算法形式不同就声称成功。

### 命题 8：瓶颈闭包在什么条件下真的补全范围

假定 \(T_+\subseteq S\)、\(T_-\subseteq\Omega\setminus S\)，并存在 \(a>b\)，使得：

1. 每个目标点存在到某个正终端的全目标路径，其每条边权至少为 \(a\)；
2. 每个背景点存在到某个负终端的全背景路径，其每条边权至少为 \(a\)；
3. 任一目标—背景跨界边的权重至多为 \(b\)。

则式 (16) 对所有点给出正确的严格符号。

**证明。** 目标点的正路径保证 \(\kappa_+\ge a\)。通向任一负终端的路径必须跨过目标边界，故 \(\kappa_-\le b<a\)。背景点同理。证毕。

这个条件比“高均值相似度”更具体：允许实体内部的不同外观通过中间部分连接，只要求存在强路径而不是每个点都直接接近参考；同时禁止跨实体桥接超过内部连接。它说明真正要寻找的不是更好的面积估计，而是**任务边界两侧的连接间隔加上正确正负锚**。

条件 1–3 是足够条件而非已证事实；O24 关系可能不满足，key 关系也不能默认满足。可观测的 \(\kappa_+-\kappa_-\) 仅是内部结构间隔，不能证明该符号等于真实语义。

### 10.5 最终接受、回退和与 T2 的合并接口

若某正闭包已在明确模型中被保证为真前景，增加其中 \(A_0\) 漏失的像素只增加交集、不增加并集；若某负闭包保证为真背景，删除其中 \(A_0\) 的假阳性只减少并集、不减少交集。因此这两类编辑都不会降低 IoU，非空有效编辑可严格改善（目标非空且分母合法）。这是一条直接的正确性证明。

现实中终端和闭包不是已知真值，故更一般的最终规则是：由终端误标与闭包混合的**有依据的**误差范围形成合法真值集合 \(\mathcal C\)，对每个式 (17) 的候选计算

\[
\Delta_{\min}(A)=\min_{S\in\mathcal C}
\{\operatorname{IoU}(A,S)-\operatorname{IoU}(A_0,S)\}.
\tag{18}
\]

只有 \(\Delta_{\min}>0\) 才接受，其他保留 \(A_0\)。T2 的稳健选择分支给出该比较器的可计算化；这里交付的是明确候选及约束接口，不使用 J 或 CLS 再排名。

**不能虚构误差预算。** 若没有可辩护的跨图终端错误范围，则 \(\mathcal C\) 必须保留这部分不确定性；它可能宽到没有候选可严格改善，此时本方法返回 SH。不能为了让算法多改图而从源内准确率推一个查询误差界，也不能把 S 开发集拟合的界当成跨域必然保证。更有用的边界/终端量需要在预声明的一轮中证实，而不是在理论里承诺。

明确的推理回退条件为：纯参考任一类别缺失、参考对应退化、终端冲突、图分量完全没有终端、候选预算无依据或稳健改进不成立。只有单类终端的分量可以提出条件性候选，但“没有异类终端”不等于已证明纯；仍需由式 (18) 的真值覆盖约束判断接受。原 SH 始终是合法输出；回退不等于新方法有收益。

### 10.6 对这条方案的一次性验收读法

若未来执行，先固定 O24/key 读取、A8 关系森林、上述终端、候选与接受规则，再封存全部预测，最后做 Q1–Q3 及实际 IoU 评价。主检验应是**实际完整输出的配对增益**；另外同时看：候选里是否有可用范围、终端是否错、闭包是否跨实体、稳健接受率是否非零。不能只用 oracle 好或少数编辑正确宣布方案成功。

- 候选范围好而终端错：否定该锚规则，不据此重扫层级。
- 终端正确而闭包混合：否定该查询连接机制，源内重建不能免责。
- 二者条件较好但 \(\Delta_{\min}\) 常不成立：说明当前可用信息不足以有把握地接受改动；报告这一实际结果。
- 整体输出未优于 SH：这条完整方案不通过；保留理论分解，不把它改名后重复运行。

这条主线比“再聚类然后多数票”多出的必要机制是：带参考正负终端的局部实体闭包，基线包含的编辑候选，以及面向实际 IoU 改进的接受条件。它是可执行的研究提案，不是已经完成的准确率解决方案。
