# W66 报告：相连区域是否属于目标——现有局部量都不比场值本身更好

2026-10-16。按 [计划](W66_region_attribution_PLAN.md) 执行。

**样本：** W65 的 S 半 1,970 个 G 场例子；门槛只看检验半 X（985 例）。

**两条分支：**
- **主会话：** 9 个量和 1 个组合，在看任何结果之前写进计划。不看 GT 的输出写完后先封存（03:29），之后才读标签。
- **子代理：** 先在看图半 V 上探索了 25 个候选，从中预注册 5 个量（03:44:42），再在 X 半检验（03:47）。

两边都只用 CPU，不用 MPS，没有读 T 半或新照片留出。

## 0 结论

**两条分支的量在 OUT（外延）和 IN（内壳）上都没过门槛。** 门槛是：AUC ≥ .75、比场值高 ≥ .05、有效域多数同号。最好的预测量就是场 G 在区域里的均值（B0）：

| | OUT | IN |
|---|---:|---:|
| B0：区域内 G 均值 | **.745** [.694, .796] | **.683** [.644, .719] |
| 主会话最好的非 B0 量 | 组合 C .664 | R4 反向注意力 .640、C .649 |
| 子代理最好的非 B0 量 | C1 核心匹配度 .667；B0 与 A1 合并 .734 | B0 与 A1 合并 .715 |

**按计划读法 4：** 有 ≥ .65 的弱量，但无一过门槛。只记录，不写规则。

## 1 G 之外还剩什么（按 B0 五分位分层后的组内 AUC；主会话为事后检查，子代理为预注册的描述项）

| 来源 | 量 | OUT | IN |
|---|---|---:|---:|
| 参考侧 | R4 反向注意力 | .59 | .62 |
| 参考侧 | R1 前景相似 / A2 前景减背景 / A1 边缘类比 | .58–.59 | .56–.64 |
| 参考侧（例子级） | C1：核心与参考前景越不像，OUT 越可能属于目标 | .61 | .55 |
| 查询侧 | Q1 近邻、Q2 聚类、Q3 颜色、B1 边的位置 | .53–.56 | .52–.55 |

- **剩下的弱信息偏参考侧。查询侧的成组关系在 G 之外几乎不带信息。**
- 主会话预测“像参考背景的不属于、参考没见过的属于”，两条方向都反了：被参考“认得”的区域更常属于目标。

## 2 图上看到的（两边各看过 80 / 60 例）

- **部件数据集里，查询内的成组与目标归属方向相反。** 同一物体的其他部件（马身、狗身、遥控器机身、盒体）与核心成组，但不属于目标。这些部件在参考里正好位于 mask 外侧。按查询内部成组来生长，在这类例子上会错。
- **OUT 属于目标的常见情形：**
  - 参考只展示了目标的一小块、另一尺度或另一视角，例如三明治切面、锅侧面、盆栽绿叶；
  - 核心本身落错了，OUT 才是目标。
- **IN 是否属于，很大程度上取决于核心落得对不对。** 这是例子层面的问题，不是区域层面的问题。
- **单元定义的局限：**
  - 69% 的 OUT 区域与自然掩码相邻的 token 不到 30%，是大片蔓延的区域，常把真目标的延伸和背景混在一起（例如 ISIC 一例，区域平均覆盖 .35）。
  - 所以区域级标签较粗。区域内 token 级排序也只是 G 最好：OUT .807、IN .730，R4 与 R1 约 .62–.70。

## 3 净账（事后，token 级近似）

- 把整片区域加入或去掉，只在约 19% 的例子里有益。改对平均 +16～19，改错平均 −24～26，保本精度约 .6。
- 即使用样本内最优阈值，B0 与 R4 也只在 1–3% 的区域上动手，净收益为 +0.2 到 −0.02。

见 `../cv_data/a/x1013_W66/exploratory_breakeven.txt`。

## 4 含义

- 在这套缓存的 O24 局部相似度、近邻、聚类和颜色里，区域归属的信息基本已被 G 用掉。剩下的少量信息主要在参考侧（反向注意力、参考边缘类比），强度远达不到保本所需。
- 这不说明输入里没有归属信息。6,200 例审计中答案唯一；W61 换参考能救回 22/89 个灾难例。
- 按 OVERVIEW 第 7 节，下一步是问：能过保本门槛的信息可能从哪里来。由用户决定。
