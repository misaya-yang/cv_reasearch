# W66：与核心相连的中等区域是否属于目标——判断它的信息在参考里，还是在查询里

2026-10-16 写定，用户同意（“你试试吧”）。第 1–3 节在运行前固定；子代理的量在它检验前另行预注册。

## 1 动机

- [W65](W65_extent_headroom_REPORT.md)：在 MFU 的 CRF 前场 G 上，每例单一切点/面积规则拿不回余量。80% 的例子不该动，20% 要移约 1.44 倍频，IoU 对面积很陡，现有不看 GT 的标量信号太弱。
- 图板显示，欠覆盖与过覆盖的区别不在场的形状，而在**与已覆盖核心相连的那片中等区域算不算目标**：
  - 欠覆盖：参考只展示了目标的一部分或另一视角，相连的侧面、头发、船舱属于目标；
  - 过覆盖：托台、杯沿、皮肤晕不属于目标。
- 所以把决策从“整幅一个水平”改成“每片区域一个归属”。立项前先回答：做这个判断的信息在哪里？
  - **参考侧：** 区域像不像参考前景、像不像参考背景、参考是否完全没见过它；
  - **查询侧：** 区域与核心是否成组，即特征近邻、聚类、颜色。
- 两边都读不出，就说明在这套缓存特征的局部相似度里读不出归属。这仍不是“信息不在输入里”。

## 2 设计

**样本：** W65 的 S 半 1,970 个 G 场例子，沿用 W65 的照片分半：V 为看图半，X 为检验半。T 半与新照片留出不读。另报不含 SUIM。

**区域（token 网格 64×64，不看 GT）：**
- G64：G（1024²）按 16×16 平均；
- 核心 K：G64 ≥ .8 的 token；少于 4 个时，取 G64 > .5 的 token 中 G64 最高的 25%（至少 1 个）；
- 自然 N：G64 > .5；
- **内壳 IN = N \ K：** 自然掩码里不属于核心的部分，对应过覆盖时多出的台阶；
- **外延 OUT：** .15 ≤ G64 ≤ .5 的 token 中，经 4 邻接、在该带内连到 N 的部分，对应欠覆盖时漏掉的平台；
- 远背景 F：G64 < .15 的 token；少于 4 个时，取 G64 最低的 25%；
- 区域至少 4 个有标签 token 才计入。

**标签（只用于评价）：**
- token 的 GT 覆盖率 = (gt & valid) 平均 / valid 平均；valid 占比 < .5 的 token 不计；
- 区域属于目标，当且仅当其 token 平均覆盖率 ≥ .5。

**我的量（全部不看 GT；“+”表示值越大越预测“属于”）：**

| 来源 | 量 | 定义 | 预测符号 |
|---|---|---|---|
| 基线 | B0 | 区域内 G64 均值 | + |
| 基线 | B1 | log(\|Z\|/\|K\|) | − |
| 参考侧 | R1 前景相似 | 区域内 log df 均值 − 核心内均值；log df = log c32 + log_e | + |
| 参考侧 | R2 背景相似 | 区域内 log db 均值 − 核心内均值；log db = log(1 − c32) + log_e | − |
| 参考侧 | R3 新颖 | −(区域内 log_e 均值 − 核心内均值)，即参考没见过的程度 | OUT +，IN 不预测（按 + 报告） |
| 参考侧 | R4 反向注意力 | log(区域内 back_f 均值 / 核心内 back_f 均值) | + |
| 查询侧 | Q1 近邻 | 区域 token 的 20 近邻（`query_neighbors20`）落在 K 的比例 − 落在 F 的比例 | + |
| 查询侧 | Q2 聚类 | 区域 token 中，所属 kmeans 簇（`regions64`）含核心 token 的比例 | + |
| 查询侧 | Q3 颜色 | Lab 均值距离 d(Z, F) − d(Z, K) | + |
| 组合 | C | R1、R4、Q1、Q2 按预测符号的秩平均 | + |

**主指标：** 跨例子的区域级 AUC（属于对不属于），IN 与 OUT 分开报告，用查询照片分组 bootstrap（1,000 次）。另报：
- X 半与全体；
- 逐域符号；
- 不含 SUIM；
- 次要：区域内 token 级 AUC 的逐例均值（只计两类各 ≥ 3 个 token 的区域）。

**子代理（独立视角）：**
- 在 V 半的区域图板上看图，提出至多 5 个自己的量；
- 写入预注册后，在 X 半上用同一套标签与主指标检验；
- 不读我的量的结果。

## 3 预测与读法（运行前写定）

**我的预测：**
- OUT 中，查询侧 Q1/Q2 最好，AUC 约 .65–.70；参考侧 R4 次之，约 .60–.65；R3 在 OUT 上为正但弱。
- IN 中，各量都弱（≤ .65），B0 与 R1 相近。
- 没有量在任一类区域上达到 .75。

**门槛：** X 半区域级 AUC ≥ .75，且比 B0 高 ≥ .05，且有效域中多数同号（两类各 ≥ 5 个区域的域才计）。

**读法：**
1. **参考侧量过门槛：** 参考里有局部归属信息，现有融合场没用上。下一步另写计划：做按区域的归属决策，在 S 半做一轮完整评分（含 CRF），通过后 T 半一次。
2. **只有查询侧量过门槛：** 归属主要靠查询内部的成组关系，参考不提供。下一步：检验“只向与核心成组的相连区域生长、从不成组的壳中收缩”这一固定局部规则，S 半一轮。
3. **只有组合 C 过门槛：** 两侧信息互补，按读法 1 推进，并在决策中同时使用两侧。
4. **都没过门槛，但有量 ≥ .65：** 弱信息。记录后不写规则，先看子代理的量与区域图板。
5. **都 < .65：** 这套缓存特征的局部相似度读不出归属。这不等于输入里没有信息；下一步要换信息来源（像素级、其他层），由用户决定。
6. 只做预定的一轮，算完不改区域定义、门槛或量。

**适用范围：** S 半、MFU 的 CRF 前场 G、非回退例、token 级区域；都是相关，不是因果。
