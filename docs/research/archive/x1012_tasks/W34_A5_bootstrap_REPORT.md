# W34 A5：照片簇 bootstrap、比值指标与有效依赖单位

日期：2026-10-15。对应 `W34_theory_PLAN.md` 的 T5.1，并为 T5 的配对检验与同时推断提供统计基础。本文只做理论推导与原始文献核查；未读取数据、预测、GT 或运行实验代码。非劣效界、发表单值比较与多重检验由 A6 处理。

## 0 结论先行

1. **比值本身不妨碍照片簇 bootstrap。** 固定槽与权重、各槽总体分母为正、独立簇足够多且无支配簇时，汇总 IoU 是簇均值向量的光滑函数；配对照片 bootstrap 一阶有效。下文给出影响函数、方差与证明。
2. **“规范化查询照片”是候选簇定义，不能仅凭题面认证为独立单位。** 同一查询的多参考任务应共同重采样；随机参考复用、照片跨角色复用、同病人/场景的多张图可能造成簇间依赖。跨域、跨臂共用权重是必要条件，但不充分。
3. **固定 benchmark 的完整确定性分数与照片超总体参数是不同对象。** 对已经完全评分的固定任务清单，分数没有由“再抽一次照片”带来的测量误差；bootstrap 区间是在额外的照片/任务生成假设下描述泛化不确定性。
4. **有效信息不能用 60,981 个任务或 bootstrap 次数代替。** 题面的 3,188 张查询照片最多提供 3,188 个候选独立查询簇；某域只有 16 个任务时，域内独立查询簇至多 16 个，实际可更少。十域等权也不会让大域替小域提供精度。
5. **BCa、studentized 与 wild bootstrap 都不能修复错误簇定义、缺失类别支持、近零分母或退化分布。** BCa 并非比值指标的强制修正；它的高阶优势有额外条件。
6. **推荐的主方案是先固定估计目标与依赖单位，再配对重算比值。** 已预定的 W30 percentile 主分析应照实保留；未来尚未开封结果的确认分析，在正则条件与稳定标准误得到支持时可预定 studentized cluster bootstrap，并将相同联合重采样用于 A6 的 max-T。本文不授权修改现行冻结分析。

## 1 形式化设定：先说清楚区间针对什么

### 1.1 三种不同的估计目标

设方法 A 为 SH+，方法 B 为完全匹配协议的 FoRIS。每个任务仍然只有一个参考；同一查询出现在多个任务中，不等于改变为多参考推理。

**F：固定清单的描述性差值。** 固定所有图像、参考配对、类别、fold、有效区域、确定性预测及评分规则，记其精确分数差为 \(\Delta_F\)。评分覆盖整张清单后，\(\widehat\Delta=\Delta_F\)。若没有另行指定参考抽取、推理随机种子或标注误差模型，就没有相应的重复抽样误差需要估计。照片 bootstrap 不是 \(\Delta_F\) 的“测量误差条”。如果只随机抽取固定有限总体的一部分照片，则应使用实际抽样设计与必要的有限总体修正，不能直接套无限总体的有放回抽样解释。

**Q：固定参考配置下的新查询照片。** 给定外部参考库与分配规则 \(\mathcal R\)，查询照片簇来自某个分布 \(P(\cdot\mid\mathcal R)\)。区间可针对条件目标 \(\Delta_Q(\mathcal R)\)。此时，参考被复用本身未必构成随机簇间效应：在确实条件化于固定外部参考、且查询的生成条件独立时，它只是固定输入。这个目标不能自动改写为“更换参考图也成立”。

**QR：新查询与新参考共同生成。** 参考、查询及配对机制均为随机，目标是在该机制下的平均表现。共享参考引起的随机效应必须进入方差。若参考本身也作为其他任务的查询，或有共同病人/场景，应再刻画相应依赖。

“照片超总体”不是默认存在的自然事实，而是明确的统计模型。十个域在此固定，不将它们当作从“所有视觉域”随机抽出的十个样本；置信区间不外推到未观察的新域。对抽样与总体目标的这种区分，可参见 [Abadie 等的原始论文](https://academic.oup.com/qje/article/138/1/1/6750017)；本文不把该论文针对处理效应的方差公式直接移用到 IoU。

### 1.2 同一公式容纳开发与官方权重，但不能混为同一指标

域 \(d=1,\ldots,D\)，此处 \(D=10\)。域内槽 \(s=(f,c)\)；方法 \(a\in\{A,B\}\)。先固定槽集合 \(\mathcal S_d\) 和权重 \(w_{ds}\)，满足 \(\sum_s w_{ds}=1\)。

- 开发口径：对原始评分清单出现的槽等权，\(w_{ds}=1/|\mathcal S_d|\)。必须区分“原始清单固定一次”与“每次重抽样重新决定出现槽”。
- 官方口径：固定应有的 fold 与类别，\(w_{d,(f,c)}=1/(F_d C_{df})\)。当各 fold 类别数不等时，这不等于所有槽一起等权。
- 对整数 I/U，官方 \(\sum I/\max(\sum U,1)\) 在 \(\sum U>0\) 时就是普通比值；在 \(\sum U=0\) 时人为定义为 0。这个记分约定不等于该类别的超总体参数已经被识别。

这里先在分母为正的正则区域推导；空槽在第 5 节单独处理。两种口径可以使用同一理论模板，但对应不同参数，不能相减或合并报告。

### 1.3 簇总量与所估计的参数

暂时假设已找到真正独立的簇 \(g=1,\ldots,G\)。令

\[
 X^a_{gds}=\sum_{e\in(g,d,s)} I^a_e,\qquad
 Y^a_{gds}=\sum_{e\in(g,d,s)} U^a_e.
\]

同一簇可以包含多个任务、槽、域和两个方法的全部输出。没有该槽任务时，其贡献为 \((0,0)\)。一个簇不是一条必须等权平均的 IoU 记录。

在簇向量独立同分布的基准模型下，定义

\[
 \nu^a_{ds}=E[Y^a_{gds}]>0,\quad
 \rho^a_{ds}=\frac{E[X^a_{gds}]}{\nu^a_{ds}},\quad
 \theta^a_d=\sum_s w_{ds}\rho^a_{ds},\quad
 \Delta_d=\theta^A_d-\theta^B_d,\quad
 \bar\Delta=D^{-1}\sum_d\Delta_d.
\]

估计量用簇总量的样本均值替换期望。特别地：

\[
 \widehat\rho^a_{ds}=\frac{\sum_g X^a_{gds}}{\sum_g Y^a_{gds}},\qquad
 \widehat\Delta_d=\sum_s w_{ds}(\widehat\rho^A_{ds}-\widehat\rho^B_{ds}).
\]

不能先逐任务算 \(I/U\) 再平均，也不能把两方法的交集差除以一个共用并集，来替代这个目标。

**大小与任务数的含义。** 在一个始终存在的槽里，若 \(R_g=X_g/Y_g\)，则

\[
 \frac{E[X_g]}{E[Y_g]}=E[R_g]+\frac{\operatorname{Cov}(Y_g,R_g)}{E[Y_g]}.
\]

所以汇总 IoU 通常不是“随机抽一张照片的平均 IoU”。它保留并集权重；若某照片生成更多参考配对任务，也保留该任务生成机制的权重。按照片重采样只修正抽样单位，不会把估计目标变成照片等权，更不会消除选择性漏任务带来的偏差。

## 2 主要定理：从槽比值到配对域差的影响函数

### 2.1 假设与证明范围

以下给出一个可完整证明、条件明确的充分条件版本，而非声称现有数据已经满足：

1. \(Z_g=(X^a_{gds},Y^a_{gds})_{a,d,s}\) 是 IID 独立簇向量；任意簇内依赖允许存在。
2. 域数与槽集合固定且有限，权重预先固定；两方法在相同任务支持上评分。
3. 所有 \(\nu^a_{ds}\ge\epsilon>0\)；\(E\|Z_g\|^{2+\eta}<\infty\)，某个 \(\eta>0\)。
4. 所讨论差值的渐近方差为正；方法及比较对象已冻结，不在这批评分上选择获胜方法。

IID 是为了使证明和普通 multinomial bootstrap 的解释透明。若各簇非同分布、簇大小随样本增长，则需要相应的三角阵 LLN、Lindeberg 条件、方差一致性和“单个簇渐近可忽略”条件，不能直接宣布 \(\sqrt G\) 速率通用。[Hansen 与 Lee（2019）](https://users.ssc.wisc.edu/~behansen/papers/JoE_2020.pdf)给出更一般的簇渐近理论，明确允许不同速率；本文不把其所有情形都缩减为 IID 定理。

### 2.2 定理 1：渐近线性表示与联合 CLT

定义方法的域影响函数

\[
 \phi^a_{gd}=\sum_s w_{ds}\frac{X^a_{gds}-\rho^a_{ds}Y^a_{gds}}{\nu^a_{ds}},
\]

配对影响函数和十域平均影响函数

\[
 \psi_{gd}=\phi^A_{gd}-\phi^B_{gd},\qquad
 \bar\psi_g=D^{-1}\sum_d\psi_{gd}.
\]

令 \(\boldsymbol\psi_g=(\psi_{g1},\ldots,\psi_{gD})^\top\)，则

\[
 \widehat{\boldsymbol\Delta}-\boldsymbol\Delta
 =G^{-1}\sum_{g=1}^G\boldsymbol\psi_g+o_p(G^{-1/2}),
\]

\[
 \sqrt G(\widehat{\boldsymbol\Delta}-\boldsymbol\Delta)
 \Rightarrow N_D(0,\Sigma),\qquad
 \Sigma=E[\boldsymbol\psi_g\boldsymbol\psi_g^\top].
\]

矩阵允许奇异；对某个边际或线性对比作普通正态/分位数推断时，该对比方差需正。

**证明。** 对任一槽、省略上下标，存在精确恒等式

\[
 \widehat\rho-\rho
 =\frac{\overline X-\rho\overline Y}{\overline Y}
 =\frac{G^{-1}\sum_g(X_g-\rho Y_g)}{\nu}
 +G^{-1}\sum_g(X_g-\rho Y_g)
 \left(\frac1{\overline Y}-\frac1\nu\right).
\]

LLN 给出 \(\overline Y\to_p\nu\ge\epsilon\)，CLT 给出第一个因子为 \(O_p(G^{-1/2})\)，而括号为 \(O_p(G^{-1/2})\)。乘积为 \(O_p(G^{-1})=o_p(G^{-1/2})\)。有限个槽按固定权重相加、两方法相减，得到线性表示。每个 \(\psi\) 均值为 0，二阶矩有限；对任意固定向量 \(v\)，IID CLT 作用于 \(v^\top\boldsymbol\psi_g\)。由 Cramér–Wold 得联合 CLT。证毕。

这里保留了两类容易漏掉的协方差：同一照片在不同槽/域的相关性，以及 A、B 在同一任务上的相关性。它们都在 \(\Sigma\) 中。

### 2.3 可直接实现的方差表达式

以样本比值和 \(\widehat\nu^a_{ds}=G^{-1}\sum_gY^a_{gds}\) 插入影响函数，得到 \(\widehat{\boldsymbol\psi}_g\)。按该定义，\(\sum_g\widehat{\boldsymbol\psi}_g=0\) 恰好成立。协方差估计为

\[
 \widehat V=\frac1{G(G-1)}\sum_g
 \widehat{\boldsymbol\psi}_g\widehat{\boldsymbol\psi}_g^\top.
\]

\(\widehat V\) 估计 \(\operatorname{Var}(\widehat{\boldsymbol\Delta})\)，不是 \(\Sigma\) 本身。十域平均的方差是

\[
 \widehat{\operatorname{Var}}(\widehat{\bar\Delta})
 =D^{-2}\mathbf1^\top\widehat V\mathbf1.
\]

在定理条件下，插入式影响函数的二阶矩一致性和 LLN 给出 \(G\widehat V\to_p\Sigma\)。独立分别抽两个方法，相当于丢掉
\( -2\operatorname{Cov}(\widehat\theta^A_d,\widehat\theta^B_d)\)；这通常损失配对精度，也可能在负协方差情形低估方差。应始终共同重采样，不能假设丢协方差一定保守。

同理，分别独立抽域会丢掉共享照片造成的域间协方差。题面“同一照片在所有域、所有臂同权”的规则正确地保留了这部分结构，前提是照片 ID 与独立簇定义正确。

## 3 定理 2：配对簇 bootstrap 的一阶有效性

每次取

\[
 (W_1,\ldots,W_G)\sim\operatorname{Multinomial}
 (G;1/G,\ldots,1/G),
\]

对全部方法、域和槽使用同一组 \(W_g\)，重算

\[
 \widehat\rho^{a*}_{ds}
 =\frac{\sum_gW_gX^a_{gds}}{\sum_gW_gY^a_{gds}},\qquad
 \widehat\Delta_d^*=\sum_s w_{ds}
 (\widehat\rho^{A*}_{ds}-\widehat\rho^{B*}_{ds}).
\]

在定理 1 的条件下，对任意方差非零的固定线性对比 \(v\)，条件 bootstrap 分布

\[
 \mathcal L^*\!\left(\sqrt G\,v^\top
 (\widehat{\boldsymbol\Delta}^*-\widehat{\boldsymbol\Delta})\right)
\]

依概率收敛到真实极限正态分布。因此 percentile 区间对该固定目标一阶有效；这不是有限样本精确覆盖承诺。

**证明。** 条件于原始样本，bootstrap 相当于从经验分布 \(P_G\) 独立抽取 \(G\) 个簇。有限维样本均值的条件 CLT 成立：经验协方差收敛于总体协方差，\(2+\eta\) 矩条件保证条件 Lindeberg 尾项趋零。在所有分母均正的邻域，对经验均值应用上一节的同一比值展开，得到

\[
 \widehat{\boldsymbol\Delta}^*-\widehat{\boldsymbol\Delta}
 =G^{-1}\sum_g(W_g-1)\widehat{\boldsymbol\psi}_g
 +o_{p^*}(G^{-1/2}),
\]

其条件协方差趋于同一 \(\Sigma/G\)。分母离 0 有界、槽数有限，保证落出该邻域的概率趋零。Slutsky 得条件分布一致性。连续、非退化正态分位点的一致性使 bootstrap 分位数具有正确的一阶极限；正态极限的对称性给 percentile 两端正确的一阶覆盖。证毕。

**证明不覆盖的情形：** 随样本增长出现越来越多极稀有槽、分母均值趋 0、固定数量的大簇、跨簇依赖未处理、估计量局部退化、任务缺失或参考配对机制有选择偏差、开发集选中方法后的无条件推断。

**bootstrap 次数 \(B\) 的作用。** 上述理论对应理想条件分布。有限 \(B\) 只是其 Monte Carlo 近似；概率 \(p\) 的 Monte Carlo 标准误约为 \(\sqrt{p(1-p)/B}\)。增加 \(B\) 可以稳定尾部计数，不能增加独立照片，也不能修正错误抽样模型。bootstrap 尾概率不是无条件的有限样本精确 p 值；对计数加 1 也不会使一个错误的零假设重采样机制变正确。

## 4 依赖单位：什么时候 query-only 足够，什么时候不足

### 4.1 同一查询出现多次

同一查询的不同类别、fold、参考配对或域别名任务，共享其内容、难度和标注。把这些任务一起纳入 \(Z_g\) 并同权重采样，允许任意簇内依赖。分别重抽这些任务会把重复使用的同一张照片误当成独立证据。

只有当该 \(Z_g\) 与其他簇独立时，定理才成立。把所有参考配对留在查询簇内，并未解决同一参考跨查询复用产生的随机效应。

### 4.2 命题 3：随机参考复用可使 query-only 方差任意错误

**构造。** 一张共享随机参考有状态 \(V\sim\operatorname{Bernoulli}(1/2)\)。每个查询的 GT 都有两个前景像素。方法 B 恒预测其中一个像素，故 \(I^B=1,U^B=2\)。方法 A 在 \(V=1\) 时预测两个像素，在 \(V=0\) 时预测空集，故 \(I^A=2V,U^A=2\)。其余图像内容可以任意不同。

于是任意数量 \(G\) 查询的汇总差值都为

\[
 \widehat\Delta=V-1/2,\qquad
 E\widehat\Delta=0,\qquad
 \operatorname{Var}(\widehat\Delta)=1/4.
\]

给定已出现的参考，所有查询贡献相同；query-only bootstrap 的每个差值都等于 \(V-1/2\)，估计方差为 0，percentile 区间是错误位置上的单点，对 QR 目标 0 的覆盖率为 0。增加查询数与 \(B\) 都无济于事。证毕。

对 Q 条件目标 \(\Delta_Q(V)=V-1/2\)，这个零方差却是正确的。反例说明问题在估计目标和依赖结构，不在 percentile 或 BCa 的名字。

### 4.3 两向聚类、跨角色依赖与连通块

在已经证明适用的模型下，若每个任务 \(e\) 有查询身份 \(q_e\) 与参考身份 \(r_e\)，仅“相同 query”或“相同 reference”造成相关，且两类身份来自分开的总体，则可考虑两向聚类。令 \(\ell_e\) 为比值线性化后的任务贡献，已包含分母总量与指标权重，标量形式的方差候选为

\[
 \widehat V_{2w}
 =\sum_q\left(\sum_{e:q_e=q}\ell_e\right)^2
 +\sum_r\left(\sum_{e:r_e=r}\ell_e\right)^2
 -\sum_{q,r}\left(\sum_{e:(q_e,r_e)=(q,r)}\ell_e\right)^2.
\]

向量版本用外积。第三项是容斥修正，避免同一 query-reference 单元被计算两次。两维的有效类别数都需要增长，仍要排除支配单位；有限样本还存在非正定等问题。[Cameron、Gelbach 与 Miller](https://cameron.econ.ucdavis.edu/research/CGM_twoway_ALL_13may2008.pdf)提供原始两向/多向聚类理论。这里展示其在线性化 IoU 上的接口，**不声称任何配对图都满足该论文条件**。

若某张底层照片在任务 e 中是 query，在任务 f 中是 reference，\(q_e=r_f\) 也可能造成相关。把 query 列和 reference 列当成互不相通的两个因素，会漏掉这种交叉角色项。适当模型是依赖于“共享任一底层身份”的 dyadic/network 结构。其线性化方差所需考虑的配对项具有形式

\[
 \sum_{e,f:\{q_e,r_e\}\cap\{q_f,r_f\}\ne\varnothing}
 \ell_e\ell_f,
\]

其中包括对角项，也包括反向角色共享项；一致性仍依赖节点抽样、稀疏程度/度数、矩条件和非退化性。原始依据是 [Aronow、Samii 与 Assenova](https://arxiv.org/pdf/1312.3398)。不能只看到“两张图”就直接宣布两向聚类足够。

保守且概念简单的另一做法是：将共享底层照片、病人或独立场景的任务连边，以独立连通块为簇。但这要以块间确实独立为前提；如果形成一个巨型连通块，就不能再援引“许多独立簇”的定理。把簇定义得更大也会损失可估计性，不是无成本修补。

[Owen 与 Eckles](https://arxiv.org/html/1106.2125v3)的交叉因素 product-weight bootstrap 在明确的交叉随机效应模型下可有保守方差性质，并非任意依赖图上的精确 bootstrap。尤其不能把独立 query/reference 因子权重或同一身份的乘积权重不加证明地用于跨角色照片；它们可能引入错误的矩与重复计数。

### 4.4 规范化照片 ID 之外的层级

同病人的双眼/多张医学影像、同一航拍图的裁块、同一视频或场景的帧、跨域文件名不同但内容相同的照片，都可能需要更高层身份。这是待核查的元数据事实，本文没有断言这些依赖在当前数据中实际存在。路径规范化解决字符串别名，不自动证明生物学或场景单位独立。

## 5 比值有限样本偏差、空槽与抽样设计

### 5.1 命题 4：比值偏差通常是二阶，方向不固定

一个槽中，进一步假设簇总量有界、\(0\le X_g\le Y_g\)，且 \(E Y_g=\nu>0\)，对零分母采用有界记分约定，则

\[
 E\widehat\rho-\rho
 =\frac{\rho\operatorname{Var}(Y_g)-\operatorname{Cov}(X_g,Y_g)}{G\nu^2}
 +o(G^{-1}).
\]

**证明。** 对 \(f(x,y)=x/y\) 在 \((\mu,\nu)\) 作二阶展开。一次项均值为 0；\(f_{xy}=-1/\nu^2\)，\(f_{yy}=2\mu/\nu^3\)，\(f_{xx}=0\)。样本均值的协方差为单簇协方差除以 G，代入得到所示二次项。总量有界保证三阶余项期望为 \(o(G^{-1})\)；\(Y\ge0\) 且均值正，使样本均值落到 \(\nu/2\) 以下的概率指数衰减，有界记分约定不会改变二阶项。证毕。

结论不是“比值必然高估”，更不是“须用 BCa 修正均值”。BCa 调整的是置信区间分位点；任务缺失、非代表性抽样、协议不匹配和未知参考选择偏差不在这个 \(1/G\) 修正之内。

### 5.2 命题 5：少数照片支撑的槽在重抽样中频繁消失

若某槽的正并集来自 \(m_s\) 个独立照片簇，普通 G 次簇重抽样恰好漏掉该槽的概率为

\[
 p_{0s}=\left(1-\frac{m_s}{G}\right)^G.
\]

**证明。** 每次抽样避开这 \(m_s\) 簇的概率为 \(1-m_s/G\)，G 次相乘即可。证毕。

若 \(m_s=1\)，随着全局 G 增大该概率趋于 \(e^{-1}\approx0.368\)。因此其他域有成千上万张照片，并不能使单照片槽稳定。

**删除空槽会改变指标。** 例：原始样本有两槽，第一槽由 \(G-1\) 个照片支持且 IoU 恒为 1，第二槽由 1 个照片支持且 IoU 恒为 0；原始两槽均值为 1/2。若每个 bootstrap 副本只平均“本副本出现的槽”，其期望为

\[
 E^*\widehat\theta^*
 =\frac12+\frac12\left[
 \left(1-\frac1G\right)^G-\left(\frac1G\right)^G\right],
\]

因为漏第二槽时得 1，只抽第二槽时得 0，其余副本得 1/2。它产生约 0.184 的偏移，不是一般比值的微小二阶偏差。若两个方法在稀有槽的差异不同，这种改变也不会由配对自动抵消。

**固定槽、空槽记 0 也不制造信息。** 将上例两槽的恒定分数互换，采用固定两槽与缺失记 0，bootstrap 均值为 \(\tfrac12(1-p_{0s})\)。官方约定使统计量有定义，但稀有完美槽会产生明显的 0 点质量。正则理论只有在各槽有效支持增长、空槽事件消失时才适用。

原始数据里根本未出现的预定类别更严重：经验分布无法生成它。开发指标若只报告已出现槽，其目标应如实限定为该槽集合；bootstrap 不能恢复全类别参数。不能为了得到窄区间而删除副本、补入虚拟观测、把空槽替成原始槽分数，或事后合并类别。

### 5.3 fold/class 分层应服从照片抽样设计

类别与 fold 是指标权重，不自动是独立抽样层。若每个照片只属于一个预先固定的、互斥的抽样层 h，层内 \(n_h\) 个簇 IID，层数有限、各 \(n_h\to\infty\) 且满足相应矩与非退化条件，并且总体混合权重 \(\pi_h\) 固定，则对

\[
 \widehat\mu=\sum_h\pi_h\overline Z_h,\qquad T(\mu)
\]

有展开

\[
 T(\widehat\mu)-T(\mu)
 =\sum_h\frac{\pi_h}{n_h}\sum_g
 \nabla T(\mu)^\top(Z_{hg}-\mu_h)+o_p(\mathrm{SE}),
\]

独立层的方差相加：

\[
 V=\sum_h\frac{\pi_h^2}{n_h}
 \operatorname{Var}_h\!\left[\nabla T(\mu)^\top Z_{hg}\right].
\]

其证明是多变量一阶 Taylor 展开与各层 CLT；层内重抽样应保留 \(n_h\)。对于已经按固定比例构建的样本，\(\pi_h\) 需要与目标及纳入概率一致。未分层的全局 multinomial 在部分自归一化比值问题可一阶等价，但不能对任意不等概率、固定配额或稀少层设计直接保证等价。

如果同一照片跨多个类、fold 或域，逐槽各自重抽会割裂这个簇；不能既称其独立分层又忽略共享照片。应保留完整照片向量，或使用匹配原始抽样设计的共同权重。把不同类别当作随机抽样单位，还会把“这些固定类别上的效果”改成“新类别总体上的效果”。

## 6 区间方法比较与少簇限制

### 6.1 方法表

| 方法 | 可取之处与适用条件 | 本题不能自动解决的问题 |
|---|---|---|
| 配对簇 percentile | 正则光滑比值下有定理 2 的一阶有效性；直接重算原指标，易审计，区间保留差值的合法取值范围 | 不保证少簇/偏态尾部覆盖；不能修复空槽、错簇、参考复用 |
| 簇级 BCa | 在额外光滑性、矩与高阶展开条件下校正偏差和偏度；具有单调重参数化性质 | 必须按真正独立簇 jackknife；稀有槽删簇即消失、\(z_0\) 发散或加速度不稳定时不能使用其高阶承诺 |
| 配对簇 studentized / percentile-t | 以每个重抽样副本自己的标准误标准化；适合尺度差异明显的域，以及联合 max-T | 需要可靠的 \(\widehat{\mathrm{SE}}^*\)；分母为零或很不稳定时尾部可失真；不是任意小样本修复 |
| 影响函数 multiplier / wild | 对簇影响函数共用随机权重，可快速保留多域相关并构造联合统计量 | 只在线性化与独立簇条件成立时有相应渐近保证；随意翻转任务差的符号不是一般精确检验 |
| 多向或 dyadic 稳健方法 | 处理确实符合其模型的查询/参考交叉依赖 | 需要足够多的两维身份或节点、无支配单位；不能从题面认证；不自动处理任意长程相关 |

BCa 与 studentized 的高阶优点来自 [Efron（1987）](https://doi.org/10.1080/01621459.1987.10478410)和 [Hall（1988）](https://doi.org/10.1214/aos/1176350933)讨论的正则展开范围。本文证明的是一阶结论，**没有证明本题有限样本达到二阶覆盖**。簇 bootstrap 与少簇限制亦见 [Cameron 与 Miller（2015）](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015_February.pdf)。

### 6.2 studentized 的具体定义与一个实现易错点

对域 d，定义

\[
 T_d^*=\frac{\widehat\Delta_d^*-\widehat\Delta_d}
 {\widehat{\mathrm{SE}}_d^*}.
\]

若其分位数为 \(q^*_{\alpha/2},q^*_{1-\alpha/2}\)，边际区间为

\[
 [\widehat\Delta_d-q^*_{1-\alpha/2}\widehat{\mathrm{SE}}_d,
   \widehat\Delta_d-q^*_{\alpha/2}\widehat{\mathrm{SE}}_d].
\]

中心必须是 \(\widehat\Delta_d\)，不能直接将未中心化的 \(\widehat\Delta_d^*/\widehat{\mathrm{SE}}_d^*\) 当零假设分布。A6 的 max-T 应使用同一次重采样产生的全部 \(T_d^*\)，并单独处理方向与检验族。

设 \(\widehat{\boldsymbol\psi}^{*}_g\) 是在 bootstrap 参数下对原始簇 g 计算的影响函数。一个副本抽中该簇 \(W_g\) 次，就有 \(W_g\) 个经验分布抽样单元。故副本标准误的一致估计为

\[
 \widehat V^*=\frac1{G(G-1)}
 \sum_gW_g\widehat{\boldsymbol\psi}^{*}_g
             \widehat{\boldsymbol\psi}^{*\top}_g.
\]

这里是 \(W_g\)，不是 \(W_g^2\)。将重复抽中的簇再次按原始 ID 合并为一个权重放大的簇，然后对该合并簇平方，改变了这个 bootstrap 标准误。以上是统计定义，本文未检查现行实现是否存在该问题。

### 6.3 BCa 的加速度必须在正确的簇层计算

令 \(\widehat\Delta_{(-g)}\) 是删除整个独立簇 g 后重算的差值，\(\overline\Delta_{(-\cdot)}=G^{-1}\sum_g\widehat\Delta_{(-g)}\)。常用 jackknife 加速度为

\[
 \widehat a=
 \frac{\sum_g(\overline\Delta_{(-\cdot)}-\widehat\Delta_{(-g)})^3}
 {6\{\sum_g(\overline\Delta_{(-\cdot)}-\widehat\Delta_{(-g)})^2\}^{3/2}}.
\]

偏差校正 \(\widehat z_0=\Phi^{-1}\{P^*(\widehat\Delta^*<\widehat\Delta)\}\) 也依赖稳定的 bootstrap 分布。删一个簇就失去一个槽，或全部差值相同导致分母为零时，加速度并无可靠定义；将这些例外用数值常量压过去不会恢复高阶理论。

### 6.4 multiplier / wild 的适当使用

在定理 1 的条件下，对独立的均值 0、方差 1 权重 \(\xi_g\)，可用

\[
 Z_d^{\#}=\frac{\sum_g\xi_g\widehat\psi_{gd}}
 {\sqrt{\sum_g\widehat\psi_{gd}^2}}
\]

近似各域标准化估计误差的联合极限；全部域共用 \(\xi_g\)。这是基于影响函数的条件 CLT，不是在原始 I/U 上乘负权后计算可能无意义的“负并集比值”。

Rademacher 权重也不能把任意差值分布变成有限样本精确符号检验：精确交换性/对称性或随机分配来自额外设计假设，而两种确定性分割算法之间一般没有这种随机分配。少簇时某些 wild 方法可以改善特定模型的误差，但不能提供无条件的覆盖认证。

### 6.5 命题 6：边界与稀有事件可同时击穿这些近似

考虑更简单的合法比值：\(Y_g=1\)，\(X_g\sim\operatorname{Bernoulli}(p_G)\)，\(p_G=1/G\)。总体参数为 \(1/G>0\)。原样本全部为 0 的概率是 \((1-1/G)^G\to e^{-1}\)；在该事件上，非参数 bootstrap 的所有统计量为 0，percentile 区间为 \([0,0]\)，BCa 加速度与 studentized 标准误退化。这个事件本身就使覆盖率至多约 0.632，不能达到统一的 0.95。证毕。

这里 \(p_G\) 随 G 接近边界，违反定理的非退化正则范围，并不反驳点态渐近结论。它证明“指标有界，所以 bootstrap 一定安全”是错误的。

只有 16 个任务的域不是足够独立簇渐近模型的自动实例。即使每个任务都来自独立照片，仍需面对偏态、杠杆集中和稀少槽；若它们还共享病人或参考，有效信息更少。不能将经验的 20、30 或 50 当作放之四海皆准的及格线，也不能承诺 BCa、t 分布或 wild 会修好该域。若必要条件不获支持，应报告估计量和推断限制，不能用“其他域很多照片”替代证据。

| 要核查的量 | 支持正则推断的结果如何读 | 不支持时如何读 |
|---|---|---|

## 8 对检验与方法设计的含义

1. **先写论文分数的解释。** 完整固定清单的数字是描述性结果；照片区间另写其目标，例如“条件于固定类别、任务配对与参考配置的查询照片泛化差”。QR 泛化需要相应的参考随机效应。
2. **按协议重算，而非更换指标。** 固定折叠/类别权重、两臂配对任务与合法的零分母约定。公开分子分母汇总和簇定义，使读者知道每个区间在估计什么。
3. **现行 percentile 有条件成立，不必因为 IoU 是比值就强制改 BCa。** 对 W30 原计划照实报告；若另做稳健性分析，标明时间、主次与预定读法，不以区间显著性反向选择方法。
4. **未来确认分析的默认选择。** 在正确独立簇、固定支持、正分母和稳定方差得到支持时，预定 paired cluster studentized 区间；影响函数提供无需嵌套 bootstrap 的 SE。相同联合副本交给 A6 做事先定义的多重推断。没有这些条件时，优先修正估计目标和采样模型，保留不确定结论。
5. **对分割方法本身，不从区间技术寻找涨分。** 重采样不改变 SH+ 或 FoRIS 的预测，也不解释融合为何有效；它决定现有证据可支持多强的主张。单照片大收益、特定参考效应与稳定跨照片收益必须区分。

### 8.1 不改 W30 的可执行分析路径

这一流程只使用最终封存的既有 I/U 和任务身份元数据，不再推理、不改预测、不增加 GT 访问轮次，也不重新调参。本文给出流程，不执行数据核查。论文可沿每个分支继续推进，不要求等所有域都能获得强推断结论。

**步骤 1：先完成不依赖抽样模型的主表。** 按 W30 冻结规则给出完整固定 benchmark 的分数、任务覆盖和配对来源。已有匹配逐例 FoRIS 的部分可以报告精确的固定清单差值；只有发表单值的部分严格使用 A6 的发表值比较标签。Road custom200 单列，不改称官方同协议。该表不因后续簇假设无法认证而失效。

**步骤 2：默认选择能由现有设计支持的较窄目标。** 首选 Q：条件于已固定的参考库、参考分配规则、类/fold 和方法，讨论新查询照片。参考仅被复用、但固定参考库与随机查询独立且无交叉角色、无病人/场景跨簇依赖时，不必为此升级到复杂的多向 bootstrap；使用现行同权 query-cluster percentile 即可，明确其条件化解释。

**步骤 3：按已知依赖结构选择唯一处理分支。**

| 元数据与目标的情况 | 明确处理选择 | 论文如何继续 |
|---|---|---|
| Q 目标；固定外部参考；查询簇独立有依据；槽支持稳定 | 保留 W30 预定配对 query-cluster percentile 作为主区间；影响函数 SE 只作解释/辅助核查 | 报告条件于该参考配置的查询泛化差，由 A6 使用有效边际/联合检验 |
| 存在同病人/同原图/同场景的多查询，且这些更高层单位彼此独立 | 既有 W30 区间原样保留并说明层级；另用现有 I/U 在该已知最高独立层聚合，出具清楚标注的辅助区间，不重跑模型 | 若辅助结论支持，可按该真实单位解释；若不支持，保留固定分数优势并把相应泛化主张标为未确认 |
| 必须讨论 QR，且参考/查询来自分离身份总体，仅两向共享造成依赖，两维均有足够支持 | 辅助分析选择第 4.3 节的两向线性化方差及与模型匹配的联合近似；不得继续把 query-only 当 QR 区间 | 描述性主表保留；QR 结论单独列出，明示新增假设与辅助分析身份 |
| 同一照片跨 query/reference 角色复用，但任务图有足够多的独立连通块 | 最简单选择是按独立连通块聚合现有 I/U 后配对重抽；不把两列身份机械分开 | 以连通块为单位报告辅助泛化区间；不改变原始预测与评分指标 |
| 跨角色图只有少数巨大连通块，且没有可辩护的 dyadic 抽样模型；或依赖元数据缺失 | 不强行做 QR 认证。W30 原区间可注明为“查询照片重加权敏感性区间”，不承诺它是该 QR 目标的 95% 置信区间 | 继续报告固定清单结果与已支持域的推断；将该域/该目标写成未确认，不以无显著下降代替非劣效 |
| 槽原始缺失、bootstrap 大量空槽、域仅少量有效簇、标准误退化 | 不切换到 BCa、wild 或更大的 B 来争取显著性；保留预定结果和异常比例，避免对该域给强确认结论 | 主表与总体/其他域结果照常报告；稀少域单列估计与限制。若它属于“全部十域”的合取主张，该主张依 A6 判为尚未建立 |

“辅助分析”不意味着择优报告：其触发来自身份结构或事先约定的支持条件，结果有利和不利都报告。每域可有不同的数据支持状况，但不能据效果正负决定采用哪条分支。对于假设尚未核查的现状，立即可用的结论是完整固定清单分数；条件泛化解释在完成所列元数据核查后升级。

**步骤 4：输出一个紧凑的推断账本。** 每域记录：配对来源、固定指标、估计目标 F/Q/QR、实际重采样单位、独立单位数与最稀槽支持、主区间方法、是否具备所声明推断条件。这个账本是主表的必要脚注信息，不是再开一轮模型实验。A6 据此把“分数更高”“配对泛化显著”“非劣效已建立”“支持不足”写成不同结论。

可用措辞：

> 我们在固定的 fold/class 汇总规则下计算两方法的配对差值。区间通过对独立的 [实际单位] 共同重采样、在每个副本中重算两方法的交集/并集比值获得，目标为 [Q 或 QR 的明确定义]。稀少支持域的区间作为有限样本近似报告；完整固定 benchmark 分数另作为描述性结果呈现。

不能仅凭题面写：“60,981 例足以保证所有域区间准确”“查询照片 bootstrap 已考虑所有依赖”“BCa 后少样本问题已解决”。本文尚未核查元数据，所以不对现有任一区间给出通过/不通过的实证认证。

## 9 证伪条件与理论边界

- **会推翻应用资格、不会推翻条件定理：** 找到共享参考随机效应、跨角色同图或同病人跨簇依赖；重要槽只有有限个独立支持；分母随样本趋零；单个簇始终控制方差；同一评分集上选方法而未处理选择。此时不能用定理 1–2 为现行区间背书。
- **会推翻本文的实现映射：** 实际指标并非给定的固定权重比值，或者实际 bootstrap 会重新选择槽、任务/域支持、方法臂。这要求重写参数与影响函数，不允许把公式机械套入。
- **不会证伪理论的结果：** 16 任务域的 percentile 与 studentized 不一致、BCa 不稳定、某个域置信区间很宽，均在已列明的有限样本风险范围内。
- **真正针对定理的反证必须满足全部假设。** 若在 IID、固定有限槽、分母均值离 0、有足够矩、非退化并持续增长的独立簇序列上，线性化余项不趋小或 conditional bootstrap 不趋同，才反驳这里的推导；本文提供了逐步证明，未以数据拟合假设替代证明。
