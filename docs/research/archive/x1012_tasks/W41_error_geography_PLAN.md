# W41：SH 的错误分布与两线字段交换

2026-10-15 写定。第 1–3 节在运行前固定，执行中不改。设计取自 [W39 A](W39_A_mechanism_REPORT.md) §2–§4（P3 字段交换、命题 A2、式 (6) 的区域归因）；本计划只把它冻结成一轮可运行的诊断，不改 W39 的文件。

## 1 动机

- **W37、W38、W40：** 边界带的量有 +9.43 的容量，但四种可部署的量都不如 F 自身。下一步的新方法需要先知道：SH 剩下的错误到底在哪里，现有融合原则上能动到哪些。
- **W39 A 命题 A2：** SH 在 CRF 前是两条实际字段的逐点凸融合（.5·U + .5·M > .5）。
  - 两线都 ≤ .5 的像素（共同负区 C0）不会被加入，两线都 > .5 的像素（共同正区 C1）不会被删除；
  - 所以共同 FN（G ∩ C0）与共同 FP（Gᶜ ∩ C1）只有 CRF 或别的动作能改。
- **尚未测量的事实：** 最终 SH 的错误有多少在共同区、多少在分歧区 D；融合的收益来自两线的**空间排序**不同，还是只来自数值标度和阈值面积（W39 A 的 H1 与 H2）。
- **本任务回答：**
  1. 只修分歧区、只修共同区，各值多少；
  2. 在相同面积、相同数值分布下，两线排序的组合是否仍有用；
  3. CRF 的收益落在哪个区域。

## 2 设计

**样本：** W37/W38/W40 同一批 1,285 个 S 例。T 半和新照片留出都不读。

**字段：** 冻结 `simple_head` 在 1024×1024、相加前的实际字段。
- U = minmax(up(U0))；M = up(M′)，不再 minmax；F = (U + M)/2；A = F > .5，必须与 W23 SH（CRF 前）的 I/U 一致，≥ 1,280/1,285。
- 回退例（rho > .9）没有两条线，所有臂都等于自然输出，单独列出。

**区域（评分前由字段确定）：**
- C0 = {U ≤ .5, M ≤ .5}，C1 = {U > .5, M > .5}，D = 其余。
- **实现检查：** 非回退例上 A ∩ C0 与 C1 \ A 的像素数必须全为 0。

**指标 1：区域容量（oracle，只作诊断）。** 在 A 上把一个区域换成 GT，其余不变：
- O_D（只修分歧区，等于任何逐点选线规则的上限）；
- O_C（同时修 C0 与 C1，即共同错误）；
- O_C0、O_C1 分别单列；
- 回退例单列：O_fb，把回退例整张换成 GT。
- 每个容量都单独计算，不相加。

**指标 2：字段交换（W39 A 式 (1)）。**
- 全秩按值升序，同值按像素的行优先坐标打破并列；
- X = M 的次序统计量按 U 的秩放置（U 的排序、M 的数值分布）；Y = U 的次序统计量按 M 的秩放置。
- 八臂：U、M、X、Y、F、XM = (X+M)/2、UY = (U+Y)/2、XY = (X+Y)/2。
- **两种读出：**
  - 自然阈值：> .5；
  - 等面积：各场取同一个 k0 = |A| 个最高像素（画布上，并列取坐标靠后者）。注意在等面积下，X 与 U、Y 与 M 的前缀相同。
- **并列敏感性：** 接收场的同值块所占秩区间，映到 donor 次序统计量在该区间的均值（Xt、Yt），重算含它们的臂，并记录并列像素数。

**指标 3：CRF 的区域归因（W39 A 式 (6)）。**
- SH+ = CRF(A)，回退例不加 CRF，与冻结 SH 一致；
- 相对 A，在每个区域记四种编辑：新增 TP a、新增 FP b、删除 TP c、删除 FP d；
- 按槽池化后，用 SH+ 的最终分母求各区域贡献，各区相加等于 SH+ − A。

**口径：** class mIoU，(fold, 类别) 槽池化后等权，十域再等权，CRF 前（指标 3 除外）。十域区间用 `w37._boot`（照片 bootstrap 500 次，rng = c.SEED）。

## 3 读法（运行前写定）

1. **实现检查：** A 与 W23 SH 一致 ≥ 1,280/1,285；A2 违反像素数为 0。任一不满足先查字段，不读后面的结果。
2. **错误在哪里**（十域 mIoU 相对 A）：
   - **O_C ≥ 2·O_D：** 主要余量在两线的共同错误，任何融合或选线规则都动不到。下一个方法必须能**推翻两线共识**，不再在 SH 的融合上做文章。
   - **O_D ≥ 2·O_C：** 主要余量在分歧区，下一步研究“分歧处选哪条线”。
   - **介于两者之间：** 两类都要，报告比例，不指定单一方向。
3. **排序组合是否有用**（等面积读出，十域均值与区间）：
   - **H2 支持：** k_XM − k_U、k_XM − k_M、k_UY − k_U、k_UY − k_M 四项都 > 0，且区间下界 > 0。在相同面积、相同数值分布下，两线排序的组合仍更好，融合收益不只是标度或面积。
   - **H1 支持：** k_XM、k_UY 都不高于两条单线中较好的一条（十域均值），而自然阈值下 F 高于两条单线。融合的收益主要来自面积与标度。
   - **其他：** 记为混合。若 XM 与 UY 结论相反，写成“依赖共同标度的选择”；若并列敏感性版本改变任一项的符号，写成“依赖并列处理”。
4. **CRF 的作用：** 只报告各区域贡献，以及 CRF 是否在 C0、C1 上净正。不据此改 SH。
5. 这是诊断，不是方法。任何臂都不当作新方法发布，也不据此读 T。

## 结果

**2026-10-15 06:15 完成。读法 2 为“两类都要”（O_C +16.48，O_D +9.63，比值 1.71）；读法 3 按规则记为混合，但量级很清楚：等面积下排序组合只值 0.1–0.6 点，融合相对单线的优势主要来自面积。CRF 的净收益几乎全在分歧区，共同错误没有任何现有部件在修。**

- **运行：** 1,285 例（195 个回退例），2 个进程 × 1 线程，nice 19，中位 2.0 s/例。
- **实现检查：** A 与 W23 SH 一致 1285/1285；SH+ 与 W27 一致 1285/1285；A2 违反像素 0。
- **并列：** U、M 的并列像素中位数为 5.8 万、10.1 万；并列保持版本只在约 4% 的例上改变像素，所有臂的十域结果与主版本相同（两位小数），没有符号翻转。
- **数据：** 完整报告在 `../cv_data/a/x1013_W41/report.txt`，证据在 `evidence/research/w41_error_geography_S.jsonl.gz`。

**错误在哪里（A = SH，CRF 前；池化像素错误占比；容量为十域 mIoU 相对 A，各自单独计算，不相加）：**

| 区域 | FN | FP | 容量（oracle） |
|---|---:|---:|---:|
| C0：两线都判背景 | 22.4% | 0 | O_C0 +7.78 |
| C1：两线都判前景 | 0 | **32.9%** | O_C1 +7.29 |
| C0 ∪ C1：共同错误 | 22.4% | 32.9% | **O_C +16.48** |
| D：两线分歧 | 19.8% | 15.2% | O_D +9.63 |
| 回退例（整张） | 6.2% | 3.6% | O_fb +12.48（Fundus +65.6、Road +38.2） |

- 逐域 O_C 都 ≥ O_D；iSAID（29.6 对 11.7）、Road（14.7 对 2.3）、COCO（19.2 对 10.0）、ISIC（22.4 对 11.4）的共同错误余量约为分歧区的两倍或以上。
- **最大的一块错误是共同假阳性：** 两线都判前景、实际是背景，占全部像素错误的 32.9%。这与 W38 中“nat 在带内平均多取 16 像素/token”同向。

**融合收益来自哪里（十域，CRF 前，相对 A）：**

| 读出 | U 线 | M 线 | XM | UY | XY |
|---|---:|---:|---:|---:|---:|
| 自然阈值 | −1.85 | −3.98 | −3.56 | −1.63 | −0.28 |
| 等面积 k0 = \|A\| | −0.22 | −0.56 | −0.09 | −0.09 | −0.25 |

- **等面积下两条线的排序只比 F 差 0.22 和 0.56**，而在各自的自然阈值下差 1.85 和 3.98。只看量级，融合对 U 的优势约 88%、对 M 的约 86% 来自面积（阈值落在哪里），来自排序组合的不到 0.6 点。这只是量级对照，不是可加的因果分解（W39 A §2.2）。
- **各线的排序在自己的面积上最好：**
  - 在 M 的面积上，U 的排序（X）比 M 自己差 0.39；
  - 在 U 的面积上，M 的排序（Y）比 U 自己差 0.41；
  - 这与“两线分别是小尺度和大尺度的读出”一致（W34 的夹逼发现）。
- **读法 3 的判定：**
  - k_XM − k_M、k_UY − k_M 均为 +0.47 [+0.33, +0.66]；
  - k_XM − k_U +0.13 [−0.04, +0.31]，k_UY − k_U +0.14 [−0.03, +0.29]；
  - 四项没有全部区间 > 0，所以 H2 不成立；k_XM、k_UY 高于较好单线（−0.22），所以 H1 的条件也不成立；
  - 按规则记为**混合**：共同标度下的排序组合只稳定地胜过 M 的排序。

**CRF 的区域归因（W39 A 式 (6)，十域）：** C0 +0.01、C1 +0.00、D +0.17，合计等于 SH+ − A（+0.18）。CRF 的净收益几乎全在分歧区；iSAID、Road 在 C1 上为负（−0.28、−0.39）。

**结论：**
1. SH 的融合本质上是在两条线之间**选面积**；两条线的空间排序在等面积下几乎可互换。
2. 一半以上的像素错误（55.3%）落在两线的共同区，融合在数学上动不到，CRF 实际也没有动（净 +0.01）。共同假阳性是最大的一块。
3. 因此下一个方法要能**推翻两线共识**，尤其是删除两线都判为前景的区域；仅在分歧区做选线，上限是 O_D +9.63。
4. 尚未区分的是：共同错误主要在边界一个 token 内（局部的量），还是远离边界（实体层面的多取或漏取）。这决定 D 线（带内）与 B 线（实体）哪一条对口，放到下一个计划里作为诊断一并记录。

**事后更正（2026-10-15 09:40，不改判定）：** 本文的错误占比都是全部例的像素池化，被少数灾难例主导：SH+ IoU < .3 的 20.3% 例占全部像素错误的 43.8%，共同错误的约一半。所以“主体在共同区／带外实体层面”描述的主要是灾难例的形态，不代表一般例子。逐例的失败类型（表示不足、迁移失败、读出失败）见 [W45](W45_solvability_PLAN.md)。
