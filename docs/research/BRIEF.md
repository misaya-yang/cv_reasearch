# 给方法生成模型的题目

用途：整段贴给 Pro、Astra、dots 等模型，让它们在已测事实的约束下出方案。数字出处在
[RESULTS](../../evidence/local/RESULTS.md)。这不是待办清单；选中的方案才进 [PLAN](PLAN.md)。

## 设置

COCO-20i 单样本分割。输入只有：一张参考图及其完整类别掩码、一张查询图、冻结的 DINOv3-L（1024 输入，64×64 个位置）。
不训练，不用 SAM，不用类别名、额外图像、基类标签或别的预训练模型。输出查询图里该类全部物体的掩码。
要超过的基线：完整 FoRIS 60.93（公开 4000 例）。

## 已有部件及实测价值（可直接用，可重组）

| 部件 | 作用 | 实测 |
|---|---|---|
| 位置去偏 | 去掉特征里的位置成分 | +5.8 |
| 原型对比证据 | 查询位置对参考前景原型的软最大相似度，减去对最难 20% 背景位置均值的相似度 | 单独读出约 52 |
| 参考投票 | 参考前景位置在查询图上的最近邻落点 | +2.27 |
| 种子先验 | 得分最高的查询聚类及其相似聚类 | +1.25 |
| 查询图上的图求解 | 互为近邻的查询特征图上解 (A+16L)z=Ay | +2.64 |
| 排序校正 | 用参考匹配的排序修正图求解的输入 | +0.66 |
| 细读出 | 四次移位编码得到 128×128 特征再读出 | +0.39 |
| 固定切分 | 每图 min-max 后切在 0.5 | 全局最优就是 0.5 |

FoRIS = 前四项 + CRF。我们现在 = FoRIS 的证据 + 后四项 = 63.10（+2.17 [+1.73, +2.63]）。

## 已测事实（方案必须与之相容）

1. FoRIS 有 17.4% 的图没找对目标（最好的切分 IoU 也不到 0.5），全修好值 +11.19。按物体占图比例
   <2% / 2–10% / 10–30% / >30%，没找对的比例是 33 / 17 / 7 / 3%。
2. 在这些图里，来自参考相似度的量分不开真目标和错圈区域：证据得分真目标更高的只有 32/84，
   反向匹配落点 39/81，参考背景落点 41/81。
3. 这些图里错圈面积的 64% 与真目标相连。小物体（<2%）错圈面积是物体的 2.58 倍，大物体（>30%）漏掉 27%。
4. 最合适的切分水平随物体大小变：0.62 / 0.57 / 0.46 / 0.31。逐图选对水平 +8.91；按真实大小分四档 +3.98，
   其中已找对目标的图贡献 +1.69。
5. 打分图自身给不出这个水平：最稳定水平 +0.52（区间跨 0）；Otsu、isodata、Kittler 只有 36 到 50；
   用打分图描述量训练的树 −0.7；九种由打分图得到的大小估计 ±0.7 以内；按预测区域放大重跑 −0.05。
   查询图的颜色和边缘也给不出：从峰值出发的颜色生长、边缘围住的区域、边缘上的分水岭，与真实大小的相关
   只有 0.25 至 0.52，选水平的收益 −0.54 至 +0.25。
6. 只对着参考图拟合判别器到不了基线：线性读出 46.58，Huber 比岭回归只多 0.71，
   AdaBoost、最大间隔、决策树、LVQ、KDE、MMD、稀疏编码都不超过它。原因是单张参考盖不住查询目标的外观。
7. 更复杂的引导（成对关系、三体关系、有向边、Poisson 读出）接在图求解上不比参考前景均值引导更好。

8. 证据决定水平（DEV241，完整 FoRIS 59.07）。每种证据"单独读出 → 接我们的图求解"：最近邻 20.12 → 20.89；
   参考前景均值相似度 37.98 → 42.76；原型对比 51.94 → 56.17；加投票和种子先验 56.36 → 59.69；FoRIS 最终得分 58.61 → 61.05。
   图求解只加 1 到 5 个点。从均值相似度到原型对比的 14 个点，来自这几样：减背景、背景只取与前景最像的 20% 位置并对前景均值正交化、前景聚成原型、软最大（各值多少正在拆）。

## 要回答的问题（只这三个）

- **Q1 圈多大**：参考相似度、打分图、查询图的低层颜色与边缘都不含范围信息（事实 2、5）。还有什么能确定被指认物体的范围？
- **Q2 是哪一个**：参考相似度在真目标和相像区域之间打平时（事实 2），规则内还有什么信息能分开它们？

- **Q3 证据**：原型对比为什么比均值相似度高 14 个点？有没有一条我们自己的原理，能写成
  "查询特征、参考特征、参考掩码 → 64×64 得分"的函数，单独读出达到或超过 52，并且同时改善 Q1 或 Q2？

## 交卷格式（每张卡不超过 15 行）

1. 新的量：公式，输入是什么。
2. 它用到的信息为什么不在参考相似度和打分图里（否则已被事实 2、5 否定）。
3. 它改变上面哪一类错图，为什么会改对而不是改错。
4. 插在哪个环节；其余环节不变。不要交替换整条流程的方案。
5. 最强的简单替代是什么，凭什么它做不到。
6. 什么读数算否定。
7. 额外编码次数和大致耗时。

宁少勿滥。教科书分类器换个名字套在位置特征上，属于事实 6，不要交。

## 筛选方式

先按事实 1 至 7 在纸面上否决；剩下的在已存数据上数张数（600 例的 64×64 得分、图求解结果、参考匹配量和真值；
公开 4000 例的两种打分图和各切分水平的交并数；dots 上约 220 例的原始特征）；过线的才实现并比 mIoU。
