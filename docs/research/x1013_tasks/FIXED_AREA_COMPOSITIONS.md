# 固定面积门控组合臂：S 半离线结果

日期：2026-10-13。三条用户提出的组合臂在冻结的 6,752 个 S 半样本上完成离线重评。只读取 T0/T2/T5 连续场、A3/F1b、E1 C1 与 FoRIS 缓存；没有构造模型或调用 DINOv3。新组合没有使用 T 半。

## 固定实现

- **R1_fix_l64：**预测面积 `<=25%` 用 `C1=CRF(A4)`；`>25%` 用缓存 T0 场重放的 `lambda=64` 读出，min-max 后以 `.5` 切分，不再叠 CRF。
- **R2_fix_core_union：**`<=25%` 用 C1；`>25%` 用 `(u>.50) | ((F1b>.50) & (u>.30))`。F1b 使用缓存连续分数，逐例核对其 `.5` 掩码与 T5 缓存一致。
- **R3_fix_l64 / R3_fix_core_union：**`<3%` 用 C1；`3–25%` 用缓存 A3（不加 CRF）；`>25%` 分别沿用 R1 或 R2 大目标分支。
- 原有 `rho>.9` 无图正则支持例在大目标分支保留 A4。面积门控以 A4 预测面积定义。

## 判读

R1 将 ISIC 拉到略高于 FoRIS（+0.05 pp），但 COCO 仍低 1.00 pp；其 Lung 虽比 FoRIS 高 1.04 pp，仍比候选 A4 低 1.15 pp（95% CI −1.48 至 −0.83）。

R2 的大目标 F1b union 把 ISIC 提至 +0.93 pp、SUIM 提至 +0.97 pp，但 Lung 低于 FoRIS 4.86 pp、低于 A4 7.04 pp（95% CI −8.26 至 −5.83）。因此它重现了 Lung 大目标的明确风险。

R3 λ64 是四臂中 COCO 最接近 FoRIS 的方案（−0.49 pp），同时 ISIC +0.46 pp、Lung +0.96 pp；但 COCO 差值区间仍跨零，且相对 A4 的 Lung 变化为 −1.22 pp（95% CI −1.55 至 −0.89），DeepGlobe Road 相对 A4 低 0.69 pp。R3 F1b union 提高 ISIC 至 +1.33 pp，但 Lung 再次低于 FoRIS 4.91 pp。

**结论：**没有一臂同时消除 COCO 差距并保住候选在 Lung 上的表现。R3 λ64 是值得保留的局部诊断候选，不足以冻结成十域方法；R2 的大目标 F1b 分支应视为 Lung 高风险。结果是已曝光 S 半开发测量，不构成独立确认。另一个已完成的 E2 评估报告记录了其按既定选择规则对 MFU 读取一次 T；本实验本身没有用 T 选臂或改公式。
