**结论。**
1. 计划里 T3–T5 的预先声明变体没有一项通过保留条件，候选不变。
2. 所有变体落在同一条轴上：做区域级整合的（类原型引导、聚类均值、解图）帮大目标、伤小目标；做锐化的（绝对阈值、不解图、纯核后验）相反。候选输给 FoRIS 的只有 GT 面积 >25% 的任务。
3. 该用哪一端由 query 中目标的大小决定。参考面积选不出来；候选自己的预测面积可以。
4. 用预测面积门控聚类均值，ISIC 从 −1.47 变为 +1.09、SUIM 从 +0.07 变为 +0.87，但 Lung 掉 15 点：只用特征的聚类在 Lung 上把肺和躯干并成一块。区域的来源不合格，机制本身成立。
