# 单参考图上下文图像分割领域研究

研究截点为2026年10月12日，按用户所在 America/New_York 时区。本文结合论文、作者实现和本仓库已有记录，研究一张参考图及其完整前景掩码如何指导另一张图的完整分割。仓库的具体目标是冻结 DINOv3，以统一规则跨十域超过完整 FoRIS 和强对照。当前工作树为 `codex_m4`，基于 `d2503d3`，同时包含其他会话的未提交研究整理与实验报告；引用的是本次实际读取的文件，而非仅该提交。

**核心判断：该领域已经证明冻结视觉特征能够支持跨图分割，尚未解决的是有限参考覆盖下，如何可靠判断目标身份、确定前景范围并恢复像素结构。** 对本仓库而言，最有价值的研究空间是这三个问题的可验证联系。仅增加背景抑制、图传播、区域聚类或不确定性模块，都不足以构成新的贡献；这些路线已有直接先例，也已有本地失败边界。

本仓库并非没有正结果。完整 FoRIS 增强、真实窗口与拒识、可靠度加权和细结构像素定位均留下有效证据。但增强收益、机制增益、跨域通用性和独立确认是不同结论。R3 在1360例开发队列上八域名义上涨，仍未过十域开发门槛；它不能替代此前2136例 C1 的确认结果。写作期间出现的R4范围与全局阈值结果也已在第5.4节补充，后续R5由原会话继续推进。详见[结果账本](RESULTS.md)、[当前缺口](GAPS.md)和[R3报告](x1012_tasks/R3.md)。

## 1 任务定义决定哪些工作可以比较

令参考为 \(S=(I_s,M_s)\)，查询为 \(I_q\)，输出为 \(\widehat M_q\)。一张完整参考掩码意味着当前任务在参考图上的前景位置已知；它不意味着查询目标的所有外观、面积、实例数或部件粒度已经给出。

“单参考”“冻结编码器”“免训练”“无需测试时优化”是四个不同条件。

|条件|准确含义|不能由它推出什么|
|---|---|---|
|本任务的单参考|每次预测只有一张带完整标注参考图|没有离线分割训练、没有外部语言先验；外部1-shot还可能按类计数|
|冻结编码器|推理或下游训练不更新编码器参数|解码器、adapter或分类器也没有训练|
|无需额外任务训练|不再用跨任务分割数据训练新组件|基础模型从未见过分割监督|
|无需测试时参数拟合|推理不做梯度更新或拟合新参数|没有聚类、线性求解、参考选择或多轮大模型调用|
|单个自监督骨干|语义与空间信息来自同一自监督编码器|所有域都可由同一种读出可靠分割|

传统 few-shot semantic segmentation 通常先在基类上训练，再用支持例分割新类别。视觉 in-context segmentation 更强调由示例指定任意概念，可能涵盖语义类、对象部件和特定实例。Referring segmentation 通常额外输入语言描述；视频分割的首帧参考还拥有时间连续性和身份保持条件。它们可以提供机制启发，但实验协议不能直接互换。[OSLSM](https://arxiv.org/abs/1709.03410)、[SegGPT](https://arxiv.org/abs/2304.03284)、[SINE](https://arxiv.org/html/2410.04842v1)。

本仓库当前合法方法可以使用参考标签和未标注 query 结构。利用未标注 query 的整体结构作自适应估计或图推理，可以属于传导式推理；读取 query 特征本身不意味着标签泄漏。用 query GT 选择阈值、候选、组件或提示则改变监督契约。R2 的参考内 logistic 拟合没有引入额外标注图，但仍属于测试时支持例拟合，论文若采用该组件，应写“冻结编码器、无额外跨任务训练”，不能笼统声称完全无优化。

## 2 领域演进及其真正变化

### 2.1 从学习类间迁移到保留稠密对应

早期工作已经形成两种选择：将参考压缩成少量原型，或保留参考与查询之间的稠密关系。前者简单，但会合并同一目标的多种外观；后者容量更强，但必须判断哪些对应可靠以及如何形成完整区域。

|代表工作|关键设计|对当前问题的启示|
|---|---|---|
|[OSLSM 2017](https://arxiv.org/abs/1709.03410)|由支持例条件化查询分割器|单参考分割本质上需要任务条件化|
|[PANet 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Wang_PANet_Few-Shot_Image_Semantic_Segmentation_With_Prototype_Alignment_ICCV_2019_paper.pdf)|前景和背景原型，训练时反向原型对齐|前景均值、背景对照和双向重建均已有先例|
|[PFENet 2020](https://i.cs.hku.hk/~hszhao/paper/2020_tpami_pfenet.pdf)|高层特征生成先验，多尺度中层特征参与学习型融合|无训练先验子模块不等于完整系统免训练；语义与空间信息可分工|
|[HSNet 2021](https://openaccess.thecvf.com/content/ICCV2021/papers/Min_Hypercorrelation_Squeeze_for_Few-Shot_Segmentation_ICCV_2021_paper.pdf)|多层4D相关体与学习型聚合|“特征好”与“关系聚合好”是两个变量|
|[CyCTR 2021](https://proceedings.neurips.cc/paper/2021/file/b8b12f949378552c21f28deff8ba8eb6-Paper.pdf)|循环一致性筛选支持像素，再做跨图注意力|对应可靠性和循环检查本身并非新问题|
|[RePRI 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Boudiaf_Few-Shot_Segmentation_Without_Meta-Learning_A_Good_Transductive_Inference_Is_All_CVPR_2021_paper.html)|支持监督、query熵和前景比例正则共同做传导推理|前景面积校准早已被识别为瓶颈；论文使用基类监督与逐任务优化，不能直接当作纯自监督冻结基线|

因此，本仓库旧“只差目标范围”的观察有文献基础，但不是普遍定理。RePRI 的比例 oracle 说明知道面积可以有用，不能说明面积能从一张参考中被准确推断；仓库 B1 更已表明，多域排序本身也随参考改变。

### 2.2 学习型通才把任务先验存入参数

[Painter](https://arxiv.org/abs/2212.02499)将多种视觉任务统一为图像补全；[SegGPT](https://arxiv.org/abs/2304.03284)通过随机颜色映射学习按示例完成分割。它们在测试时可以只给一例，但怎样理解掩码、怎样跨图聚合和如何形成输出，已经经过大量离线任务训练。

[SegIC](https://arxiv.org/html/2311.14671v3)将冻结视觉特征的对应关系转成几何、视觉及元信息指令，再训练解码器。[SINE](https://arxiv.org/html/2410.04842v1)显式区分身份、实例与语义输出。[SANSA](https://arxiv.org/html/2505.21795)利用 SAM2 的记忆和解码结构，同时监督训练适配器。这些工作说明强骨干之外，任务读取方式仍然重要；其性能不能全部归于冻结骨干。

这种路线为本仓库提供一个能力参照：如果一个描述子加简单监督头可以读出目标，而手工准则不能，缺口可能是可迁移决策；如果两者都失败，才进一步检查表示或描述子。监督探针的作用是区分解释，不能冒充最终免训练方法。

### 2.3 冻结模型组合与单骨干方法

PerSAM、Matcher、GF-SAM 等方法利用基础模型已有的语义或形状能力，将参考信息转成查询提示或掩码选择。SAM 路线带有掩码监督形成的空间先验；使用自监督 DINO 匹配并不会抹去这部分监督。最近的单 DINOv3 路线进一步把对应与分割读取放到同一骨干上，成为本仓库最直接的竞争范围。

[DINOv3](https://arxiv.org/html/2508.10104v1)的密集表征是共享基础，而非一个完整分割方法。其预训练中的 Gram anchoring 用于保持密集特征质量，与FSSDINO在推理中用支持特征Gram矩阵评分不是同一操作。

### 2.4 概念推理正在改变系统层比较

[SAM3](https://proceedings.iclr.cc/paper_files/paper/2026/file/e0982cbc81401df3430ee1ff780dc7a2-Paper-Conference.pdf)支持概念分割，但其标准 exemplar 接口是同一输入图中的框，不天然等于“另一张参考图加完整 mask”。[CG-ICS](https://media.eventhosts.cc/Conferences/ECCV2026/pdfs/9601.pdf)通过参考与查询拼图建立视觉提示，同时让 Qwen3-VL 从参考推断概念，借助 SAM3 评分与搜索后预测。它不要求用户额外提供类别名，但引入了语言模型先验、多模型和多轮推理。

这类方法值得列为不同资源条件下的系统参照；不能用其结果证明单 DINOv3 已落后于一个同预算算法。反过来，若论文讨论整个 ICS 领域，也不宜只讨论早期 SAM1 组合。参考变化的稳定性已经是公开研究问题，后续贡献应落在具体机制和条件上。

## 3 直接竞争方法与可复现边界

本节区分原论文的方法契约、作者报告和本仓库实测。相同的1-shot标签不足以保证骨干、分辨率、语义任务、后处理和指标分母相同。

|方法及版本|参考信息如何形成查询掩码|训练和观察条件|对本仓库的直接意义|
|---|---|---|---|
|[PerSAM 2023](https://arxiv.org/abs/2305.03048)|参考前景相似度产生点提示，语义引导SAM并级联细化|SAM预训练掩码先验；PerSAM无梯度，PerSAM-F另拟合两个尺度权重|适合个性化目标，尺度选择不天然等于任意语义或部件任务|
|[Matcher 2023](https://arxiv.org/html/2305.13310)|双向匹配过滤、分层点提示、SAM候选筛选与合并|DINOv2-L加SAM-H，无新增参数训练|完整参考Mask通过反向匹配提供负证据，不能当作只用FG均值的弱基线|
|[GF-SAM 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/3a2ef31a1e45908901adc0ca853a8faf-Paper-Conference.pdf)|FG/BG对比选点，点与Mask构图，再分组及排除过覆盖|DINOv2加SAM，无额外训练|图结构建立在SAM候选关系上，与DINO token图不是相同条件|
|[FSSDINO 2026年2月](https://arxiv.org/html/2602.07550v1)|含背景的每类多原型，加支持Gram能量，再聚合分类|原论文DINOv3-B、512输入，无SAM和测试时更新|直接且简单的冻结特征基线；重点揭示层选择能力与可部署选择器的差距|
|[INSID3 2026年3月](https://arxiv.org/html/2603.28480v1)|原始特征组织query区域，去位置特征跨图匹配，选择种子并聚合|DINOv3-L、1024；论文结果含CRF|完整单骨干直接对照；跨图和图内使用不同特征空间|
|[FROST 2026年6月](https://arxiv.org/html/2606.31136v1)|类内白化后估计FG/BG非参数密度比，支持留一选带宽，再传播|DINOv3-L、1024；含水平翻转观测，无梯度更新|直接检验密度与校准路线，原论文重点含遥感及多参考；不能称通用1-shot最优|
|[REBASE 2026年7月首发及10月v2](https://arxiv.org/html/2607.09082v2)|参考BG低秩子空间投影，同时修正support/query，再产生SAM点与密集提示|主实验DINOv2-L加SAM-H，另有DINOv3实验|背景消除的新颖性必须面对它；仅换为DINOv3并不构成新机制|
|[FoRIS 2026年9月](https://arxiv.org/abs/2609.03384)|前景净化、定位、整合，利用FG/BG、投票、区域与语义分歧|冻结DINOv3-L、1024，完整评估含CRF|当前主竞争者；作者八域均值58.1相对INSID3的53.6，不能替代本地十域匹配比较|

FSSDINO揭示的重点尤其相关：query GT选层oracle可以明显提高成绩，支持自重建和反向一致性等选择器却没有可靠提取出该空间。这与本地“oracle有余量，合法读出仍缺失”相呼应。FROST重跑的FSSDINO对照使用DINOv3-L/1024；应与FSSDINO原论文B/512结果分列，不能拼成一条未经说明的基线。

FROST的核心分数是按各类锚点数归一后的核密度对数比：

\[
\ell(q)=\log\left(\frac1{n_F}\sum_{a\in F}e^{\langle q,a\rangle/\sigma}\right)
-\log\left(\frac1{n_B}\sum_{b\in B}e^{\langle q,b\rangle/\sigma}\right).
\]

它保留多模式参考分布，与单均值原型有实质差异。但过零决策的等先验解释并不推出IoU最优，也不会自动解决参考未覆盖的query模式。作者明确报告六个自然图及跨域基准的1-shot平均仍落后最强对照2.1pp，而10-shot有优势。因此“密度估计必然更适合所有单参考任务”并非现有证据支持的结论。[FROST原文](https://arxiv.org/html/2606.31136v1)。

公开实现还有三项直接影响复现的细节：

- **INSID3没有硬性空间连通聚类约束。** 官方[聚类实现](https://github.com/visinf/INSID3/blob/0c165a10cf52ab91f335883d06260de86854adbe/utils/clustering.py)按特征距离凝聚聚类；空间连贯是特征产生的性质，不能将其描述为显式连通区域算法。
- **FROST需固定论文或代码口径。** 已核验的[model.py](https://github.com/jhpark-ai/FROST/blob/b9ece69d7495a698c298e7cc3d16efacd4497a43/frost/model.py#L275)与[density.py](https://github.com/jhpark-ai/FROST/blob/b9ece69d7495a698c298e7cc3d16efacd4497a43/frost/density.py#L90)在传播特征、额外分数核、空间距离和LOO类别权重上，与论文公式存在差异。这是复现口径的不确定性，不是其论文成绩无效的证据。
- **REBASE机制公开但代码尚未发布。** 本次核验的[官方仓库](https://github.com/ai-and-lab/rebase)只有README和图，并标注代码待发布；v1/v2背景阈值与README/论文分数也有差异。后续若重现，应固定版本并标为自实现，不能宣称已经跑通官方代码。

相邻工作另有不同契约：[HERA](https://openreview.net/forum?id=BBNrtWVMSG)包含测试时参数适应；[No Time to Train](https://arxiv.org/html/2507.02798v4)主要处理参考驱动实例分割，其COCO主结果为多参考AP；[Iris](https://arxiv.org/html/2503.19359v1)是训练的3D医学上下文模型。它们可提供机制参照，不能直接放进单图二值mIoU同预算表。

## 4 一个连接文献与本地结果的分析框架

以下分解是本文的分析工具，不是某篇论文的算法，也不是已经获得新实验支持的理论结论。

\[
(I_s,M_s,I_q)\longrightarrow
\underbrace{\text{任务与粒度}}_{z}\longrightarrow
\underbrace{\text{参考到查询证据}}_{s,e}\longrightarrow
\underbrace{\text{区域范围和像素位置}}_{A,G}\longrightarrow\widehat M_q.
\]

这些环节相互耦合，但拆开后能避免把一种 oracle 的余量误认为另一种机制已经可实现。

### 4.1 一个例子提供的是任务证据

同一参考中一只狗的掩码，可以与“这只狗”“所有狗”或更宽泛的视觉类别兼容。在给定基准中，协议规定了该分割哪种对象，因此可以客观评分；开放交互中，意图未必由一个例子唯一确定。SINE 通过保留不同粒度输出处理歧义，不能据此推导任何单参考输入都无法识别。[SINE 原文](https://arxiv.org/html/2410.04842v1)。

仓库6200任务的闭集检查没有发现完整输入的精确任务别名，这排除了那批数据上的一种解释；它没有证明开放世界的所有概念均唯一。PACO 的部件与整物体错误也不能只靠更强类别语义解决：选中正确对象后，仍需保留参考掩码指定的部分。

### 4.2 条件前景比例与参考解释度应当分开

仓库 IND0 使用参考 token 的软覆盖标签 \(y_j\) 和正核权重 \(k_{ij}\)：

\[
D_F(i)=\sum_j k_{ij}y_j,\quad
D_B(i)=\sum_j k_{ij}(1-y_j),\quad
c_i=\frac{D_F(i)}{D_F(i)+D_B(i)},\quad
E_i=D_F(i)+D_B(i).
\]

\(c_i\)描述当前参考证据内部更像前景还是背景；\(E_i\)描述总匹配强度。两者不是同一个量：很陌生的 query token 仍可能获得接近1的比值，因为极弱背景响应比极弱前景响应还小。反过来，低总匹配可能来自参考未覆盖的真正目标外观，不能自动赋为背景。定义和实现依据见[独立基座计划](INDEPENDENT_BASE_PLAN_20261012.md)第3节。

这也解释为何“缺少前景证据”不能等同于“具有背景证据”。参考背景是当前参考图中的负例分布，并不穷尽查询图所有非目标。参考前景同样没有覆盖目标类的全部形态。这是有限覆盖问题，不需要先假设模型发生了类别混淆。

核的总和还隐含参考前景比例。令 \(n_F=\sum_jy_j\)、\(n_B=\sum_j(1-y_j)\)，\(d_F=D_F/n_F\)、\(d_B=D_B/n_B\)，则在两者均非零时：

\[
c_i=\frac{\pi_s d_F(i)}{\pi_s d_F(i)+(1-\pi_s)d_B(i)},\qquad
\pi_s=\frac{n_F}{n_F+n_B}.
\]

这是代数恒等式，不是对真实 query 后验的证明。它说明支持图占比、类条件相似度与 query 前景先验可能混在一个分数里。简单改成平衡原型不能自动解决问题，因为真实 query 占比仍未知；仓库已失败的平衡或角色构造也不会因这个解释重新成为未测方向。

此外，\(E\)随特征中心、温度、归一化和参考构成而变，不能未经校准就称为“正确概率”。B1增加参考时还改变联合中心和角色质量，因此必须通过干预隔离信息来源。

### 4.3 降低锚定与压低前景是不同操作

对 query 图拉普拉斯矩阵 \(L\)，一种常见推理为：

\[
\min_f\ \frac12\sum_i a_i(f_i-s_i)^2+\frac\lambda2 f^\top Lf,
\qquad
(\operatorname{diag}a+\lambda L)f=\operatorname{diag}(a)s.
\]

将不可靠位置的 \(s_i\)乘小，改变了它应取的标签方向；将 \(a_i\)减小，改变的是对原判断的信任程度，让邻接证据有更大作用。R1的 BG 和 UN 正是针对这一区别的对照。图传播和可靠度加权各自都有历史先例；本地需要证明的是特定参考解释度的空间位置是否额外有用，而非求解器是否收敛。[R1计划](SINGLE_REFERENCE_NEXT_PLAN_20261012.md)、[经典谐波方法](https://mlg.eng.cam.ac.uk/pub/pdf/ZhuGhaLaf03a.pdf)、[UNICL-SAM](https://openaccess.thecvf.com/content/CVPR2025/html/Sheng_UNICL-SAM_Uncertainty-Driven_In-Context_Segmentation_with_Part_Prototype_Discovery_CVPR_2025_paper.html)。

同分布置换的 PERM 控制很关键：UN 超过未加权图，只能说明修改有用；UN 同时超过 PERM，才更直接支持权重放置位置的价值。即便如此，结论仍仅覆盖已经出现正证据的域与当前图结构。

### 4.4 分割增益取决于纠错收支

对一个固定 query，设真前景总数 \(T\)、当前真阳性 \(TP\)、假阳性 \(FP\)，则 \(J=TP/(T+FP)\)。一次修改产生 \(\Delta TP,\Delta FP\)，在分母有效时：

\[
J'>J\quad\Longleftrightarrow\quad\Delta TP>J\,\Delta FP.
\]

因此“恢复更多目标像素”本身不足以证明改善。恢复同时增加误报时，必须看两者比例；删除预测时，也要计入被误删的真目标。该式仅用于单例或同一池化单元，不能直接把全数据像素合计套入类等权 mIoU。

它给仓库的拒识和恢复负结果一个更准确的解释：很多恢复构造确实增加 TP，但也撤销了 S 的有效排除。下一次恢复若没有新的可区分证据，就不能仅凭召回率变化继续推进。依据见[结果账本](RESULTS.md)的 anchor6200、veto_reversal 和 negative_exposure。

### 4.5 前景范围与块内位置有不同上限

一块16×16区域应分出多少像素，是范围问题；这些像素放在哪，是定位问题。R2固定每块前景像素数，只允许重新排序位置，因此不可能恢复整块漏检，也不能撤销整块误认。其固定面积 oracle 可以估计这类修正的最大收益，但不约束可改变块面积的方法。

同理，A6的硬区域并集 oracle 衡量指定区域划分的表达容量；阈值 oracle 衡量固定连续场可实现的排序质量；监督描述子探针衡量指定输入可被指定模型读出的能力。三者各回答一个问题，均不等于冻结 DINOv3 或单参考任务的信息论上界。

## 6 跨域失效应如何理解

|现象|最可能需要区分的问题|现有证据限制了什么|
|---|---|---|
|COCO或LVIS的小目标误报|参考外观覆盖、负例角色、目标范围|更高分辨率或恢复候选可能同时放回FP，必须比较同预算控制|
|PACO或PASCAL部件变成整物体|概念粒度与部件范围|更强物体原型或跨区域传播可能扩大错误目标|
|SUIM特定类别差距大|区域身份及背景分布变化|已有类归因不能授权移除难类或改正式分母|
|ISIC小病灶外溢|全图前景范围与背景对比|固定块面积的几何oracle也补不齐当前差距|
|Fundus细血管|软覆盖、块内位置、连续结构|局部像素证据有用，但不意味着其增益能迁移到完整物体|
|道路断裂或过度扩张|局部几何与跨区域连接正确性|图平滑或CRF不是通用补救，拓扑正确也不能代替语义正确|

FoRIS附录已经将细结构作为压力测试，并展示层与分辨率敏感性。因此“末层特征不适合细结构”应作为已有问题背景，而非新发现。其论文DeepGlobe数字与本地缓存队列数字明显不同，不能直接跨表计算改进。[FoRIS附录F](https://arxiv.org/html/2609.03384v1)。

这些域差异也提醒我们：单一大幅正域可能抬高宏平均。Fundus的+17.790pp有研究价值，但它不能抵消仓库目标要求下ISIC仍未过门槛的事实。

## 7 哪些研究问题最值得继续

以下是由现有证据导出的研究优先级，属于文献研究结论；实际执行继续以[当前计划](PLAN.md)及所属会话为准。没有在本次研究中启动新的实验。

### 7.1 先明确可靠度位置何时真正有用

动机是R1在LVIS、ISIC对G0和PERM均有正证据，而PACO、SUIM没有。这比“图传播能提高平均分”更具体。值得建立的主张是：在何种合法可观察条件下，参考解释度应控制判断强度，而不是直接控制前景标签。

下一项判别应使用已保存输出，区分原分数错误且低解释度的位置，是否通过图连接到语义正确的高解释度证据；同时观察跨部件边界传播造成的损失。若受益必须依赖GT标出的区域或域标签，仍未得到合法通用准则；若可由参考或无标签query统计稳定识别，才有构建统一规则的依据。它需要与已有G0/PERM及FROST、学习型不确定性方法区分，不能再次只更换图名字。

### 7.2 用参考干预查明新增信息来自哪里

B1是最直接反驳“所有排序已饱和”的证据。下一科学问题是增加参考究竟补了前景外观、背景排除、中心估计，还是核质量。现有E2建议的价值正是固定其他量，分离这些因素，并用重复同一参考与仅改变中心作控制。

若只有新增真实前景标注有效，应承认当前单参考观察有覆盖缺口，不能把query自生成掩码当成等价新增监督。若改善主要来自中心或角色估计，则可在单参考条件下研究相应估计是否可实现。若仅增加背景就能保持收益，才有理由针对背景覆盖进一步构造方法。这里多参考仍是诊断工具，不改变最终单参考目标。

### 7.3 测区域描述子的可提取性

A6仍留有相对同档FoRIS的区域容量，但旧70门槛跳过了监督读出。E1值得回答：固定已有区域与自然描述子，一个简单监督模型是否能提取收益，并在照片隔离和留一域条件下保留它。

正结果只能证明该输入存在可学习信号，随后仍需寻找符合目标契约的决策方式；只在域内有效则提示学习了域先验；阴性只约束所测描述子与模型，不升级为DINO或单参考任务上界。区域选择已有INSID3，多原型和语义读出已有FSSDINO等直接邻居，新贡献应是可迁移判别证据，而非重复计算一个oracle。

### 7.4 将细结构几何作为有边界的贡献

R2在Fundus有正组件证据，适合保留为“参考可提供像素定位信息”的实测结果。它不能承担修复所有语义范围错误的任务。若未来使用同一组件，须保留同块面积恒等、标签置换、固定强度和零修正对照；这些都是现有实验已采用的对照，不需要再扩展无目的参数网格。

在当前零新增编码条件下，应先使用现有证据作决策；多层或新增高分辨率观察属于另一种计算条件。FoRIS已有相关公开结果，本仓库也有真实窗口记录。以后若改变观察预算，应明确是哪条未解证据支持，且重新匹配同预算强控制。

### 7.5 不应再次作为新路线提出的内容

|表面上的新方向|已有最近邻或本地反证|真正尚待证明的部分|
|---|---|---|
|前景减背景或背景子空间去除|PANet、FoRIS、REBASE；本地多个背景构造失败|新的负证据来源或保护目标语义的可验证条件|
|基于不确定性的图传播|经典谐波推理、UNICL-SAM；本地A7/R1|无额外训练时可靠度的可迁移估计与独立收益|
|query区域聚类后选目标|INSID3；本地A6|可靠的区域选择和范围读取|
|循环一致性、双向验证|PANet、CyCTR、SegIC；本地A2存在耦合|一致性何时对应任务正确，而非错误自洽|
|目标面积或阈值校准|RePRI；本地B1否定普遍排序饱和|合法面积信息从哪里来，哪些域仍需改善排序|
|给旧组件加门控或重命名|本地B3、B4及多个固定组合失败|新证据改变了哪一个失败前提|

## 8 公平评估应回答哪些问题

### 8.1 分层组织基线

第一层是完全相同输入、特征和计算条件下的机制对照：完整FoRIS、精确MEAN、现有独立基线，以及候选自身对应的简单控制。MEAN在本仓库是对FoRIS场做秩修正和图平滑的具体算法，不是泛称的前景均值原型，也不是本文发现的一篇外部基线。[MEAN源码](../../src/ics/methods/mean_control.py)。

第二层是同类方法：INSID3、FSSDINO、FROST等。在声称相同骨干优势前，统一模型大小、层、输入大小、参考Mask缩放、原图恢复与后处理；保留官方规则和确有必要的适配说明。

第三层是额外先验或训练的参照：Matcher、GF-SAM、REBASE、SegGPT、SINE、SANSA、CG-ICS。它们帮助理解系统能力边界，但应显式列出SAM、额外训练、语言模型或多次调用，不能与单骨干结果混成不加说明的排名。

这不是要求立刻重跑所有方法。已有候选尚未满足开发目标时，文献契约核查与必要的机制对照更有价值；有希望的候选再补足支撑具体论文主张的匹配比较。

### 8.2 固定指标的统计单位

对类槽 \(c\)，像素池化IoU为：

\[
\operatorname{IoU}_c=\frac{\sum_{e\in c}I_e}{\sum_{e\in c}U_e},
\qquad
\operatorname{mIoU}=\frac1{|\mathcal C|}\sum_{c\in\mathcal C}\operatorname{IoU}_c.
\]

它不等于 \(\frac1N\sum_e I_e/U_e\)。先对fold求均值再平均，也不总等于全部观察槽等权，尤其各fold槽覆盖不同或固定槽包含缺失类时。本地旧6200、x1012与论文官方表必须分别标明契约。

原图、CLI1024、token级指标也不是一个测量。原图Mask恢复、ignore像素和掩码插值会改变分母及边界。iSAID中R2的全图块面积恒等不必推出排除ignore后的有效面积恒等；参考完整标签不授权推理读取query的ignore/GT图。[当前评估边界](GAPS.md)、[R2计划](SINGLE_REFERENCE_NEXT_PLAN_20261012.md)。

### 8.3 把参考敏感性与参考数量分开

固定query，轮流使用不同单参考，并报告均值、绝对标准差与低分位性能，仍是在测单参考稳定性；把多个参考结果融合后报告最佳或平均掩码，就改变了推理输入或计算预算。按query GT挑参考更不属于合法单参考评测。

CG-ICS已经专门研究换参考的稳定性；其标准表与多参考选择下的稳定性表使用不同查询抽样，不能混用数字。CV等于标准差除以均值，均值上升本身也会降低CV，因此不能只看CV断言绝对波动降低。这是统计解释，不是对该论文性能的反证。[CG-ICS原文](https://media.eventhosts.cc/Conferences/ECCV2026/pdfs/9601.pdf)。

### 8.4 保留确认的真实边界

同照片新配对测试支持的是配对泛化；新照片、新类别和新域各是更强且不同的外推。C1现已曝光，不能重复作为盲测。照片参与多个配对时，逐episode独立bootstrap会忽视相关性，至少需要按query照片配对重采样并重新聚合指标；当前R1/R2/R3已这样处理，但其区间仍是当前支持例和照片池条件下的区间。

支持例选择的方差与算法间差值不应混为一个统计量。如果结论依赖“换哪张参考都更稳”，需显式设计参考重采样层级；不应从一次固定support的配对区间推出该性质。

### 8.5 成本应从同一入口计量

完整代价可拆为参考/查询编码、匹配、聚类或求解、测试时拟合及输出恢复。缓存上的零新编码只表示本次没有再次调用编码器，不等于在线零成本。真实窗口、更多层、SAM/MLLM调用、参考内部拟合与CRF均应计入对应成本。

同预算K在旧N研究中几乎解释全部收益，说明这是科学归因所必需的比较。速度是代价报告的一部分，不替代当前准确率目标。对明确失败的候选，没有必要仅为补齐表格再开展完整性能工程。

### 8.6 广义基准的额外边界

[VFM时代的FSS基准](https://arxiv.org/abs/2401.11311)采用每类K张、合计N×K张支持图的多类适应定义，所以其“1-shot”不等于本任务的一张参考图。它也提醒下游类隔离不能证明基础模型预训练从未见过这些类别或图像；本研究没有证据指称本地发生了预训练污染。

[Support Dilution](https://arxiv.org/abs/2501.13529)显示在其学习型FSS设置中，额外或噪声参考不必单调提高效果。它与B1并不矛盾：B1只证明既定参考池和方法的平均干预效果，不能升级成任意新增参考均有用。

[FAME](https://arxiv.org/abs/2607.27856)覆盖多医学部位与模态，主要考察zero-shot和ten-shot，并单独评估目标缺席时的可靠性。它说明有目标时的定位质量与无目标时的空预测是两个性质。目标缺席可以作为以后有动机的独立压力测试，但不会替代当前十域主任务，也不是本次要求新增的基准。

## 9 论文可以怎样定位

目前可写的内容包括：强冻结特征在单参考条件下的能力与跨域边界；匹配、范围和像素定位的可区分误差；参考干预对排序和校准的影响；可靠度放置与细结构定位的有限正证据；有强控制的失败消融。这些证据可支撑研究动机和机制分析。

当前尚不能写成“统一十域优于FoRIS/强控的新免训练方法”，也不能写成“排序已经饱和”“任何区域方法无效”或“背景缺失是共同根因”。R3提供更接近目标的开发候选，但还欠同条件强控优势和适当独立确认。

如果未来正证据持续成立，较有辨识度的主张应具体到：**单参考解释度何时应作为证据可靠性、怎样保持目标范围与像素定位的职责，以及这种处理为何在未见任务上保住已有语义能力。** 新颖性需要同时面对区域选择、密度比较、背景消除和学习型不确定性方法，而不是只与FoRIS某个删减版比较。这是有待建立的主张，不是本次研究已经证明的方法。
