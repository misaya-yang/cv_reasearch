## 尚未成立的候选方案

工作表述：**用可加的局部前景量，驱动一致的掩码决策和按需重新观察。** 不主张「加 verifier」或「加不确定性」本身是贡献。

设互不重叠的区域为 A_j，面积为 a_j，真实前景量为 μ_j。任意由这些区域组成的候选 C 满足

\[
J(C)=\frac{\mu(C)}{|C|+\mu(C^c)}.
\]

拟议视觉模块预测区域的前景比例和区间，而不是让每个候选独立猜整体 IoU。同一局部观测被所有覆盖它的候选复用。固定候选的分歧区域决定下一次 crop / 较高分辨率编码应观察哪里。

关键动机：一个只看独立候选 crop 的质量预测器，在候选外添加同类对象时输入不变，但完整 query 的 IoU 会变化。因此 crop 更适合估计局部前景量，而整体质量由全图共享的量重建。这只针对确实没有候选外信息的局部读出，不能据此声称全图上下文化特征没有外部信息。

**已经推导和实现的数学性质：**

1. 当前 mask 的 IoU 是 J。加入一个不重叠区域 D 会改善 IoU，当且仅当 D 的真实前景比例大于 J/(1+J)；删除内部区域的条件相反。这是基本代数关系，不是独创 IoU 理论。
2. 如果同时有效的区间 L_j≤μ_j≤U_j 成立，则

\[
J_{lo}(C)=\frac{L(C)}{|C|+U(C^c)},\qquad
J_{hi}(C)=\frac{U(C)}{|C|+L(C^c)}.
\]

选择最大下界的候选 b，若 max_C J_hi(C)-J_lo(b)≤ε，则在该候选集合内的真实逐图 IoU regret≤ε。没有假设像素独立；但**必须先有同时有效的区间**，不能把模型分数直接当区间。
3. 令总前景量 G>0，局部量估计的总绝对误差为 e，则统一的 IoU 估计误差不超过 e/G，plug-in 最优选择的 regret 不超过 2e/G。小前景对质量估计误差更敏感。
4. 不限制形状、允许任意区域并集时，最优下界是一个非负线性分式问题，可排序前缀求解，O(k log k)。一般线性分式优化不是本项目首创。实际需要形状限制时应使用有限候选版本。
5. k 个层次树区域形成的共同细分最多 k+1 个原子；再加一个任意基线 mask 最多翻倍。原子可能不连通，其裁剪成本不能自动视为相同。

实现：`mass_decision.py`。检查包括 2000 组区间、2000 组停止界、1944 个增量条件及 100 组全部 64 种区域并集枚举，全部通过，回执为 `results/theory_self_check.json`。这些检查确认实现与推导一致，不确认新颖性或真实视觉收益。

`next_atom` 使用改变当前候选和挑战者差距的区间敏感度启发式；没有最优观测策略的理论保证。当前标准覆盖的是目标确实存在的 episode。没有完成 absent-target 处理和跨域校准。

## 理想观测实验 必须保留 oracle 标记

`oracle_observation_study.py` 在四折各 300 例运行。候选是前 12 个 F1 树节点加 INSID3 输出；每次额外观测直接揭示一个原子的**真实 query 前景量**。它是信息价值／控制器诊断，不是模型性能。

主要表采用平均逐图 IoU，与理论的目标一致：

| 设置 | 平均逐图 IoU |
|---|---:|
| INSID3 | 57.53 |
| F1 初始选择 | 56.11 |
| 1 次针对性的理想观测 | 59.97 |
| 2 次针对性的理想观测 | 63.20 |
| 4 次针对性的理想观测 | 67.95 |
| 4 次最大面积优先理想观测 | 66.98 |
| 4 次随机理想观测 | 60.52 |
| 8 次针对性的理想观测 | 70.46 |
| 该候选集逐图 oracle | 70.87 |

针对性策略相对最大面积优先在 4 次观测时只多约 0.97 点，不能省略这个强简单对照。

初始区间为完整 [0,a_j]。4 次观测仅 1/1200 例达到 ε=0.01 的停止条件，12 次达到约 82.3%；因此不能宣称已有便宜的提前停止能力。

JSON 也包含 class-mIoU。8 次策略的 class-mIoU 会超过“逐图最优候选”的 class-mIoU，这不表示超过 oracle：逐图 IoU 最大化不等于类别汇总 IoU 最大化。不要混用两个目标或把后一列叫全局上界。

| 方法 | class-mIoU | 平均逐图 IoU |
|---|---:|---:|
| F1 | 57.22 | 56.33 |

## 前作核查入口

以下是已查阅的主要直接来源，不把“没有检索到完全相同标题”当作新颖性证明：

- [INSID3 原文](https://arxiv.org/html/2603.28480v1)：单冻结 DINOv3、聚类与种子扩展；正式 CVPR2026 oral 已核实。
- [FROST](https://arxiv.org/html/2606.31136v1)：密度比、支持集带宽与特征处理；不能把普通非参数分类新命名为创新。
- [REBASE](https://arxiv.org/html/2607.09082v1)：参考背景子空间消除与 SAM 提示。
- [FoRIS](https://arxiv.org/html/2609.03384v1)：前景净化、定位、整合；论文报告 COCO 60.9 对 INSID3 57.6，需同协议复现后才能与本机数字比较。
- [FSSDINO](https://arxiv.org/html/2602.07550v1)：已报告内部层选择 oracle 与可用选择器之间的差距。
- [RePRI](https://arxiv.org/abs/2012.06166)：query 统计、熵与区域比例的 transductive 推断已有直接先例。
- [Nowozin 2014 IoU 决策](https://openaccess.thecvf.com/content_cvpr_2014/papers/Nowozin_Optimal_Decisions_from_2014_CVPR_paper.pdf) 与 [Ahmed 等 2015](https://openaccess.thecvf.com/content_iccv_2015/papers/Ahmed_Optimizing_Expected_Intersection-Over-Union_ICCV_2015_paper.pdf)：IoU 决策理论与期望之比／比之期望的区别。
- [Tree Cut for Probabilistic Image Segmentation](https://arxiv.org/abs/1506.03852)：层次树与精确动态规划已有经典工作。
- [Shape of You](https://arxiv.org/abs/2603.11618)：结构对应与 fused Gromov Wasserstein 已有 CVPR2026 工作。
- [BALD SAM](https://arxiv.org/abs/2603.10828)：基于分歧的主动提示已有直接先例；本候选若继续，需要证明局部机器观测和任务决策收益的独立贡献。
- [Conformal Prediction Sets for Instance Segmentation](https://proceedings.mlr.press/v337/lu26b.html)：高 IoU 候选集合的覆盖保证已有工作。本候选的候选选择 regret 条件界与“集合内有一个好 mask”不同，但这不自动建立足够创新。
- [Denoising Vision Transformers](https://arxiv.org/abs/2401.02957)：跨视图消除位置伪影已有工作，不宜再当空白方向。
