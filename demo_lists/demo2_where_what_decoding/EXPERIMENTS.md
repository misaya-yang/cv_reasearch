## 0. 纪律

这几条来自 demo1 的教训和本项目先导实验里踩过的坑，优先级高于下面任何具体任务。

1. **先复现基线。** 任何模型接入后，第一件事是核对 argmax 的 mIoU 与论文单尺度数字是否一致（差距 ≤ 0.3）。
   不一致就先修预处理，不要往下做。
2. **全量评测。** ADE20K 用全部 2000 张验证图。先导实验已经看到，300 张子集上结论可以反号。
3. **不在测试集上调参。** 融合指数 `γ` 全项目固定为 2（见 A6）。确实需要选的超参数，
   只允许用训练集的留出部分，或者在验证集上做 2 折交叉拟合并在表里注明。
4. **每个变体都报告。** 结果 JSON 里保留所有尝试过的设置，包括变差的。
5. **对照优先于扩展。** 阶段 A 的对照没出结论之前，不要去跑更多数据集和更多模型。
6. **如实记录失败。** 某个假设被证伪就写进 `NEGATIVE_RESULTS.md`，然后停，不要换指标或换子集去"救"。

## 3. 阶段 A（10 月 2 日 – 8 日）：把对照做对

只用 ADE20K。目标是回答 H1、H2、H6、H7。

### A0. 整理代码

把 `pilots/pilot8–11` 的逻辑合并成三个正式脚本，放进 `scripts/`，复用 `mdecode/`：

| 脚本 | 作用 | 输入 → 输出 |
|---|---|---|
| `scripts/diagnose.py` | 幻觉像素率、每图幻觉类数、存在性上限、只删幻觉类上限 | 分割器 + 数据集 → JSON |
| `scripts/build_recognizer.py` | 抽区域特征、训练识别器、报告真值区域上的准确率和上限 mIoU | 编码器 + 训练集 → 识别器权重 + JSON |
| `scripts/eval_fusion.py` | 所有融合变体 + 指标规则 | 分割器 + 识别器 → JSON |

验收：新脚本复现下表数字，误差 ≤ 0.05 mIoU。

| 设置 | 目标 mIoU |
|---|---:|
| SegFormer-B5，argmax | 50.99 |
| SegFormer-B5，类区域逐像素融合 `γ=2` | 53.21 |
| SegFormer-B5，类区域整体重标 `γ=2` | 53.34 |
| Mask2Former Swin-L，argmax | 56.05 |
| Mask2Former Swin-L，类区域逐像素融合 `γ=2` | 57.87 |
| Mask2Former Swin-L，类区域整体重标 `γ=2` | 57.96 |
| Mask2Former Swin-T，查询级 `γ=2` + 类区域 `γ=2` | 55.23 |
| 真值类区域 + DINOv2-L 识别器 | 73.94 |

特征抽取必须用 `DataLoader` 多进程，并在 worker 里 `torch.set_num_threads(1)`。
先导实验里单进程版本因为线程过度订阅，抽 2 万张图用了 25 分钟；多进程版本 5 分钟。

### A1. 普通集成对照（H1）—— 最重要

`pilot11` 给出了第一版结果（`README.md` 2.2 节）：三个分割器上区域级融合都比像素级集成高 0.8 以上。
但这个对照**还不够强**：先导实验里训练的逐 patch 线性头单独只有 41.5 mIoU（3 个 epoch、518 分辨率整图压缩、单层特征），
低于文献里 DINOv2-L 线性头的数字。对照弱，结论就不可信。正式版需要做全：

- 训练同一冻结编码器的逐 patch 线性分割头，并把它做强：训练到收敛、多层特征拼接、滑窗或更高分辨率推理，
  目标是单独达到文献水平。同时报告它单独的 mIoU。
- 比较四种用法：线性头单独；与分割器做像素级乘积集成（`γ ∈ {0.25, 0.5, 1, 2, 4}`，这里允许取最好的，
  因为它是对照，要给它最有利的条件）；区域级融合（`γ=2` 固定）；两者叠加。
- 分割器：SegFormer-B5、Mask2Former Swin-T、Swin-L、UperNet ConvNeXt-L。

再加一个更强的对照：两个分割器互相做像素级集成（例如 B5 × UperNet ConvNeXt-L），
它给出"多一个同量级模型"能带来多少，作为增益的参照系。

### A2. 同骨干识别器（H2）—— 决定新颖性

识别器的特征改为分割器**自己的**骨干输出，于是推理时不需要额外骨干。

- Mask2Former：`model.model.pixel_level_module.encoder`（Swin）的最后两级特征。
- SegFormer：MiT 编码器的四级特征。
- UperNet：ConvNeXt 骨干。

风险：这些骨干在 ADE 训练集上微调过，训练集上的区域特征过于"干净"，识别器会过拟合。
所以要报告两种训练方式并对比：在训练集真值区域上训练；在训练集留出的 2000 张上训练（其余不用）。
如果两者差距很大，说明过拟合是主要问题，需要用带噪声的区域来训练（见 A3）。

### A3. 让识别器适应"不纯"的区域

上限（真值区域 73.9）与实际（预测区域 53–58）之间的差距来自区域不纯。三个互不依赖的做法，逐个测：

1. **带噪训练**：训练时对真值区域做随机腐蚀、膨胀、与相邻区域部分合并，再池化特征。
2. **用预测区域训练**：在训练集留出的 2000 张上跑分割器，用预测区域（标签取区域内真值的多数类）训练识别器。
3. **更细的区域**：连通分量；Mask2Former 的查询掩码（`pilot10` 已测，与类区域相当）；
   超像素或 SAM2 掩码与类区域求交（可选，放最后）。

每一项报告：真值区域上的准确率、预测区域上"真实类 / 幻觉类"的 AUC（先导值 0.82–0.84）、融合后的 mIoU。

### A4. 先验校正（理论预言 T3）

`THEORY.md` 3.4 节推出融合时应除以识别器的训练先验 `ρ_c`。先导实验没有做这一项。
比较 `s · r^γ` 与 `s · (r/ρ)^γ`，并按类频率三等分报告 IoU 变化。预言：差距集中在稀有类。

### A5. 校准决定融合指数（H6）

在训练集留出部分上分别估计分割器和识别器的 NLL 最优温度 `T_seg`、`T_rec`，
检验 `γ* ≈ T_seg / T_rec`。先导实验的旁证：B5 的 `T_seg = 2.0`，实测 `γ` 在 2 以上仍缓慢上升；
Mask2Former Swin-L 的 `T_seg = 1.25`，实测 `γ = 2` 最优、更大则下降。

### A6. 超参数协议

除非 A5 给出更好的无调参方案，**全项目固定 `γ = 2`**。两个结构完全不同的分割器上它都接近最优，
这本身就是论文里要报告的一个事实。不要为每个模型单独挑 `γ`。

### A7. 指标规则叠加（H7）

先导实验里在 `γ = 4` 的融合后验上叠加指标规则只有 +0.05，因为融合后验极端过置信（期望 mIoU 95）。
需要测：`γ = 2`；融合后验做温度校准后再叠加；先指标规则后融合。

## 6. 阶段 D（10 月 16 日 – 29 日）：分析

这些分析决定论文读起来是"一个技巧"还是"一个发现"。

1. **骨干变大买到的是什么。** 对同一家族的不同骨干（Mask2Former Swin-T/S/B/L，SegFormer B0–B5），
   分别报告 argmax、接同一识别器后的 mIoU、存在性上限。先导实验的线索：Swin-T 接 DINOv2-L 识别器后
   是 55.2，Swin-L 自己是 56.1。如果整个家族在接上同一识别器后收敛到相近的数字，
   结论就是"大骨干主要买到了识别能力，定位能力差别很小"。
2. **幻觉类的类型。** 把幻觉类按与图中真实类的混淆关系分成两类：近义混淆（扶手椅 / 椅子）与场景不一致（卧室里的天空）。
   分别统计占比和各自被识别器纠正的比例。
3. **标注约定的份额。** 存在性上限里有多少是"猜中标注者的选择"？
   做法：把训练集混淆矩阵里最常互相混淆的类对合并，重新计算 mIoU 和上限。
4. **逐类增益。** 按类频率、按平均区域面积分组。
5. **失败案例。** 识别器把真实类否决掉的情况：是小物体、遮挡，还是区域不纯。
6. **代价。** 额外推理时间与参数量；与"直接换更大骨干重训"的对比表。

## 9. 风险

| 风险 | 应对 |
|---|---|
| 被认为是 FC-CLIP 一类"冻结编码器做掩码分类"的翻版 | H1、H2 的对照是答案；论文的重心放在诊断（幻觉类、两个上限）和"骨干变大买到什么"的分析上 |
| 增益只对弱模型明显 | H3；若不通过，如实把定位改成"便宜的分割器 + 冻结识别器"的性价比路线 |

| 识别器在训练集上过拟合 | A2、A3 的留出方案 |
