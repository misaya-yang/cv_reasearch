# 理论：语义分割的"在哪 × 是什么"解耦解码

本文件只写推导和它给出的可检验预言。实测数字见 `README.md`，实验安排见 `EXPERIMENTS.md`。
凡是标注"先导实测"的数字，原始 JSON 都在 `pilots/results/`。

## 0. 一句话

语义分割的标准推理是"逐像素取后验最大的类"。它把两件难度完全不同的事绑在一个决策里：

- **在哪**：把图像划分成区域。
- **是什么**：给每个区域定类。

先导实验显示，现有分割器的错误里有四到五成是"是什么"错了，而且错成了图里根本没有的类；
而一个冻结的基础编码器在区域已知时几乎能解决"是什么"。于是把两者解耦：
分割器只负责"在哪"，一个独立的识别器负责"是什么"，用贝叶斯规则在区域级合并。
另外，mIoU 是数据集级的不可分解指标，argmax 对它不是最优决策，这给出第二个（小得多的）修正。

## 1. 记号

- 图像 `I`，像素 `x`，类别 `c ∈ {1..C}`，真值标签 `y_x`。
- 分割器后验 `s_c(x)`：它对 `P(y_x = c | I)` 的估计。训练时的像素先验记为 `P_s(c)`。
- 区域 `R`：一组像素。`R(x)` 是像素 `x` 所在的区域。区域来自分割器自己的预测。
- 识别器后验 `r_c(R)`：给定区域 `R`，对"这个区域是类 `c`"的估计。训练时的区域先验记为 `ρ_c`。
- 存在性 `z_c(I) ∈ {0,1}`：类 `c` 是否出现在图像中。`y_x = c ⇒ z_c = 1`。

## 2. 三个诊断量

对一张图，`S_gt` 是真值中出现的类集合，`S_pred` 是 argmax 预测中出现的类集合。

1. **幻觉像素率** `H`：预测错误的像素中，预测类不属于 `S_gt` 的比例。
2. **"是什么"的上限**：把每个像素的 argmax 限制在 `S_gt` 内得到的 mIoU。
   它回答：如果图像级识别是完美的，同一个分割器的"在哪"能支撑到多少。
3. **"在哪"的上限**：把真值的类区域交给识别器定类得到的 mIoU。
   它回答：如果区域划分是完美的，这个识别器的"是什么"能支撑到多少。

先导实测（ADE20K）：`H` = 40%–47%；"是什么"上限 61.3（SegFormer-B5）和 69.6（Mask2Former Swin-L）；
"在哪"上限 73.9（冻结 DINOv2-L + 小分类器）。两个上限都远高于各自的 argmax（51.0 / 56.1）。
同一个冻结编码器，逐 patch 线性头单独只有 41.5，而区域已知时是 73.9：这个差距全部来自“在哪”。

这三个量只需要前向和真值，是把分割误差拆成"认错"和"画错"的基本工具。

## 3. 把识别器的证据并进来

### 3.1 两个专家的贝叶斯融合

目标是 `P(y_x = c | e_x, g_R)`：`e_x` 是分割器在像素 `x` 用到的证据，`g_R` 是识别器在区域 `R = R(x)` 用到的证据。

假设：

- **A1**：`s_c(x) ∝ P(e_x | c) · P_s(c)`，即分割器后验是其训练先验下的贝叶斯后验。
- **A2**：`r_c(R) ∝ P(g_R | c) · ρ_c`，识别器同理。
- **A3**：给定 `y_x` 时 `e_x` 与 `g_R` 条件独立。

则

```
P(y_x = c | e_x, g_R)  ∝  P(e_x | c) · P(g_R | c) · P(c)
                       ∝  s_c(x) · r_c(R(x)) / ρ_c                             (规则 R)
```

（取 `P(c) = P_s(c)`，于是分割器那边的先验约掉，只剩识别器的训练先验 `ρ_c` 要除掉。）

### 3.2 为什么这不是普通的像素级集成

像素级集成用的是 `s_c(x) · d_c(x)`，其中 `d` 是另一个模型在**同一个像素**上的后验。
规则 R 用的是 `r_c(R(x))`：识别器的证据先在整个区域上汇总，再作用到区域里的每个像素。

区别在于证据量。设区域含 `n` 个 patch，每个 patch 给出一份带噪声的类别证据。
逐 patch 分类时每个像素只用到一份；区域池化后，对数似然比随 `n` 累加，噪声被平均掉。
所以区域越大、越纯，识别器越准。这正是"在哪"对"是什么"的贡献：**分割器告诉识别器该把哪些证据加在一起。**

由此得到一个可检验的预言：用同一个冻结编码器，逐 patch 线性头的像素级集成应当明显弱于区域级融合（假设 H1）。

### 3.3 融合指数由校准决定

A1、A2 要求两个后验都是校准的。现实里分割器过置信。若它的校准温度是 `T_seg`，校准后的后验是 `s^{1/T_seg}`，
识别器同理为 `r^{1/T_rec}`。代入规则 R 再整体取 `T_seg` 次幂（不改变 argmax）：

```
argmax_c  s_c(x) · ( r_c(R) / ρ_c )^γ ,      γ = T_seg / T_rec                 (规则 R_γ)
```

所以融合指数不是自由超参数：**它等于两个专家校准温度之比**，可以在训练集留出部分上估计。

先导实测的旁证：SegFormer-B5 的 `T_seg = 2.0`，`γ` 从 2 到 6 仍缓慢上升；
Mask2Former Swin-L 的 `T_seg = 1.25`，`γ = 2` 最优、更大则下降。方向一致，定量关系待检验（假设 H6）。

### 3.4 先验校正

规则 R 里的 `1/ρ_c` 在先导实验中**没有做**（只用了 `r^γ`）。它的作用是纠正识别器对常见类的偏好，
预言是：加上之后稀有类的 IoU 上升，平均类准确率上升（预言 T3）。

### 3.5 图像级的版本，以及它为什么不够

把区域取成整张图，识别器输出存在性 `π_c(I) = P(z_c = 1 | I)`。同样的推导给出

```
P(y_x = c | e_x, g_I)  ∝  s_c(x) · π_c(I) / f_c                                (规则 P)
```

`f_c` 是训练集中类 `c` 出现的图像比例。（推导：`P(y_x = c | g_I) ≈ π_c · a_c`，`P_s(c) = f_c · a_c`，
面积项 `a_c` 约掉。）它是逐图像的先验偏移校正：`π_c → 0` 时否决幻觉类，`π_c/f_c ≫ 1` 时提升漏检的稀有类。

理论上没有问题，但先导实测里它几乎没用（B5：+0.3）。原因是门控对召回率极其敏感：
错删一个真实存在的类，代价是它的全部像素。全局特征的存在性探针在阈值 0.5 时只召回 68%–78% 的存在类，
小物体尤其差。**图像级接口太粗；区域级接口把问题从"150 类里有哪些"变成"这一块是不是这个类"，容易得多。**

### 3.6 否决的阈值

对单个被预测出的类做期望分析。分割器把 `m` 个像素判给类 `c`，识别器认为它真实存在的概率是 `π`：

- 类确实在（概率 `π`）：删掉它，损失其中判对的像素。记判对比例为 `q`，损失 `q · m`。
- 类不在（概率 `1 − π`）：删掉它，这些像素转给次优类。记其中变对的比例为 `u`，收益 `u · m`。

删掉更优当且仅当 `π < u / (u + q)`。`q`、`u` 可以在训练留出集上直接统计，阈值不需要在测试集上调。
软融合（规则 R_γ）不需要阈值，先导实测里也更好（B5：否决 +1.7，软融合 +2.4）。

### 3.7 这个框架对"骨干变大"的预言

如果大骨干主要提升"是什么"、对"在哪"提升很小，那么同一家族的不同骨干在接上同一个强识别器之后，
mIoU 应当收敛。先导实测：Mask2Former Swin-T 接 DINOv2-L 识别器后是 55.2，而 Swin-L 自己是 56.1；
Swin-L 接同一识别器后是 58.0。小骨干的增益（+7.2）远大于大骨干（+1.9）。

反过来说，增益的大小由"识别器相对于分割器自身识别能力的强弱"决定（预言 T2）。
要让最强的分割器也受益，识别器必须比它的骨干更强，或者必须从同一骨干里读出分割头没用上的信息（假设 H2）。

## 4. 数据集级指标的最优决策

### 4.1 定理

把测试集所有像素汇总。对一个（可随机化的）决策规则 `h`，定义

```
A_c(h) = E[ 1(h = c) · η_c ]      （真阳性质量）
P_c(h) = E[ 1(h = c) ]            （预测质量）
G_c    = E[ η_c ]                 （真值质量，与 h 无关）
mIoU(h) = (1/C) Σ_c  A_c / (G_c + P_c − A_c)
```

其中 `η_c(x) = P(y_x = c | x)`。

**定理 1。** 设 `h*` 最大化 mIoU，`J_c`、`U_c` 是它对应的各类 IoU 和并集质量。则几乎处处有

```
h*(x) ∈ argmax_c  [ (1 + J_c) · η_c(x) − J_c ] / U_c                           (规则 M)
```

**证明。** `h ↦ (A, P)` 是线性的，可行集是凸集。每一项 `A/(G + P − A)` 可微，所以最优点满足一阶条件：
对任意 `h`，`Σ_c [ ∂_A · (A_c(h) − A_c(h*)) + ∂_P · (P_c(h) − P_c(h*)) ] ≤ 0`。
而 `∂_A = (U + A)/U² = (1 + J)/U`，`∂_P = −A/U² = −J/U`。于是 `h*` 最大化线性泛函
`E[ Σ_c 1(h = c) · ( (1 + J_c) η_c − J_c ) / U_c ]`，逐点取最大即得。∎

这是必要条件。mIoU 是若干线性分式之和，不是凹函数，可能有多个驻点；
算法从 argmax 出发做带保护的上升，保证期望意义下不比 argmax 差。

### 4.2 这个规则在做什么

- 分数为正当且仅当 `η_c > J_c / (1 + J_c)`：每个类有自己的 IoU 阈值，IoU 低的类阈值低。
- 多个类分数为正时按 `1/U_c` 竞争：并集小的稀有类胜出。
- 所有类分数都为负时，像素被分给 `U_c` 最大的类：没把握的像素倒进大类，因为大类多一个假阳性的代价最小。

这也是对 mIoU 本身的一个刻画：它奖励"稀有类多报、不确定的往大类里倒"。

### 4.3 其他指标

同一推导适用于任何由 `(A_c, P_c, G_c)` 决定的指标，规则都是 `argmax_c α_c η_c − β_c`：

| 指标 | `α_c` | `β_c` | 说明 |
|---|---|---|---|
| 像素准确率 | 1 | 0 | 就是 argmax |
| 平均类准确率 | `1/G_c` | 0 | 除以先验 |
| mDice | `2/(G_c + P_c)` | `D_c/(G_c + P_c)` | 阈值 `D_c/2` |
| mIoU | `(1 + J_c)/U_c` | `J_c/U_c` | 阈值 `J_c/(1 + J_c)` |
| 频率加权 IoU | `G_c (1 + J_c)/U_c` | `G_c J_c/U_c` | |

`mdecode/core.py` 实现了这张表，`tests/test_core.py` 在合成数据上验证了局部最优性。

### 4.4 无标签的直推估计

规则 M 需要 `J_c`、`U_c`，而它们取决于决策本身。在测试集上用模型自己的概率 `p` 代替 `η`：

```
A_c = Σ_x 1(h_x = c) · p_c(x),   P_c = Σ_x 1(h_x = c),   G_c = Σ_x p_c(x)
```

交替"按当前参数解码 → 重新统计"，先导实测 2–3 轮收敛。期望 mIoU 不需要标签就能算，
所以只接受让它上升的更新。

统计量是在整个测试集上累计的，比值的期望与期望的比值之差是 `O(1/n)`，所以数据集级的规则是简单的闭式。
逐图像的版本（RankSEG）要处理小样本下的分布，算法复杂得多，而且优化的是另一个指标：
先导实测里它让标准的数据集级 mIoU 下降（预言 T5）。

### 4.5 局限

规则 M 假设 `p ≈ η`。现实中强模型的错误是高置信的整块错误，规则对它们无能为力。
合成的校准世界里增益是 +2.8，先导实测是 +0.4 到 +1.1，且随模型变强而缩小。
评测集太小（许多类不出现）时增益为负（预言 T6）。

## 5. 合并后的解码器

```
输入：分割器后验 s(x)；冻结编码器 + 区域识别器 r(·|R)；识别器训练先验 ρ；融合指数 γ
1.  用 s 的 argmax 得到区域（类区域；对掩码分类模型还可以用查询掩码）
2.  对每个区域池化编码器特征，得到 r(·|R)
3.  p'_c(x) ∝ s_c(x) · ( r_c(R(x)) / ρ_c )^γ                    # 规则 R_γ：是什么
4.  （可选）在测试集上对 p' 做无标签不动点得到 (α, β)，输出 argmax_c α_c p'_c − β_c     # 规则 M：指标
```

分割器的权重不动；识别器是冻结编码器上的一个小分类器，训练只要几秒到几分钟。

## 6. 理论给出的可检验预言

| 编号 | 预言 | 状态 |
|---|---|---|
| T1 | "是什么"的上限随"词表大小 ÷ 每图类数"增大；Cityscapes 上接近 0 | 待测 |
| T2 | 融合增益随"识别器相对分割器自身识别能力的强弱"单调变化 | 先导实测支持：+7.2 / +2.6 / +1.9 |

任何一条被证伪，都说明这里有东西没想对，要回来改推导，而不是在实验里绕过去。

## 7. 没解决的理论问题

1. **A3 不成立时怎么办。** 当识别器和分割器共享骨干时，两份证据高度相关，朴素贝叶斯会重复计数。
   需要一个估计"识别器相对分割器的新增信息量"的方法，否则同骨干情形下的 `γ` 没有原则性的取法。
2. **区域不纯。** 规则 R 假设一个区域只有一个类。预测区域经常把两个类并在一起。
   把区域建模成类的混合（识别器输出混合比例）是自然的推广，推导和实验都还没做。
3. **标注约定的不可约部分。** "是什么"的上限里有多少是在"猜标注者的选择"，需要一个可估计的界。
4. **规则 M 的不动点**是否唯一、迭代是否单调，只有实测，没有证明。
5. **全景分割。** PQ 等价于段级别的 Dice，对应的最优发射规则是"匹配概率 × 期望 IoU > PQ_c / 2"，
   但段之间抢像素的相互作用没有处理。
