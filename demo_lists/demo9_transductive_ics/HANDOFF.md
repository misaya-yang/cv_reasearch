## 决策理论

**设定。** 一张带标注参考图 (S, m)、一张查询图 Q、冻结主干 φ。宿主方法从 (S, m, Q) 产生一个实值分数场
s: Q → R^N（per-patch 或 per-pixel），再用一条规则把它变成二值掩码。记查询像素（patch）i 的特征为 x_i，定义
似然比 r(x) = p(x | 目标) / p(x | 背景)（两个条件密度都在查询图的像素分布上取）。逐像素贝叶斯判决是

    M* = { i : log r(x_i) ≥ log((1 − π)/π) },   π = |M*| / N（查询里目标的占比，share）。   (1)

在似然比校准的模型里，外观条件分布与查询目标占比共同决定 Bayes cut。FoRIS、FROST、INSID3 的实用分数或聚类输出未被证实是这个似然比的校准变换；式 (1) 是解释模型，不会直接给出它们可用的测试时信号。

**当前方法的错配（可核对源码）。** 每一种冻结宿主都把判决水平写死，与 π 无关：
- FoRIS：把分数场 min-max 归一化后切在中点（减 0.5），即 τ = (min s + max s)/2；
- FROST：对数密度比在 0 处切。原文（arXiv 2606.31136）："a threshold the Bayes rule fixes at zero under equal
  priors"、"the equal-prior assumption keeps at τ=0"；查询占比完全不估计，参考掩码的前景比例只用于空间 gating，
  不进入逐 token 的切断水平；
- INSID3：在相似度/聚类结构上切固定的分位，参考图多数投票。
式 (1) 说正确水平应当由 π 决定；这是"水平误差"，与"排序误差"（同样水平下挑错了像素）正交。

**Oracle 诊断（不可部署）。** 若分数是查询条件似然比的单调变换，给真实 π 的阈值只改决策水平、不改排序。下表使用查询标签决定 π 或剔除误并 patch，只说明这批 DEV241、patch 级 FoRIS 输出中的误差规模，不是可部署的测试时信号（`results/decision_v1/fit/report.json`）：

| 干预 | mIoU | 相对 FoRIS | 95% 区间 |
|---|---:|---:|---|
| FoRIS 原生 | 56.996 | — | — |
| 同一分数场，按真占比切（用标签） | 66.085 | **+9.089** | [+6.146, +10.448] |
| 删掉每一个被错误包含的 patch（排序 oracle） | 76.969 | +19.973 | [+16.684, +21.797] |
| 原分辨率完整流程里的 GT-cut（241 例） | — | +10.52 | [+8.49, +12.36] |

在此前的 241 例审计中，FoRIS 争议区 AUC 为 0.664；最佳已测无标签候选 AUC 为 0.724、相对增益 +1.07 [−0.16, +2.39]，区间跨零（`results/evidence_v1/audit.json`）。标签探针把漏检目标排在误并背景之后（AUC 0.19–0.41），但这是带标签诊断。它们只约束已测信号，既没有证明当前存在可用的无标签校正，也不是冻结特征的上限。

**监督读出不证明无标注可行。** 过去四种无标签占比估计的对数面积误差为 0.62–0.66，手写规则约 +1.5–1.8；这些结果只覆盖已试规则。按基类 mask 监督拟合的 `convctx:layers` 头在 COCO-20i seed 0、CONFIRM600 的完整流程相对 FoRIS +3.54 [+1.96, +4.96]，但它修改 FoRIS 输出、使用基类标签，不是用户要求的独立方法。相同结构只看分数的训练对照是 patch 级 +2.27 [+1.59, +3.20]。没有类别名输入不等于无标注训练。

用户报告 D1 的自造样本读出在三个训练集上为 −7 到 −28；对应原始报告未在此 checkout，故本文不重算各臂。该结果只否定本次 `same`/`paste` 构造和所测协议，不否定所有无标注学习。用户也报告 COCO 拟合读出迁移到 PASCAL-Part、PACO-Part 的增益区间均跨零；这两项是未定，不是“已证明不迁移”。

**D1 可识别性假说及边界。** 假说是决策映射可能属于宿主证据结构：掩码按构造已知的成对样本也许能教会同一个读出。D1 以 `same`（同图两个窗口）和 `paste`（抠图贴到另一图）检验。`same` 与真实 episode 的场景更相似，是较容易的构造。当前用户报告指出该次构造失败；因为 raw report 不在 checkout，这里保留为用户报告而非独立复核结果。结论限制在这次构造和设定，不将其推广为“无标注决策不可学”。

**与最近工作的边界。** RePRI（CVPR 2021）已用查询前景占比先验做转导推理，但需要元训练分割网络和整批查询。当前方向是单查询；现有头不输入类别名，但训练使用基类 mask。FoRIS/FROST 的固定水平可作为这项标签诊断的比较对象；这不说明由此产生了可用的无标签水平校正。CNOS/SAM-6D 的 global-first 选择是排序/身份路线的参照，不是当前读出的贡献。实测的 +9.09/+10.52 仍是带查询标签的阈值诊断；不能当作独立方法收益。

## 读出的实现要点

- 推理输入只含相似度、排名和邻域差（16 张关系图，加第 6/12/18 层与末层的参考前景/背景边际），不含类别名；拟合使用基类 mask 监督。
- 输出加在宿主 logit 上，末层零初始化，所以未训练的读出与 FoRIS 逐位相同。
- 推理时按 FoRIS 放大自身响应的方式放大后在 0 处切，再走 FoRIS 自己的 CRF。
- 早停轮数在留出的 20% **类别**上选，然后全量重拟合。训练集只有一个类别号时，所有样本都会被留出，
  拟合退化成 1 轮：构造样本要带分组号（`decision_selfmade_pairs.py` 的 `GROUPS`）。

## 踩过的坑

- **样本量。** 40 个 episode 的配对区间半宽 3 到 9 点；DEV241 约 1.8；CONFIRM600 约 1.5。方法探针用 DEV241。
- **入口。** FoRIS 的 direct-predict 加 CRF 是 64.28，完整公开入口是 65.16（同 40 例）。对照一律用完整入口。
- **缓存要逐例核对。** INSID3 的编码器在 bfloat16 下运行，单独编码与成对编码的特征不同，足以改变聚类：
  单独编码时只有 43% 的 episode 掩码与官方实现相同，成对编码时 97–100%。
- **导入顺序。** FoRIS 和 INSID3 都有顶层包 `models`、`utils`，先导入 FoRIS。
- **文件句柄。** 同时保持几千个 `np.load` 句柄会超过 1024 的上限。
- **拟合速度。** 小读出的拟合受单核 CPU 限制，要按臂分进程。
- **缓存顺序。** 缓存按折顺序生成，只取前缀试跑会只有第 0 折。
- **守卫。** GPU 上有别的进程时守卫返回 `DEFER_FOREIGN_GPU`（返回码 2 或 4）而不启动，队列必须等待重试。
  不要修改正在运行的 bash 队列脚本。
- **服务器。** `pgrep -f`／`pkill -f` 会匹配到自己的 ssh 命令；等结果时不要匹配 `Error`（有无害警告含这个词）。
- **每类固定一张参考图的设置方差极大**（同一折换一组参考图，62.0 变到 51.3）。只用标准 episode。
