# 创新性与贡献判断

截至 2026-10-05，项目已经形成有价值的实验事实与完整对照，但尚未建立满足当前目标的零新增训练方法贡献：相同骨干、相同评测分辨率下，稳定超过 FoRIS 最终 native 输出约 2 个 mIoU 点。训练读出的 CONFIRM600 正结果可以保留；它属于使用基类标注训练的另一资源列。RCG 和完整掩码假设选择是应保留的强对照，目前不能仅凭新名称、开发集增益或高 GT oracle 宣称获得新的对象身份识别机制。

本文区分已测事实、解释和待验证主张。仓库依据固定为 [0e1dea1](https://github.com/misaya-yang/cv_reasearch/tree/0e1dea19716faec8cc4c623ce54c79f8a9df3173)，以包内 [STATUS](evidence/repository_sources/STATUS.md)、[README](evidence/repository_sources/demo9_README.md)、[HANDOFF](evidence/repository_sources/demo9_HANDOFF.md) 与实际源码为准。云端旧 120 例结果是补充开发证据，不能混入仓库 CONFIRM600 的确认叙述。当前评价规则见 [复验协议](07_reproduction_and_continuation.md)。

## 一、先把“存在答案”和“能识别答案”分开

本任务涉及五个不同的信息层级：

| 层级 | 实际包含什么 | 当前证据允许说什么 |
|---|---|---|
| 原始 RGB 与参考标注 | 图像数值、参考目标的指定 | 定义任务输入；不能把人的类别知识默认当作算法可用输入 |
| 预训练模型及完整内部计算 | 预训练所得参数、中间层、注意力、所有实际编码过程 | 可能产生可迁移的统计结构；某个末层实验不能替代对所有内部状态的判断 |
| 当前缓存 q/r/cov | 特定编码、去偏、精度和分辨率后的 query/reference 特征，以及参考覆盖率 | 限定本轮算法实际可访问的信息；不等于完整 RGB 或全部模型状态 |
| 算法所用统计与候选 | 均值、NN、图边、候选掩码、关系分数等 | 可以实测它们在允许输入下是否提供独立的选择证据 |
| 查询 GT oracle | 额外知道正确 query 标签后挑层、阈值、原型、候选 | 只给出相应候选空间的有标注诊断；不可作为实际推断输入 |

高候选 oracle 只证明候选中存在好掩码。它不证明仅凭 reference/query 可以识别该掩码，不证明跨姿态、外观变化下的语义规律已能从缓存读出，也不证明问题“只剩选择”。同样，多个后处理失败，只能限制这些具体统计、目标和算子，不能反向证明表示必然缺少所需信息。

后处理可以改善任务输出。若没有新的受控证据，不应将这种改善写成“给冻结模型新增类别识别能力”或“恢复模型已经理解但未表达的语义”。更准确的表述是：在给定输入和候选范围内，某条推断规则改变了预测，并在指定数据上取得某种效果。

## 二、当前可以保留的贡献，及其边界

下表旧 120 例均在 1024 工作栅格按类累计 I/U 后宏平均，native 指同栅格的缓存最终 CRF 输出；它们不与原分辨率 CONFIRM600 直接横比。旧 120 区间采用 2000 次照片连通组重采样、RandomState(0)，每次重新按类聚合。

| 方向 | 已有证据 | 目前可成立的表述 | 目前不能成立的表述 |
|---|---|---|---|
| 基类监督读出 | CONFIRM600 原分辨率完整流程 63.33，对 FoRIS 59.78 为 +3.54，历史配对区间 [1.96,4.96] | 基类标注拟合的轻量残差读出，在这套确认协议下改善了宿主 | 无训练方法；已经证明类无关决策定律；已经证明跨任务通用 |
| RCG | 旧 120：63.723 对 native 62.018，+1.705 [0.453,3.250]；69 升、50 降、1 平 | 已核实际掩码的有竞争力开发集方法，可作完整强对照 | 已独立确认约 +2；CSLS 或线性求解本身为原创；已识别相似类别 |
| 完整假设竞争 | 固定 960 个完整假设；source-contrast 主臂 62.640，原 seed 62.189，native 62.018 | 可以把决策对象从一个 seed 改为一个完整假设，并直接测量其作用 | 新身份信息已被证明；两个修好的困难样本代表总体收益 |
| 参考条件边度量 | 条件边 AUC 增量明确，但完整掩码相对 RCG 为 −0.027 点 | reference 标签影响了哪些局部特征差异更像跨类边 | 边相关性已经转化为完整语义分割贡献 |
| 系统诊断与失败账本 | 缓存一致性、强对照、候选容量、排序/切点、完整流程均有记录 | 支持可复验研究与更准确的机制定位 | 仅凭大量负例足以形成用户要求的方法论文；证明算法家族或表示达到上限 |

监督读出数字来自固定版本 [README](evidence/repository_sources/demo9_README.md)。其区间沿用仓库当时协议；不与本包旧 120 的新统计协议混写。RCG 见 [实际掩码与统计核验](evidence/cloud_results/rcg_verification.json)。完整假设结果见 [假设选择敏感性](evidence/01_02/hypothesis_sensitivity.json) 与 [同候选全局对照](evidence/01_02/context_global_control.json)。边结果见 [完整掩码](evidence/03_04/reference_axis_masks.json) 和 [信号统计](evidence/03_04/reference_axis_signal.json)。

### 2.1 监督读出：正结果真实，理论解释仍需降级

[decision_heads.py](https://github.com/misaya-yang/cv_reasearch/blob/0e1dea19716faec8cc4c623ce54c79f8a9df3173/demo_lists/demo9_transductive_ics/tics/decision_heads.py) 的核心是宿主 logit 加可训练残差，包含可训练 scale/shift、卷积与上下文统计；以基类标注的 BCE 和 soft-IoU 目标拟合。输入没有类别编号，是接口性质，不意味着没有类别相关训练分布，也不构成类无关性的数学保证。零初始化保证残差初始为零；完整渲染和后处理是否逐位复现宿主，应由实际推理路径验证。

四折线性系数余弦约 0.988，可以说明在这些拆分上拟合公式接近。共享输入尺度、宿主形状先验、共同 COCO 分布或较弱的可识别性都可能产生相近系数。它不能单独推出一个对新领域、目标粒度、姿态变化都成立的决策定律。

最新 README 已记录 D1 合成标注构造和 T2 迁移结果，不能继续写成“尚未运行的关键验证”：D1 卷积读出明显下降，线性臂约 +0.30 至 +1.01；T2 的 PASCAL-Part 与 PACO-Part 增量弱。它们限制了目前“通用且无需人工掩码拟合”的解释。它们也不否定 CONFIRM600 的原始监督结果。最强简单解释仍是对 COCO 宿主输出的有效校准与有限结构修正。

另外，patch 层的 score-only +2.27 不能直接从完整流程的 +3.54 中相减，写成结构信息独立贡献 +1.27。需要相同输入、训练量、架构、推理与评测阶段下的配对比较。

### 2.2 RCG：组合可以有价值，但组件归属必须准确

锁定版本先构造引导：

$$
u=s+\tfrac12(R_g-R_s),\qquad
(A+16L)z=Au.
$$

其中 $R$ 是排名映射，$g$ 来自跨图匹配，$A$ 是正的宿主置信权重，$L$ 来自非负对称 mutual-20-NN 图，最终连续字段双线性放大后切为掩码。这属于“稠密软标签保真项 + 图平滑”的成熟形式。CSLS 的局部密度修正、二次图能量、共轭梯度求解及最大值原理都有既有来源，详见 [相关工作](04_related_work.md)。可争取的贡献只能落在新的任务信息、特定组合的必要性、或经强对照证实的完整收益上。

旧 120 有 237 个开发配置。RCG 对强 MEAN_CONTROL 仅 +0.223 [−0.574,0.737]；该控制使用相同 W/A/λ/渲染，但排名引导系数为 0.25，RCG 为 0.5。因此它适合判断简单替代是否足够，不能说两者“只差 CSLS”并据此作纯粹因果归因。原系数下的 NN 控制与调优后的 NN 控制也应同时保留，不能选择最弱的一个。

此处 +1.705 具有实际研究价值，但还没有证明稳定达到当前约 +2 目标。置信区间表示不确定性；不能把跨零机械写成失败，也不能把下界正直接写成方法成功。开发配置搜索后的区间不等于独立确认。

### 2.3 有新增信号，不等于有新增完整方法效果

旧 120 的参考轴边门控固定了原 RCG 的 u、A、边集合、λ=16 和输出方式。仅用参考纯 FG/BG 均值差的单位方向，以及类内投影方差，改变边权；另有固定标签乱序控制。

在 86 个可评 episode 的纯 FG–FG 对 FG–BG 边上，控制原余弦分位后，条件 AUC 对原权重增量 +0.07464 [0.03989,0.11170]，对乱序轴 +0.06906 [0.03431,0.10663]。但完整掩码为 63.69565，相对 RCG −0.02735 [−0.18098,0.23200]，54 升、63 降、3 平。可保留“参考标签提供一项边区分信号”；不能把 RCG 相对 native 的主体收益归给这一步，也不能据此宣称新对象身份机制成立。

这一例尤其说明三个检验缺一不可：信号有区分力、算法实际利用该信号、完整输出获得足够收益。仅完成第一步不能替代后两步。

### 2.4 完整掩码假设：动作空间改变，比给分数重新命名更实质

这里“完整掩码假设”只指一次输出的整张 mask，不保证它对应一个正确识别的对象。同一均值分数用于选择一个 seed，与用于竞争一组完整掩码假设，是不同的实际决策。这里显式枚举原 eligible seed 本来可生成的完整输出，对完整 mask 重新评分；生成规则与同 bank 可达集合不变。这种决策改变可能产生有意义效果，应保留为强对照。但均值 FG/BG 对比本身是经典统计，仍需与同 bank 的标量对比、全局背景、固定 reverse-IoU 等比较。

当前 source-contrast 全 120 主结果约 +0.450 对原 seed；去掉用于构造的两个困难样本后，增量转为负。错误 query-ring 对照仍能修好那两个样本，因而不能宣称局部语义上下文绑定是收益原因。次要 scalar-contrast 对 native 约 +1.789 也未建立稳定约 +2。候选生成和选择目前仍是可继续研究的机制位置，不是已完成的创新结论。

## 三、现有理论叙述需要怎样修正

### 3.1 Bayes 阈值不是当前所有读出的统一正确答案

在已知类条件密度、已知先验且优化等代价逐像素 0–1 损失时，似然比有标准 Bayes 阈值。当前余弦、聚合乘积、min-max 分数未被证明是查询密度比的已知单调变换；先验也不能简单定义为待求预测集合自身的面积来完成推导。即使密度模型正确，IoU 最优决策也不等于该逐像素 Bayes 规则。

因此“真占比切点改善很多”是有标注诊断，说明固定排序容许某些更好的切点；它没有证明占比能从允许输入估计，也没有证明当前主要误差唯一来自缺少先验。排序和切点的分解便于实验，但不是独立因果因素的定理。

### 3.2 图最大值原理不能被写成模型语义能力上限

若 $A$ 为严格正对角矩阵、$W\ge0$ 且对称、$\lambda\ge0$，则解可以写成 $z=(A+\lambda L)^{-1}Au$，是同一连通分量内 u 的非负加权平均。整个分量的 u 均不超过阈值，token 解就不能越过阈值。这个结论依赖具体图与 forcing，不等于“深漏检不可恢复”：图分量中存在正证据时，结论不适用；最终双线性像素还涉及相邻 token 的混合。

它约束一个固定后处理能做什么，不证明冻结表示中不存在更好的参考条件证据，更不证明需要训练或引入另一个模型。详细条件及可识别性边界见 [理论分析](05_theory_and_identifiability.md)。

### 3.3 单参考的歧义必须成为假设，而不是被符号隐藏

同一参考目标可能允许部件、实例、类别等不同解释；source 背景也不代表 query 所有干扰类别。要求 query 覆盖全部 source 部件，会把遮挡当成负证据，或把多个错误区域拼成看似完整的匹配。关系结构的作用必须实测，不能用“全局一致”“对象级”或“闭环”这些名字替代目标身份的证据。

反过来，若要否定某个关系统计，也只能否定已测构造。既有 D4 局部布局、回环 source 重建、全 query 伪负样本的负结果，不覆盖所有可能的跨图关系。

## 四、与既有工作的真实边界

1. **“单查询转导、利用占比”已有 RePRI。** 仓库 HANDOFF 对其“需要元训练和整批查询”的描述不准确。原文明确面向一张 query，基础训练使用普通交叉熵而非 episodic meta-learning。当前工作的差别应写成具体表示、监督资源与读出方式，不能靠错误排除先例建立创新。
2. **“prototype + Gram，GT 层 oracle 与选择失败”已有 FSSDINO。** 作者提出 semantic selection gap 的解释。可以引用其诊断动机，但不能把作者的解释当作当前缓存可识别性的证明；本项目若形成贡献，必须落到自己的固定候选、允许输入和可部署选择证据。
3. **“source 拟合/逆向重建”已有 PANet 等背景。** PANet 的 prototype alignment 是训练正则，不是当前无训练 reverse-IoU 的同一算法；也不能把任一高 source IoU 当作 query 身份证书。
4. **FROST 不能用 QDA 失败替代。** 它保留所有锚点做非参数密度比，另有完整传播和候选门控。项目历史已有完整 head 运行；可说明那次结果，不可用当前单高斯实验覆盖其全部推断。
5. **SAM3、自命名和 MLLM 属于新增资源列。** CG-ICS 已有概念引导先例；真类名属于特权输入。路线可有效，但不能把跨资源分数差写成纯 DINO 推断创新。

每条对应的原始论文与代码见 [04](04_related_work.md)。

## 五、什么证据才足以将下一条路线写成方法贡献

下一个候选需要回答一个具体问题：在强完整候选或强宿主实际错选的区域，哪一项仅由合法参考/查询输入计算的量，能提供均值、NN、简单背景对比或原图传播没有的目标身份证据？它不必更复杂，但必须在最强简单替代面前仍有不可省略的作用。

- **信息与资源固定。** 清楚列出 RGB、编码层、额外视图、SAM/文本、训练标签和跨 episode 数据；新增输入不能藏在“零训练”之下。
- **先验证必要环节。** 用预测预先冻结后的真实数据测量争议区或完整假设的区分力。GT 只评分；高全图 AUC 不能由大量简单背景替代真正错误区域。
- **同信息最简对照。** 同候选、同渲染、同阈值协议，区分表示、排序、尺度、候选数量和目标函数的贡献。若同 bank 均值已经解释增益，应归属给候选或动作空间，而非关系评分器。
- **完整可部署输出。** 输出全部目标区域，报告 native 最终流程、强简单控制、分折与批次、升降个例；不能仅报一个信号或 GT 最优切点。
- **独立确认。** 已暴露旧 120 只能开发。新增数据在方法冻结前不得查看 query 标签；本包时点新 100 仅固定预测，不能写成完整 241 例确认。待补齐的新增 121 仍属于 DEV 固定复验，不是独立 CONF；合并 241 还存在两组跨旧/新共照片，统计须合并照片连通组。没有预先读取新标签，不等于自动取得独立确认集身份。
- **贡献叙述与证据一致。** 可争取“一个具体推断在指定资源下稳定改善结果”；若要声称跨姿态身份绑定、类别无关性或可识别性，则需要各自的额外对照与清晰假设。

当前最稳妥的论文素材是：可信的实验平台、强完整对照、受限制的正负机制事实，以及一个仍待建立的新推断。整理这些材料不能代替寻找与验证这个推断。
