# 旧120例：标签辅助的线性候选选择诊断

## 结论

固定的六分数线性读出没有提高完整候选的跨类选择质量。完整头为 **61.0241 mIoU**，默认候选为 **62.1893**，相差 **−1.1651 [−2.5720, −0.0670]**。它只改变4例，4例均下降；对照与完整头使用同一候选库、同一线性模型和同一训练协议。

**这是使用查询标签训练的诊断，不是零训练方法。** 仅涉及已经曝光的旧120例，没有读取新增100/121例数据或标签，也没有改动待验证的方法。

## 已测

四个既有类别折轮流留出：其他三折90例训练，留出折30例评估，训练与评估类别不相交。每例候选两两比较，以保存的查询IoU顺序作标签；每例训练总权重相同。固定L2逻辑回归C=1，无截距，不扫参数。标准化均值与方差只在训练折拟合。

| 固定臂 | 特征 | 留出汇总mIoU |
|---|---|---:|
| default_only | 原默认候选标记 | 62.1893 |
| foreground_mean_control | 前景均值余弦、点积、候选面积、默认标记 | 62.0115 |
| full_six_score_ranker | 六个已有分数、候选面积、默认标记 | 61.0241 |
| 已冻结source_contrast_mean | 无本次监督拟合 | 62.6398 |
| 已冻结scalar_contrast | 无本次监督拟合 | 63.8068 |
| FoRIS最终native | 同1024工作分辨率 | 62.0176 |
| 已冻结RCG | 同1024工作分辨率 | 63.7230 |

完整头相对简单前景均值头为 **−0.9874 [−1.4053, 0.0000]**，0升2降118平；相对默认头四折分别为 **−0.6618 / −2.8066 / −1.2294 / 0.0000**。相对FoRIS最终native为 **−0.9934 [−4.6452, 1.6675]**，四折 **−3.3413 / 2.3647 / 0.5401 / −3.2186**，45升75降。当前结果没有达到稳定至少+2点的要求；区间跨零本身不是判据。

完整头留出候选pair准确率四折为 **0.8008 / 0.8174 / 0.8149 / 0.8079**，简单头为 **0.8320 / 0.8584 / 0.8152 / 0.7753**。较高pair准确率并不等于选出的最大值更正确：大量容易排序的非最佳候选可贡献准确率，而最终只执行最高分候选。

## 推断与边界

现有六个聚合分数在这个固定线性头上，没有展现超出简单前景相似度、面积和默认标记的可泛化候选选择收益。该结果不证明全DINO特征没有信息，也不证明非线性模型或新的输入无效。默认标记本身是强线索，因此完整模型倾向保留默认选择；这属于本次固定构造的实际行为，不通过结果后删除特征来改写结论。

信息层级也须分开：本次没有输入原始RGB，没有读取完整DINO token或内部注意力计算；只读取由已有表示与算法生成的六个聚合分数、面积和默认标记。训练折的查询GT另外提供了候选优劣顺序。测试折只按已拟合线性规则选择既有掩码。它测的是这个受限读出的行为，不是RGB、整个预训练模型或所有关系算法的可识别性。候选库中存在GT选出的好掩码，也不能补成“这些八个输入必然足以无标签选对”的论据。

120例已用于开发与启发候选分数；类别留出消除了本次头拟合的直接跨类泄漏，但不能把这批数据重新命名为独立确认集。配对区间仅对固定的out-of-fold预测做2000次照片连接组重采样，并未在每个bootstrap里重新训练四个头，因此不包含训练集重采样的不确定性。

## 可复核文件

- `protocol.json`：训练前固定协议。
- `run_rank_diagnostic.py`：完整CPU脚本。
- `report.json`：每折系数、标准化统计、pair准确率和完整mask I/U统计。
- `choices.json`：逐例候选分数与选择。
- `episodes.jsonl`：冻结候选对应的原始I/U，没有重新生成掩码。

统计：67类、120照片连接组，RandomState(0)，2000次抽样；每次先重聚合各类I/U再宏平均。CPU总耗时约0.41秒。
