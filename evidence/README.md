# Research evidence

This directory holds recorded observations, not active research code or run queues.

- [local/RESULTS.md](local/RESULTS.md): the local experiment ledger; `local/results/` retains numerical reports,
  per-episode statistics and a small number of cited failure/protocol records.
- [insid3/RESULTS.md](insid3/RESULTS.md): the old INSID3 region-selection diagnostics and their measurements.
- [dots-2026-10-05/IMPORT.md](dots-2026-10-05/IMPORT.md): the supplied ten-document synthesis and cloud-only
  evidence. Embedded code is a provenance snapshot, not a current runtime.

Original retained JSON/JSONL result bytes have not been rewritten. The per-episode file over the repository's
1 MB limit is not retained here; its summary report remains. Absolute paths inside reports identify historical
runs, so they may not be executable now. Local caches, screenshots, most operational logs and preparation
receipts are excluded from this evidence tree.
