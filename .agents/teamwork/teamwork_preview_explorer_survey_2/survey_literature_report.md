## 1. 领域变革与范式迁移：2025–2026 计算机视觉新前沿

在 2025–2026 年，计算机视觉（CV）领域经历了自 Vision Transformer 普及以来的最深刻范式转移。这一轮变革并非简单的模型参数堆叠，而是在表征基础、预测交互形态以及推理时计算范式三方面发生了结构性重构：

### 1.1 冻结超大视觉基础模型（Frozen Large Visual Models: DINOv3 与原生密集表征）
- **从端到端微调走向冻结表征解耦**：以 DINOv3 为代表的数十亿参数自监督视觉基础模型，通过在大规模多模态/无标注图像流上的多尺度自监督掩码图像建模与对比学习，展现出惊人的零样本特征对齐与空间局部对应能力。
- **浅层线性微调与参数高效微调（PEFT）的边际递减**：实践表明，直接对超大 ViT 进行 LoRA 或全量微调极易破坏预训练特征的空间度量结构（metric structure），导致对未见分布（OOD）和少样本任务的过拟合。前沿研究全面转向“冻结骨干网络（Frozen Backbone）+ 轻量外挂读出器（Lightweight Readout）”的架构路线（如 LiDeRe, CVPR 2026）。
- **表征层级选择鸿沟（Semantic Selection Gap）**：最新研究（如 FSSDINO, 2026）揭示，DINOv3 等模型的不同中间层对应了不同粒度的语义抽象（从底层几何边缘到高层类别语义）。Oracle 逐样本最优层选择与固定最终层读出之间存在巨大的性能鸿沟（平均 IoU 差距达 12% 以上），表明冻结表征内部隐藏着丰富信息，但缺乏鲁棒的自适应读出机制。

### 1.2 上下文视觉分割（In-Context Visual Segmentation, ICVS）的崛起
- **视觉通用提示范式的确立**：继 NLP 的 In-Context Learning（ICL）与 SAM 的交互式分割之后，ICVS 成为衡量纯视觉表征理解能力的终极试金石——仅给定一张（或几张）带有特定概念标注的 Support（参考）图像，模型必须在无任何梯度回传、零微调的前提下，于 Query 目标图像中分割出语义一致的对应概念。
- **非参数化推断的挑战**：传统语义分割严重依赖固定的类别 Head（如 80 类 COCO、150 类 ADE20K），而 ICVS 要求完全基于跨图像的特征对应关系（Dense Correspondence）进行动态语义聚类与概念认领。在此赛道上，CVPR 2026 Oral 基线 INSID3（57.6 mIoU）与最新 SOTA FoRIS（60.9 mIoU）展现出前沿竞争的白热化，但距离人类与全监督水平（70+ mIoU）仍存在巨大缺口。

### 1.3 推理时缩放与自适应测试期推断（Test-Time Scaling & Test-Time Adaptation）
- **从单次前向（One-pass Forward）走向思考与验证闭环**：受大语言模型“Reasoning & Inference-Time Compute Scaling”（如 o1 范式）启发，2025–2026 年密集预测领域开始探索推理时计算扩展——即通过在测试期引入多步假设检验、主动区域重采样（Active Observation）、局部放大复检与全局一致性校验，将固定的计算预算动态转化为更可靠的分割边界。
- **主动视觉感知与序贯实验设计（Sequential Experimental Design）**：前沿工作（如 ARTA, CF-GAP, Active Visual Reasoning 2026）开始将测试期推断形式化为序贯决策问题：识别当前预测的不确定性瓶颈，有针对性地消耗计算力观测高信息增益区域。

## 3. 口头报告级强基线（Oral Baselines）的架构与理论深层盲区

为确保 CVPR 2027 创新的本质性与非平凡性，我们对当前最前沿的四大 Oral/SOTA 基线进行显微镜式的机理剖析：

### 3.1 INSID3 (CVPR 2026 Oral)：单种子向外扩展聚合与覆盖率硬门控的致命缺陷

```
[INSID3 经典推断流程]:
DINOv3 特征 -> 位置去偏 -> 层次树聚类 -> 寻找最大响应种子簇 S* 
                    |
                    v
    计算各簇相似度与覆盖率因子: Score(C) = Sim(C) * (Coverage(C) > 0.2)
                    |
                    v
            阈值聚合合并 (Seed Expansion) -> 输出最终 Mask
```

#### 理论与架构盲区：
1. **种子向外扩展假设（Single Seed Expansion Assumption）的瓦解**：
   - INSID3 的核心哲学是：只要在目标图中找到一个与 Support 最相似的“种子簇”，就可以通过特征相似度和空间近邻关系将该物体的其他部分聚合进来。
   - **实测证伪**：本仓库在 COCO-20i 上 4000 例的严格实测证明：**INSID3 损失最大的错误类型是“种子选对了，但漏掉了同一物体的其他部分”**（占所有错误 episode 的 26%）。在这些被漏掉的前景中，**90% 属于种子所在的同一个几何连通物体**，而非外部其他实例。
2. **覆盖率因子（Coverage Gate）的双刃剑与信息锁死**：
   - 官方公式中包含覆盖率因子 $\text{cov}(C) = \frac{|\text{NN}(C) \cap \text{FG}_{\text{ref}}|}{|\text{FG}_{\text{ref}}|}$，当 $\text{cov}(C) \le 0.2$ 时该簇被永久锁定。
   - **理论盲区**：实测显示，**有高达 13.4% 的真实前景簇因为覆盖率低于 0.2 被永久锁死**。
   - **无法简单解除**：当强行移除覆盖率门控（指示因子换为 $\text{cov} > 0$）时，真阳性面积虽增加 14.5%，但**假阳性面积暴增 197%**，mIoU 从 56.1 断崖式跌落至 50.9！根因在于被锁死的前景簇在冻结特征上与背景簇完全无法区分（前景平均相似度 0.45 对背景平均相似度 0.46）。单靠特征相似度根本无法完成扩展。
3. **固定切割高度破坏对象完整性**：
   - INSID3 在聚类树的固定高度切一刀。实测目标物体恰好是该高度下一个完整簇的概率仅为 **32%**；**40% 被过度切碎**（Fragmented），**28% 与背景或邻近异类物体融合**（Under-segmented）。

### 3.2 FoRIS (2026)：前景净化定位合并与高分辨率+CRF 堆叠瓶颈

```
[FoRIS 流程]:
Query/Ref 图像 -> 512/1024 ViT 特征 -> 粗级前景净化 (Purification)
                      |
                      v
             区域局部化 (Localization)
                      |
                      v
        多阶段合并 (Integration) -> Dense CRF 优化 (Permutohedral Lattice)
```

#### 理论与架构盲区：
1. **计算复杂度与无差别均匀算力开销**：
   - FoRIS 依赖高分辨率输入（512×512 或 1024×1024）。对于 ViT-L/16，1024 分辨率意味着 $64 \times 64 = 4096$ 个 Token，自注意力计算量是标准的 16 倍。
   - 无论 Query 图像中的目标是清晰明了的独占大物体，还是微弱模糊的遮挡物体，FoRIS **对所有样本一律执行全图 1024 编码与昂贵的 Permutohedral Lattice Dense CRF 滤波**。
2. **后处理 Dense CRF 的语义盲区与伪边缘平滑**：
   - Dense CRF 依赖低阶像素双边滤波（颜色与空间距离），不具备高阶语义一致性。在目标与背景具有相似纹理（如伪装动物、水面反射、阴影、同材质地面）时，CRF 会将原本微弱的语义假阳性区域平滑扩散为巨大的致密错误区块。
3. **缺乏质量反思与闭环仲裁机制**：
   - 前景合并阶段本质上是一组顺序级联的启发式阈值规则。一旦前期净化（Purification）错误地排除了某一关键部分，后续合并阶段无法召回，缺乏对“候选掩码整体 IoU 质量”的全局决策判定。

### 3.3 FROST (2026)：完整前景/背景密度比假设的失效

```
[FROST 核心假设]:
Score(x) = log [ p(x | Support_FG) / p(x | Support_BG) ]
通过对 Support 全量 Token 建立核密度估计 (KDE) / LogSumExp 实现
```

#### 理论与架构盲区：
1. **非对称背景分布假设（Support Background Asymmetry）的破产**：
   - FROST 假设 Support 图像中的背景分布 $p(x | \text{Support\_BG})$ 能够作为通用的负样本先验，压制 Query 中的非目标区域。
   - **理论破产**：Support 背景往往具有偶然性。例如：Support 是一只站在“草地”上的狗，Query 是一只坐在“沙发”上的狗。Support 背景提供了海量“草地”Token，对抑制 Query 中的“沙发”、“地毯”毫无作用；甚至如果 Query 背景也恰好有少量植物，会被过度抑制，而 Query 中的猫（同类干扰）却无法被压制。
2. **高维 Token 空间的核密度估计（KDE）维度灾难与标定漂移**：
   - DINOv3 特征维度为 1024。在高维非紧流形上，基于欧氏距离或余弦距离的 LogSumExp 密度估计存在极端的数值集中性（Curse of Dimensionality）。软温度系数 $\beta$ 极难在跨类别、跨光照条件下保持自适应标定，极易发生置信度崩塌。
3. **缺乏空间拓扑先验（Spatial Topology Blindness）**：
   - 纯粹的密度比计算将每一个 Query Token 视为条件独立的质点，完全忽略了物体作为一个具有几何边界、连通性与骨架拓扑的物理实体的先验约束。

### 3.4 REBASE (2026)：闭式背景正交投影的内在上限

- **机制**：计算 Support 背景 Token 的协方差矩阵主成分子空间 $U_{\text{bg}}$，将 Query 特征投影到其正交补空间 $P_{\perp} = I - U_{\text{bg}} U_{\text{bg}}^T$，以消除背景干扰。
- **理论盲区**：
  1. 线性子空间假设严重简化了自然图像背景的非线性流形结构。
  2. 投影操作只能移除在 Support 图像中已出现的背景模式，对 Query 图像特有的未见背景分布与语义混淆物完全无效。
  3. 最终依赖将提示送入 SAM，使得分割质量强耦合于 SAM 的无类别局部亲和度，面对复杂语义概念时无法提供可解释的质量决策。

## 4. 仓库负结果深层根因：标量选择器与无空间上下文 Crop 为何彻底失效？

本仓库前期积累了大量具有极高学术价值的“负结果”（Negative Results），揭示了现有尝试无法突破强基线的本质物理与数学根因：

### 4.1 负结果事实汇总（严格的实测证据链）
1. **4000 例标量统计选择器失败**（`cpu_selection_probe.py`）：
   - 在严格的类别折与图像双隔离（Class & Image Disjoint）协议下，提取 11 个至 38 个精选统计量（F1、相似度均值、方差、分位数、面积等），训练 Ridge 与 Gradient Boosting 模型选择候选树节点。
   - **实测成绩**：INSID3 原生为 56.06，Ridge 为 55.47，梯度提升为 55.75；梯度提升相对基线的配对 Episode Bootstrap 置信区间为 **[-0.93, +0.39]**，无任何统计显著性优势！
2. **裁剪相似度验证器未通过**（`verifier_contract_probe.py`）：
   - 提取候选区域的 6 类裁剪相似度（Plain CLS, Plain Pool, Debiased Pool, Grey CLS, Grey Pool, Debiased Grey Pool），拟合直接 IoU 头与局部前景比例头。
   - **实测成绩**：直接 IoU 头 class-mIoU 仅 49.68（对比 F1 基线 57.22）；协调前景量仅 38.89；比例估计 MAE 高达 0.2473。
3. **稠密特征图 CNN 读出器未超越标量对照**（`analyze_readouts.py`）：
   - 提取 8 通道稠密匹配图（全景及局部配对），使用参数量对齐的 CNN 读出器在 1200 个旧开发 episode 上对比。
   - **实测结论**：配对图像连通分支 Bootstrap 检验表明，稠密图 CNN 读出器**未展现出相对标量任务头的独立统计增益**。

### 4.2 为什么标量特征选择器必然失败？（信息论维度的坍缩）
- **高阶拓扑信息的不可逆降维**：一个候选掩码内包含数千个像素。无论计算多少阶统计矩（均值、标准差、10%/50%/90% 分位数），都不可逆地抹杀了这些特征在空间上的二维几何排布。
  - *例证*：一个“中心为纯前景（相似度 0.9）、边缘侵入大块背景（相似度 0.2）”的错误掩码，与一个“整体均匀略带噪声（全域相似度 0.55）”的正确掩码，可以拥有完全一致的标量统计量（均值 0.55，相似标准差）。标量学习器在数学上处于决策不可识别（Statistically Non-identifiable）状态。

### 4.3 为什么无空间上下文的简单 Crop 相似度彻底失败？（数学机理推导）

这是本项目最核心的理论发现之一，构成了对传统基于 Crop 重打分思路的降维打击：

#### 定理证明：整体 IoU 对局部观测的非局部依赖性
设 Query 图像中由互不重叠的原子区域 $A_j$ 构成全图剖分，其真实前景量为 $\mu_j$。对于任意由这些原子组合而成的候选掩码 $C$，其在全图上的真实 IoU 严格定义为：
$$
J(C) = \frac{\mu(C)}{|C| + \mu(C^c)}
$$
其中：
- $|C|$ 为候选区域的像素面积（已知先验）；
- $\mu(C) = \sum_{j \in C} \mu_j$ 为候选区域内部包含的真实前景量；
- $\mu(C^c) = \sum_{j \notin C} \mu_j$ 为**候选区域外部（余集）所包含的真实前景总量**！

#### 矛盾分析（External Mass Blindness）：
- 当我们将候选区域 $C$ 简单从原图中“裁剪”（Crop）出来并缩放到固定尺寸（如 448×448）输入验证器时：
  1. 验证器看到的**仅仅是 $C$ 内部的像素**，它最多只能推断局部前景量 $\mu(C)$；
  2. 验证器**对候选区域外部的前景量 $\mu(C^c)$ 拥有绝对的零可见性（Zero Mutual Information）**！
- **反例情境**：
  - 假设图像中存在两只猫（实例 1 面积 1000，实例 2 面积 1000）。
  - 候选 $C_1$ 精确包裹了实例 1。从 Crop 视角看，$C_1$ 是一个无懈可击、极其纯净的“猫”，局部相似度极高。
  - 但是，因为实例 2 在外部，$\mu(C_1^c) = 1000$。全图 $J(C_1) = \frac{1000}{1000 + 1000} = 0.50$！
  - 若另一个候选 $C_2$ 同时包裹了两只猫，$J(C_2) = \frac{2000}{2000 + 0} = 1.00$。
  - **任何孤立的 Crop 打分模型，在面对 $C_1$ 与 $C_2$ 的裁剪输入时，由于无法观测 $\mu(C^c)$，必然无法正确评估全图 IoU！**
- 此外，**尺度与纵横比畸变**（Scale Distortion）：简单 Crop 强行插值打破了 DINOv3 预训练所固有的绝对尺度与感受野比例，导致特征漂移与虚假响应。

## 5. 本质突破口：多粒度跨视图/Token条件化局部观测 + 全局一致性质量决策

基于上述深刻反思，真正能够超越 SOTA 的技术路径必须在物理表征与数学决策两端同时完成范式跃迁：

```
+--------------------------------------------------------------------------+
|                     全局一致性质量决策体系 (Global Consistency)             |
|                                                                          |
|  全图原子剖分 {A_j} ---> 局部可加前景量向量 \mu = (\mu_1, ..., \mu_k)       |
|                                     |                                    |
|                      J(C) = \mu(C) / [ |C| + \mu(C^c) ]                  |
|                                     |                                    |
|              同时有效置信区间 [L_j, U_j] -> 严格 Regret 上界保证           |
+--------------------------------------------------------------------------+
                                     ^
                                     | 局部量估计与区间标定 [L_j, U_j]
                                     |
+--------------------------------------------------------------------------+
|              多粒度跨视图/Token 条件化局部观测 (Local Observation)         |
|                                                                          |
|  宏观 (Macro): 全图上下文锚定 (计算 \mu(C^c) 全局负荷)                      |
|  中观 (Meso):  保留充足空间上下文 Margin 的局部窗口 (维持尺度与几何拓扑)    |
|  微观 (Micro): Support 前景 Token <---> Query 候选 Token 稠密双向交互    |
+--------------------------------------------------------------------------+
```

### 5.1 为什么这一范式能够实现破局？
1. **彻底解决外部前景盲区（Eliminating External Mass Blindness）**：
   - 全局一致性决策模块将“候选评估”转化为“全图共享原子状态向量 $\boldsymbol{\mu} = (\mu_1, \dots, \mu_k)$ 的更新”。
   - 任何局部观测所得的证据，不仅更新当前候选内部的 $\mu(C)$，同时自动更新所有其他候选的外部项 $\mu(C^c)$。局部观测与全局评价通过严格的代数恒等式闭环耦合。
2. **多粒度 Token 级条件化消解语义混淆**：
   - 不再使用粗暴的池化原型（Global Prototype）或非参数 KDE。在微观层面，利用 Support 真实前景的 Token 集合作为 Key/Value，对 Query 局部候选 Token 进行 Cross-Attention 交叉调制。
   - 保持中观空间 Margin，使得特征保留目标边界与其所在物理环境的语义关系（如“在水中的船”、“在桌上的杯子”），彻底杜绝无上下文 Crop 带来的尺度畸变。
3. **序贯决策与测试期计算缩放（Test-Time Scaling）的可行性**：
   - 我们无需像 FoRIS 那样在全图 1024 尺度上穷举所有计算。系统维护着每个候选的 IoU 理论上界与下界 $[J_{\text{lo}}(C), J_{\text{hi}}(C)]$。
   - 算法精确计算哪一个原子 $A^*$ 对“当前最优解（Incumbent）”与“最强挑战者（Challenger）”的决策差距贡献最大，并将宝贵的高分辨率/深层特征抽取计算力**仅投喂给该关键原子**，实现计算效率与推断质量的最优 Pareto 前沿。

## 6. CVPR 2027 所提方法与现有 SOTA 的三大本质机理差异

为杜绝任何“换壳包装”或浅层修补，我们在此正式确立拟提论文方案与已发表 SOTA 基线（INSID3, FoRIS, FROST, REBASE）的 **4 项根本性机理差异（Fundamental Mechanism Differences）**：

```
+-------------------------------------------------------------------------------------------------------------------+
| 核心维度          | 现有 SOTA 范式 (INSID3 / FoRIS / FROST / REBASE)    | 本项目所提 CVPR 2027 核心方法范式                 |
+-------------------+---------------------------------------------------+---------------------------------------------------+
| 1. 质量决策机理   | 局部/启发式分数融合; 依赖单种子聚合或外部 CRF;      | 严格全图原子剖分与可加局部前景量重构全局 IoU;     |
|                   | 割裂内部置信度与外部前景余量 (External Mass Blind)| 显式解耦局部测量与全局非线性集合指标, 代数闭环     |
+-------------------+---------------------------------------------------+---------------------------------------------------+
| 2. 局部表征交互   | 静态无上下文池化 / 粗暴独立 Crop / 非参数 KDE /   | 多粒度跨视图双向 Token 条件化观测; 维持空间上下文 |
|                   | 线性背景投影; 忽略尺度畸变与高维特征漂移          | 几何锚定, 消除高维距离集中与尺度拉伸偏差          |
+-------------------+---------------------------------------------------+---------------------------------------------------+
| 3. 推理计算范式   | 单次硬编码前向流通; 均匀无差别消耗全图计算预算    | 决策论驱动的自适应测试期缩放 (Test-Time Scaling); |
|                   | (如 FoRIS 全局 1024+CRF); 无法自适应难易程度      | 基于决策差距敏感度序贯观测, 动态收敛 Regret 边界   |
+-------------------+---------------------------------------------------+---------------------------------------------------+
| 4. 停止与认证保证 | 无停止准则或经验阈值门控 (如 Coverage > 0.2);     | 形式化 IoU Regret 严格数学上界与有限样本停机保证; |
|                   | 锁定真实前景, 缺乏统计可信度证书                  | 动态下界超过所有候选上界时即刻可证明无损早停      |
+-------------------------------------------------------------------------------------------------------------------+
```

### 差异 1：全局集合一致性重构 vs. 局部启发式候选打分 (Global Additive Mass vs. Heuristic Scoring)
- **SOTA 缺陷**：
  - INSID3：基于种子相似度与距离启发式聚合，无法感知全图目标总量；
  - FoRIS：通过多阶段级联规则过滤，严重依赖密集 CRF 在低维颜色空间的平滑；
  - FROST：逐像素 LogSumExp 密度比，完全忽略像素间的集合依赖；
  - REBASE：无条件投影后盲目依赖 SAM 局部解码。
- **所提机制**：建立严格的形式化集合论映射，将任意候选掩码的 IoU 分解为原子可加测度 $\mu_j$ 的有理分式：
  $$J(C) = \frac{\sum_{j \in C} \mu_j}{|C| + \sum_{j \notin C} \mu_j}$$
  任何局部的观察不仅赋予局部区域权重，更直接改变候选之间的相对排序博弈，从数理底层消除了无空间上下文的局部打分失真。

### 差异 2：多粒度跨视图 Token 条件化 vs. 孤立特征匹配/KDE (Token-Conditioned Cross-View vs. Frozen KDE)
- **SOTA 缺陷**：
  - FROST 将 1024 维冻结 Token 视为各向同性高斯进行非参数估计，面临高维集中现象且易受无意义的 Support 背景带偏；
  - 传统二次检查方法使用无上下文 Crop，破坏物体几何比例与外围场景语义。
- **所提机制**：设计三层嵌套观测流：
  1. **宏观层**：保留整图上下文编码以监控全局语义负荷；
  2. **中观层**：引入带有自适应边界 Margin 的 Contextual Box，消除边界突变与尺度形变；
  3. **微观层**：构建 Support 细粒度前景 Token 与 Query 局部 Token 之间的双向交叉注意力图（Bidirectional Token-Conditioned Correspondence），直接输出原子区域的前景质量密度与有效置信区间 $[L_j, U_j]$。

### 差异 3：决策论驱动的主动测试期缩放 vs. 均匀无差别固定算力 (Decision-Theoretic TTA vs. Rigid Uniform Compute)
- **SOTA 缺陷**：
  - FoRIS、INSID3 无论面对 10 个像素的微小目标还是占据 80% 视野的简单物体，前向计算图完全静态且不可变（FoRIS 强制执行 1024 ViT + CRF，INSID3 强制执行固定层次聚类）。
- **所提机制**：实现视觉领域的“推理时计算扩展（Inference-Time Compute Scaling）”：
  - 算法初始获得全图粗粒度表示与候选簇；
  - 构建候选区间的非凸极小极大博弈，定义原子 $A_j$ 对胜者与挑战者差距的敏感度系数 $S_j$：
    $$S_j = \frac{\left| (J(C_{\text{chal}}) - J(C_{\text{inc}}))_{\text{upper}} - (J(C_{\text{chal}}) - J(C_{\text{inc}}))_{\text{lower}} \right|}{\text{Cost}(A_j)}$$
  - 优先将高精度跨视图 Token 交互预算分配给 $S_j$ 最大的歧义原子，以最小的边际计算开销实现决策边界的指数级收缩。

### 差异 4：可证明的逐图 Regret 上界停机准则 vs. 经验性覆盖率硬死锁 (Provable Regret Bounds vs. Empiric Gate Deadlock)
- **SOTA 缺陷**：
  - INSID3 的覆盖率门控导致 13.4% 真实前景被永久锁死，放开则假阳性激增 197%，缺乏任何统计置信度说明；
- **所提机制**：引入形式化置信界理论。若局部前景量满足同时置信区间 $L_j \le \mu_j \le U_j$，则候选 $C$ 的真实 IoU 严格介于：
  $$J_{\text{lo}}(C) = \frac{L(C)}{|C| + U(C^c)} \le J(C) \le \frac{U(C)}{|C| + L(C^c)} = J_{\text{hi}}(C)$$
  定义当前推荐候选 $b = \arg\max_C J_{\text{lo}}(C)$，则其在候选集合内的真实逐图 IoU 遗憾（Regret）严格满足：
  $$\text{Regret}(b) = \max_C J(C) - J(b) \le \max_C J_{\text{hi}}(C) - J_{\text{lo}}(b)$$
  当该差值收敛至用户设定的容差 $\epsilon$ 时，系统触发具有数学可证伪性的确定性早停，提供学术界首个具备理论可证明精度的测试期自适应推断保障。

## 7. 对下游理论推导与实验协议的建议与守则

结合本次文献与机制深度调研，对后续理论推进组（Survey 3 / Theory）及实验实现组（Survey 1 / Protocol）提出以下关键守则：

1. **理论推导的显式假设控制**：
   - 严禁隐式引入“像素空间独立分布”或“高斯无偏噪声”等脆弱假设；
   - 必须在引理中明确形式化定义：从同时有效质量区间 $[L_j, U_j]$ 到区间 IoU $[J_{\text{lo}}, J_{\text{hi}}]$ 的单调性保序证明，以及基于排序前缀的分式背包问题全局最优解证明。
2. **严防基线协议漏洞与虚假超越**：
   - 坚决杜绝在有标签泄露的 Oracle 候选（如真值树选择 79+ 或簇选择 82+）上报喜，必须以无标签的实际可部署模型为对照；
   - 严格在类别与图像双隔离（Class & Image Disjoint）的数据切分上运行；
   - 强基线必须对齐复现 FoRIS (512/1024+CRF) 与 INSID3 官方核心，在相同算力预算（FLOPs / Latency）与配对 Bootstrap 置信区间下汇报统计增益。
3. **设定明确的可证伪关键击穿指标（Kill Criteria）**：
   - 如果在双折配对 200 例探针中，多粒度 Token 局部观测未能将局部原子前景量的 MAE 从当前的 0.247 压缩至 0.12 以下，或端到端配对增益未突破 FoRIS 1024+CRF，立即启动备选收敛调整路径，防止无休止自说自话。
